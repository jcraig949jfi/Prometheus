# TH-006 -- Evidence portability and verification locality

Status: OPEN (operational thread). Origin: C-001 pilot findings 1-2 (ops/campaigns/C-001/CAMPAIGN.md).
Observation: compute was portable and evidence was not. In every E-001 task the execution ran on ubu001/ubu002, while the
"science unchanged" verification ran on M2, because the reference evidence (BEE traced logs 282 MB, PORTABILITY-01 NPE replays, run
configs) exists only on M2's disk. The Git relay (nodes cannot push) also stayed on M2.
Question: which verification artifacts can be made portable (committed hashes, compact reference fixtures like
archaeon/tests/fixtures_v03/, content-addressed copies), so that a node can verify as well as execute, and M2 keeps only what
genuinely depends on bulk local evidence?
Non-goals (operator, 2026-09-27): no scheduler, no broker, no push credentials for the nodes, no M3 SSH work for its own sake.
