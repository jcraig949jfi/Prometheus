## 1. What shipped

`prometheus_llm/` — one model API for the whole program. Replaces seven
competing `llm_client` implementations (`apollo/`, `forge/`, `cartography/`,
`agents/icarus/`, `agents/_shared/`) and gives 59 direct call sites a single
entry point.

Zero third-party dependencies beyond `requests`. No provider SDKs, no MCP
bridge, no downloaded agent framework. This was a deliberate trust decision:
the alternative on the table was an npm/pip package exposing 70–80 tools with
process-spawn and code-exec rights over the repo. Most providers speak
OpenAI-compatible `/chat/completions`, so one generic adapter plus
Gemini/Anthropic/claude-CLI special cases covers everything — owning the
transport costs less than auditing someone else's.

Entry points: `complete()`, `complete_json()`, `council()`, `health()`,
`list_models()`, plus `python -m prometheus_llm.cli`.

Targets are `provider:model` — **colon**, not slash, because model ids contain
slashes (`stealth/ox-alpha`).

## 3. Findings worth comparing against M1

**3a. The shelf was measured too narrowly on 2026-08-12.** That audit probed
only the four providers `keys.py` happened to wire, and `keys.py` read only the
repo-root `.env`. `agents/eos/.env` held **nine more keys** — OPENROUTER, GROQ,
CEREBRAS, NVIDIA, TAVILY, SERPER, S2, GITHUB_TOKEN, GOOGLE_AI — and had been
sitting there unread the whole time. The error was treating the loader's
coverage as the shelf's boundary. **Check whether M1 has the same blind spot,
and whether M1's `.env` set differs.**

**3b. 21 of 59 model-calling files cannot run at all.** They reference only
providers measured DEAD. Another 31 are partially degraded — a council that
polled four models now silently gets two and returns a thinner answer with no
error. That silent-degradation class is the dangerous one. Full classified
inventory in `prometheus_llm/MIGRATION.md`.

**3c. Two DEAD verdicts were my own bug, not the providers'.** NVIDIA and
`claude_cli` both first read DEAD because model discovery picked first-in-list —
an uninvokable id for NVIDIA, and a model id the CLI does not need. Groq's
catalog mixes chat models with Whisper and prompt-guard classifiers, so
first-in-list is a bad heuristic generally. **Before reporting any provider dead
on M1, try an explicit `provider:model` first.**

**3d. The empty-content trap.** Reasoning models emit thinking tokens that count
against `max_tokens` while reporting `reasoning_tokens: 0`. Under-budget and you
get HTTP 200, tokens billed, `finish_reason: "length"`, and empty content. The
first harness written against `stealth/ox-alpha` scored that as success and
exited 0, because `ok` meant "HTTP 200". Now `Completion.ok` means usable
content, `empty_content` is a distinct flag, and `auto_expand` retries at 4×.
Generalizes to any metric whose success condition is "the call returned".

**3e. A live bug the tests caught on first run.** `result = last or
Completion(...)` silently discarded every failure, because
`Completion.__bool__` returns `ok` and a failed completion is falsy. Every
status, error and flag was being replaced with a generic stub. **Never combine
`or` with a Completion.**

## 5. The rule governing migration

**Migration must not silently change which model answers.** Adding a fallback
chain to research code swaps the model mid-experiment and contaminates any
comparison across the change.

* **Infra / builders / daemons** — may take a fallback chain.
* **Measurement / probe / experiment code** — pin an explicit `provider:model`,
  pass **no** fallback. A dead target there is a *finding to report*, not
  something to reroute around.

Wave 0 is done: `forge/llm_client.py`, which was hard-dead on deepseek 402, now
routes through the layer. Public surface preserved, `_extract_python` verified
byte-identical, live run confirmed. Wave 1 is **not** started — several of the
21 dead files are `harmonia/tmp/probe_cnd_frame_*` replication probes pinned to
specific models by design, and re-pointing them is the user's call.

## 6. Applying the `keys.py` change on M1

Three edits. Preserve the public `get_key()` signature and the
`_load_env_file()` name — `agents/hephaestus/benchmark_models.py` imports the
latter directly.

**6a. Replace the single `_ENV_FILE` constant with a search list:**

```python
_ROOT = Path(__file__).resolve().parent

# Searched in order; the FIRST file to define a name wins.
_ENV_FILES = [
    _ROOT / ".env",
    _ROOT / "agents" / "eos" / ".env",
]

# Back-compat: some callers still reference the single-file constant.
_ENV_FILE = _ENV_FILES[0]
```

Add any additional `.env` paths that exist on M1. Order matters: earlier files
win on a name collision, so the repo-root `.env` stays first.

**6b. Extend `_KEY_NAMES`** (only with entries M1 actually has):

```python
    # --- agents/eos/.env ---
    "OPENROUTER": "OPENROUTER_API_KEY",
    "GROQ": "GROQ_API_KEY",
    "CEREBRAS": "CEREBRAS_API_KEY",
    "NVIDIA": "NVIDIA_API_KEY",
    "TAVILY": "TAVILY_API_KEY",
    "SERPER": "SERPER_API_KEY",
    "S2": "S2_API_KEY",
    "GITHUB": "GITHUB_TOKEN",
    "GOOGLE_AI": "GOOGLE_AI_KEY",
```

**6c. Make `_load_env_file()` merge every file:**

```python
@lru_cache(maxsize=1)
def _load_env_file() -> dict[str, str]:
    """Parse every known .env file into one dict. Cached — reads once.

    Files are merged in _ENV_FILES order and earlier files win, so the
    repo-root .env always takes precedence over per-agent .env files.
    """
    env: dict[str, str] = {}
    for path in _ENV_FILES:
        if not path.exists():
            continue
        for line in path.read_text(encoding="utf-8", errors="replace").splitlines():
            line = line.strip()
            if not line or line.startswith("#") or "=" not in line:
                continue
            k, v = line.split("=", 1)
            k = k.strip()
            if k not in env:  # first file to define a name wins
                env[k] = v.strip().strip('"').strip("'")
    return env
```

And update the `ValueError` at the end of `get_key()`:

```python
    searched = " or ".join(str(p) for p in _ENV_FILES)
    raise ValueError(
        f"API key {env_var} not found. "
        f"Set it as an environment variable or in {searched}"
    )
```

**Do not commit `keys.py`.** It is gitignored on purpose.
