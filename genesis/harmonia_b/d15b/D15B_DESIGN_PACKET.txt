## 1. TRANSFER TAXONOMY

Seven regimes. Each is a *relation between a source world and a target world*, and each exists to
kill a specific non-transfer explanation. The ground-truth object that may or may not transfer is
the **obstruction class Omega** (2).

| # | Regime | Construction | The explanation it kills |
|---|---|---|---|
| **A** | HOMOLOGOUS | same interaction hypergraph family, same coordinate map pi, same surface encoding E | none -- this is the ceiling. If A fails, nothing transfers and the campaign ends early |
| **B** | RECOORDINATED | same Omega; pi drawn independently per world (permutation + polarity flips) | **shared-coordinate leakage.** Any gain that survives B cannot be variable-index matching |
| **C** | FAMILY-SHIFTED | same mechanism; different distribution over clause arity and core size | **family frequency / marginal priors.** Gain surviving C is not "the source told me the base rate" |
| **D** | STRUCTURAL-TRANSFER | different **surface encoding** E (bitstring vs. program vs. grammar derivation); same Omega underneath | **dataset identity and cargo-cult reuse.** This is the decisive regime: the target's surface generator was never seen |
| **E** | IRRELEVANT | source Omega drawn independently of target Omega | **evidence volume.** If E transfers as well as A-D, the gain is "more bytes", not structure |
| **F** | ANTI-TRANSFER | source Omega systematically **inverted** relative to the target (cores that are infeasible in the source are exactly the feasible ones in the target) | detects **negative transfer**, and makes the experiment two-sided: a design that can only find gains is not measuring transfer |
| **G** | ANSWER-LEAK | source artifacts contain target-identifying content | **audit control only.** Proves the 8 audit *detects* leakage. FORBIDDEN in the science ledger -- see 12, and the quarantine in 3.4 |

**Positive vs negative transfer is a signed quantity here, not a filter.** F is expected to produce
a *negative* TRANSFER_GAIN. A design that reports only |gain| cannot distinguish "learned nothing"
from "learned the opposite", and the second is the more interesting result.

## 2. SOURCE AND TARGET GENERATOR DESIGN

**Family: Masked Interaction Landscapes (MIL).** Chosen because it separates four things the brief
requires to vary independently -- deep structure, coordinates, surface form, and difficulty -- and
because the transferable object can be defined with ground truth I hold and no world ever sees.

**Instance.** N = 32 binary variables. A set of m clauses, each over 3 variables with one forbidden
assignment pattern. `score(x) = fraction of clauses satisfied`. Instance seeds frozen as
`SeedSequence([20260902, regime, family, idx])`.

**Deep structure -- the obstruction class Omega.** Each instance is constructed to contain a planted set
of **minimal infeasible cores**: clause subsets that cannot be jointly satisfied. Omega is the
*multiset of core shapes*, expressed as an isomorphism-invariant signature of each core's
clause-variable incidence graph (5). **Omega is invariant under pi and under E by construction.** That
invariance is a property of the construction, not a hypothesis, and it is what makes B and D fair
tests rather than rigged ones.

**Coordinate map pi.** A permutation of variable indices plus per-variable polarity flips.
HOMOLOGOUS shares pi; RECOORDINATED draws it independently per world.

**Surface encoding E.** Three, all decoding to the same assignment space:
- `E1 BITSTRING` -- candidate is 32 bits; edits are bit flips.
- `E2 PROGRAM` -- candidate is a short straight-line program over a small write-instruction set;
  the same assignments are reachable, the *neighbourhood* is different.
- `E3 GRAMMAR` -- candidate is a derivation in a small CFG.
STRUCTURAL-TRANSFER crosses E1 -> E2/E3.

**Family shift.** The distribution over clause arity and core size. FAMILY-SHIFTED changes it while
holding the mechanism.

**Ground truth.** I hold Omega. **No world ever receives it.** A source world can only *learn* an
obstruction from its own failures; that learned object is what may cross. Any path by which Omega
reaches a world other than through that world's own experience is a leak and a contamination stop.

### 2.1 The prediction task -- why it is not a search score

The target-world endpoint is a **prospective, falsifiable, binary prediction**, not a search score.
Given a frozen query set of *repair proposals* (small variable-flip sets), the target world must
predict for each: **will this repair FAIL (hit an obstruction) or SUCCEED?**

Three reasons this is the right endpoint and a search score is not:
1. **The engine enforces prospectivity for me.** A prediction is prospective iff
   `prediction.created_seq < experiment.committed_seq`, checked at commit. This is exactly the
   brief's 5 requirement that imports be legally available *before the prediction being evaluated*,
   and it is enforced by the substrate rather than asserted by me.
2. **The answer has never been available.** Query-set outcomes are computed only at observation.
3. **It separates knowing-the-structure from being-good-at-search.** A better searcher scores
   higher without understanding anything. A better *predictor of where repair fails* has to have
   acquired the obstruction.

Base rates of FAIL are matched across worlds by construction (target 0.50 +/- 0.05, verified at
census) so that a constant predictor sits at balanced accuracy 0.50.

## 5. ABSTRACTION FORMAT

The compressed object. **Exported instead of trajectories** in `FOREIGN_ABSTRACTIONS`.

```
OBSTRUCTION_CERTIFICATE v1   (canonical JSON, UTF-8, sorted keys)
{
  "cert_version": 1,
  "source_world": "<engine world id>",
  "n_failures_consumed": <int>,
  "cores": [
    { "size": <int>,                    # clauses in the minimal core
      "arity_multiset": [<int>, ...],   # sorted
      "wl_hash": "<hex>",               # 1-WL colour-refinement hash of the
                                        # core's clause-variable incidence graph
      "support": <int>,                 # failures exhibiting this core
      "confidence": <float in [0,1]> }
  ],
  "derivation": "minimal-core extraction from local failures",
  "schema_closed": true
}
```

**Why the WL hash.** Colour refinement on the incidence graph is invariant under any relabelling of
variables and clauses, so the certificate is invariant under pi **by construction** -- which is what
makes RECOORDINATED a real test rather than a coordinate lookup. It is also invariant under surface
encoding E, because E changes the neighbourhood, not the incidence structure. (1-WL is incomplete --
it can collide non-isomorphic cores. That is declared: collisions add noise and can only *reduce*
measured transfer, so they cannot manufacture a positive result.)

**Leak firewall, mechanically checked.** The schema is **closed**: any key not in the whitelist, or
any value containing a variable index, polarity, literal candidate, score, or target identifier, is
a schema violation. A validator runs on **every** certificate before it is stored as an artifact and
again at import. A violation is a **contamination stop** (12, C-3), not a warning. This is the
control that makes B-F2-2 survivable: the engine cannot tell an abstraction from a trajectory, so I
must, and I must be able to show a reviewer the check.

**Learned, never read off.** Certificates are extracted from a source world's *own recorded
failures*. A certificate that cannot be reconstructed from that world's ledger is a contamination
stop (C-4).

For any positive TRANSFER_GAIN, sever the hypothesised link. Each ablation holds volume and

is wrong and is withdrawn.

| # | Ablation | Held constant | Severed |
|---|---|---|---|
| **S1** SHUFFLED_PAIRING | certificate count, byte volume, vocabulary, marginal FAIL prior | worldcertificate correspondence (certificates from other targets' sources) |
| **S2** WRONG_WORLD_ATTACH | abstraction vocabulary, count | attaches each certificate to the wrong target |
| **S3** RANK_RANDOMIZED | candidate-set narrowing (same shortlist) | the *ordering* within the shortlist |
| **S4** IRRELEVANT_SWAP | evidence volume and type | relevant evidence replaced by regime-E evidence |
| **S5** SCRAMBLE_EACH | everything | coordinate correspondence: each source independently recoordinated |

**S1 is the primary comparator.** The brief's decomposition instantiates as:

```
TRANSFER_GAIN = BalAcc(FOREIGN_ABSTRACTIONS) - BalAcc(S1 SHUFFLED_PAIRING)
```

S6 is the sharpest single competitor: if a world does as well knowing only "about 50% of repairs
fail here" as it does with certificates, there is no structural transfer, only prior transfer.

## 7. DUPLICATE-EVIDENCE MODEL

**The scenario, constructed explicitly.** Evidence `E` is native in world `A`. `A` shares to `B`.
`A` independently shares to `C`. `B` and `C` both later inform target `D`. Can `D` count `E` twice?

**Where the substrate helps and where it stops.** F3 protects *observation adjudication within a
world*: the first observation of an experiment/prediction is `ORIGINAL`, a repeat needs
`replication=true` and never re-adjudicates. That is a within-world guarantee. It says **nothing**
about two *imported artifacts* that descend from one native ancestor. The engine records
`source_world`, source lineage and `content_hash` on every import, so **provenance-aware dedup is
computable from the ledger** -- but the engine does not perform it, and nothing in the scientific
layer is obliged to.

**Two meta-analyses, both computed, difference reported:**
- **NAIVE** -- treat each imported artifact as an independent observation.
- **PROVENANCE-AWARE** -- collapse to the equivalence class of the **native ancestor**, identified by
  `(origin_world, content_hash)` walked back through `lineage`. Weight each class once.

**Preregistered prediction (falsifiable, mine, losable):** the naive analysis will show a
*confidence* gain (narrower intervals) without a corresponding *accuracy* gain, and the gap will
grow with the number of sharing paths. If naive and provenance-aware agree, duplicate evidence is
not a live hazard in this ecology and I will say so.

**Dependency on X-04.** If same-client transitive re-export is permitted (3.2), then `D` can also
receive `E` **through** `B` with `B` as apparent source, and the native ancestor may be recoverable
only by walking lineage -- not from `source_world` alone. If re-export is refused, the multi-path
case is limited to independent imports from `A` and dedup is a one-hop walk. **The design covers
both; which one obtains is measured, not assumed.**

**Expected deficiency, filed in advance as a GEN-2.2 candidate (B-DUP-1):** the substrate has no
first-class notion of *evidential independence*. If confirmed, the recommendation is a
`native_ancestor` field on imported artifacts, or a `knowledge_set` that reports equivalence classes
rather than identities. Documented, per brief 12 -- not patched inside experiment code.

## 8. KNOWLEDGESET AUDIT PROTOCOL

For **every** target-world prediction, the following row is written to `d15b/ledger/frontier.jsonl`
at the moment of the decision, and the entire analysis is later reconstructed **from the ledger and
this row only** -- never from application memory. This is the direct test of F10 the brief asks for.

```
prediction_seq            prediction.created_seq
committed_experiment      exp_id + committed_seq
knowledge_set_at_pred     full knowledge_set(target, seq=prediction_seq)
imports_available         artifact ids with first_available_seq <= prediction_seq
imports_not_yet_available artifact ids with first_available_seq  > prediction_seq
source_world / source_event_seq / import_event_seq
sharing_policy / topology_group / info_kind
engine_source_hash        X-SFE-Engine-Source-Hash from THIS call (F4)
```

**Audit gates, each with a stop condition:**
- **K1 RECONSTRUCTION.** The analysis is recomputed from the ledger alone and must reproduce every
  reported number **exactly**. Any divergence -> stop (C-1).
- **K2 NO FUTURE INFO.** No artifact with `first_available_seq > prediction_seq` may appear in the
  frontier used for that prediction.
- **K3 ORDERING CANARY.** At every capture, an artifact is created *immediately after* the frontier
  is taken; it must **not** appear in it. This fires on the off-by-one that would make every
  "prospective" decision silently future-informed.
- **K4 FORK EQUALITY.** At each fork, `child.knowledge_set(fork_seq)` must equal
  `parent.knowledge_set(checkpoint_seq)` **in both directions** -- nothing extra, nothing missing.
- **K5 HASH CONTINUITY.** Every response's `X-SFE-Engine-Source-Hash` is recorded. Any run spanning
  two hashes is marked **discontinuous** and its cells are quarantined (C-7).
- **K6 LEAK SCAN.** Every imported payload is scanned against the 5 closed schema and against a
  target-identifier blacklist. ORACLE_LEAK must trip K6; if it does not, the audit is unqualified.

## 9. PARALLEL CROSSING SCHEDULE

Harmonia A (D15-A) and Harmonia C run concurrently. This is used as a source of genuine independent
counterfactuals, and it is treated as a hazard as well as an asset.

**Isolation until preregistered frontiers.** Every target world is `ISOLATED` from creation. At a
declared frontier `Phi_k` the target is **forked**, and each child receives exactly one crossing
condition -- so every arm faces a byte-identical target state and every fork is a live F10 test:

```
Phi_k -> fork -> { import NOTHING | import A-selected | import C-selected
               | import BOTH | import SHUFFLED-equivalent }
```

**Arrival order is captured** (`import_event_seq` per child). Two arrival orders of the same two
imports are run as a declared pair. **If arrival order changes the scientific conclusion, that is a
finding to classify, not a nuisance to average over**: expected semantics (later evidence updates a
posterior) vs. a Foundry defect (order-dependent availability) are distinguished by whether
`knowledge_set` at the decision seq is identical across the two orders. Identical frontier +
different conclusion = semantics. Different frontier = defect (C-6).

**Cross-seat imports are an OPTIONAL enrichment arm (`D15B-X`), never load-bearing.** They require a
registered cross-client topology group, A's or C's cooperation, their source policy emitting the
kind, and NATIVE origin. That is a dependency on another seat's schedule, so `D15B-X` has a declared
fallback: if unavailable at the frontier, the arm is **skipped and recorded as skipped**, and no
primary endpoint depends on it.

**Contention is a real cost, and it is Daedalus's own declared limitation.** GEN-2.1 opens a
per-request `Foundry` with a write-lock schema check, serialising requests; the packet says the
write lock is contended under a heavy concurrent campaign. A's D15-A and Topology-2 (180 worlds)
plus C plus D15-B on one host will contend. **Mitigation:** D15-B declares a world budget before
execution, runs its attack matrix in an idle window or a private instance per Daedalus's 16.3
advice, and records wall-clock and error rates per phase. Throughput is not correctness -- but a
timeout mid-crossing is an availability event with a seq, so contention can *change the ledger*.
That is why K5 and the idempotency discipline (11 X-13) are continuous, not sampled.

## 10. POWER ANALYSIS

**Procedure frozen now; numbers from the pilot.** No effect size is invented before data.

**Unit and pairing.** The unit is a `(target instance x regime)` cell. Every arm faces the **same**
target instance via fork-at-frontier, so contrasts are **paired** -- the same device that let A's
Topology-2 beat isomorphism arguments, and the right one here.

**Primary statistic.** Balanced accuracy on the frozen query set; paired difference vs. S1;
instance-paired bootstrap CI (10,000 resamples, seed `20260902`), resampling **target instances** as
the independent unit. Calibration reported as Brier score and a reliability curve; a gain in
accuracy without a gain in calibration is reported as such and does not count as structural
transfer.

**Preregistered MDE.**
```
TRANSFER_GAIN >= +0.08 balanced accuracy over S1 SHUFFLED_PAIRING,
with the 95% paired bootstrap CI excluding 0,
AND a non-negative calibration change (Brier not worse).
```
**Rationale for +0.08, stated so it can be argued with:** below ~0.05 the effect is within the range
that certificate noise and 1-WL collisions can produce; a substrate capability that buys less than
8 points of balanced accuracy over a volume-matched, prior-matched control does not justify a
cross-world crossing mechanism and its provenance burden. The number is a judgement, and it is
frozen before data so it cannot become one afterwards.

**Pilot (declared, non-adjudicating):** 6 instances x 3 regimes x {LOCAL_ONLY, FOREIGN_ABSTRACTIONS,
S1} to estimate between-instance SD and the exclusion/decline rates. Confirmatory n is then solved
for 80% power at MDE = 0.08 and **frozen before the confirmatory run**. Pilot numbers may not appear
in any verdict.
