0. SUMMARY FOR THE HURRIED REVIEWER
---------------------------------------------------------------------
QUESTION. What measurable properties distinguish a computational
substrate that supports navigable accumulation of useful behavioural
change from one that does not, and can that be decided cheaply and
prospectively, before spending compute on search?

    PRIMARY VERDICT: NO_TRANSFERABLE_NAVIGABILITY_COORDINATE

No single property measured before search transfers across materially
different substrate families. The best predictor reaches held-out
Spearman 0.28 against a preregistered bar of 0.50.

FOUR THINGS SURVIVED, and they are the campaign's product:

 1. THE DECOMPOSITION IS NOT MEASUREMENT-INVARIANT (E8, the deepest
    result). On IDENTICAL cells, the mutation operator explains 0.0002
    of the variance in mutation GEOMETRY and 0.0968-0.1202 of the
    variance in SEARCH outcome -- a 511x to 634x increase. Interaction
    goes 0.0021 -> 0.109-0.130 and on search EXCEEDS the operator term.
    A substrate-qualification gate built on geometry systematically
    understates how much the operator governs the thing anyone
    actually cares about.

 2. SMOOTHNESS IS NOT NAVIGABILITY, MEASURED AND NOT ASSERTED (E4).
    Two control landscapes with PROVABLY IDENTICAL local geometry --
    a single consequence spike at exactly 0.0625 for both -- and
    opposite navigability are separated by target-relative statistics
    at 1.000 and by all three smoothness statistics at |diff| =
    0.000000. Exactly zero, three times.

 3. SINGLE-STEP IMPROVEMENT CANNOT SEE NAVIGABILITY (E1-M5). A sha256
    hash substrate scores 0.967 against the designed-navigable
    control's 1.000 on "does the neighbourhood contain an improving
    edit". From a random point about half of all moves reduce distance
    to any fixed target, so pure noise looks 97% navigable.

 4. THE BAND IS SUBSTRATE-OWNED; DESTRUCTION IS OPERATOR-SENSITIVE
    (E3). On a crossed 3x3 with substrate-agnostic operators, eta^2 on
    band rate is substrate 0.9752 / operator 0.0002. Swapping a raw
    byte-scramble for an instruction-aware operator on the IDENTICAL
    byte substrate moves destruction by 0.0259 (95% CI +0.0056,
    +0.0462) while the band difference is 0.0044 with CI (-0.0024,
    +0.0115) -- crossing zero.

3. THE SUBSTRATE x OPERATOR MATRIX
---------------------------------------------------------------------
ONE PHENOTYPE SPACE FOR EVERYTHING. Every substrate maps a genotype to
a Boolean function on {0,1}^10 held as a 1024-entry truth table
computed by FULL ENUMERATION. This is the design's load-bearing
choice: d is then exactly comparable across substrates, so a
cross-substrate comparison compares genotype->phenotype MAPS and not
two different behaviour spaces wearing one name.

REAL SUBSTRATES
  CIRCUIT   24 straight-line gates over {AND,OR,XOR,NAND}. A's native
            representation, ported verbatim. The CALIBRATION ANCHOR.
  BYTEVM    48-byte stack machine. An ANALOG of a byte-level genotype
            map. NOT StackVM -- see section 5.
  DNF       6-term DNF over 10 variables. Grammar-constrained: every
            genotype is well-formed, so there is no invalid-program
            class at all.
  RELAX(t)  continuous genotype, soft gates at temperature t,
            phenotype = threshold of the soft output at 0.5.

OMITTED, with reasons on the record: graph-rewrite and explicit
module/composition substrates, as disproportionate -- each needs a
rewrite engine and a composition semantics before one number exists,
and neither adds a cell the factorial cannot estimate (typed structure
is carried by DNF, operator-family conditioning by CIRCUIT's op/wire
split). A probabilistic instruction representation is omitted because
RELAX already varies exactly the property it would contribute.

OPERATORS, DEFINED SEPARATELY FROM SUBSTRATES AND CROSSED WITH THEM
  M-UNIFORM   uniform site, uniform alternative        (budget 1)
  M-UNIFORM2  two independent such edits               (budget 2)
  M-TAILSITE  uniform alternative, last third of sites (budget 1)
  M-RAWBYTE   replace one byte with a random other byte (BYTEVM)
  M-INSTR     change EITHER opcode OR operand, never both (BYTEVM)
  M-OPONLY / M-WIREONLY   circuit ops-only / topology-only
  M-GAUSS[s]  one continuous coordinate, Gaussian step s (RELAX)
  SWEEP-ALL   NOT an operator: the full single-edit neighbourhood,
              used where the estimand is the SITE POPULATION. Site-
              population and operator-weighted estimands are labelled
              on every row and are NEVER interchanged. This adopts
              external review #1's Q4 objection to D-14 at design
              time.

IDENTIFICATION PROBLEM AND AMENDMENT A-B1, disclosed. After E2 it was
explicit that every operator except M-UNIFORM is substrate-TYPED (a
byte scramble is meaningless on a DNF), so the matrix as first built
was NESTED and could not separate substrate from operator main
effects -- the campaign's third mandate. M-UNIFORM2 and M-TAILSITE
were added, using ONLY the Substrate interface and knowing nothing
about what a site means, giving a genuine 3x3 crossed factorial.
Additions only; nothing existing was edited, so E1 and E2 are
unaffected. I had seen E2's table before writing them; neither is
tuned to move any coordinate and both are defined without reference to
the ruler. Journaled, not hidden.

4. EXACT OPERATIONAL DEFINITIONS (fixed before any result)
---------------------------------------------------------------------
  d(f,g)        Hamming(f,g)/1024, by full enumeration. Exact.
  LOCAL         exactly ONE elementary intervention in the substrate's
                own native coordinates.
  BEHAVIOURAL   d(f,f') > 0. Neutrality is never called a small
   VARIATION    change.
  CONSEQUENCE   R_VEC2, verbatim from A: NEUTRAL if f' == f;
   CLASS        DESTRUCTION if minmass(f') <= 0.025; SMALL if
                d <= 0.25 and surv_sym >= 0.5; else LARGE.
  USEFUL        STRICTLY reduces distance to a frozen target:
                d(f',T) < d(f,T). Target-relative, deterministic, and
                defined with no reference to any search trajectory,
                operator, or substrate.
  REACHABLE@B   attainable in at most B elementary interventions.
  COMPUTE       number of phenotype evaluations. The only currency
                every substrate shares, and the matched budget
                wherever a comparison is claimed.

THE NAVIGABILITY VECTOR Q (never scalarised as a primary)
  GEOMETRY, target-free
    q1  neutral rate            P(d = 0)
    q2  destruction rate        P(class = DESTRUCTION)
    q3  band rate               P(class = SMALL)
    q4  middle mass             P(0 < d <= 0.25)  [A's D-14 statistic]
    q5  median non-zero d
    q6  gapped                  1 iff q4 <= 0.05  [A's GAPPED rule]
  TARGET-RELATIVE
    q7  improving rate          P(d(f',T) < d(f,T))
    q8  improve | non-neutral
    q9  mean improvement magnitude
    q10 reach_improve@1         P(the single-edit neighbourhood
                                contains an improving edit) -- the
                                campaign brief's E(S)
    q11 drift                   P(improve) - P(worsen) | non-neutral
  STRUCTURE
    q12 neutral option gain     among neutral neighbours, the mean
                                fraction of their non-neutral
                                consequences unreachable from the
                                parent
    q13 baseline d              normaliser; never a claim on its own

FROZEN TARGET BATTERY (10, chosen before any substrate was profiled)

5. CONTROLS
---------------------------------------------------------------------
The control pair is this campaign's sharpest instrument, and both its
design claims were verified MECHANICALLY before the charter froze.

  P1-BLOCKS  SMOOTH + NAVIGABLE by construction. 16 blocks; each bit
             XORs one block of the target. Every edit moves d by
             exactly 1/16; hill-climbing reaches d = 0 in at most 16
             strictly monotone steps.
  N1-SMOOTH-UNREACHABLE  SMOOTH + NON-NAVIGABLE. The SAME 16-block
             geometry. Its target disagrees with the anchor on exactly
             half of every block, so flipping any block exchanges the
             agreeing and disagreeing halves and leaves d(f,T) exactly
             0.5 for all 2^16 reachable phenotypes.
  VERIFIED PRE-FREEZE: edit-consequence unique value 0.0625 for BOTH
             P1 and N1; N1's d(f,target) = 0.5 across 400 sampled
             genotypes with NO other value observed.
  N2-HASH    DISCONTINUOUS + NON-NAVIGABLE. sha256 counter-mode; every
             genotype an independent random truth table.
  DISCONTINUOUS + NAVIGABLE was NOT constructed. It was declared an
             EMPIRICAL cell at E4 and left EMPTY rather than filled by
             relabelling. E5 filled it: CIRCUIT (middle mass 0.092,
             rough) at 0.339 improvement, beating all three continuous
             cells.

BOOTSTRAP CORRECTION, disclosed. A labelled non-adjudicating bootstrap

the FULL arena including the three designed controls, both collapse.

not strawmen: N1 has a provably flat target field under a consequence

So geometry-based prospective qualification works only under an
assumption that the substrate is not geometrically deceptive, and
NOTHING IN THE GEOMETRY TELLS YOU WHETHER IT IS. That is the sentence
this campaign exists to have earned.

11. STRONGEST SURVIVING EXPLANATION
---------------------------------------------------------------------
Neither the substrate hypothesis nor the mutator hypothesis wins as
stated, and the reason is that THEY ARE ANSWERS TO DIFFERENT QUESTIONS
THAT THIS PROGRAMME HAD BEEN TREATING AS ONE.

  On MUTATION GEOMETRY the substrate is overwhelmingly dominant
  (eta^2 0.9752 vs 0.0002 on the band). The genotype->phenotype map
  decides whether a local consequence band exists, and no operator
  tested here conjures one where the map does not provide it: BYTEVM
  stays gapped under a raw byte-scramble AND under a semantics-
  respecting instruction-aware operator.

  On SEARCH the same cells give the operator and its interaction with
  the substrate ~21% of the variance against the substrate's ~65%. The
  operator's share is 511-634x larger than the geometry decomposition
  implies, and the interaction term is the second largest.

  What the operator moves in geometry is DESTRUCTION, not the band
  (E3 ARM 2, with CIs on both sides of that dissociation).

  And smoothness is not the object at all. Three smoothness statistics
  are exactly blind to a pair of landscapes with opposite navigability,
  a hash function scores 97% of the navigable control on single-step
  improvement, and increasing relaxation raised middle mass 7.59x while
  raising search 1.60x without ever beating the discrete circuit.

The strongest surviving statement is therefore narrow and it is a
statement about MEASUREMENT rather than about substrates:

  A SUBSTRATE'S MUTATION GEOMETRY IS A PROPERTY OF ITS MAP, IS CHEAP
  TO MEASURE, AND IS REAL -- AND IT IS NOT THE QUANTITY THAT GOVERNS
  WHETHER BOUNDED SEARCH ACCUMULATES. The two are related (rho ~ 0.6
  within real substrates) but the relation does not survive the
  addition of legitimate landscapes designed to be geometrically
  deceptive, and it does not transfer across substrate families
  (0.28 against a 0.50 bar).

14. RECOMMENDATION: SHOULD PROMETHEUS IMPLEMENT A SUBSTRATE
    QUALIFICATION GATE?
---------------------------------------------------------------------
    QUALIFIED NO -- with one narrow YES inside it.

NO, as a PREDICTIVE GATE. Do not gate substrate adoption on a
geometry-derived navigability score. The best coordinate transfers
across families at rho 0.28 against a 0.50 bar; a hash function passes
the single-step improvement test at 97% of a designed-navigable
control; and a landscape with a spectrum identical to the positive
control's can be provably unsearchable. A gate with those properties
would reject working substrates and admit deceptive ones, and the
geometry gives no signal about which case it is in.

YES, as a CHEAP DISQUALIFIER with an explicitly bounded claim. The one
thing the geometry does robustly is detect the ABSENCE of a band, and
that IS substrate-owned (eta^2 0.9752 vs 0.0002, stable across every
operator tested including a semantics-respecting one). At k = 50 draws
per object -- 2.5% of the search cost -- the estimate is stable
(rho 0.962). So a gate may say "this map provides no local consequence
band, and no operator we tested conjures one" and it may say it
cheaply. It may NOT convert that into a prediction about search
outcomes, because E5 and E6 show it does not license one.

THREE CONDITIONS ON EVEN THAT NARROW USE
  (a) Any gate MUST carry a target-relative measurement beside the
      geometry. Geometry alone cannot distinguish P1 from N1, and that
      difference is the whole question.
  (b) Any gate MUST name the operator it was measured under, and its
      verdict is scoped to that operator. Geometry says the operator
      is worth 0.0002; search says 0.0968-0.1202 on identical cells.
      A gate reporting the first number about a system judged by the
      second is measuring the wrong thing.
  (c) Any gate MUST publish its own deceptive-landscape control. This
      campaign's P1/N1 pair costs nothing to run and would have caught
      every failure mode found here. A qualification gate without one
      cannot tell a navigable substrate from a smooth trap.

WHAT TO BUILD INSTEAD, if anything: the cheapest high-value successor
is not a better geometry statistic. It is the external validation this
campaign could not run -- test whether ANY cheap geometry predicts the
already-measured ordering treegp > pushgp > stackvm from B-R1, on the
M1 instrument, with the operator named. That is three real substrates,
already measured, already ordered, and currently unused.

DO NOT read this packet as a recommendation to adopt any substrate.
DNF searched best here and that is a fact about 6-term DNF on Boolean
functions over ten variables, under (1+1) hill-climbing, at 800
evaluations. It is not a proposal.
