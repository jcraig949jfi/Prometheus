# rules_sources

Published rule sheets fetched for W3 audits (LUDUS-01 and successors). The
files themselves are NOT committed (publishers' copyrighted sheets); each is
recorded in `ludus/bench/rules_audit.json` by URL, fetch time and sha256, with
the sentence behind every audited line quoted there. To re-verify, fetch the
URL and compare the sha256.
