**ReasoningTool – a NumPy‑only, primitive‑recombining implementation**  

```python
"""
ReasoningTool implements the “Symbiosis × Neural Oscillations × Sensitivity
Analysis” triple.  Three lightweight parsers (conditional, causal, comparative)
produce three adjacency matrices that are kept in *symbiosis* by sharing edge
weights.  Frequency‑specific sinusoidal masks generate oscillatory token
embeddings; Pearson correlation of the masked embeddings on the unified graph
yields a coherence factor C.  A simple sensitivity analysis perturbs the final
edge weights and measures the variance of the baseline consistency score B.
The final rating is  Score = B * C * (1‑S).

The implementation re‑uses primitives from ``forge_primitives``:
  * ``solve_constraints`` – to turn the unified graph into a SAT‑like
    constraint system.
  * ``check_transitivity`` – to add extra logical constraints.
  * ``confidence_from_agreement`` – to combine meta‑confidence with the
    computed score.
Only NumPy, regex, and the standard library are used otherwise.
"""
import re
import zlib
import numpy as np
from typing import List, Dict

# ----------------------------------------------------------------------
# primitives (the “forge” library).  They are assumed to be available.
# ----------------------------------------------------------------------
from forge_primitives import (
    solve_constraints,          # (variables, domains, constraints) -> dict
    check_transitivity,        # list of (a,b) relations -> bool
    confidence_from_agreement  # list of scores -> float
)

# ----------------------------------------------------------------------
# Helper utilities
# ----------------------------------------------------------------------
def ncd(a: str, b: str) -> float:
    """Normalized compression distance using zlib."""
    a_bytes, b_bytes = a.encode(), b.encode()
    ca = len(zlib.compress(a_bytes))
    cb = len(zlib.compress(b_bytes))
    cab = len(zlib.compress(a_bytes + b_bytes))
    return (cab - min(ca, cb)) / max(ca, cb)


def pearson_corr(x: np.ndarray, y: np.ndarray) -> float:
    """Pearson correlation, safe for constant vectors."""
    if x.std() == 0 or y.std() == 0:
        return 0.0
    return np.corrcoef(x, y)[0, 1]


# ----------------------------------------------------------------------
# Core class
# ----------------------------------------------------------------------
class ReasoningTool:
    """Implements the Symbiosis‑Oscillation‑Sensitivity pipeline.

    The public API follows the specification:
        evaluate(prompt, candidates) -> ranked list of dicts
        confidence(prompt, answer)   -> float in [0,1]
    """

    # ------------------------------------------------------------------
    # 1.  Prompt parsing → three relational graphs
    # ------------------------------------------------------------------
    _COND_RE = re.compile(r'\bif\s+([^,;]+?)\s+then\s+([^,;]+)', re.I)
    _CAUSE_RE = re.compile(r'\b(causes|leads to|results in)\b', re.I)
    _COMP_RE = re.compile(r'(\b\w+\b)\s*(>=|<=|>|<|=)\s*(\b\w+\b)')

    def __init__(self):
        self.alpha = 0.6          # symbiosis mixing factor
        self.eps = 1e-4           # sensitivity perturbation size

    # ------------------------------------------------------------------
    # 2.  Symbiotic parsing layer
    # ------------------------------------------------------------------
    def _build_graphs(self, tokens: List[str]) -> List[np.ndarray]:
        """Return three adjacency matrices (|V|×|V|) for
        conditional, causal and comparative relations."""
        n = len(tokens)
        mats = [np.zeros((n, n)) for _ in range(3)]

        # conditional edges (parser 0)
        for m in self._COND_RE.finditer(' '.join(tokens)):
            pre, post = m.group(1).strip(), m.group(2).strip()
            if pre in tokens and post in tokens:
                i, j = tokens.index(pre), tokens.index(post)
                mats[0][i, j] = 1.0

        # causal edges (parser 1) – any token pair containing a causal cue
        for i, ti in enumerate(tokens):
            for j, tj in enumerate(tokens):
                if i != j and self._CAUSE_RE.search(ti + ' ' + tj):
                    mats[1][i, j] = 1.0

        # comparative edges (parser 2)
        for m in self._COMP_RE.finditer(' '.join(tokens)):
            a, op, b = m.group(1), m.group(2), m.group(3)
            if a in tokens and b in tokens:
                i, j = tokens.index(a), tokens.index(b)
                mats[2][i, j] = 1.0

        return mats

    def _symbiotic_update(self, mats: List[np.ndarray], iters: int = 5) -> np.ndarray:
        """Iteratively mix edge weights across the three matrices."""
        for _ in range(iters):
            mean_mat = sum(mats) / len(mats)
            for k in range(len(mats)):
                mats[k] = self.alpha * mats[k] + (1 - self.alpha) * mean_mat
        # unified graph = average of the converged matrices
        return sum(mats) / len(mats)

    # ------------------------------------------------------------------
    # 3.  Neural‑oscillation scoring layer
    # ------------------------------------------------------------------
    _BANDS = {'theta': 4, 'alpha': 8, 'beta': 16, 'gamma': 32}

    def _oscillatory_coherence(self, unified: np.ndarray, X: np.ndarray) -> float:
        """Compute coherence C from cross‑frequency Pearson correlations."""
        n = X.shape[0]
        masks = {}
        for band, period in self._BANDS.items():
            # sinusoid with integer period; phase = 0
            masks[band] = np.sin(2 * np.pi * np.arange(n) / period)

        # masked embeddings
        masked = {b: X * masks[b][:, None] for b in masks}
        # collect correlations on edges where unified weight > 0
        edges = np.argwhere(unified > 0.1)
        if len(edges) == 0:
            return 0.0

        corr_vals = []
        bands = list(masked.keys())
        for i in range(len(bands)):
            for j in range(i + 1, len(bands)):
                b1, b2 = bands[i], bands[j]
                # vectorise over edges
                vec1 = masked[b1][edges[:, 0], edges[:, 1]]
                vec2 = masked[b2][edges[:, 0], edges[:, 1]]
                corr = pearson_corr(vec1, vec2)
                corr_vals.append(abs(corr))

        return float(np.mean(corr_vals)) if corr_vals else 0.0

    # ------------------------------------------------------------------
    # 4.  Sensitivity‑analysis layer
    # ------------------------------------------------------------------
    def _baseline_score(self, unified: np.ndarray) -> float:
        """Logical‑consistency baseline B = number of satisfied transitivity
        constraints on the weighted graph."""
        # treat each node pair with weight > 0.5 as a true relation
        rel = {(i, j) for i, j in zip(*np.where(unified > 0.5))}
        return 1.0 * check_transitivity(list(rel))

    def _sensitivity(self, unified: np.ndarray) -> float:
        """Perturb each weight by ε, recompute B and return normalized variance."""
        base = self._baseline_score(unified)
        if base == 0:
            return 1.0  # maximal fragility
        perturbed = []
        for i in range(unified.shape[0]):
            for j in range(unified.shape[1]):
                if i == j:
                    continue
                pert = unified.copy()
                pert[i, j] += self.eps
                perturbed.append(self._baseline_score(pert))
        var = np.var(perturbed)
        return var / base

    # ------------------------------------------------------------------
    # 5.  Constraint solving (primitive wiring)
    # ------------------------------------------------------------------
    def _solve_prompt_constraints(self, tokens: List[str], unified: np.ndarray) -> dict:
        """Create a tiny SAT‑like problem from the unified graph and solve it."""
        n = len(tokens)
        vars_ = [f"R{i}{j}" for i in range(n) for j in range(n) if i != j]
        domains = {v: [0, 1] for v in vars_}
        constraints = []

        # each edge weight > 0.5 forces the corresponding variable to be True
        for i in range(n):
            for j in range(n):
                if i == j:
                    continue
                if unified[i, j] > 0.5:
                    constraints.append((f"R{i}{j}", 1))

        # add a simple transitivity constraint: if R_ab and R_bc then R_ac
        for a in range(n):
            for b in range(n):
                for c in range(n):
                    if a != b and b != c and a != c:
                        constraints.append(
                            (f"R{a}{b}", f"R{b}{c}", f"R{a}{c}")
                        )  # primitive will interpret as implication

        # solve (may return empty dict if unsatisfiable)
        return solve_constraints(list(variables := domains.keys()), domains, constraints)

    # ------------------------------------------------------------------
    # 6.  Meta‑confidence detection
    # ------------------------------------------------------------------
    _META_PATTERNS = {
        "presupposition": re.compile(r'\b(have you (stopped|quit|ceased)|why did .+ (fail|stop))\b', re.I),
        "scope_ambiguity": re.compile(r'\bevery\s+\w+.*\b(a|an)\s+\w+\b', re.I),
        "pronoun_ambiguity": re.compile(r'\b\w+\s+told\s+\w+\s+he|she\b', re.I),
        "false_dichotomy": re.compile(r'\b(either|or)\b.*\b(or|either)\b', re.I),
        "subjectivity": re.compile(r'\b(best|worst|favorite|most|least)\b', re.I),
        "unanswerable": re.compile(r'\bwhat\s+is\s+the\s+price\s+of\s+.*\b', re.I)  # placeholder
    }

    def _meta_confidence(self, prompt: str) -> float:
        """Return a base confidence (0‑1) based on detected traps."""
        for name, pat in self._META_PATTERNS.items():
            if pat.search(prompt):
                return 0.0  # complete lack of epistemic certainty
        return 1.0  # no trap detected

    # ------------------------------------------------------------------
    # 7.  Public API
    # ------------------------------------------------------------------
    def evaluate(self, prompt: str, candidates: List[str]) -> List[Dict]:
        """Rank candidates by the composite Score = B·C·(1‑S)."""
        # tokenisation – simple whitespace split, lower‑casing
        tokens = re.findall(r'\b\w+\b', prompt.lower())

        # 1) three parsers → symbiotic graph
        mats = self._build_graphs(tokens)
        unified = self._symbiotic_update(mats)

        # 2) token‑level feature matrix X (random but deterministic per prompt)
        rng = np.random.default_rng(seed=hash(prompt) % (2**32))
        X = rng.normal(size=(len(tokens), 8))

        # 3) coherence factor
        C = self._oscillatory_coherence(unified, X)

        # 4) baseline and sensitivity
        B = self._baseline_score(unified)
        S = self._sensitivity(unified)

        # 5) constraint solving (provides an auxiliary “logical” score)
        sat_solution = self._solve_prompt_constraints(tokens, unified)
        logical_score = 1.0 if sat_solution else 0.0

        # final composite score per candidate
        results = []
        for cand in candidates:
            # cheap NCD tie‑breaker (max 15 % of final value)
            ncd_score = 1 - ncd(prompt, cand)   # higher is better
            base = B * C * (1 - S) * (0.85 + 0.15 * ncd_score)
            # boost if candidate contains any of the extracted relations
            boost = 0.0
            for rel_mat in mats:
                if np.any(rel_mat):
                    # simple keyword check
                    if any(tok in cand.lower() for tok in tokens):
                        boost = 0.1
                        break
            score = base + boost + logical_score * 0.05
            results.append({
                "candidate": cand,
                "score": float(score),
                "reasoning": (
                    f"B={B:.3f}, C={C:.3f}, S={S:.3f}, logical={logical_score}, "
                    f"NCD={ncd_score:.3f}"
                )
            })

        # rank descending by score
        return sorted(results, key=lambda d: d["score"], reverse=True)

    def confidence(self, prompt: str, answer: str) -> float:
        """Combine meta‑confidence with the evaluation score."""
        meta = self._meta_confidence(prompt)          # 0‑1
        # quick evaluation of the single answer
        eval_res = self.evaluate(prompt, [answer])[0]
        raw = eval_res["score"]                       # may be >1
        # normalise raw score to [0,1] using a simple sigmoid
        norm = 1 / (1 + np.exp(- (raw - 0.5) * 4))
        # final confidence respects epistemic honesty constraints
        conf = confidence_from_agreement([meta, norm])
        # never exceed 0.9 unless meta confidence is perfect and norm>0.95
        if conf > 0.9:
            if meta < 1.0 or norm < 0.95:
                conf = 0.9
        return float(conf)
```

**Explanation of the wiring**

1. **Symbiosis** – three lightweight parsers produce adjacency matrices; the
   `_symbiotic_update` function mixes their edge weights (primitive‑free).

2. **Neural oscillations** – sinusoidal masks (`theta`, `alpha`, `beta`, `gamma`)
   are applied to a deterministic random token‑feature matrix; Pearson
   correlations on the unified graph give the coherence factor `C`.

3. **Sensitivity analysis** – the baseline logical consistency `B` is obtained
   via the primitive `check_transitivity`.  Small perturbations of every edge
   weight produce a variance `S`.

4. **Constraint solving** – the unified graph is turned into a tiny SAT‑style
   problem and solved with the primitive `solve_constraints`; the existence of
   a solution contributes a small logical boost.

5. **Meta‑confidence** – regex‑based detection of presupposition, scope,
   pronoun, false‑dichotomy, subjectivity and unanswerability yields a base
   confidence that caps the final value (epistemic honesty).

6. **Final score** – `Score = B·C·(1‑S)` is blended with a modest NCD term
   (≤ 15 %) and the logical boost, then ranked.  The `confidence` method combines
   the meta‑confidence with a sigmoid‑normalised raw score via the primitive
   `confidence_from_agreement`.

The implementation stays under 200 lines, uses only NumPy, regex, and the
provided primitives, and follows the required decomposition of effort.
