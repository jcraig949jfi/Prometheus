**1. Emergent computational mechanism**  
The three ideas fuse into a **Fractal‑Scale Adaptive Bandit Controller (FSABC)**.  A hierarchical multi‑armed bandit is instantiated on a self‑similar tree generated by an iterated‑function system (IFS).  Each node of the tree represents a “scale‑bandit” that selects actions (hypotheses, experiments, or model refinements) within a sub‑region of the hypothesis space.  A PID‑style feedback loop monitors the regret or prediction error at that node and adjusts the node’s exploration rate (e.g., the UCB confidence width or Thompson‑sampling variance).  Because the tree is fractal, the same control law recurs at every depth, yielding a power‑law distribution of sampling effort that automatically balances fine‑grained local search with coarse‑grained global search.

**2. Advantage for a self‑testing reasoning system**  
A reasoning system can treat each hypothesis cluster as a fractal leaf.  The PID‑driven bandit controller continuously shrinks the error‑signal at each scale, so promising clusters receive exponentially more samples while still preserving a mathematically guaranteed exploration budget (UCB‑type regret bounds).  This gives the system *scale‑adaptive metacognition*: it can rapidly zoom into a conjecture that shows early promise and, if the error rises, the controller pushes the system back to higher‑level branches without manual re‑parameterisation.

**3. Novelty assessment**  
Hierarchical bandits, control‑theoretic regret minimisation, and fractal search spaces have each been explored separately (e.g., “hierarchical UCB”, “bandits with PID‑based learning rates”, “fractal optimization”).  However, a **single architecture that embeds a PID feedback loop inside a self‑similar IFS‑generated bandit hierarchy** has not been formalised in the literature, so the combination is largely novel, albeit a natural extension of existing components.
