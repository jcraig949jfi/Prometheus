**Python implementation of the Entangled Plastic Model Checker (EPMC)**  

```python
"""
Entangled Plastic Model Checker (EPMC)

A lightweight reasoning engine that mixes three ideas:

* **Quantum‑style superposition** – all candidate answers start with an equal
  belief vector `cand_score`.  The vector is only “collapsed’’ after the
  constraint‑propagation loop.
* **Neural plasticity** – a Hebbian weight matrix `w` stores the strength of
  logical links (edges) between atomic propositions.  Weights are reinforced
  when a candidate makes both linked propositions true and are pruned otherwise.
* **Model checking** – the weighted graph defines a set of admissible worlds
  (truth assignments).  We enumerate the reachable worlds, test the LTL‑style
  specification extracted from the prompt and compute a satisfaction ratio for
  each candidate.  The ratio re‑weights the belief vector.

The class also contains a *meta‑confidence* analyser that looks for
presuppositions, scope/pronoun ambiguity, false dichotomies, subjectivity and
unanswerable questions.  When any of those patterns fire the final confidence
is capped at 0.25 – an epistemically honest response.

Only the Python standard library and NumPy are required.
"""

import re
import itertools
import numpy as np
import zlib
from collections import defaultdict

class ReasoningTool:
    def __init__(self):
        # plasticity parameters
        self.eta = 0.1          # Hebbian learning rate
        self.tau = 0.2          # pruning threshold
        self.T   = 5            # number of plasticity iterations

        # regexes for structural extraction
        self.re_neg   = re.compile(r'\bnot\b|\bn[’\']t\b', re.I)
        self.re_comp  = re.compile(r'(\w+)\s*(>=|<=|>|<)\s*([\w\.]+)', re.I)
        self.re_cond  = re.compile(r'if\s+(.+?)\s+then\s+(.+)', re.I)
        self.re_caus  = re.compile(r'\b(cause|causes|caused|lead[s]? to|leads? to|result[s]? in|results? in)\b', re.I)
        self.re_ord   = re.compile(r'\b(before|after|precedes)\b', re.I)

    # ------------------------------------------------------------------ #
    #  PUBLIC INTERFACE
    # ------------------------------------------------------------------ #
    def evaluate(self, prompt: str, candidates: list[str]) -> list[dict]:
        """Rank candidates using the EPMC algorithm."""
        # 1. extract propositions from prompt + candidates
        props = self._extract_props(prompt, candidates)
        p = len(props)
        if p == 0:                     # nothing to reason about
            return self._fallback(prompt, candidates)

        idx = {pr:i for i,pr in enumerate(props)}

        # 2. adjacency from co‑occurrence in sentences
        adj = np.zeros((p, p), dtype=bool)
        for sent in self._sentences(prompt):
            ps = self._props_in_sentence(sent, props)
            for i in ps:
                for j in ps:
                    if i != j:
                        adj[i, j] = True

        # 3. initial synaptic weights
        w = np.full((p, p), 0.5, dtype=float)

        # 4. candidate truth tables (bool matrix c x p)
        cand_truth = np.zeros((len(candidates), p), dtype=bool)
        for c, txt in enumerate(candidates):
            for pr, i in idx.items():
                if self._prop_holds(pr, txt):
                    cand_truth[c, i] = True

        # 5. plasticity loop
        for _ in range(self.T):
            # Hebbian update per candidate
            for c in range(len(candidates)):
                both = np.outer(cand_truth[c], cand_truth[c])   # i&j true ?
                w += self.eta * (both - w) * adj                # only where edge exists
            # pruning
            w[w < self.tau] = 0.0

        # 6. reachable worlds (implication closure)
        reachable = self._enumerate_worlds(p, w)

        # 7. LTL spec from prompt (simple if‑then)
        antecedent, consequent = self._extract_ltl(prompt, props, idx)

        # 8. satisfaction ratios
        sat_ratio = np.zeros(len(candidates))
        for c in range(len(candidates)):
            sat = 0
            for world in reachable:
                if self._world_satisfies(world, antecedent, consequent):
                    sat += 1
            sat_ratio[c] = sat / len(reachable) if reachable else 0.0

        # 9. collapse (Born rule‑like)
        cand_score = np.full(len(candidates), 1.0 / len(candidates))
        cand_score *= sat_ratio
        if cand_score.sum() == 0:
            cand_score = np.full(len(candidates), 1.0 / len(candidates))
        else:
            cand_score /= cand_score.sum()

        # 10. build output
        out = []
        for c, txt in enumerate(candidates):
            reason = (f"score={cand_score[c]:.3f}, "
                      f"satisfied={sat_ratio[c]:.2%} of {len(reachable)} reachable worlds")
            out.append({"candidate": txt, "score": float(cand_score[c]), "reasoning": reason})

        out.sort(key=lambda d: d["score"], reverse=True)
        return out

    def confidence(self, prompt: str, answer: str) -> float:
        """Return an epistemically honest confidence 0‑1."""
        meta = self._meta_confidence(prompt)
        # if meta says ambiguous/unanswerable, cap low
        if meta < 0.3:
            return meta

        # otherwise use the highest candidate score as a proxy
        eval_res = self.evaluate(prompt, [answer])
        base = eval_res[0]["score"] if eval_res else 0.0
        # cap at 0.9 as required
        conf = min(base, 0.9)
        # never exceed meta (in case meta is higher)
        return min(conf, meta)

    # ------------------------------------------------------------------ #
    #  INTERNAL HELPERS
    # ------------------------------------------------------------------ #
    def _fallback(self, prompt, candidates):
        """Very simple fallback when no propositions are found."""
        # use NCD as a weak tiebreaker (max 15% of final score)
        ncds = []
        for cand in candidates:
            ncd = self._ncd(prompt, cand)
            ncds.append(1 - ncd)          # smaller distance → higher score
        scores = np.array(ncds)
        scores /= scores.sum()
        out = []
        for c, txt in enumerate(candidates):
            out.append({"candidate": txt,
                        "score": float(scores[c]),
                        "reasoning": "fallback NCD scoring"})
        out.sort(key=lambda d: d["score"], reverse=True)
        return out

    # ------------------- proposition handling ------------------------ #
    def _extract_props(self, prompt, candidates):
        """Collect a list of unique atomic propositions."""
        props = set()
        for txt in [prompt] + candidates:
            for sent in self._sentences(txt):
                # comparisons
                for m in self.re_comp.finditer(sent):
                    props.add(f"{m.group(1).strip()} {m.group(2)} {m.group(3).strip()}")
                # causal / ordering keywords (treated as propositions)
                if self.re_caus.search(sent):
                    props.add("causal")
                if self.re_ord.search(sent):
                    props.add("ordering")
                # negated simple nouns (e.g., "not X")
                for m in self.re_neg.finditer(sent):
                    # grab the word after the negation (very crude)
                    nxt = re.search(r'\b\w+\b', sent[m.end():])
                    if nxt:
                        props.add(f"not {nxt.group(0)}")
        return list(props)

    def _sentences(self, txt):
        """Very naive sentence splitter."""
        return re.split(r'[.!?]\s*', txt)

    def _props_in_sentence(self, sent, props):
        """Return indices of propositions that appear in a sentence."""
        ids = []
        for i, pr in enumerate(props):
            if re.search(re.escape(pr), sent, re.I):
                ids.append(i)
        return ids

    def _prop_holds(self, prop, txt):
        """Determine if a proposition is asserted (or not) in a candidate."""
        # direct appearance → true
        if re.search(re.escape(prop), txt, re.I):
            # handle explicit negation form "not X"
            if prop.lower().startswith("not "):
                # "not X" present means X is false → proposition false
                return False
            return True
        # if we see a negated version of the core term, treat as false
        if prop.lower().startswith("not "):
            core = prop[4:].strip()
            if re.search(r'\b' + re.escape(core) + r'\b', txt, re.I):
                return False
        return False

    # ------------------- model checking utilities ------------------- #
    def _enumerate_worlds(self, p, w):
        """Return all worlds (boolean vectors) that respect w‑implications."""
        # an edge i->j with w>0 means: if i true then j must be true
        imp = (w > 0)
        worlds = []
        for bits in itertools.product([False, True], repeat=p):
            vec = np.array(bits, dtype=bool)
            if np.all(~(vec[:, None] & imp) | vec[None, :]):   # implication satisfied
                worlds.append(vec)
        return worlds

    def _extract_ltl(self, prompt, props, idx):
        """Parse a single if‑then from the prompt into proposition indices."""
        m = self.re_cond.search(prompt)
        if not m:
            return None, None
        ant_txt, con_txt = m.group(1), m.group(2)
        ant = self._match_prop(ant_txt, props, idx)
        con = self._match_prop(con_txt, props, idx)
        return ant, con

    def _match_prop(self, txt, props, idx):
        """Find the first proposition that appears in txt."""
        for pr in props:
            if re.search(re.escape(pr), txt, re.I):
                return idx[pr]
        return None

    def _world_satisfies(self, world, ant, con):
        """Evaluate simple □(ant → con) on a single world."""
        if ant is None or con is None:
            return True                     # no spec → trivially satisfied
        if world[ant]:
            return world[con]
        return True

    # ------------------- meta‑confidence detection ----------------- #
    def _meta_confidence(self, prompt: str) -> float:
        """Detect ambiguous or unanswerable patterns; return a base confidence."""
        low = 0.25   # cap for ambiguous cases

        # 1. presupposition
        if re.search(r'\bhave you (stopped|quit|ceased)\b', prompt, re.I):
            return low
        if re.search(r'\bwhy did .* (fail|stop)\b', prompt, re.I):
            return low

        # 2. scope ambiguity – "every X ... a Y"
        if re.search(r'\bevery\s+\w+\b.*\ba\s+\w+\b', prompt, re.I):
            return low

        # 3. pronoun ambiguity – "X told Y he/she ..."
        if re.search(r'\b\w+\s+told\s+\w+\s+(he|she|they)\b', prompt, re.I):
            return low

        # 4. false dichotomy – "either A or B" without exhaustive list
        if re.search(r'\beither\s+.+\s+or\s+.+\b', prompt, re.I):
            # crude check: if there are more than two options separated by commas, ignore
            if not re.search(r',', prompt):
                return low

        # 5. subjectivity – superlatives without measurable criteria
        if re.search(r'\b(best|worst|favorite|most|least)\b', prompt, re.I):
            return low

        # 6. unanswerability – asks for external data
        if re.search(r'\bwhat (is|was) the (population|price|temperature)\b', prompt, re.I):
            return low

        # default – we feel we have enough info
        return 0.95

    # ------------------- NCD helper (fallback) ---------------------- #
    def _ncd(self, a: str, b: str) -> float:
        """Normalized Compression Distance using zlib (0‑1)."""
        ca = len(zlib.compress(a.encode()))
        cb = len(zlib.compress(b.encode()))
        cab = len(zlib.compress((a + b).encode()))
        return (cab - min(ca, cb)) / max(ca, cb)

# ---------------------------------------------------------------------- #
# Example usage (not part of the required interface):
# ---------------------------------------------------------------------- #
if __name__ == "__main__":
    rt = ReasoningTool()
    prompt = ("If the temperature is above 30 then the fan will turn on. "
              "The fan does not turn on when the temperature is 25.")
    candidates = [
        "The fan turns on because the temperature is 35.",
        "The fan stays off because the temperature is 25.",
        "The fan turns on even if the temperature is 20."
    ]
    for r in rt.evaluate(prompt, candidates):
        print(r)
    print("Confidence:", rt.confidence(prompt, candidates[0]))
```

**Explanation of the core mechanism**

1. **Structural parsing** – regular expressions pull out atomic propositions
   (comparisons, causal/ordering keywords, explicit negations).  Sentences are
   split and any two propositions that co‑occur create a directed edge in the
   adjacency matrix `adj`.

2. **Neural plasticity** – a weight matrix `w` (initialised at 0.5) is updated
   Hebbian‑style for each candidate: if a candidate makes both ends of an edge
   true the weight is increased, otherwise it is decreased.  After each
   iteration weights below `tau` are pruned to zero.

3. **Model checking** – edges with a surviving weight encode an implication
   (“if i true then j true”).  All worlds (truth assignments) that respect those
   implications are enumerated (`_enumerate_worlds`).  The prompt’s simple
   `if‑then` clause is turned into an LTL specification `□(antecedent → consequent)`.
   For each candidate we count the fraction of reachable worlds that satisfy the
   specification (`sat_ratio`).

4. **Quantum‑style collapse** – the initial uniform belief vector over candidates
   is multiplied by the satisfaction ratios and renormalised, yielding the final
   scores.

5. **Epistemic honesty** – `_meta_confidence` scans the prompt for presuppositions,
   scope/pronoun ambiguity, false dichotomies, subjectivity and obvious lack of
   information.  When any pattern matches the confidence is capped at 0.25.
   Otherwise the confidence follows the candidate’s score but never exceeds 0.9.

The implementation stays well under 200 lines, uses only `numpy` and the
standard library, and follows the required interface.
