# hephaestus/ — the Forge Queue and the Apprentice Forge

**Governing document:** `roles/Hephaestus/CHARTER_AMENDMENT_2026-09-01_forge_queue_master_smith.md`
(James, 2026-09-01). **Context:** `roles/Hephaestus/DESIGN_REVIEW_2026-09-01_external.md`.
**Station:** `stations/M3_STATUS.md`. **Cold-start for a Master Smith:** `HEPHAESTUS_HANDOFF.txt`.

Two regimes, never mixed:

| | Apprentice Forge (default, unattended) | Master Smith (operator-invoked only) |
|---|---|---|
| who | cheap/free/local models, enumeration, mutation, CPU | a capable Claude Code agent, agentic loop |
| product | sharper **Mint Packets**, executed failures, counterexamples, baselines | at most one candidate per wall, with knockout + scrap left behind |
| trigger | scheduled jobs (§8–11) | the operator says "start a deep forge" (§3, §20) |
| admission authority | none | **none** (§14) — independent machinery tests the blade |

```
  src/apprentice.py            §8 cheap-model job (nvidia NIM free tier + local ollama/phi3)
  src/refine.py                §10 refinement + state transitions
  src/rank.py                  §11 ranking
  src/handoff.py               §21 handoff
  jobs/                        .cmd wrappers + schtasks registration (Windows / M3)
```

## Run the first loop by hand

```powershell
cd C:\prometheus; $env:PYTHONPATH="."
python -m hephaestus.src.triage        # creates MINT-0001..0004 (idempotent)

```

## Rules this code enforces mechanically

- `apprentice.py` refuses any premium target (`claude*`, `anthropic*`, `openai:gpt-5*`, `openai:o*`).
- A packet reaches `READY-FOR-DEEP-MINT` only when every `READY_REQUIRED` field is non-empty **and** the
  apprentice is exhausted (≥4 executed attempts, ≥2 models, ≥2 failure families) — `refine.py`.
- A cheap-model candidate that passes the dev harness goes to `CANDIDATE-PRODUCED`, never `ADMITTED`.
- Charon's blind E9 battery is never read by anything under `hephaestus/`.
- Not implemented yet, by design (§25 "stop there"): the mutation job (§9), historical replay (§17),
  Serendipity ingestion beyond Apollo's canary. Build after one complete cycle has been observed.
