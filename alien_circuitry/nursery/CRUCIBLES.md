# Cheap crucibles for the strongest cousins (proposals; none funded or run in this task)

Ordering rule used: exact oracle exists; smallest world already built; headroom measurable; boring explanation
subtractable; mechanism differs from NUR-001; cost in minutes. Ranked by that rule, not by novelty.

## CRUCIBLE-A  NUR-001 second-ecology test: does the quotient pay outside T_7?  (recommended FIRST)

QUESTION: does discover->verify->quotient->search->restore reduce search cost in an ecology whose bottleneck is not
known to be state multiplicity?
OBSERVED TENSION: NUR-001 is at oracle in T_7; the independent tensor-QD lineage built the same object and found it
consequentially inert. One positive, one inert: promotion needs a discriminating third case.
MINIMAL WORLD: the Diomedes h1 counterfactual rows (statistical world) -- see CRUCIBLE-C, which is the concrete
instance; or the Ludus World Foundry's smallest finite world with an explicit transition graph (candidate consumer of
the NUR-010 gate).
EXACT ORACLE: per world (Diomedes exact labels; Ludus exact enumeration).
INCUMBENT: the world's existing best mechanism at its recorded score.
CANDIDATE: canonicalise by a verified symmetry/nuisance class, re-run the incumbent on canonical representatives.
BORING EXPLANATION / POSITIVE CONTROL: T_7 itself (known positive) run through the same script.
NEGATIVE CONTROL: canonicalise by a NON-symmetry (a random relabelling) -- must not help; and the tensor-QD case as
the recorded inert control.
PRIMARY METRIC: search cost ratio canonical/raw at equal solve rate; for statistical worlds, accuracy under the
permutation null against the pooled model.
ACCOUNTING: transitions/evaluations examined; wall-clock beside.
KILL: ratio >= 0.9 (no reduction) in the third ecology, or the gain is inside the null.
PROMOTION: ratio <= 0.5 with zero failures in a world where the tensor-QD-style inertness could have occurred.
LEAKAGE/DEGENERACY: the symmetry must be verified on the oracle BEFORE use (the v1 value-relabelling error is the
recorded failure mode); coverage at the search frontier, not on scored rows (the rank-2 bug).
BUDGET: <= 2 hours engineering, minutes compute.
POSITIVE DESCENDANT: Techne primitive-candidate proposal via techne/registry/primitive_candidates/ (Atalanta route).
NEGATIVE DESCENDANT: NUR-001 stays a T_7 specimen; the lesson "exact quotient, inert search" is recorded twice.

ACCOUNTING: macros count as one action but their expansion cost is charged in transitions.

PROMOTION: HC_D >= 0.2 from macros alone.
LEAKAGE: macros mined from FIT-problem paths only; held targets never seen.

POSITIVE DESCENDANT: CRUCIBLE-E composition test with the orbit table.
