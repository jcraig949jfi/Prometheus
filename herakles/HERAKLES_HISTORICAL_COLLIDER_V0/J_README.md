# J. RECOVERED ARTIFACT MANIFEST — EMPTY

`J_RECOVERED_ARTIFACT_MANIFEST.jsonl` is empty in V0 because **nothing has been recovered**.
Zero bytes of historical source, data, genome dump, log, config, seed or binary are in hand.

This is not an oversight and must not be papered over: every "artifacts: REPORTED / KNOWN"
entry in the specimen registry is a belief written from model recall, and the whole point of
this seat is that such beliefs are leads, not findings.

The manifest gets its first rows when the artifact hunt in `roles/Herakles/todo_2026-09-02.md`
runs. Row shape is defined in `SCHEMAS.md` section J. Custody rules are in
`roles/Herakles/METHOD.md` section 3: hash at recovery, originals immutable, derived copies
carry `derived_from`, blobs over ~50 MB live on Z:\ with only the hash in the repo.
