# TRANSPLANT FEASIBILITY — INSPECTION ONLY, NOTHING EXECUTED

Question, per prompt section 14: could the committed evolved genotypes be
re-evaluated under swapped beta/operator settings WITHOUT rerunning evolution?

## What the frozen rows actually preserve

Each of the 120 grid CSVs stores, per checkpoint, a single `geno` string in a
parseable form: `<eggcell> promoter:rhs promoter:rhs ...`. Worked examples from
`derived/grid/a0.03_b0.1_s1.csv`:

    gen 500   <ffcb> f:fffffebbhfcca f:abcde
    gen 1000  <g> g:gggggcehdggggghhhhhhcg e:b e: e: g:abcde

That genotype is the SHORTEST genotype in the population that still encodes the
correct phenotype, or index 0 when none is correct. It is one individual.

**The population is not preserved.** `hct01.c` writes only aggregate statistics
plus that one genotype string. HC-T01's detector is a population mean over
lambda = 100 individuals, so a single genotype is not the same measurement.

The simulator also exposes no genotype-parse entry point. `main` accepts only
`selftest` and `run`; a parser from the printed string back into the `Geno`
struct would have to be written.

## Answer

    TRANSPLANT_REQUIRES_NEW_COMPUTE

for the transplant that would actually match HC-T01's detector, because the
population it averaged over no longer exists and would have to be regenerated by
deterministic replay from the seed. Replay is cheap, about 8 seconds per run, and
the code is deterministic, but regenerating a population is new compute and is
outside this pass.

## One qualification a reviewer should have

A WEAKER single-genotype variant is feasible with zero evolution: parse the
preserved `geno` string, rebuild the genotype, and run the existing
`detect_one()` under both beta settings. That needs a parser and no evolution at
all.

It would answer a narrower question than HC-T01 asked. It measures the
best-and-shortest individual rather than the population, so it cannot reproduce
the population-mean detector and cannot be compared directly with any HC-T01
number. It is recorded here as an option, not a recommendation, and nothing was
run.
