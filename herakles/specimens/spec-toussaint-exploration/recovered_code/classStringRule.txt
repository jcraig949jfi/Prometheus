StringRule Class ReferenceList of all members.Detailed Description
A string object that implements grammar-rule methods.

The string is simply represented as an array of chars. The first char has a very special meaning - similar to the plug of a graph. When interpreted as a grammar rule the first char represents the lhs whereas the rest gives the rule's rhs.

A single grammar rule realizes the methods necessary to apply (also inversely) a grammar rule on a given structure. Each application is meant as a transformation step of a genotype-phenotype mapping. The grammar rule itself is also a structure: the rule structure basically represents the rule's rhs; a marked unit of the structure is the lhs Examples:
