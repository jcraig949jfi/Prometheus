# AUTOPSY TAXONOMY — 21/21 agents, dedup/merge pass

Generated by Aporia P70 (2026-08-21) from `engine/ledger/AGENT_AUTOPSIES.jsonl` (21 typed
records, evidence-first: artifact censuses, log greps, code boundaries — every claim in a
record cites its census). This document is the tier's consumable product. Its intended
reader is the designer of the NEXT agent generation; each cluster ends with the design
invariant that would have prevented it.

Census: 21 agents autopsied — 16 carry typed findings, 5 are clean nulls
(NO-DESIGN-FAILURE-ESTABLISHED). The 11 raw class labels merge into 5 clusters + 1
singleton. Two findings are LATENT (defect present, harm never realized in the observed
window) — a typing this pass introduced deliberately: healthy-looking artifact streams
are exactly where latent defects hide.

---

## Cluster 1 — DEAD-GATING (4 instances: Atalanta, Moros, Nephele, Nemesis-secondary)

A gate or detector whose firing condition does not track the reality it guards.

- **Atalanta** — internal form, maximal: 100%-purity gate dead for the agent's whole life.
- **Moros** — external-dependency form: DeepSeek unreachable from first tick; 80/80
  artifacts are absence reports. An unavailable API is an upstream-liveness precondition,
  not a career.
- **Nephele** — LATENT proxy form (new this tier): gate observable (producer's log mtime)
  measures daemon liveness, but the guarded quantity is substrate production. Clio's own
  log ends in `new=0` cycles — a zombie-production Clio never trips the gate. Zero harm
  realized (Clio verifiably produced through the window; 286/286 skips were CORRECT), so
  this is fallback-never-needed with a real dependency — NOT the Moros form.
- **Nemesis (secondary)** — structural-zero-detector instrument form: `blind_spot =
  (n_correct == 0)` over a ~150-tool library cannot fire; 3013 consecutive zeros were
  VACUOUS, not "no blind spots."

**Invariant:** gates observe the PRODUCT stream, not producer heartbeats; every
all-X-simultaneously detector ships with a pre-committed vacuous reading and a proof it
CAN fire (one synthetic positive). A proxy that diverges from the guarded quantity
precisely in the guarded regime is dead gating that hasn't been exercised yet.

## Cluster 2 — LOW-BITS-EMISSION (6 instances: Acheron, Pollux, Hecate, Polyhymnia, Hypatia, Moros-flavor)

Emission volume masquerading as coverage: many artifacts, few facts.

- **Acheron** — origin form: low bits per verdict emission.
- **Pollux** — static-rescan form, the cleanest census in the tier: 9 pairs × 1 outcome
  each = 9 facts, emitted as 286 ledger rows + 286 artifacts. Mechanically explains
  Hecate's cross-generator MI null (0.0034 bits): presence without variation contributes
  zero mutual information. The wiring worked; the information didn't.
- **Hecate** — artifact-per-tick-for-a-time-series (origin of that form).
- **Polyhymnia** — artifact-per-tick second instance: 250 null-tick .json files, each
  embedding the full scour mtime state; a counter's worth of information as 250 files.
- **Hypatia** — liveness-as-artifact: liveness signaling written into the work stream.
  (Nephele's 286 skip artifacts are a DESIGNED, directive-sanctioned instance; Moros's
  absence reports carry the same flavor.)

**Invariant:** an information-per-artifact floor: no-op ticks go to a counter or rolling
state file, never one artifact each; scanners over static data need a novelty gate keyed
on (input-version, instrument-version) — re-emit only on change. Polyhymnia's mtime gate
is the working example; Pollux's absence of one is the failure example. They were
running in the same swarm at the same time.

## Cluster 3 — BOUNDED-MENU-SATURATION (3 instances: Nemesis, Sophia, Polyhymnia-secondary)

The gen-30 wall (feedback_gen_30_wall) observed in deployed agents: a fixed option-space
saturates and the agent keeps drawing from it.

- **Nemesis** — no escalation edge at all: MAP-Elites grid filled 92/100 early, then
  placed=0 for 2931/3013 cycles (97% of lifetime compute, zero new coverage) while
  emitting 3014 full reports. Consumers for its output existed (coeus.py, hephaestus
  forge_v4 + test_harness) — the saturation was producer-side, not consumer drift.
- **Sophia** — DEAD escalation edge, the instructive contrast: the designed escape
  existed (grid exhausted → meta_expand_toolkit request) but emitted 13/13 byte-identical
  requests into a channel with no consumer. The in-life patch deduped the requests —
  treating the symptom, not the missing receiver.
- **Polyhymnia (secondary)** — stub-declared-adaptation: self-improvement menu of 7 with
  5 log-only placeholder rungs; 257 cycles, 4 stub events, zero behavior change. The
  menu-growth path existed as documentation, not mechanism.

**Invariant:** saturation is a SIGNAL (placed=0 × k cycles; 0 untried pairs) and must
trigger a wired escalation: grow axes, re-descriptor, or self-retire with a typed gate.
An escalation edge is only an escape if its far end has a named consumer with an SLA.
A stub rung is a liveness signal wearing an adaptation's name.

## Cluster 4 — SELECTION-DECOUPLED-FROM-SIGNAL (4 instances: Charon_Loop, Telos, Harmonia_Loop, Pollux-secondary)

Pick policies that never consume the signal that should steer them.

- **Charon_Loop** — YIELD-BLIND-ROTATION: coverage-seeking rotation ignoring yield.
- **Telos** — GREEDY-SELECTION-SUPPORT-COLLAPSE (new this tier), the exact dual:
  yield-seeking priority ignoring coverage — deterministic stall-weighted top-1 collapsed
  onto {F011, F014} for the agent's entire observed life while F013/F041A/F045 starved.
  Patched in-life (weighted round-robin, top_n=5); post-patch effect unverified in-repo.
- **Harmonia_Loop** — STATIC-DIFFERENTIATED-ALLOCATION: the knob existed, nothing turned it.
- **Pollux (secondary)** — rotation index advanced regardless of yield.

**Invariant:** every deterministic selector over a persistent queue states a coverage
floor (min-picks-per-eligible-item per window) AND a yield-feedback term at design time;
the health signal to audit is the pick DISTRIBUTION, not the pick log. Rotation and
greed are dual failures of the same missing feedback loop.

## Cluster 5 — SEAM-BROKEN (2 instances: Argos, Erebos; + Sophia's edge)

Producer–consumer contract failures at agent seams.

- **Argos** — PRODUCER-HALT-WITH-LIVE-CONSUMER: the inverse of consumer drift.
- **Erebos** — SELF-CONTAINED-GENERATION: thesis section 13's pathology at agent scale;
  a loop consuming only its own output.
- (Sophia's consumer-less escalation channel is this cluster seen from the producer side.)

**Invariant:** seams are declared contracts monitored from BOTH ends; a producer without
a consumer and a consumer without a producer are the same defect and should be detected
by the same audit.

## Singleton — SEMANTIC-TASK-SYNTACTIC-TOOL (Lethe)

A stance judgment implemented as keyword matching. Kept un-merged: the mismatch is
between task TYPE and tool TYPE, not an emission/gating/selection defect. **Invariant:**
name the task's semantic class at design time and require the tool's class to match or
exceed it; a regex can gate a pipeline but must never adjudicate a stance.

## Interlocks — where autopsies explain each other

- Pollux's constant re-emission (9 facts, 286 rows) is the mechanical CAUSE of Hecate's
  cross-generator MI null — two records, one causal story.
- Nemesis had consumers; Sophia had an escalation edge; Polyhymnia had menu slots. Each
  had one more piece of the healthy design than the last cluster-mate — and each still
  failed one seam further downstream. The wall moves; it does not disappear.
- Nephele (gate blind to zombie production) and Alethelia's `zombie_running` field are
  the same insight from opposite directions; the reporter grew the field the gate lacked.

## One-line summary for the next designer

Wire every gate to the product stream, put a floor under information-per-emission, make
saturation trigger a WIRED escalation, give every selector coverage+yield feedback,
monitor seams from both ends, match tool class to task class — and ship the swarm audit
plus a null-rate self-alarm from birth, because the two meta-instruments in this census
caught in days what took the autopsy tier three months to reconstruct.
