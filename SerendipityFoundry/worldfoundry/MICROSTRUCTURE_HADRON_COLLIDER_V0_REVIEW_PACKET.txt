5. NULL CONSTRUCTION (REBUILT AFTER THE RED TEAM)
--------------------------------------------------------------------------------
THE SUBSTRATE FACT: worlds are deterministic and bit-exact replayable, so any
effective perturbation either changes the trace or does not. "No difference"
is therefore never the null. The DRAFT null -- no coherent sign direction
across blocks, tested by block sign-flip -- was destroyed by the red team on
four independent grounds (fragility asymmetry; kinship dependence across
blocks; scale heterogeneity; an asserted-not-constructed bridge to anytime
validity). THE REBUILT CONSTRUCTION:

  PER BLOCK (one world x seed unit):
    one CANDIDATE contrast   (e.g. plant twin minus control twin)
    m REFERENCE contrasts    (identically constructed pairs differing only
                              by irrelevant seeds -- or, for operator nulls,
                              other draws from the same frozen perturbation
                              distribution)
  Under H0 the candidate is EXCHANGEABLE with its references WITHIN the
  block, so its rank among them is EXACTLY uniform -- for any block scale,
  any world chaos, any fragility or operator push common to candidate and
  references. The null is CONSTRUCTED, not assumed.

  ACCUMULATION: a wealth process bets a preregistered fraction (mixture over
  lam in {1/4, 1/2, 3/4}) on "candidate ranks top"; exact ties (all-zero
  contrasts) bet nothing. Product over independent blocks is an e-process;
  wealth >= 1/alpha is an anytime-valid level-alpha test (Ville). Optional
  stopping -- which is what field use looks like -- is safe BY CONSTRUCTION,
  from block one. Exact rational arithmetic; no float drift in inference.

  WHAT THIS BUYS, DEMONSTRATED IN QUALIFICATION:
    * operator-coherence artifacts cancel (Q2): a perturbation operator that
      mechanically pushes a mu coordinate the same way in every world fires
      the rejected sign test and does NOT fire the rank construction;
    * exact-zero nulls behave exactly (Q3): an inert dP produces perfect
      twin agreement -- wealth 1, nothing to explain;
    * pseudo-replication is structural, not statistical (Q6/N1): duplicated
      blocks collapse under block-id dedup instead of compounding wealth.

  REMAINING DEPENDENCE DEBT (open, stated): kinship ACROSS blocks (shared
  founders/grammar families) is priced in production by hierarchical units
  (founder-cluster x grammar-family flips) and an unrelated-founder
  replication axis at admission -- specified, NOT yet exercised, because v0
  has no evolved pedigrees. Gate table row G6.

8. CAPABILITY-VECTOR DEFINITION
--------------------------------------------------------------------------------
A CAPABILITY_VECTOR is a reproducible local direction in player/world
configuration space associated with changing structured behavior relative to
the appropriate null. Deliberately analogous to KillVectors, inverted. The
name implies nothing about intelligence.

Record content (weak_signal_record.schema.v0.json): the frozen perturbation
AND the hash of the DISTRIBUTION it was drawn from; the Delta-mu direction;
invariance profile; an explicit zero-outcome flag (an interesting direction
may lose every game); replication status on fresh blocks.

RED-TEAM HARDENING (was FATAL): a frozen-but-asymmetric perturbation
distribution manufactures directions that every organism shows (a probe
property, invariant across seeds/worlds/lineages precisely because it is not
about the organism). THEREFORE: every capability vector is reported as a
CONTRAST against the reference-ensemble response to the identical frozen
distribution; perturbation supports are sign-symmetrized where the encoding
permits; the perturbation GAUGE (coordinate scaling, support) is versioned
inside the record; vectors across gauges are never compared. Curvature
claims inherit all of this plus the frozen-fan discipline: no manual
hill-climbing; the question is whether a hill exists BEFORE evolution is
allowed to climb it.

9. CAUSAL-DEPTH INSTRUMENT
--------------------------------------------------------------------------------
QUESTION: how far back in experience does current behavior actually depend on
information? ANSWER BY INTERVENTION, not estimation -- the substrate replays.

  PREREGISTERED PROTOCOL (open-loop; red-team FATAL resolved):
    1. record one encounter: the player-facing observation stream (post-
       permutation, post-corruption -- the stream the player actually saw)
       and the action stream;
    2. for each seeded anchor tick tau: flip ONE bit of one seeded
       observation element at tau; re-run THE PLAYER ONLY against the
       recorded stream; the world is never re-stepped, so world chaos
       contributes exactly zero;
    3. IMMEDIATE-ACTION STRATIFICATION: if the action at tau itself changed,
       the event is a REACTIVITY (r0) count -- lag-0 use of the observation.
       D(k) is computed ONLY on interventions whose immediate action was
       unchanged: later divergence can then flow only through STORED
       INTERNAL STATE. This kills the reactivity-x-recurrence confound that
       made the draft non-identifiable.

  EXACTNESS: an unused buffer yields D(k) = 0 exactly (capacity without use
  is invisible, as it must be); an observation-blind player yields zero
  everywhere (verified: dead-code twin agreement 20/20 exact, Q3).
  FALSIFIER FOR ECHO-VS-USE: v0 uses the reactivity/depth stratification
  plus the trajectory contrast; the full inert-channel falsifier requires
  grammar-level causally-inert channels (engine request, section 24).
  ATTENUATION HONESTY (red team): interventions on corrupted channels
  realize with probability < 1; production logs realized interventions and
  conditions estimates on them, and power statements are stratified by
  world-family corruption/delay parameters. v0's pool is dominated by
  moderate-corruption worlds; the stratified restatement is future work and
  is listed as a blindness (section 22).

17. COMPUTE / LUMINOSITY REQUIREMENTS
--------------------------------------------------------------------------------
Measured on one commodity core (prototype, pure Python):
  * one block = 8 encounters (<=128 ticks) + 48 player-only open-loop
    replays: ~25-30 ms. The full qualification campaign (~50k encounters +
    ~300k replays) ran in ~3.5 minutes.

    world; a replay is O(horizon) player calls. Causal-depth profiling is

    roughly as P(events >= 4), events ~ Binomial(6L, eps/width) -- so the
    luminosity to reach eps ~ 0.01 at admission grade is L ~ 2000-4000

    demand ~10^6+ blocks per candidate -- hours per candidate, which is why
    PRESERVATION IS PERMISSIVE, INVESTIGATION IS RATIONED, and luminosity
    accumulates across preregistered axes instead of being re-bought.
  * the Observatory's production budget is a FIXED preregistered slice of
    fleet time (World Foundry reference-stream discipline applies).
