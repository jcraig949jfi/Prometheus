CANDIDATE-CONDITIONAL RANDOMIZATION -- THE OPPOSITE CASE
==============================================================================

[E1/E2] LEVEL vs HISTORICAL SELECTION INTENSITY (null is true)
  The specimen is chosen as the MAXIMUM of n draws, on the very
  statistic the analyst cares about. Then a FRESH randomized
  intervention is run on clones, with assignment drawn after the
  specimen is fixed.
      selection depth n = 1        -> rejection 0.0533
      selection depth n = 100      -> rejection 0.0553
      selection depth n = 1000     -> rejection 0.0567
      selection depth n = 200000   -> rejection 0.0647
  LEVEL IS FLAT IN SELECTION INTENSITY. Arbitrarily extreme
  historical selection does NOT inflate the randomized causal
  test, because the null concerns the response to experimenter
  randomness, not the specimen's provenance.

[E4] AND THE TEST IS NOT VACUOUS (power against real effects)
      true effect 0.0 -> rejection 0.0625
      true effect 0.5 -> rejection 0.2150
      true effect 1.0 -> rejection 0.5850
      true effect 2.0 -> rejection 0.9788

[E3] THE BOUNDARY WITHIN CLASS E -- TEST selection is NOT free
  analyst reports best of 20 observables : 0.6475
  beacon selects the observable         : 0.0525  (target 0.05)
  CLASS E IS FREE WITH RESPECT TO SPECIMEN SELECTION,
  NOT WITH RESPECT TO TEST SELECTION. The specimen may be chosen
  by unlimited hindsight; the intervention, the observable, the
  tail and the stopping rule may not.
