# Falsifiers

Part of programs/selective_irreversibility/ (README.md: writing rules,
directive path + hash). Append-only.

Per countermodel (s4 A reversible, B lossless memorizer, C indiscriminate
loss, D unknown): the concrete result that would damage the law, the
accounting boundary it must hold (s2, s9), and which lane attacks it. A
falsifier with no lane attacking it is a MISSING FALSIFIER (s13.6).
