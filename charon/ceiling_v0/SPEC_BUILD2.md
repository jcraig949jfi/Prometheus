## 1. Scope, renamed

> **v0 tests accumulation and refinement of latent structure under a shared
> representational affordance.**

Every arm is told the same thing about what kind of structure may exist. This
tests *exploitation* of a hypothesis class, not *invention* of one. Invention
belongs to a separate later condition with no hint given to anybody, and must not
replace this one — the easier rung has to be climbed first to know where failure
begins.

## 2. F7 demoted from falsifier to branch condition

Optimising the arena to defeat a particular baseline optimises the environment
instead of testing the hypothesis, and risks the flatline regime the calibration
sweep already found. The algorithmic baseline establishes that this universe
contains extractable regularity at the available budget. That is calibration, not
contamination. Branch instead:

- **B1** algorithmic >> P2 — environment solvable, model contributes no useful induction.
- **B2** P2 ~= P3c < algorithmic — substrate works, model adds no proposal advantage.
- **B3** P2 > P3c — the model contributes to representation discovery.
- **B4** P2 > algorithmic — model+substrate found structure beyond the engineered mechanism.

## 3. Target claim, restated

Build 1 demonstrated that externalised competence accumulation is possible. It
did **not** demonstrate that the reasoner caused it — the substrate results
survived a run in which the model layer crashed and contributed nothing.

> **Can a frozen reasoner make epistemically productive changes to a persistent
> cognitive substrate — changes unavailable to the substrate-building algorithm
> alone?**

"P2 survives amnesia" is near-guaranteed once the substrate is executable and is
not the interesting result.

## 4. The intervention ladder

C0's result (essentially never emits a claim) is preserved permanently and is
**not** a ceiling finding on its own. Progressively remove every mundane
explanation:

- **C0** claims optional. *Result: 1 claim in 39 turns across two lanes.*
- **C1** mandatory generativity, with an incentive. *Result: 15/15 turns.*
- **C1N** the same demand with the incentive REMOVED, because C1's wording
  supplies a motive to speculate and would otherwise confound induction with
  instruction-following. *Result: 14/14 turns, more claims per turn than C1.*
- **C2** dedicated induction call. Deferred under scarcity.
- **C3** candidate discrimination — harness supplies candidates from the arm's own
  observations; the model selects. Recognition rather than generation.
- **C4** abstraction pressure — no schema, hint withheld at system level, at most
  200 machine-actionable bytes for a successor. The unparsed fraction is a
  measurement, not a discard.

## 5. The funnel replaces the scalar

`I -> D -> R -> B -> G`: incompleteness, distinction, representation, behaviour,
gain. The driver is **incompleteness, not surprise** — demanding surprise before
learning demanded that the safety mechanism fail first, which is wrong for a
verification-gated architecture that is never wrong, only ignorant.

Contradiction rate survives as a separate integrity axis. A healthy run is
`I down, G up, contradiction ~ 0`. A rise is an alarm to be attributed, not
automatically "the verifier admitted a false rule".

**Causal linkage is not claimed.** Ignorance falling while distinctions rise shows
only coexistence. Until the proposer records which deficit motivated each
candidate, `I` is a measure of opportunity, not mechanism.

**Generalisation distance**, over gains, no semantics consulted: query length /
rule length; L1 distance between action-count profiles; longest common suffix.

## 6. Build 2 falsifiers

- **G1** No ladder condition produces a non-empty, environmentally-surviving rule set.
- **G2** C3 succeeds while C1 and C2 fail, AND C3's selections are no better than the
  harness's own ranking of the same candidates — the model is being carried.
- **G3** Any condition's advantage disappears under interaction-matched *and*
  LLM-turn-matched comparison.
- **G4** C4 artifacts never parse into anything the verifier can execute — the
  200-byte channel measures formatting, not abstraction.
- **G5** Gains concentrate at generalisation distance ~0 — "representation" is memorisation.

## 7. Controls are frozen once they have done their job

P3c frozen at iteration 2 (0.364). P3d added and frozen at iteration 4 (0.647).
A control should eliminate alternative explanations, not asymptotically absorb
every clever strategy available to the experimenter; past that point the
comparison degrades into "frozen LLM versus more engineering hours". Three
thresholds, three distinct claims: **A** vs P3c 0.364, **B** vs P3b 0.475,
**C** vs P3d 0.647. A model at 0.55 fails C but passes A and B, and the correct
report is "the reasoner causally contributes useful induction, but its proposal
policy is inferior to a task-informed engineered heuristic". That is not a null
result.

## 8. C1 proposal-efficiency metrics, fixed before any C1 accuracy run

Final accuracy is not the primary reading; C1 forces a claim, so raw proposal
count is not competence. Pre-registered: `G / model_proposals`, `G / D`, `R / D`,
`novelty_vs_P3d`, leverage `L(r)`, epistemic yield `Y(r)`, and final accuracy.
One model run is compared against all frozen controls; the controls are
counterfactual reference trajectories, not opponents, so the budget is spent once.

The decisive question is not "did it clear 0.647" but **did the model originate
useful distinctions the deterministic proposer did not.**

## 9. Known-open, recorded rather than resolved

- **P3d's 0.647 is unexplained.** Static relevance gives 0.374, dynamic relevance
  0.414, and the perfect-proposer comparison was confounded by generator
  saturation (iteration 10). No mechanism currently accounts for the gap.
- **Reproducibility is a property of code that sorts.** P3b was hash-order
  dependent for its entire history and every P3b figure before iteration 12 was a
  sample, not a measurement. Cross-process determinism is now asserted directly.
