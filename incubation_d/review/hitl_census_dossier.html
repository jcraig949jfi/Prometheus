1Mandate and question

Agent D’s target is the endogenous evolution of machine-native self-modification. The question the eventual experiment must answer:

Can accumulated executable experience create reusable transformations of executable structure, such that the system learns not merely artifacts, algorithms, representations, or routing policies, but new ways of modifying its own cognitive machinery?

The specification imposes hard constraints on how that question may be attacked:

  • No general reasoning system; no natural language in the learner’s symbolic substrate; no LLM as judge.
  • No human-authored mutation categories in the learner’s API. There is no mutate_as_algorithm(...) because no such category may exist. Tokens equivalent to APPEND_MUTATION, CONTROL_WRAP, PRE_TRANSFORM, or BRANCH_ROUTE are forbidden; if those families arise, they must arise as compositions humans recognize only retrospectively.
  • The central control is M0 vs M1: generic enumeration over the frozen meta-language versus history-conditioned generation, under identical budgets, worlds, and gates. If M0 finds useful transforms as cheaply as M1, no learned self-modification search may be claimed.
  • Selection, not semantic diagnosis: survivors persist because the environment filtered them, and the system is never credited with knowing why a mutation works.

The mandated first action — the only phase executed so far — was to attack the proposed homoiconic substrate itself: produce a design manifest, build a census of the meta-language, and try to demonstrate that the language secretly contains the vending machine. Grammars were to be killed until that criticism no longer survives quantitatively, and only then frozen.

2Experimental boundary

No claim of freedom from designer priors is made, and reviewers should not evaluate the work against that impossible standard. Humans (here, the Agent D seat) chose: the virtual-machine physics, the primitive operations, the type system, resource budgets, admissible observations, the census probes, deterministic verification, and the selection rules. The narrower hypothesis under test is:

Given fixed computational physics and selection, can the system construct useful self-transformations without being given a human ontology of what kinds of cognitive changes exist?

The census phase reviewed here tests a precondition of that hypothesis: that the frozen meta-language is neither a re-labeled set of human mutation buttons (leakage) nor too impoverished to express anything beyond them (poverty).

3The D-VM substrate

The D-VM (incubation_d/vm/machine.py) is a deterministic, bounded, typed stack machine with a single value universe — Int and Block — and two opcode tiers sharing it. There are no clocks, no randomness, and no host-language introspection anywhere in learner-visible space. Python implements the VM; learned artifacts are Blocks only.

Homoiconicity

A program is a Block: an immutable tuple of instructions, where an instruction is an opcode name or a literal push ('P', value) whose value may itself be a Block. Blocks live on the same stack as integers, so an executable artifact is directly inspectable, decomposable, and recombinable data. The qlit operation reifies any Block into a single instruction that pushes it — the reflection step that makes transforms-of-transforms reachable. There is no parse/unparse boundary and no path to host-language source generation.

Meta tier (edits Blocks as data)

Total and straight-line in the frozen grammar: no loops, no recursion, no meta-tier conditional — every transform terminates by construction and its execution cost equals its token count. Learner-visible names are arbitrary IDs; the semantics column is human documentation that never enters machine state.

Deliberate absences, recorded as attack surface: no meta-tier conditional (a transform cannot branch on artifact content), and no introducers for meta tokens (a transform can emit meta-code only by harvesting it from its input or via qlit).

Failure geometry and bounds

Every execution failure is a typed numeric descriptor (code, ip, depth) — underflow, type breach, block cap, stack cap, step cap, bad op, int cap. No English diagnostic ever reaches learner-visible state. Frozen physical caps: stack depth 16, block length 64, integer magnitude 220, object step budget 64, modulus 97.

4Census protocol

The census (census/prereg_census.json, committed before the first run in commit cb9acf6d) applies unchanged to every grammar candidate. It enumerates all typed Block → Block meta-programs to length L=5 in shortlex canonical order (the grammar’s frozen token order defines rank), so every count is exact and every gate deterministic.

Dual fingerprints

Each valid program runs on 7 frozen probe artifacts (lengths 0–5, content-varied, with and without the conditional token). Two extensional fingerprints are taken:

  • Structural — the exact output Block per probe. Defines “behaviorally distinct.”
  • Object-semantic — each output artifact executed on 5 frozen probe stacks, error codes included. Structural distinctness upper-bounds semantic diversity; both are reported, and the semantic floor is the binding diversity gate.

Offline — and only offline — each distinct behavior is audited into a collapsed edit shape (identity, constant, quote, append, prepend, wrap, insert, take, drop-prefix, delete, self-concatenation, permutation, mixed, other) plus behavior flags (introduces / removes / reorders tokens, introduces control, introduces literals). The four legacy families map to: append → APPEND_MUTATION, prepend → PRE_TRANSFORM, wrap → CONTROL_WRAP, and the introduces-control flag → BRANCH_ROUTE. These labels exist for grammar auditing and never become learner-visible (the interpretation firewall of spec §25).

5Grammar lineage

Three candidates were censused. The load-bearing pattern: the leakage gates (CK1, CK2, CK4) never fired on any candidate. Both rejections were for the opposite defect — poverty of the cheap region — and both fixes were generic structural combinators, never mutation categories.

gv0 REJECTED · POVERTY CK3, CK5, CK7

17 tokens: stack ops, block ops, int ops, introducers. 1,508,597 sequences enumerated; 7,404 valid programs; 681 distinct behaviors (541 semantic). Insert was unreachable at the horizon; the cheap window held only 7 of 12 shapes; true mixed density was 0.007 (5 of 680) against the 0.01 floor. Leakage side: legacy share 0.400, legacy minimal lengths (append 2, prepend 3, wrap 5, route 2) against a shape median of 3 — passed.

gv1 REJECTED · POVERTY CK3

gv0 + unc/tuck/nip, decomposition-first canonical order. 3,368,420 sequences; 18,629 valid; 903 distinct (751 semantic). Mixed density recovered to 0.131 and every shape became reachable (CK5 and CK7 passed) — but insert, at minimal length 5 and lexicographically late, was the single shape missing from the first-200 window: 11 of 12. Legacy share 0.365; legacy minimal lengths at or above the median of 2 — leakage gates passed again.

gv2 PASSED · FROZEN

gv1 + icat (argument-swapped concatenation, the swoncat of the Joy family), with the canonical order restructured: structural edits first, fragment injection second, measurement and arithmetic third, construction-from-nothing and reflection (qlit) last. icat brings insert to length 4 and prepend to length 2 — note that cheapening a legacy family tightens CK2/CK4 against the grammar’s own favor, which is the honest direction for a leakage test. 4,288,305 sequences; 28,891 valid; 1,584 distinct (1,296 semantic). All seven gates passed; details in §6. Frozen and hashed into meta_grammar.json.

7What is and is not established

Established

  • A homoiconic, deterministic, bounded substrate exists in which artifacts and transforms share one typed value universe, transforms-of-transforms are type-reachable, and all failure is numeric. Six VM unit tests pass; the census executes 28,891 programs with zero runtime failures.
  • Under a fixed, preregistered, fully deterministic protocol, the frozen meta-language gv2 is quantitatively neither a re-skinned vending machine (CK1/CK2/CK4) nor an impoverished one (CK3/CK5/CK6/CK7): the census horizon’s cheap region contains all twelve audited edit shapes, mixed edits at 15% density, and legacy families at 36.5% share with minimal lengths at the shape median.
  • The rejection machinery works and was used: two grammars and one defective protocol run were killed and preserved, not discarded.

Not established — and not claimed

  • Nothing about learning, self-modification, meta-plasticity, or history-conditioned advantage. No world has applied selection pressure; no transform has ever been admitted; M0 and M1 do not exist yet.
  • Nothing about the meta-language’s adequacy under real selection. The census measures reachability and cost structure at L ≤ 5, not usefulness.
  • Nothing beyond the probe sets: behavioral equivalence is probe-relative extensionality, not proven program equivalence.

The strongest claim this dossier supports: within this frozen substrate, the four human mutation categories are ordinary, unprivileged points in a much larger reachable space of structural edits. That is a statement about the instrument, not about any learner.

8Attack surface

Weaknesses reviewers should press on, in rough order of how much I would weight them:

  1. Weak-form preregistration. The prereg was authored and committed by the same agent that then ran the census, hours apart, in one session. Mitigations: gates are deterministic exact counts with no analyst degrees of freedom at evaluation time; thresholds were never edited after data (the one protocol change was an instrument repair, disclosed, with the defective run preserved); the full history is in two commits. But this is self-preregistration, and the evidence-phase prereg should be held to a stronger standard — ideally reviewed by a second party before the first evidence row.
  2. Designer adaptivity under fixed gates. The grammar was iterated against the census: unc/tuck/nip and icat were chosen after seeing where gv0 and gv1 failed, and the canonical token order (edits first, reflection last) was restructured knowing that order determines which behaviors land in the CK3 window. The defense: gates never moved; every addition was a generic combinator with standard concatenative-language pedigree; the order is a declared part of the frozen spec that M0 will use identically; and reordering also pulled legacy families earlier, tightening CK2 against the grammar. The residual worry is real: CK3 was passed partly by choosing what canonical search sees first. A concrete robustness check is proposed in §10.
  3. Threshold choices are judgment calls. The 200-behavior window, the 60% share line, the 12-shape requirement, the 3%/500/300 floors, and the 1% mixed floor were set by argued rationale, not derived from anything. They were set before any run and survived unchanged — but different defensible numbers exist, and gv2’s CK3 pass (12 of 12, where 11 was a kill) has no slack.
  4. The shape audit is heuristic. Collapsed shapes are fixed-parameter templates; 811 of 1,584 behaviors land in “other” and are not individually audited. A behavior in “other” could be legacy-like in a way the templates miss (e.g., a length-relative append). Since CK2/CK3 count “other” as non-legacy, template misses bias toward passing the leakage gates.
  5. Structural distinctness inflates diversity. Two structurally different outputs can be semantically equal; the 1,584 figure is an upper bound on what selection can distinguish. The semantic count (1,296, floor 300) partially covers this, but the shape audit itself runs on structural fingerprints.
  6. Horizon L = 5. The learner will search beyond length 5; the census says nothing about the landscape there. The horizon was fixed for tractability of full enumeration (no sampling) — a deliberate trade of depth for exactness.
  7. No meta-tier conditional. A gv2 transform cannot branch on the content of the artifact it edits (only on lengths, via arithmetic into splt). This caps the expressible transform space and may matter under world pressure. It is a recorded absence, to be revisited only if worlds demand it — never as a convenience.
  8. Small probe sets and a small object tier. Seven structural probes, five semantic stacks, five object opcodes. Route-likeness reduces to “introduces o4 where the input had none” — coarse. Larger probe batteries are cheap to add at world time and should be.

9Not built, and why

Spec §40 forbids building the full experiment before the substrate survives its own attack, and the seat stopped at that line. Deliberately absent: Worlds A–F (meta-pressure, frozen transfer, hostile transform, transform-of-transform, mutation-distribution, NULL), the candidate generator, the M0/M1 arms, quality-diversity maintenance, the append-only transform ledger, the anti-cheat battery, evidence seeds, and verdict code.

The committed next-phase order, each step behind its own preregistration and freeze:

  1. World census (CK8). Every world candidate faces the same discipline the grammars did: kill any world whose target is solvable by a ≤3-token single-legacy-family template; preserve rejections in rejected_worlds.jsonl. World A’s mixed pathology must demand deletion/restructuring, selective preservation, and insertion-with-reordering simultaneously.
  2. Full evidence prereg. Budgets, candidate counts, QD descriptors, admission gates, confirmation protocol (discovery and confirmation data strictly segregated; battery-wide hypothesis count recorded; Holm–Bonferroni where exact tests are impossible), evidence seeds, and verdict code — all frozen before the first evidence row.
  3. M0/M1 with the anti-cheat battery, including the static check that no candidate-independent information enters M1 but not M0, and that no work escapes the shared meter.

The verdict hierarchy is conservative by construction (from NO_META_PLASTICITY up to RECURSIVE_MUTATION_EVOLUTION), the top verdict requires the World E history-advantage gate, and a null — M1 no cheaper than M0 — is a preserved outcome, not a failure. Stop condition: the experiment halts at its preregistered verdict; no open-ended evolution, no external language models, no unrestricted code generation, no scaling because something looked interesting.

10Questions for reviewers

  1. Canonical-order robustness. Does the edits-first token order constitute tuning the CK3 window? Proposed check before the world phase: rerun the census under N random token orders with gates unchanged, and report how many orders gv2 survives. Should a minimum survival fraction be added as a frozen gate, and at what N?
  2. Threshold audit. Are the CK2 (60%), CK3 (12 shapes / 2×), and CK6/CK7 floors defensible where they stand? If a reviewer would move any line, that argument is wanted now, while no evidence depends on them — moving them later is exactly what the discipline forbids.
  3. Post-hoc combinators. Is the gv0 → gv2 iteration (adding unc/tuck/nip/icat after observed failures, under fixed gates) acceptable grammar engineering, or does it demand an additional control — e.g., censusing a small family of independently plausible grammars and requiring the conclusion to hold across survivors?
  4. The “other” bucket. 811 behaviors escape the shape templates and count as non-legacy. Should a sampled manual audit, or additional templates (length-relative append/take), be required before the leakage verdict is trusted?
  5. Meta-tier conditional. Hold the line on content-blind transforms until world pressure demands otherwise, or admit a bounded select now so the M1 hypothesis space is not silently capped from the start? Either choice changes what “history-conditioned generation” can mean.
  6. M0’s definition. Frozen shortlex enumeration, seed-fixed uniform sampling of the valid space, or both as separate arms? The choice sets the cost baseline every meta-learning claim divides by, and it should be fixed by argument before any M1 code exists.
