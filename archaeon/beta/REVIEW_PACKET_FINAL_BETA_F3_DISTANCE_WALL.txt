------------------------------------------------------------------------------------------
5. WHAT THIS GENERATION LEARNED (shapes)
------------------------------------------------------------------------------------------
1. Whether state is reached depends on whether the WORLD makes it decisive. Where regeneration keeps pools full,
   state is worth 0.000 and is not used. Where pulses empty pools, a gating latch is worth 3.6x and is reached in
   ~half of populations.
2. State is reached in several forms, including self-modified code. A persist-only ablation undercounts it.
3. Update-on-condition is reached from the write-once precursor almost always, from a stateless forager sometimes,
   and from random never (at G=300). The wall is distance in program space, graded by how much coupled structure is
   still missing. This is consistent with the B55-B57 wiring-chain slope.
4. Competition does not raise the latch rate (B69d), but it shapes which state forms win: patrols are excluded by an
   invasion asymmetry (B73).
