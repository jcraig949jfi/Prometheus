3. DESIGN AS EXECUTED
------------------------------------------------------------------------------------------
Arms (seeds 6001-6006 for P-boom, 6401-6406 for B-scatter)
- CONC: each generation the population is randomly partitioned into groups of 4. Fitness = own
  concurrent reward.
- SOLO: same evaluator, k=1.
- SHAM: per generation, x_i = concurrent reward and s_i = solo reward. Least squares x = a*s + e.

8. WHAT THIS GENERATION ACTUALLY LEARNED (shapes)
------------------------------------------------------------------------------------------
1. Coupling must be SIMULTANEOUS to bite. With in-episode regeneration, sequential sharing returns
   every organism to the same equilibrium. Frequency dependence needs co-presence.
2. Under co-presence, selection produces SPECIALISTS BY BLINDNESS: each organism attends to one
   pool word only. Partitioning follows because mutually blind specialists stop colliding.
3. Without competition (SOLO) and under matched noise (SHAM), the same search converges on
   near-monomorphic DOMINANCE. The polymorphism is caused by the competition residual being
   ATTACHED to the organism.
4. Competition does not rescue the memory law. Where state cannot pay (regenerating pools) it is
   never used. Where it pays (pulse refill), competition shrinks its absolute value: the
   ecological route does not amplify state.
5. Pulse worlds are a place where the REACHABLE memory form (a write-once latch, Finding 3) is
   decisive (2-4x). That makes them a test bed for whether search finds the latch when it matters
   (B69).
