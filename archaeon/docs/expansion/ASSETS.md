## 0. The integration surface (what INTEGRATED_WITH_SFE concretely means)

SFE (`SerendipityFoundry/SerendipityFoundryEngine`, `sfe/executors.py`) is an orchestration and provenance engine, not a substrate. Its only world semantics live in two executors: `BitStringExecutor` (kind `evaluate_bitstring`: a 24-bit OneMax against a target derived as `sha256("target:{seed_root}:{length}")`, result `{bits, score, solved, length}`, reproducibility `BIT_DETERMINISTIC`; note `score` divides by `len(target)` while matching over `min(len(bits), len(target))`, so short candidates are penalised) and `NondeterministicExecutor` (os.urandom; exists so tests prove the engine never claims determinism falsely). Everything else is a container: `POST /v2/worlds {seed_root}`, `/experiments`, `/observations {exp_id, content, outcome}`, `/artifacts`, `/failures`, `/fork`, `/work/claim|complete` (docs/SERENDIPITY_FOUNDRY_GEN2_API.md lines 27-54). Engine test suite: `python -m pytest SerendipityFoundry/SerendipityFoundryEngine/tests --collect-only -q` -> 297 tests collected (not run here; Daedalus's M2 packet 0b7635bb1 records DEPLOYED_QUALIFIED).

Vivarium (`vivarium/viv/`, `b70d7a665 2026-09-06`) is the executor host. `viv/kinds.py` has exactly three live kinds: `noop_v0`, `evaluate_bitstring` (delegates to `sfe.executors.BitStringExecutor`, `viv/executors.py:108-126`), `random_walk_v0` (a deterministic 1-D walk bench primitive), plus one RETIRED archaeon kind (`implemented=False`, retired 2026-09-06). `viv/runner.py:262-430` does session -> world (with `seed_root`) -> experiment -> claim -> executor -> `complete()` -> observation; `viv/pew.py` writes the `pew.fossil.v2` fossil. `python -m pytest vivarium/tests --collect-only -q` -> 156 tests collected (not run: `test_live_*` need live SFE/PEW and Postgres).

The other proven path into SFE is `integration/harmonia_arena.py` (`f6e82d483 2026-09-05`): `arena.run(specimen, world_config, action_plan)`; `execute()` at line 334 imports `proteus.foundry.vm.Player, Meter` and `proteus.foundry.prng.SplitMix64`, runs the player locally, and posts the transcript hash as an SFE observation plus a PEW fossil. This is the ONLY non-bitstring organism execution that has ever been recorded into SFE.

Consequence for every asset below: the smallest faithful integration path always has the same shape: (a) a `KindContract` in `vivarium/viv/kinds.py` declaring the exact parameter set, (b) a pure executor function in `viv/executors.py` taking `(params, seed)` and returning a JSON-able result, (c) an `outcome_rule` in the spec. The engine never needs to know the substrate. What differs per asset is whether it is a pure function of `(declared params, seed)`, and whether its result is one observation or a trajectory that needs `/artifacts`.

Cross-cutting finding: apart from Proteus-via-arena and the genesis/harmonia campaign scripts, NOTHING in the repo records into SFE. Every substrate directory (ludus, incubation, incubation_d, agent_d*, herakles, worldfoundry, D6A/D7/D8/D10, tensor_decomp_qd) has zero references to sfclient, sfe, vivarium or :8811.
