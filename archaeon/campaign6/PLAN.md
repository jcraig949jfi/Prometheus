0. WHAT THIS CAMPAIGN IS, IN ONE LINE
-----------------------------------------------------------------------
Build the generators that make SFE stranger and the observatory that
keeps it legible, then measure the point where the second fails before
the first does. The observatory is the object of study; the discoveries,
if any, are a by-product it must be able to catch.

1. SHAPE: FOUR PHASES, FIVE GATES, NO SLOT LIST
-----------------------------------------------------------------------
Campaign 5 was ten preregistered slots. Campaign 6 cannot be: the
directive asks for a search whose volume is scattered, escalated where
the rulers fire, and partly generated by no one. The unit of
preregistration is therefore a GENERATOR (its distribution, provenance
schema, frozen thresholds) and an ESCALATION PROTOCOL, not a hypothesis.
Every run still carries a sealed prereg-of-record: which generator, which
seed, which lane label, which thresholds were live.

  PHASE 0  OBSERVATORY BACKBONE ON THE OLD SUBSTRATE   gate G6-0
    Build T0 fingerprints, the eleven detectors, tiered storage and the
    escalation/replay machinery FIRST, and calibrate them on runs whose
    ground truth is known (Campaign 4/5 substrates, worlds and
    lineages). Freeze thresholds. Prove: a Campaign-5-style run passes
    through the observatory unchanged in its numbers (replication), and
    a set of PLANTED events from the calibration set is recovered at a
    stated rate. Nothing new is searched in Phase 0.
  PHASE 1  EXPANSION GENERATORS                          gate G6-1
    Axis W (composable worlds), O (graph organisms), P (pressure
    schedules) built as generators with complete provenance and the
    five lane labels; each proven against fixtures (a generated world
    runs; a generated organism evaluates; a schedule replays exactly);
    the observatory attached to all three.
  PHASE 2  SCATTER, ESCALATE, GO LONG                    gates G6-2, G6-3
    Broad initial scattering across generators (>= 25% LLM-free by
    volume, accounted in evaluations), deep allocation on the
    directive's triggers, blind planted fixtures interleaved by a seat
    that is not me, long runs under the long-run policy. G6-2 = the
    scatter has run with the observatory live; G6-3 = the blind recall
    matrix is adjudicated by the planting/judging seats.
  PHASE 3  RETURN                                        gate G6-4
    The thirteen returns, the six success classes judged independently,
    the complexity-ceiling answer, review packet.

2. AXIS DESIGNS (v0.1; each becomes its own DESIGN.md before it runs)
-----------------------------------------------------------------------
W  WORLDS FROM PRIMITIVES. A world is a composition of FEATURE modules,
   each a small stateful dynamic with a stated interface to the
   organism's channels: resource pools (types, depletion, regeneration),
   a locality graph (nodes the organism occupies/moves on), objects
   (manipulable state cells), a delayed-consequence queue, hidden state
   (observed only through a noisy or lagged channel), a regime clock
   (feature parameters change on a schedule), hazards (local, state-
   dependent), history-conditioned opportunities (value depends on the
   organism's or population's past), organism-organism coupling (shared
   pools, signals), and K action channels. The GENERATOR samples a
   feature set and parameters from a distribution whose support ranges
   from one-feature worlds to ten-feature worlds; the sample is
   PROCEDURAL by construction (seeded), and every world record carries
   generator version, seed, feature list, parameters, and the lane
   label. The existing WorldSpec worlds remain as calibration fixtures.
O  GRAPH ORGANISMS ("representation G", campaign-scoped, under
   archaeon/campaign6/organism/). Genome = a graph of small nodes (the
   same primitive classes as the affordance table: read/write, arith,
   logic, compare, route, I/O, memory, randomness) with typed ports,
   persistent per-node state, MODULES = subgraphs callable by reference
   (so one copy can be invoked at several sites), conditional routing
   nodes, and an evolvable interface (which ports a module exposes).
   Mutations, each small: parameter, edge rewire, node insert/delete,
   MODULE DUPLICATE (copy functioning structure), MODULE TRANSPLANT
   (insert the copy elsewhere), DISCONNECT (keep, unroute), RECONNECT
   (route a neutral subgraph in), INTERFACE change, and NEUTRAL GROWTH
   (add unrouted structure). Every child carries a diff record from its
   parent sufficient to reconstruct it. Proteus's VM and Representation
   B remain as substrates/controls, not the platform.
P  PRESSURE SCHEDULES as composable segment sequences (stable, step,
   drift, periodic, catastrophe, redistribution, migration, temporary
   opportunity) over any world parameter or over the fitness map; some
   schedules generated with NO label (a seeded random walk over segment
   types and magnitudes). Every lineage's exact pressure history is
   stored as the schedule id + the realized segment boundaries. Pressure
   arising from population behaviour or organism-made environment
   change is tagged ENDOGENOUS_PRESSURE at the source (the feature that
   changed because of an organism action), exogenous otherwise.
T  TELEMETRY. T0 = one fixed-length fingerprint per evaluation (action
   histogram over channels, state-transition counts, resources touched,
   objects changed, node/module execution counts, routing decisions,
   memory reads/writes, interaction and communication counts, survival
   transitions, environmental dependencies as the set of features whose
   state the organism read), plus genotype and phenotype structural
   digests; comparable by fixed distances to ancestors, siblings,
   peers, the behaviour library and the same organism in other worlds.
   T1 = a ring buffer of per-tick traces kept only around detector
   firings. T2 = the freeze packet (organism, parent, k ancestors,
   siblings/cousins, world state, pressure history, mutation chain,
   T1 window). T3 = replay/counterfactual instrumentation for A-G.
   Storage is tiered and costed: T0 always, T1 on firing, T2 on
   escalation, T3 on adjudication; the cost table is a return item.

3. DETECTORS AND ESCALATION
-----------------------------------------------------------------------
Eleven independent rulers, each with its own frozen threshold set in
Phase 0 on the calibration set, each returning FIRE / QUIET / UNABLE
and a score; no global score. Disagreement (some fire, some quiet on
the same event neighbourhood) and UNABLE ("none of the above") are
event classes with their own escalation. A single strong firing
preserves; multiple firings raise priority for deeper compute. The
escalation protocol executes steps 1-9 BEFORE any interpretation is
written (the packet has no free-text field until adjudication), then
replays A-G as compute allows, each with a receipt.

4. BLINDNESS TEST
-----------------------------------------------------------------------
Planted fixtures are constructed and interleaved by a seat that does
not operate the search (proposed: Nemesis plants, Rhadamanthus
adjudicates; both have the standing lanes for it). The planting seat
commits a SEALED registry (sha256 of the fixture manifest) before the
scatter; the operating seat (Archaeon) sees run ids only. The eight
fixture kinds of the directive are the minimum; the planter may add
decoys (familiar-looking mechanisms from other causes). At G6-3 the
registry is unsealed and the recall matrix is computed by the judging
seat: detection, preservation, false escalation, replay success, causal
recovery, classification accuracy, unknown-retention.

5. LANES AND VOLUME
-----------------------------------------------------------------------
Every run carries one of HUMAN_DIRECTED / LLM_PROPOSED / PROCEDURAL /
EVOLUTION_GENERATED / MIXED. PROCEDURAL = seeded samplers with no LLM
in the loop; EVOLUTION_GENERATED = worlds/pressures produced by the
population's own environmental modifications or by an evolved
generator; volume is counted in evaluations and the >= 25% LLM-free
floor is a hard budget line reported per phase. The lanes are never
ranked against each other by one score.

6. SEARCH AND LONG-RUN POLICY (as the directive states; here only what
   is decided)
-----------------------------------------------------------------------
Scatter: N_scatter runs sampled across generators with short depth;
deepen a run (or branch it) only on one of the ten triggers, with the
trigger and its detector receipt recorded as the branch's provenance.
Long runs: at least L_long runs to >= G_long generations with
exponential archiving (every generation to 64, then every 2^k) and
dense neighbourhoods around firings; stopped only for the four
reasons; a plateau is not a reason.

7. GATES (each a receipt on main; nothing after a gate runs before it)
-----------------------------------------------------------------------
  G6-0 observatory calibrated: replication of a C5 run through the
       observatory; planted-calibration recall stated with bands;
       thresholds frozen (digest); storage cost per tier measured.
  G6-1 generators proven: W/O/P fixtures pass; provenance schema
       validated; lane labelling enforced by code; Representation G
       qualification fixtures (as C5-03's, without fitness).
  G6-2 scatter executed with the observatory live and the LLM-free
       floor met.
  G6-3 blind recall adjudicated by the judging seat.
  G6-4 return delivered.

8. QUESTIONS PUT TO THE OPERATOR (defaults apply on silence)
-----------------------------------------------------------------------
  Q1 SEATS. Default: Archaeon builds the observatory backbone,
     Representation G and the three generators and asks (with
     deadlines, never blocking): Proteus to review G and the world
     primitives; Vivarium to run the scatter and long runs through its
     queue and to own the tiered store; Daedalus for engine/storage
     scaling receipts; Nemesis to plant blind fixtures; Rhadamanthus to
     adjudicate recall; Harmonia to review detector calibration;
     Mnemosyne for the ledger/PEW side. If a seat does not answer, the
     work is done by Archaeon and labelled so.
  Q2 RESOURCE CEILING (preregistered, the long-run stop rule): default
     14 days of M2 wall, 28 cores, 100 GB for T1/T2/T3 stores, long runs
     to 10,000 generations; scatter 400 runs; >= 25% LLM-free in
     evaluations.
  Q3 PHASE 0 FIRST. Default yes: no expansion search before G6-0.
  Q4 REPLAY DEPTH. Default: A-D on every escalation; E-G on
     multi-ruler events and every planted-fixture candidate at
     adjudication.
  Q5 UNKNOWN. Default: UNKNOWN_MECHANISM is assigned by the judging
     seat, not by me, and never downgraded by a later narrative.

9. WHAT IS NOT IN THIS PLAN
-----------------------------------------------------------------------
No hypothesis about what will emerge. No literature phenomenon as a
target. No promotion of Representation B or G to the platform VM. No
single interestingness score. No stopping on a fitness plateau.
