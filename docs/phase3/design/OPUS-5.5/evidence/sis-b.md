## 0. Bottom line (one paragraph)

This group is the program's HEREDITY-RULER FOUNDRY and its ACCESSIBILITY FOUNDRY, not a source of positive
findings about reasoning. The apparatus could genuinely reveal (a) whether byte programs CONSTRUCT copies of
themselves under a given write/birth physics, (b) which world-rule deformations (self-location, encoding length,
newborn energy, write-back rule, splice) gate copying, (c) which cross-step state carrier a tiny analog graph
recruits for a one-bit latch, and (d) that a hand-built procedure-reuse mechanism exists and pays but is not found
by small undirected search. It could NOT reveal heredity with any validated ruler until 2026-09-28, and even the
best certificate (CVT-R) was then shown to false-accept (W2-36). No world in the group ever required its organism
to do more than: hold one bit (Ares), emit a one-byte conditional transform decoupled from reproduction (NPE, BEE),
or classify density with a fixed table (Theophrastus). The single world with a genuinely higher demand (Crius
RELAY: infer a hidden procedure library, store, address, invoke, compose) never had its demand met by search.
Chiron built nothing. The most valuable outputs are the CHAIN OF RULER FAILURES and the validated instruments that
came out of them (P-11 randomized-victim assay, CVT-2/CVT-R and the R* repair, z8taint material certificate,
static write-back decomposition N9, Crius A-J content battery and gate v2, Ares edge/SCC carrier cuts,

## 3. Write-back physics (where the world, not the organism, did the work)

3.1 NPE pair tape BASE rule [IMPL-confirmed world.py:782-887]
- Two organisms' genomes are concatenated on a 2n tape; each half runs one slice from its own start with carried
  registers; then BOTH halves are written back into the organisms and each is mutated (`_mutate`) every epoch.
- The world's birth/lineage event is emitted INSIDE `if p11.predecessor_accepts(...)` (line 839), i.e. the world's
  lineage bookkeeping is the ruler. On acceptance the victim keeps its Org object (including registers and flags)
  and is relabelled: `org.pid, org.anc, org.oid = src.oid, src.anc, self.next_oid` (line 877). A "newborn" therefore
  inherits the destroyed occupant's register state [IMPL]; identity is not material (C9-D14: identity to birth genome
  0.97 after 1 epoch, 0.00 by 600 epochs, no lineage event; HIST PREFREEZE_STOP).
- P-11 is run on a private tape with a private RNG so the assay cannot perturb the world (good pattern; line 844-854).
- Side order matters: organism a runs first; a victim at side 0 can run on into the donor half and execute the
  donor's copier with the victim's context, overwriting the donor before it runs (Artemis RESULT s7; W2-36 "side-1
  order hazard"). 7ae3 itself is a side-1-only copier (W2-18 s2 item 3).

3.2 "Erosion" and ATOMIC [IMPL-confirmed c_atomic/run_cat.py:72-89; VERDICT.json parsed]
- Claim (c9x): BASE write-back is a ~5%/byte/epoch erosion, ~25x nominal mutation, that sterilizes lineages;
  ATOMIC (keep a half's new contents only if an accepted replication re-identified it as a child, else restore the
  pre-interaction genome and mutate) raises runaway (P-11 depth >= 20) from 1/80 to 46/80, p 4.4e-17 (C1). Across
  the other 15 specimens: 1/120 vs 0/120 (C2 NOT_CONFIRMED; only 2/15 donors could copy from a fresh state).
- The ATOMIC rule's keep decision is `if o.oid != oid` (line 80), and oid changes only when the predecessor
  acceptance rule fired. So ATOMIC = "the world keeps writes that its fidelity detector approves and discards every
  other write, self-writes included".
- N9 static decomposition [IMPL-confirmed wdecomp.py + wdecomp.json]: applying alternative write-back rules to the
  same 1,200 post-interaction tapes of 7ae3 vs random partners and fitting a Galton-Watson offspring law:
  BASE m=0.965 P_est 0.000; ATOMIC m=1.181 P_est 0.501; ATOM+SELF (keep own writes) m=1.135 P_est 0.375;
  WRITEGATE (keep iff partner wrote >= n/4, no fidelity clause) m=1.001 P_est 0.003 (ZERO context; RANDOM context
  similar). The difference between ATOMIC and WRITEGATE is the fidelity clause. W2-18 P07 [REPORTED]: "about 75% of
  ATOMIC's effect is the world's fidelity clause; under ATOMIC the world's detector, not the organism, maintains copy
  fidelity"; and BASE "erosion" is not an extra mutation process but a one-sided copy op unmaking its carrier from
  the other side, leaving BASE branching near-critical (m ~ 1).
- Reading for Phase 3 [INFER]: every NPE result run under ATOMIC after 09-25 (W1, P2, ARC3, X-MAT, X-TASK-GATE
  design) studies organisms living in a world that performs error correction for them using the experimenter's
  replication detector. That is not a defect if declared as a treatment; it was not declared as one.

3.3 BEE write/birth physics [IMPL-confirmed world.py:540-556, vm.py]
- Birth viability is a WRITE-COUNT rule per physics: ENDOGENOUS_COPY all L bytes, ENDOGENOUS_PARTIAL >= 1 byte
  (chimeras), OVERWRITE/CONSTRUCTIVE/PAIR_EXECUTION >= L/2. Null rewrites (partner rewritten as exactly itself) are
  not births. The world does not consult a fidelity detector to decide births (contrast with NPE ATOMIC) but the
  genetic label does consult resemblance.
- Chemistry makes replication cheap by construction: undefined opcodes execute as 1-step NOPs (~80% of byte values),
  LDIR with C=0 sweeps 256 bytes. Grounding P8 [REPORTED, GROUNDING_REPORT.md grep-confirmed]: base 8/300 spontaneous
  SR; LDIR off 0/300; LDIR cost x4 0/300; undefined->HALT 0/300. A random tape is a replicator with p ~3e-5
  (dossier). The "CONFIRMED_CAUSAL" spontaneous SR is therefore an ablation-confirmed property of the chemistry's
  engineered basin, not of evolution.

3.4 NPE mutation-operator physics (genotype-phenotype map) [REPORTED, ACCESSIBILITY.md s0 opened; W2-8 D4]
- 7ae3 (Z8_64, OPERAND): opcode positions never mutate in place; "the program skeleton is frozen for the lifetime of
  a lineage; only copying can change it"; a random genome has ~8-9 operand bytes, ~34 effective mutations per 2,000
  epochs. (W2-18 P05a corrects: second bytes of ED-prefixed instructions are operands and do mutate.)
- ffa6 (Z8_SLOTTED): the operator is ignored; 87% of "OPERAND" mutations hit opcodes; ~239 effective mutations per
  2,000 epochs (~8x). Every 7ae3-vs-ffa6 contrast is confounded with mutation supply.
- 72 h non-pair physics mutated only at birth: random populations that never reproduced never varied (S1-A: 907 FREE
  runs, 0 births; 114,485 BIRTH calls with no pending allocation) [REPORTED].

## 4. Neutral paths, accessibility and search

4.1 Crius: existence vs accessibility, by construction [IMPL-confirmed PARTS.md, terminal review]
- Value landscape of the reuse mechanism on gate streams (paired): recorder alone -0.001 (0/10 streams), invoker alone
  -0.002 (0/10), recorder+invoker +1.138 (7/10) at 26 edits, planner alone -0.057 (0/10) at 41 edits, full
  P_REC_INV_PLAN +15.974 (10/10) at 47 edits from the 19-instruction enumerator P_BASE.
- Search: (8+24) truncation, 1-3 mutations + 30% segment splice of length 1-8 (IMPL-confirmed c2c.json), 300
  iterations, 3 seeds, 7,208 candidates/run; 36 runs across rungs A-D: 0 reproducible acquired-state candidates,
  0 complete mechanisms, 9 "selectable" partial steps at +0.0004..+0.0011 with 0 solved delta, inside the
  neutral-edit null (0-3 of 8 neutral edits also pass the same rule).
- Splice donors (rung D): of 1,771 PART-fragment children, retained fragments carried constants and digit loops; the
  only fragment that paid was a bare `CONST R6, 4`. INFER: the splice length cap (8) is shorter than any working
  typed link (26 and 47 coordinated inserts), so the donor experiment could not transfer a link intact.
- Artemis R-07 [REPORTED; code off-repo at ubu002, only REPORT.md committed]: 44% of 1,440 one-mutants along neutral
  walks are neutral, 52% broken (mostly non-terminating loops), 1.6% beneficial (all enumeration-order tweaks);
  neutral walks drift AWAY from the ledge (edit distance 26 -> 36-37); a single-insertion path exists from P_BASE to
  the full mechanism with 41 neutral inserts, a +1.23 ledge, then a +12.6 final insert (confirmed on 10 fresh
  streams); the ledge shrinks to +0.645 on fresh streams. Conclusion: neutral connectivity is present; phenotype bias
  / direction is missing. The essay's ruler value "accessible path length undefined" is wrong (CORR, not applied).
- Two disagreeing readings agree on the fact (search did not reach it) and disagree on why. Under the axes this is
  search_insufficiency with an open mechanism, not evidence of an accessibility barrier in the map.

4.2 NPE: acquisition landscape [REPORTED, ACCESSIBILITY.md opened]
- From random material (RANDOM STOCK/DENSE/SHAM, PLANT; 400 genomes per row): 0/3,200 genomes and 0/6,400 one- and
  two-step mutants COMPETENT (P-11 L2 screen). Block copy EXECUTES from a fresh start in 35-59% of dense/planted
  genomes; the missing piece is register setup pointing the copy at the partner half.
- Around competent genomes: one-mutants remain COMPETENT 0.72-0.80, two-mutants 0.56-0.66: competent copiers sit on
  broad neutral networks; losing the copy instruction is a trap.
- best_fid_final is not an accessibility proxy: SHAM (acquires 0/96) has the highest share of random genomes with
  fid >= 0.5, from random block writes landing donor-like bytes.
- Missing baseline [HIST, dossier s6]: whether the pair soup searches better than a neutral random walk for first
  donor appearance. Pilot ratio 1.75, p 0.20; WP-9 (~9 CPU-h) never ran.

4.3 NPE barrier geometry (non-pair physics) [REPORTED, CAMPAIGN_REPORT.md opened]
- Four serial barriers: no search (mutation at birth only), copier cannot self-locate, the ALLOC->copy->BIRTH op chain
  is too rare (6 bytes), newborns starve under energy economies. Relieve all four -> spontaneous replication from
  random bytes (C-DENSE 13/40 vs 0/40); remove any of the first three -> it disappears (C-ABLATE). W2-9: C-DENSE
  ROBUST for "certified replication occurs", FRAGILE as heredity (5/13 cells have exactly 1 event; 151 events in
  42,934 births; >=2 events 8 vs 0 fails both frozen bars).
- This is the cleanest "world deformation ladder" in the group: a sequence of declared world-rule relaxations, each
  with a frozen confirm, mapping where construction becomes possible.

4.4 Ares: basin vs peak, and a clip [IMPL-confirmed basin.json parsed]
- Hand-wired sweep: keep carrier best 33.75 at keep = 0.98 (the clip in alter_keep; the curve is still rising:
  27.8 at 0.96); recurrence reaches 40.0 (the cap) for self-weight >= 4.0, viable fraction 0.61 vs keep 0.12.
- The cycle-2 headline "evolution took the wide basin, not the higher peak" (DESIGN_C2 premise keep 33.75 > recurrence
  24.56 at weight 3.0) is contradicted by the seat's own file: recurrence has BOTH the higher peak and the wider basin.
  "Recurrence wins on speed" (median time-to-threshold 10 vs 30) stands as reported; cause open. Training fitness
  saturates to 90% of cap within 2.5-6 generations in every cycle-2 arm (Artemis R-29, REPORTED), so path gradedness
  is invisible at a 5-generation logging grid.

## 9. Most informative experimental geometries in this group

1. Matched randomized-victim RE-EXECUTION on a private tape with a private RNG (P-11): the right shape for
   "did this agent's writes cause this content", and it leaves the world trajectory untouched.
2. Counterfactual variant transmission (CVT): perturb the PARENT, track offspring differences over >= 2 generations
   with common random victims. Perturbing the parent is what separates heredity from construction.
3. Static rule decomposition (N9): apply alternative world rules to identical post-interaction states and estimate a
   branching law. Cheaply attributes a lineage effect to world vs organism.
4. Declared initialization axis (NPE reset_axis CARRIED/ZERO/CONST/RANDOM/SCHEDULE; BEE reg_world ZERO/P90/P75):
   scaffold dependence and withdrawal (ABRUPT/GRADUAL) as world treatments. BEE K1 (partial scaffold 93/200 vs
   always-scaffold 18/100) is the cleanest payoff-dependent signal from this axis.
5. World-deformation ladder with frozen confirms (NPE non-pair: search, self-location, encoding length, newborn
   energy): relieve all, then remove one at a time.
6. Existence-vs-accessibility split (Crius): constructive PARTS with a measured value landscape, separate positive
   (world fact) and causal (channel fact) controls, paired foothold test vs neutral-edit null; plus a path census along
   insertion routes (R-07).
7. Present / absent / shuffled world modes with per-hidden-variable balanced seeds (Ares), single-carrier and
   carrier-exclusion arms.
8. Contingency battery for coupling (BEE v3: ON vs YOKED vs SHUFFLED vs RANDOUT vs DELAYED vs IRRELEVANT ...).
9. Swap / transplant at three distances (R-12: own library 50, same-world other lineage 28, empty 2, foreign world 1;
   NPE X-DONOR-SWAP: competence belongs to the genome x cell pair).
10. Cross-engine rebuild of a mechanism claim (REPL-01): showed label vs material divergence that neither engine
    could see alone.

## 10. Design implications for Phase 3 (each tied to evidence)

1. Heredity must be certified by perturbing the parent and following >= 2 generations, with an inheritance clause,
   a lineage-fidelity floor and K >= 8 seeds with an INDETERMINATE band; certify on a ground-truth panel that includes
   painters, rescue mutants, half-blank non-reproducers, complement, guest-in-host, two-tape and budget-limited
   copiers. (Artemis panel; W2-36.)
2. World physics must never read the ruler. Birth, relabel and write-back rules that call the replication detector
   (NPE ATOMIC; lineage events inside predecessor_accepts) make the world supply fidelity and make depth a ruler
   artifact. If a world-side error-correction rule is wanted, declare it as a treatment and decompose it (N9).
3. Measure where the event happens, before any world variation operator, on a private replay (Z80A-D05 vs P-11).
4. Identity and descent must be material (byte provenance), never slot, oid, resemblance or a label that survives
   overwrite (C9-D14; DEF-BEL-008; REPL-01 93 vs 0; X-CONTENT 13-25%).
5. Every kill test ships with a real-data planted positive showing the readout can return the non-null outcome, run
   as code before freeze (REPL-01 K3, REPL-02 0/50, X-TASK-GATE CD, 72 h anticheat; W2-18 P08: prose lessons did not
   hold, the running check did).
6. Prove organism capacity constructively before search (Crius PARTS, CT_UA, Ares 2-edge latch, BEE 8-byte
   replicator) and prove world demand with an ablated-capability baseline. Ares W4 was solved by 2 edges; graphworld
   by abstaining; Theophrastus is a solved benchmark. A world whose demand is one bit cannot reveal reasoning machinery.
7. Couple the target computation to reproduction inside the world, and test that coupling with a contingency battery
   (YOKED is the decisive control). In NPE the task was never on the reproductive path; BEE v3 coupled it and obtained
   maintenance, not acquisition beyond ECHO.
8. Separate existence, accessibility, maintenance and acquisition as distinct endpoints (Crius; BEE coupling).
9. Treat the genotype-phenotype map and operator semantics as first-class world parameters and report effective
   mutation supply per cell (7ae3 frozen opcode skeleton vs ffa6 87% opcode hits; BEE 80% NOP + LDIR C=0 basin;
   1-byte aliases moved acquisition 1/64 -> 39/64). Many "physics" effects were encoding effects.
10. Neutral connectivity is not the lever; direction/phenotype bias is (R-07: 44% neutral, drift away from the exit).
    Always run a neutral-walk baseline for first-appearance claims (WP-9 never ran).
11. Never select on held-out data; report held-out of the training-selected champion (Ares D1: W14 shuffled floor
    13.47 reported vs -2.38 clean).
12. A ruler's context must equal the world's reproductive context (zero-state screen inside CARRIED worlds; C-ZERO
    built by its screen; N13).
13. Every declared factor must be shown to reach the scorer in every crossed cell; competence caches must key on
    (genome, niche, task, seed) (W2-8 D1; COEVO overrides read_order).
14. Development rungs (Chiron/R-12): persistence must be compared against an equal-information context arm that may
    extract, at matched bytes and compute in a frozen currency; held-out world family frozen and hidden from any
    generator; lineage count per condition fixed before CDE-0; frozen writer hash if an LLM writes artifacts.
15. Substrate closure audit: list the channels an organism can possibly use; "nothing outside the enumerated
    channels" is then a non-result (Ares).
16. Evidence custody: immutable copies of per-event data, no gitignored decisive files, no host-local-only results,
    no off-repo code for cited results, no scheduled tasks that can relaunch production (run 3; R-05; R-07/R-12).
17. Pair-tape-style interaction physics carries order hazards; randomize or symmetrize execution order and report
    side-specific rates (Artemis RESULT s7; W2-36).
