# Ranked unknowns that can change the recommendation

**2026-10-01: 15 unresolved questions, ranked by dependency and expected decision value, not by promised scientific excitement.**
The recommendation is already A0-first D1-D5. The open question is whether that recommendation survives direct operational evidence, not whether another operator must approve its wording.
Actual implementation, spending, custody, host access and bounded run releases remain separate gates.
This completion read only the permitted ASTRA requirements/report/companions and the shared deliverable specification, not other architects' conclusions; it ran no new research or campaign.

## How to use this queue

- Owners below are **functional roles to staff**, not assigned seats, named people, availability claims or authorization to act. Independent checker and custodian responsibilities require genuine access/authorship separation.
- Costs are **proposed bounded investigation envelopes**, in engineering person-hours (eng h), core-hours (CPU h), and scientific review hours (review h). They are judgments, not measurements or quotes.
- Each investigation must fit its owning MVP lane/stage's remaining allowance. Shared work overlaps rows, so do not sum these estimates or add them to the campaign budget; later-family/Q6 work needs a separately released plan.
- Direct evidence means native bytes, traces, control outcomes, independent truth, signed intervals, access records and actual resource receipts. Prose, a file count, a model vote or a PASS flag does not close a question.
- A proposed experiment becomes confirmatory only after its native semantics, endpoint, threshold, units, custody and analysis are frozen. Unavailable evidence stays unresolved; no fabricated run closes a row.

## Decision dependencies, not fifteen parallel workstreams

1. **Preflight and S0:** Q01-Q03 determine native feasibility, independent custody and resource realism. Q14 review allegations can nominate small control tests but cannot replace direct qualification.
2. **Before a natural negative:** Q04-Q06 must support applicable calibration, reachable/selectable paths and valid independent units; a convenient native positive is not a class-limit certificate.
3. **After the Q2 decision:** select the cheaper unresolved Q07 or Q09 discriminator, with Q08's independent candidate controls and Q10's accounting. Do not promise both downstream confirmations.
4. **Expansion:** Q11 needs a distinct physical prediction; Q12 needs process identifiability and conditional authorization. Q13 can narrow interpretation without erasing a valid ordinary mechanism.
5. **All stages:** Q15 tests whether infrastructure and attention actually serve a scientific decision, with costs and correction dependencies visible.

Question ranks are not lane IDs: for example rank 07 concerns lane Q4. No functional owner has been assigned to a historical seat by this ledger.

## Resource and interpretation boundary

The campaign ceiling is **480 core-hours = 372 during days 1-90 + 72 conditional + 36 protected audit**, with **0 GPU**, **30 kWh**, and **20,000 optional input-plus-output campaign tokens**.
First-90-day labor is capped at **320 engineering hours** including protected independent work, and **21 scientific-review hours**; conditional labor/review is not silently included in those figures.
All numbers are planning caps or estimates, not measured performance or authorization. The routine experimental loop makes zero external inference calls; a question in this queue does not automatically spend tokens.
Local/cloud rates, dollar cap, host/energy boundary, staffing, run authority and actual custody evidence remain unresolved operational gates.
The latest user instruction permits publication planning and explicitly requests a design-package commit; it does not authorize external scientific publication, wiki contribution or disclosure of active holdouts.
