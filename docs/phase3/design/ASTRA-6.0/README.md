### Review corrections used by the completed companion documents

The final MVP and portfolio contain the corrected detailed specifications. Offline exact arithmetic is tested; a native A0 implementation and its qualification are not delivered by this design package.
The corrected planning contract is:

- **W3-R:** three 75%-reliable cues; conditionally independent majority accuracy 27/32; low/high query prices 1/32 and 1/8; correlated c2=c3 yields no-query optimum at positive prices. These are analytical targets for independent native verification, not experiment results.
- **Q4:** delta*=0.02, with separate qualification/power and likely pilot-only scope. Do not reuse Q2/Q3's 0.20-effect power illustration.
- **Q5:** 18 candidate-specific cells plus 2 paired rescue cells per founder block, including candidate-specific sham/donor obligations; rescue adds observations, not independent n.
- **Reachability:** per-founder zero-hit bounds must not be divided by whole-assay sensitivity. Native curated-mechanism qualification is not a class-wide limit on unseeded development.
- **A0 and search:** the MVP specifies exact address/offset/link semantics and hand traces, still requiring independent native execution. Eight of 32 persistent slots use bridge search, accepting neutral worse-cost proposals with probability 1/2; this is an allocation, not a recovery threshold.

Historical text is not a license to execute stale numbers. Any remaining mismatch between an executable manifest and the corrected contract must block release until reconciled before outcome exposure.
