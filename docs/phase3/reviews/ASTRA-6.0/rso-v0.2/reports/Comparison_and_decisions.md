# Comparison and decisions: Fable, ASTRA, and ChatGPT 5.6

## 1. Verdict and evidence asymmetry

**Fable made the most important experimental contribution in this source set:
an executable specification-failure corpus. ASTRA supplied broader causal and
custody safeguards, but did not execute them. ChatGPT 5.6 correctly combined
several principles and withdrew strong-recursion authority, but its supplied
package does not contain the executable harness it claims.**

This is neither a vote among architects nor a defense of the earlier ASTRA
design. Sources and exact pins are in [the index](../README.md). Detailed
source spans are in the [Fable comparison](../research_notes/Wind%20tunnel%20design%20hardening/fable_comparison.md),
[design audit](../research_notes/Wind%20tunnel%20design%20hardening/design_audit.md),
and [test audit](../research_notes/Wind%20tunnel%20design%20hardening/test_plan_audit.md).

## 2. What Fable actually established

Fable's run 2 reports a fixed-constructor library learner passing all six
registered conjuncts in 24/24 replicates. Median B acquisition cost falls from
313.5 to 20.5 task observations; reported lifecycle medians are 1045.5 versus
171.0, including development. These are source-reported medians, not new local
measurements or quantities assumed additive. The inherited enumeration is
unchanged; learned entries and their pairs are tried before that enumeration.
Thus the tested conjunction does not separate useful library reuse from the
stronger intended recursive-constructor interpretation.

It is wrong to discard that result merely because the organism is conventional.
It is equally wrong to call it a refutation of every nested-learning criterion:

- B/D/E are selected composite kinds built from learned parts. C principally
  tests the B kind or a narrower family, not arbitrary fresh structure.
- The sham improves BUILDER's median B cost from 20.5 to 12.0. Equal entry count
  did not produce a neutral-damage control.
- U_TRANSFER lacks a dedicated fire test. Four clauses never become false in
  the registered cells. A reset-omission probe changes MEMORISER's savings but
  not its whole-test rejection; reset-only false promotion was not established.
- The U contrast partly uses a deadline tied to intact cost and a bad default
  score on failed construction. That is not an isolated learner-law assay.
- Task-count savings omit some host work: candidate-list construction,
  function-class comparisons and order ranking. Report those costs separately.
- D/E start again from post-A state. Repeated transfer opportunities are not
  evidence of successive B -> D -> E compounding.

Run 3 reports STRATEGIST passing five conjuncts 24/24 and PROVENANCE 23/24;
median B cost is 398.0 versus 57.0. Its state selects among 32 inherited orders
over 660 templates. However, curriculum AND component sharing changed from
run 2. Fable's crossed exploratory probes withdraw the simple claim that
stricter freshness alone admitted the smaller organism. Read that correction
with the result; do not keep the headline while dropping its counterevidence.

The synthetic permutation-key assay reports retained-information estimates,
but Fable withdraws its CONSTRUCTED/WITHIN_SELECTION_BOUND origin classifier.
Multiple indices can defeat the proposed single-index exclusion. The old
receipt remains an immutable historical output, not a current origin verdict.

Local provenance checks in the research note matched the four script hashes
to receipts and their stated preregistration commits. Such continuity does
not prove the absence of pre-registration exposure. No Fable run was rerun
here, no independent host/author replication occurred, and no mathematical
rederivation of the key-information bound was performed.

## 3. What our earlier ASTRA review must change

1. **Replace the promised unspecified positive.** We budgeted a "genuine
   authored learned-updater constructor" without defining one. The new finite
   rational control defines an attainable narrower positive. It is not a
   strong-recursion positive and cannot justify budgeting that stronger result.
2. **Mediation is not origin identification.** Blocking V, freezing U and
   swapping U can identify a pathway under valid interventions. A fixed
   interpreter carrying an acquired family prior can pass those tests too.
3. **Freshness requires a relation table.** Different seeds, components,
   grammars, curricula and generator families are different changes. Demanding
   universal disjointness can destroy the positive as well as the counterfeit.
4. **A thin proposal is not a small measured workload.** Retract ungrounded
   day-by-day and percentage precision. Price concrete work packages and
   preserve independent checks before expanding architecture coverage.
5. **Do not force R3 into R0 by familiarity.** Preserve its plasticity/search
   hypothesis separately. R1/R2 share code only while native semantics survive.
6. **Operational terminology cannot repair non-identification.** No layer count,
   object allocation, source-write ancestry or new memory is a recursion test.
7. **Counterfeit negatives require legitimate admissions.** Libraries, learned
   optimizers and flattened equivalents can be true positives for bounded
   capabilities. A pedigree blacklist would be a new failure, not hardening.

## 4. What the meta-analysis improves, and what it leaves open

Retain D's thin federation, ORDER/RETENTION/ORIGIN separation, two-door entry,
repair/cold split, physics-specific ruler status, serious R0 competition, and
P's claim-specific R8 verdicts. Strong recursion being unqualified is the
correct current ceiling, not evidence that recursion is impossible.

Repair these gaps before promoting the specification into an instrument:

- D's runtime contract lacks explicit reset closure. Snapshot fidelity and
  WAIT/DISTRACT do not establish erasure of forbidden history.
- Capacity and neutrality occur in its gate list but disappear from its stored
  facet list. v0.3 makes requirements proposition-specific and references both.
- The L1 ceiling without an exact restricted-class bound conflates class
  exclusion with robust named-comparator or local causal evidence.
- No artifact-bound requirement matrix, independent positive truth source,
  sham-equivalence margin, power model or complete-run custody seal is supplied.
- H9 demotion and independent challenge must begin with the first checker,
  not wait for days 76-90. Labels such as ACTIVE/NEXT are proposed portfolio
  decisions, not evidence of available native runtimes.
- D line 24 compresses ASTRA's proposed cargo attack into "showed". Read it as
  analytic construction, not an executed escape. D line 288's harness-delivery
  assertion remains unverified for the supplied directory.

## 5. Resolve disagreements explicitly

| Question | Decision, not a compromise average |
| --- | --- |
| Must every robust claim have an exact cheap-class bound? | No. Whole-class exclusion needs an applicable proof; a named comparison needs frozen strong comparators and valid inference. Neither substitutes for the other. This supersedes the test-audit note's retained blanket L1 ceiling. |
| Is nested improvement strong recursion? | No. Keep operational, world-order, mechanism and stronger origin propositions separate. Strong recursion has no qualified positive here. |
| Internal-only versus immediate internal/external campaign? | First qualify one boundary. Build a tiny external route when it tests a named reset/attribution assumption. A real 2x2 follows only with physical controls and budget. |
| R3 or R4 next? | R3 for an operator-matched reach question; R4 for a locality/ontology defect; R5 for distributed custody. No comparative result selects a universal runner-up. |
| Retire R7? | Retire the standalone commitment for now, not the scientific possibility. Reopen only for a prediction rank/capacity controls elsewhere cannot express. |
| 65/25 versus 30/40 versus 35/30 allocation? | The buckets and denominators differ. Do not average them; estimate absolute work, oracle effort and compute first. |
| Is the new checker the missing harness? | No. It validates a smaller explicitly named contract domain; original harness review stays BLOCKED. |

## 6. What the new bounded implementation adds

The [reference harness](../reference_harness/README.md) instantiates exact
retention/no-carry bounds, finite search distinctions, a reachable queue leak,
continuation loss, biased re-encoding, scoped evidence refusal and transitive
invalidation. Five source faults are compiled in memory and subjected to
assertion probes; syntax/import errors do not count as kills.

The rational updater learns beta, builds eta=1/(beta*x), then solves both
fresh +/-1 targets from the only task-dependent gradient input. All eight
beta/x/target cases pass; U swaps change outputs, a fixed U removes the V-history
effect in the tested assay, and a deliberate bypass breaks that invariance.
The flattened program AND sign-gradient R0 also solve all eight cases. The
accuracy advantage over R0 is exactly zero. The example therefore strengthens
the positive-admission test while weakening any novelty/economic interpretation.

This is development-time exact enumeration, not preregistered science or
independent authorship. It does not establish a scientific cargo detector,
cross-physics neutrality, full resource accounting, or native reset closure.
The [validation receipt](../VALIDATION.md) records actual tests and remaining
gaps rather than letting these illustrative programs inherit the whole charter.
