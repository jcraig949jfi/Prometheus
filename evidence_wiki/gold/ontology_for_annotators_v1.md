# Prometheus canonical dimension vocabulary (V1 annotator handout)

Definitions only. No prior assignments are shown anywhere.

## MECHANISM

- `accessibility_geometry` — Navigability/gradient structure of a search landscape (paths, degradation, needles)
- `algebraic_identity_artifact` — Apparent coupling from shared definitions/observables/units
- `calibration_anchor` — Known-true structure used to validate instruments end-to-end
- `chance_floor_calibration` — The attainable-without-reasoning floor/ceiling of an instrument or gate
- `circular_verification` — Verification consumes an assumption of the tested claim or a verdict-correlated filter
- `confound_conditioning` — Stratification/conditioning dissolving or rescuing an effect
- `denylist_leak` — A denylist/filter admits everything it fails to enumerate; allowlist discipline
- `instrument_tautology` — The instrument measures itself (classifier=menu, gate-pass rate, exposure x competence)
- `interface_contract` — Consumption paths/interfaces as the binding constraint on what can be used
- `latent_affordance` — Future reachability / mutational affordance as the real object, distinct from current behaviour
- `memorization_surface` — Gains from memorization/format/surface features rather than structure
- `native_vocabulary` — Operators/handles must be native to the objects; generic verbs/labels are silent
- `negative_evidence_reuse` — Preserved failures/exclusions become productive inputs downstream (or fail to)
- `null_model_discipline` — Permutation/reference nulls deciding whether signal is object-level
- `projection_equivalence` — Equivalence under a projection/representation conceals differing latent structure (fingerprints, feature geometry, marginals, identity-level views)
- `provenance_integrity` — Pipeline/data defects as epistemic events (truncation, transport, desync, freeze checks)
- `recursive_structure_reuse` — A successor learner reuses previously learned structure/decompositions
- `seed_instability` — Effect fails replication across random seeds
- `selective_retention` — Principled retention/forgetting of memory items vs recency/arbitrary eviction
- `transfer_mediation` — What carries or blocks transfer across substrates/relations/families
- `unit_of_inference` — Statistics computed on the correct unit (lineage, cell, cluster, block)
- `wrong_population` — Statistic measured on one population quoted as a property of another (scope, windowing)

## SUBSTRATE CLASS

- `action_corpus` — Theseus/aporia recorded action-outcome corpus (h4, d2, d3)
- `computational_basis` — Agent D-3/D-4 frozen computational bases (S1-S4)
- `db_pipeline` — Data-layer pipelines and stores
- `feature_tensor` — Harmonia cross-domain feature tensor space
- `foundry_ecology` — Serendipity Foundry artifact ecologies (D6-D8)
- `game_world` — Ludus game worlds and stochastic-stopping families
- `grammar_world` — Incubation grammar/concept worlds (v1-v3, gv2)
- `kernel_substrate` — Sigma-kernel claims substrate
- `knot_corpus` — Knot invariant data
- `llm_probe_band` — LLM probe band / model-zoo profiling instruments
- `lmfdb_arithmetic` — LMFDB arithmetic objects (EC, NF, L-functions, modular/Artin)
- `program_ecology` — Executable-artifact ecologies (D-5 search, Ergon generations, seam work)
- `residue_corpus` — Failure-residue/scrap corpora used for routing and completion

## FAILURE CLASS

- `chance_floor_error` — Chance floor/ceiling miscalibrated
- `circularity` — Conclusion consumed by its own premises
- `confound` — Effect explained by a lurking variable (conductor, host, missingness)
- `instrument_artifact` — Artifact of instrumentation, not the world
- `memorization` — Memorization masquerading as capability; anti-transfer
- `navigability_collapse` — Space exists but offers no navigable paths
- `pipeline_defect` — Data/transport/parse defect contaminating records
- `replication_failure` — Does not replicate across seeds/implementations
- `scope_inflation` — A scope claim treated as a measurement; aspirational scope
- `structural_silence` — Correct instruments find nothing; silence is structural
- `tautology` — Instrument or statistic measures itself
- `transfer_failure` — Result fails to transfer across families/substrates
- `wrong_population` — Sample quoted as population; windowed sampling
