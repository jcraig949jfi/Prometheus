--------------------------------------------------------------------------------
4. THE TWO LEAKAGE EVENTS (preserved, protocol-handled)
--------------------------------------------------------------------------------
1. Haiku controls violated the evidence_wiki access boundary in 7/15
   attempts (sonnet: 0/12), despite explicit instructions; cells
   quarantined, re-run once with byte-identical prompts, one cell (T10
   haiku) excluded after a second violation. Lesson: condition isolation
   (and any future access policy) must be HARNESS-enforced for weak models.
2. THE DISCOVERY: designer agents cited operator memory doctrine that
   exists NOWHERE in the repository. The agent harness injects the
   project's auto-memory into every session, subagents included. Both arms
   received it equally (parity held), but it pre-seeded condensed gold on
   ~5 tasks, inflating control recall -- the wiki's measured advantage is
   a LOWER BOUND. More important than the bias: Prometheus already runs an
   implicit memory channel that shapes design behavior -- unlogged,
   unversioned, provenance-free, single-operator, single-machine. The
   Evidence Wiki's V3 case is now precisely about replacing that channel
   with a provenance-preserving, shared, queryable one.
