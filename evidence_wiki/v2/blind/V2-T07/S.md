# PROPOSAL V2-T07 (arm)

## Hypothesis
The local database mirror's stored derived quantities for arithmetic objects (regulators, L-function special values / leading coefficients, and related analytic invariants such as Sha, Tamagawa products, and periods) are internally consistent with the conjectural formulas that relate them (principally the Birch–Swinnerton-Dyer formula for elliptic curves, with the same audit pattern extendable to Beilinson/Deligne-type special-value conjectures wherever the mirror carries the required ingredient fields) — but ONLY where the compared quantities were computed by genuinely independent methods. Where one field was back-solved from another using the conjectural formula itself, "consistency" is a provenance artifact, not evidence for the conjecture, and the audit's first job is to separate these two populations before scoring anything.

## Motivating evidence
`aporia/docs/CYCLE_150N_MAGNITUDE_TAUTOLOGY_2026-08-24.md` is a direct, in-repo precedent for exactly the failure mode this audit must avoid: a prior campaign (mutation generators c4/c5 over `theseus/corpus`) paired invariants including `regulator` and `conductor` and found the "holds" outcome was 100% explained by which two catalogues were being diffed (regulator, a small float, scored `abs_diff_le_N` = 1.0000 against everything; conductor, a 4-5 digit integer, scored 0.0000 against everything) — a units/scale confound, not a mathematical signal. The campaign was killed at pass 1 on this tautology. Any new audit that computes absolute or ratio agreement between stored quantities living on different natural scales (e.g., a regulator vs. a conductor-sized quantity, or a raw special value vs. a normalized period ratio) must inherit this lesson directly.

`roles/Aporia/RESPONSIBILITIES.md` documents a live, named void in the same data family: "Artin ↔ lfunc gap — 798K reps, 0 Artin L-functions in data ... Open — needs LMFDB Artin L-function data." This tells us the local mirror is a partial mirror of LMFDB-style content with documented coverage gaps, and that at least one class of "should relate but the related field is simply absent" case already exists and was caught by absence, not by false agreement. This is the sibling risk to the magnitude confound: a naive audit that treats "no comparison possible" as "no violation found" would silently rack up vacuous passes on exactly the rows where the mirror doesn't yet carry the counterpart quantity.

Two internal search passes (regulator/BSD/special-value terms, "database mirror"/"LMFDB") surfaced no existing pipeline in the repo whose explicit job is to check stored regulator/special-value pairs against BSD-type formulas — `techne/cartography/store/claims.jsonl` samples inspected turned out to be literature-claim adjudication (evolutionary computation papers), not a math-invariant store, and `aporia/q100/REGISTRY_L3.jsonl` catalogs AI-reasoning open problems, not arithmetic invariants. This is a genuine information-budget-bounded search (11/15 ops used, 4/12 documents opened) and is reported as a finding, not a proof of absence: the audit design below opens with an explicit schema-discovery phase for this reason.

## Prospective predictions
- P1 (provenance split exists): the local mirror's ingestion metadata (or absence thereof) will let us partition rows carrying both a regulator-type field and a special-value-type field into "independently computed" vs "back-solved / one derived from the other under the conjecture" vs "provenance unknown." We predict the unknown bucket is non-trivial (>10% of joinable rows) given the mirror's partial-LMFDB-mirror character already documented for Artin L-functions.
- P2 (real-test population, if non-empty): among rows classified independently-computed on both sides, the BSD-type quotient (or analogous relation) computed from stored fields will cluster near the conjectured value (1, for the basic BSD quotient with Sha assumed 1) with a residual distribution whose spread reflects the mirror's documented numerical precision, not gross disagreement — because these are well-tested cases in the literature the mirror draws from.
- P3 (confound canary): a deliberately magnitude-mismatched control pairing (e.g., stored regulator vs. stored conductor, or vs. any field on a categorically different scale) run through the SAME agreement statistic used for P2 will reproduce the all-0/all-1 saturation pattern from CYCLE 150-N, confirming the statistic is scale-sensitive and validating that a genuine P2 pass is not an artifact of the same confound.
- P4 (coverage-gap honesty): the fraction of rows where the conjecture-relation cannot be evaluated because a required field is absent (the Artin-lfunc-gap pattern) will be reported as its own rate, separately from both "passed" and "failed," per the vacuous-reading discipline (a structural zero is not evidence of agreement).

## Experiment
Phase 0 — Schema discovery (capped, time-boxed): enumerate the actual fields present in the local mirror for arithmetic-object records that carry any of {regulator, L-function leading coefficient / special value, Sha, Tamagawa numbers, real/complex period, torsion order, rank, conductor}, and for each field, whatever provenance/method metadata exists (computation method, source dataset, ingestion date, "derived_from" pointers). Output: a field inventory table and, critically, a determination of whether independent-vs-back-solved provenance is recoverable at all. If it is NOT recoverable for a field pair, that pair is excluded from Phase 2 scoring and reported only under P4/coverage.

Phase 1 — Row inventory and stratification: for each object family with a usable field set (expected primary family: elliptic curves, since the mirror's known BSD-relevant ingredients — regulator, conductor, torsion — appear together in the CYCLE-150N corpus), count joinable rows (both sides of the relation present) stratified by rank (0, 1, ≥2 or unknown), by provenance class (independent / back-solved / unknown), and by the precision/format the value was stored at (fixed decimal digits vs. exact algebraic vs. floating approximation). Sampling must NOT be alphabetical-prefix or file-order (per house sampling-antipattern precedent); stratify by these strata and sample proportionally with a minimum stratum n before any statistic is computed on it.

Phase 2 — Conjecture-formula check, independent-provenance rows only: compute the BSD quotient (or the relevant analogous ratio for any non-elliptic-curve family the mirror supports) from stored fields and record the relative residual `|quotient - 1| / 1` (or the family-appropriate normalized form — never an absolute difference across heterogeneous scales). Report the residual distribution per stratum (rank, provenance class, precision class).

Phase 3 — Confound canary (control, run on the SAME code path as Phase 2): compute the identical agreement statistic on at least two magnitude-mismatched field pairs not conjecturally related (e.g., regulator vs. conductor; torsion order vs. conductor), predicting saturation at the CYCLE-150N pattern (near-0 or near-1 with essentially no informative spread). This is the internal replication check that the Phase 2 statistic is not reproducing the known confound.

Phase 4 — Coverage/vacuous-reading accounting: report, as a first-class number alongside pass/fail rates, the fraction of candidate rows that could not be evaluated at all (missing counterpart field) and the fraction excluded from Phase 2 for unresolvable provenance.

## Controls
- Magnitude-mismatch canary (Phase 3, above) — direct replication target for the CYCLE-150N confound signature.
- Provenance-blind negative control: within the "back-solved" bucket (if found non-empty), confirm the agreement statistic is at or near machine/rounding precision (a near-perfect, uninformative match) — this validates that the provenance classifier is doing real work, since a back-solved row MUST show near-zero residual by construction, and if it doesn't, the provenance tag itself is untrustworthy.
- Random-row control: a random (not rank-stratified) draw of the same size as the Phase 2 independent-provenance sample, to check the stratified result isn't an artifact of which rank bucket happens to be best-populated in the mirror.
- Permutation null: shuffle the pairing between regulator-side and special-value-side rows within a matched rank/precision stratum and recompute the agreement statistic; the true-paired residual distribution must be detectably tighter than the shuffled-pairing distribution, or the "agreement" carries no row-level information (per the house permutation-null-for-coupling-claims doctrine).

## Confound defenses
- Scale/units confound (CYCLE-150N pattern): enforced by using only relative/normalized residuals in Phase 2, never absolute-difference thresholds, and by running the Phase 3 canary on the identical code path.
- Circularity confound (back-solved values): enforced by the Phase 0 provenance split; any row pair without a resolvable "independently computed on both sides" classification is excluded from the headline Phase 2 statistic and reported only in the coverage/unknown-provenance bucket.
- Vacuous-pass confound (missing counterpart field, the Artin-lfunc-gap pattern): enforced by Phase 4's separate accounting — an unevaluable row is never counted as "consistent."
- Wrong-population confound: Phase 1's explicit stratification by rank and precision class guards against quoting a residual measured on (say) rank-0-only rows as if it characterized the whole mirror.
- Selection-relation confound: the random-row control (above) guards against the stratified sample being drawn from a rank bucket whose selection into the mirror already correlates with easy agreement (e.g., only well-studied low-conductor curves have both fields populated).

## Preregistered falsifiers (numeric thresholds)
- F1: if, after the Phase 0 provenance split, the "independently computed on both sides" population is empty or has fewer than 30 joinable rows in any single object family, the family is DECLARED UNTESTABLE for that family and no conjecture-agreement claim is made for it (falsifies "the mirror supports this audit" for that family specifically).
- F2: if the Phase 3 magnitude-mismatch canary does NOT reproduce near-saturation (i.e., its residual distribution has interquartile range within 2x of the Phase 2 independent-provenance residual IQR), the agreement statistic is judged scale-insensitive and the whole design must be revised before Phase 2 results are interpreted (falsifies the confound-defense premise itself).
- F3: if the back-solved-bucket negative control (above) shows median relative residual > 1e-4 (i.e., "back-solved" rows do NOT show near-exact agreement), the provenance classifier is declared unreliable and Phase 2 is halted pending a re-audit of the classifier (falsifies "provenance is recoverable from the mirror's metadata").
- F4: the conjecture-consistency claim proper is FALSIFIED for a stratum if the median relative residual in the independent-provenance, non-back-solved population exceeds 0.01 (1%) for rank-0/rank-1 curves with fully specified BSD ingredients (Sha, Tamagawa numbers, period all present) — this threshold is set an order of magnitude above the mirror's expected floating-point storage precision (Phase 0 will confirm the actual stored precision and this threshold will be revised upward only if Phase 0 shows coarser native precision, never revised after Phase 2 residuals are seen).
- F5: the permutation-null control is FAILED (no informative pairing signal) if the true-paired residual distribution's median is not below the 5th percentile of the shuffled-pairing residual distribution.

## Stopping rule
Stop and report UNTESTABLE (do not proceed past Phase 0/1) if F1 fires for every object family found in the mirror. Stop and report DESIGN-INVALID (do not proceed past Phase 3) if F2 fires. Stop and report INSTRUMENT-BROKEN (halt before scoring any conjecture claim) if F3 fires. Otherwise proceed through Phase 4 and report pass/fail against F4 and F5 per stratum, with the coverage/vacuous rate always reported alongside — no stratum's result is reported without its companion coverage number.

## Expected failure modes
- The mirror's provenance metadata may not exist at the granularity needed (method-of-computation per field) — Phase 0 is designed to surface this early and cheaply, before any statistical work is spent on an unrecoverable split.
- Regulators and special values in mathematical databases are frequently stored at the precision the source computation used (often high, e.g., LMFDB uses many digits), which could make F4's 1% threshold trivially easy to pass regardless of real conjectural agreement (ceiling effect) — Phase 0's precision-class stratification exists specifically to catch this, and F4's threshold is explicitly deferred to Phase 0's findings rather than fixed in advance of seeing native precision.
- Sample sizes per rank stratum may be small enough (per F1) that several families end up UNTESTABLE, in which case the audit's positive claim shrinks to whichever family (most likely elliptic curves, per the CYCLE-150N corpus evidence) has enough joinable, provenance-resolved rows.
- The audit could rediscover a units/scale confound in a NEW form not anticipated by the canary field pairs chosen in Phase 3 — the canary list is not exhaustive and should be extended if Phase 2's own residuals show suspicious saturation patterns not explained by F2.

## Compute estimate
Phase 0 (schema discovery): trivial, file/schema reads only, no numerical computation. Phase 1 (stratified row inventory): a single pass over the joinable rows in the mirror per family, expected to be a database/file scan, not requiring symbolic or high-precision arithmetic — minutes, not hours, unless the mirror is multi-million-row, in which case a stratified sample (not full scan) is used per the house sampling-strategy discipline. Phase 2/3 (residual computation): closed-form arithmetic per row (ratios and quotients of stored floats/rationals), negligible per-row cost; total cost dominated by row count, expected minutes for the anticipated few-thousand-row scale suggested by the CYCLE-150N corpus's per-batch sizes (tens of thousands of rows per generator batch in that adjacent corpus). No GPU, no model inference required anywhere in this design — this is a database consistency audit, not a learned-model experiment.

## Prior evidence that materially changed this design
`aporia/docs/CYCLE_150N_MAGNITUDE_TAUTOLOGY_2026-08-24.md` directly changed the design: the original plan (before this evidence was found) would have been a straightforward "compute BSD quotient, check near 1" audit. Reading this file added the mandatory Phase 3 magnitude-mismatch canary, banned absolute-difference thresholds in favor of relative/normalized residuals, and is the reason F2 exists as a preregistered falsifier of the design's own premise rather than just a footnote. `roles/Aporia/RESPONSIBILITIES.md`'s documented Artin-lfunc coverage gap materially added Phase 4 as a first-class, separately-reported output rather than folding missing-data rows silently into a denominator, per the standing rule that a structural zero needs its own pre-committed vacuous reading.

## Unresolved uncertainty
The information budget for this design task (15 retrieval ops, 12 documents) was spent primarily locating precedent and confound evidence, not confirming the local mirror's actual current schema for elliptic-curve or other arithmetic-invariant records. Two candidate stores probed directly (`techne/cartography/store/claims.jsonl`, `aporia/q100/REGISTRY_L3.jsonl`) turned out to be unrelated content (literature-claim adjudication; AI-reasoning problem catalog), not the arithmetic-invariant mirror itself — meaning Phase 0 of this design carries real, unresolved risk of discovering the mirror does not currently hold enough independently-computed regulator/special-value pairs to clear F1 for any family. Whether Sha (Tate-Shafarevich group order) is ever stored as a genuine independent value versus always assumed/imputed as 1 is also unconfirmed and directly affects how the BSD quotient in Phase 2 should be interpreted. This design should be treated as ready to execute Phase 0 immediately, with Phases 1-4 contingent on what Phase 0 finds.
