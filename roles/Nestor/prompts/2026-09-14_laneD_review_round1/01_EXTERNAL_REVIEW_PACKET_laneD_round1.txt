3. METHOD / SETUP / SUBSTRATE
--------------------------------------------------------------------------------
World (primordial/lingua/signal.py, numpy, n_envs batched):
  R in [0,256) redrawn per tick per env (splitmix seed -> xorshift64).
  Slot 0 sees R. Slot 1 sees only the channel and acts a in [0,8).
  Correct iff a == R>>5: 3 consequential bits, 5 irrelevant.
Code genome (k, enc, dec):
  enc[R] = symbol < 2^k; symbol 0 = silence (0 bits), others cost k bits.
  dec[symbol] = action.
Channel (channel.lua + channel.py, Redis 8.6.3/FalkorDB image on 6393):
  ONE EVALSHA per tick for all envs. Order: credit last tick's yield
  (y_int), then charge alpha_int*bits if affordable, else do NOT deliver.
  XADD the delivered bits+symbols; the receiver reads that stream entry
  back (XRANGE by id). Charges are u32 packed in one string key.
Learner (D1): (1+32) hill climber, 2000 gens, 128 episodes x 64 ticks per
  generation, sampled from a 65536-episode pool. Mutation = 4 enc + 2 dec
  point changes, k +-1 (p=0.1), semantics-preserving relabel (p=0.05).
  Ties go to the child. Search seed = 1000*run_seed+17 (cell-independent).
Grid: alpha {0,.1,.3,.6,1.5} x beta {0,.01} x 3 run seeds, delta=1.
D1b: exact cost (all 256 R), exhaustive single-move neighbourhood scan,
  exact-cost climber accepting child if cost <= parent+eps,
  eps {0,.01,.03,.1}, 4000 gens, best-so-far kept, same start genomes
  as D1.
Budget: 3 worker processes, OMP/NUMBA threads 3. D1 record 81.7 s;
  D1b record 45.8 s.

--------------------------------------------------------------------------------
4. GROUND TRUTH / KEY DEFINITIONS
--------------------------------------------------------------------------------
Analytic optimum (exact, not fitted):
  min over m=1..8 of alpha*ceil(log2 m)*(m-1)/8 + beta*m + delta*(1-m/8).
  Bound: silence can be right on at most 1 bucket, and each other symbol
  on at most 1. The staircase gives m* = 8,8,4,2,1 across the alpha grid.
  Hand codes m=1..8 hit the formula exactly (unit tests).
Conservation (channel oracle, uses only channel outputs):
  final_charge == start + y_int*corrects - alpha_int*delivered_bits
  per env.
Trace hash: sha256 over per-tick (R, sym, delivered bits, action, charge).
Scramble probe: decoder symbol table (silence included) permuted per
  episode. normalised drop = (y - y_scrambled)/(y - 1/8); eligible iff
  y > 1/8 + 0.05; flagged LEAK iff drop <= 0.1.
Audit economy: alpha_int=2, y_int=3, start=8, 256 envs x 64 ticks. This is
  chosen so unaffordable sends happen; it is NOT the learning cost.

8. KNOWN LIMITATIONS & CAVEATS
--------------------------------------------------------------------------------
- The world is memoryless with uniform R, so the optimum is closed-form.
  The "Pareto front" is known a priori; D1 tests a learner and an
  instrument, not discovery.
- The Lua channel is used only in audit episodes. Learning and the probe
  run in numpy. "Messages go through Streams" is true for audits only.
- delta*error is collinear with yield. The anti-silence control reduces to
  the ratio alpha/delta; no independent behavioural-error term.
- beta = distinct symbols in the encoder table (rent/memory). It is NOT
  decode computation, despite the charter's "decode" label.
- All D conclusions about "silence" are about ONE local-search learner.
  They are not about evolution or QD in general.
- Bars were set without a dev draw: P2b died at 0.11 vs 0.10, and the D1b
  eps grid was not eligibility-checked against measured barrier sizes.
- The probe is blind near chance and against a partial leak (seed used some
  of the time); no graded-leak cheat was run.
- The conservation audit's sensitivity floor per cheat was not measured
  (cf. lane B's B1s one-semantic floor).
- D1's journal post-hoc explanation (rent barrier only) was wrong and was
  corrected in D1b. The D1 receipt draft said "19 genomes"; it was fixed to
  15 before filing.
- D2 (consequential symbols by ablation) and D3 (query niche) NOT started.
  The channel is not yet plugged into lane B's world (CHIMERA-0).
