## 4. STEP 1 — the ceiling is closed, exactly, at all depths

**Neither offered route works.** Enumeration past k=10 with repetition is 27^k. The literal
normalization theorem is **false**: `op_fencepost` and `distribution_reducer` append to `evidence`
and never clear, so applying either k times yields k distinct states — the substrate is *not*
finite-state. A first full-state BFS ran 20 minutes without terminating, for exactly that reason.

**The theorem that does hold** (`instruments/answer_slice.py`). Let `D` be the least slot set with
`selected_answer ∈ D`, closed under "if an operator writes into `D`, all its reads are in `D`",
computed over `declared_reads ∪ AST-detected reads` (over-approximated, so `D` can only grow and the
bound only tighten; this absorbs `select_nth`'s two undeclared reads of `candidates`).

> **Theorem.** States agreeing on `D` produce the same `selected_answer` under every operator
> sequence. *Proof:* induction on length; writes missing `D` cannot change a `D`-slot, writes meeting
> `D` are computed from reads that are in `D`, and nothing outside `D` flows in. ∎

`|D| = 17` of 23. `evidence` is outside it, so the divergence is invisible to the answer and the
closure over `D` is finite.

**Method.** A program is an operator sequence; operators are deterministic (verified: no `random`,
no clock, no uuid in `blackboard_ops*.py`). So track all 120 tasks at once — the joint state is the
120-tuple of per-task state indices, and the reachable joint set *is* the set of program-induced
states. Per-task transition tables are built first (5,029 states, max 104, so one byte per index),
then the joint BFS is table lookups only.

**Two positive controls before any result was read:** the known organism scores 0.8333 via Apollo's
own `_evaluate_acc`, and **replays through the transition tables to the same 0.8333** — so the BFS
explores Apollo, not a model of Apollo.

**Result, under Apollo's own clean-routing pool** (transformers + guarded scorers, which `evolve()`
enforces via `_MUT_SCORER_POOL` and `fitness()` enforces by zeroing `routing_purity` on
plain+guarded hybrids):

```
SEARCH EXHAUSTED — joint reachable set CLOSED. 484,218 states, frontier empty at depth 23.
BEST ACHIEVABLE BY ANY PROGRAM, ANY DEPTH, ANY REPETITION = 100/120 = 0.8333
per-task upper bound under the same pool                  = 100/120 = 0.8333
```

The bounds **meet**, so this is exact rather than sandwiched. Depth, repetition, ordering and tail
caveats are all removed. O1's *"well-supported but not proven"* is discharged.

**ΔE = 16.67%, ΔS = 0.00%.** The 20 unreached tasks are canary indices **30–49**, contiguous, four
categories × 5: `all_but_n`, `temporal_ordering`, `vacuous_truth`, `consistency_check`.

**The pre-committed kill did not fire, but a real correction did.** With the *unrestricted* 27-op
pool an **11-transformer** program reaches 107/120 = 0.8917 (verified through `_evaluate_acc`), so
O1's `max_k = 10` was one operator short and its tail grammar excluded mixed plain+guarded tails.
The mechanism is guessing: removing the single plain scorer drops it 0.8917 → 0.7500; `max_value is
None` on all 7 gained tasks; **6 of 7 emit `candidates[0]`**, the documented fallback. Canary answer
positions are near-uniform (13/11/14/12), so this is luck concentrated in the residual, not a
position bias being exploited. The claim that survives: **0.8333 is the exact ceiling under Apollo's
clean-routing regime, and the only way past it is unconditional guessing.**

**Side finding.** Two of Apollo's 27 registry operators — `distribution_reducer` and
`evidence_updater` — write **only** slots outside `D`. They cannot change any answer in any pipeline
at any depth. Decoration proven statically, in Apollo, on the same day the forge's 86% was measured.

**Admitted: none.** And the failures share one mechanism. All three escape the closure — on 10, 40

> Apollo is not short of computation. It is short of **readout verbs** (guarded scorers that route a
> newly computed value) and **surface parsers** (that get real inputs into typed slots). The middle
> layer works; both ends are welded shut.

**New mandatory instrument: the metamorphic permutation null** (`instruments/permutation_null.py`).
Permute the candidate list — same prompt, same correct string, same option set. Content-driven
answers are invariant; position-driven answers die. Two deterministic permutations (reverse,
rotate-by-one); credit requires surviving both. Confound direction: permuting can only remove a
positional advantage, so the test can only *lower* a ΔE claim.

It overturned **two already-written claims in one session**, one of Apollo's and one of mine.
