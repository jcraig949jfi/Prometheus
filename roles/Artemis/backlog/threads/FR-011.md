# FR-011 -- Must the program author its unit of inheritance? (heredity without a supplied copy primitive)
State: SHARPENED. Cluster: replication / North Star. Sources: H-D2-02 H-D1-35 H-D2-33
Relations: umbrella of FR-090 (AL-1 mutable interpreter) FR-091 (AL-5 implicit replication); related FR-013 FR-010; FR-130 ANSWERED
(copier prior, given COPY); prior art PA_origin_of_replication.md s2 W1-W2, s4 P2/P5, s7 T5-T7
Last reviewed: 2026-09-27 (first sharpening; one new committed-data tally added: NPE BYTEWISE P-11 split)

QUESTION -- In our Z80 worlds, does heredity arise or persist when no designer-supplied copy op (LDIR / LDI / COPY / COPYALL) exists,
and if it does not, is that a law of these substrates or an artefact of VM choices (no stack route, fixed frames)? Program form
(Aporia D-A02 / APO-28): does the program author its replicator and say so, or hold that it condenses?

WHY IT MATTERS -- The North Star is "supply primitives, let mechanisms grow". If every heredity result is one opcode's semantics,
the Z80 line has studied that opcode, and Block D's "three engines converge" (FR-010) is partly this one shared choice. APO-28
(roles/Aporia/BACKLOG_H0H5.md:40) recommends authoring it as H6; the operator has never ruled.

EXISTING EVIDENCE
Measured:
- BEE P8 (RANDOM, n = 300 per arm): base 8 spontaneous; LDIR off 0; LDIR cost x4 0; undefined -> HALT 0
  (roles/Bellerophon/forensics_2026-09-23/GROUNDING_REPORT.md:78-84 @3efdacf7e). Fisher one-sided p ~ 0.004 for 0 vs 8 (my
  arithmetic). "LDIR off" executes only the LDIR byte as NOP (prometheus/z80atlas/vm.py:94,110 @3efdacf7e): LDI and LD (T),A
  stay available, so byte-loop copiers were possible and none arose in 300 x 500 ticks.
- BEE historical origins: of 361, LDIR 204, COPYALL 47, context-dependent 57, LDI loops 9, LD (T),A byte loops 3
  (POST_CAMPAIGN_FORENSICS.md:109-113 @3efdacf7e) -- the "12 of 361" byte-loop routes, all from a 72-h campaign with LDIR on.
- BEE HIST ablation: every LDI/LDIR/COPYALL byte NOPed, 126/345 still self-replicate, 124 by a copy op re-created at a new
  position (GROUNDING_REPORT.md:101-109) -- byte knockouts are rescued; only ISA-level removal is a real ablation (PA P5).
- Archaeon COPIER-CENSUS-01 (c5067fac6): vmcopy32 96 exact copiers in 1e7 random tapes; z80 substrate with COPY decoding as NOP
  (LD A,(r) / LD (r),A / DJNZ still present): 0 copiers of any grade in 1.2e7 (upper 3.7e-7). Hence "Copying requires the COPY
  primitive in this bench" (archaeon/z80atlas/pivot/Z80ATLAS_RULINGS_FOLLOWUP_REVIEW_2026-09-24.md:227 @863d34a55). Note Archaeon's
  COPY is a one-byte copy-and-advance (LDI-like), not a block copy (archaeon/z80atlas/vm.py @c7610ea19).
- NPE: C-CORE 17/27 runaways conserve OP_SELF (23-24) and LDIR (52-53) (roles/Nestor/FINDINGS.md:370-375); Aporia's accepted
  limit: purifying selection predicts it, calling them "relevant" is circular (:376). C-DENSE-COPY 1/64 -> 39/64 with 1-byte
  LDIR/LDDR aliases; W1's SELF-free copier (n = 1) still uses LDIR/LDDR (W1_REPORT.md:24-25,65-66 @d63b76a5f,
  origin/nestor/s1-forensics-2026-09-23 only). E-6: implanted ALLOC;LDIR;BIRTH needs self-location (FINDINGS.md:218-226).
- NEW (read-only tallies, committed data): NPE's 72-h grammar has a copy_primitive factor, BLOCK vs BYTEWISE (no LDIR/LDDR, explicit
  loop; grammar.py:64-67 @aa5833488). Over the 1,031 predecessor-rule spontaneity flags
  (roles/Nestor/campaigns/z80atlas-forensics-2026-09-23/P11_REASSAY.jsonl @d7641744d, cell + first P-11 donor genome per row):
  runs with >= 1 P-11-certified copy event BLOCK 47/531 vs BYTEWISE 10/500; P-11 depth >= 2 only in 2 BLOCK runs. All 10
  BYTEWISE donors are near-homopolymers (dominant byte 91-96% of the genome; 5 of 10 are 0x36, Z80 "LD (HL),n", whose operand
  equals its own opcode, so painting memory reproduces the genome); none contains ED B0/B8. BLOCK donors: 33/47 below 80%
  dominant byte, 34/47 contain ED B0/B8. The admissible flags themselves are copy-op-blind (531/833 vs 500/802 PAIR_TAPE runs,
  INDEX.jsonl.gz). Reading: without LDIR, NPE's only certified heredity carries ~0 bits; P-11 cannot tell painting from copying.
- All three VMs lack a stack/PUSH route (checked in all three at build SHAs; FR-010 table). Prior art: in a real Z80 soup the first
  replicators are stack/PUSH copiers (Aguera y Arcas et al. 2024, arXiv 2406.19108, VERIFIED in PA W1); with block copy removed,
  LDD byte loops emerge but take over "only under task pressure" (Cicala et al. 2026, arXiv 2607.09211, VERIFIED in PA W2).
Proposed / not run: AL-1 mutable interpreter and AL-5 implicit replication are COMMISSIONED only (roles/Atlas/theory/
BLIND_SPOTS.jsonl:2,4 @f8df65681; no AL-1 commit since 09-21); NPE W1 "Remove the scaffolds" (W1_REPORT.md:100, branch-only).

UNCERTAINTY -- (a) Whether any copy-op-free route carries more than a homopolymer anywhere: the NPE data say no for BYTEWISE
(which also lacks LDI), BEE has LDI + LD (T),A but produced 0/300 with LDIR off; (b) whether "copy op required" is an ISA-subset
artefact: no PUSH in any VM, and BEE/Archaeon fixed frames give free self-location; (c) whether task coupling rescues byte-loop
takeover here as in 2607.09211 (BEE P8 ran with the task causally inert, GROUNDING_REPORT.md:51-55); (d) APO-28 is a program
decision -- evidence can inform it, not settle it.

CHEAPEST DISCRIMINATOR -- (1) 0 CPU, committed data, ~1 h agent: add an information criterion to the heredity count (e.g.
donor genome dominant-byte share < 0.8, or fidelity above a same-composition shuffled-genome baseline) and re-tally all three
engines' certified heredity by copy route: NPE P11_REASSAY (57 runs, above), BEE HIST/G6 origin tapes (receipts under
roles/Bellerophon/forensics_2026-09-23/receipts @3efdacf7e), Archaeon HITS.json (c5067fac6). If informative heredity is 0 in
every copy-op-free arm -> "the op is the unit of inheritance" holds in all three, and APO-28 should be decided as "authored,
say so" (H6). (2) ~1 CPU-h per engine (PA T5), only if (1) holds: seed a hand-written byte-loop replicator (and a PUSH
replicator where the ISA allows); replicates-when-seeded but never-found -> a discovery barrier (encoding length, as
C-DENSE-COPY); cannot-replicate -> an ISA gate, i.e. our design choice, not a law. A byte-loop copier that emerges with an
information criterion met would move belief the other way (heredity condenses, the op only buys rate).
