QUESTION -- Under W16 (cue in a random 3-step window starting in [0,20], reward only in the last 10 of 40 steps), which
cue-holding architecture do evolved Ares lineages build: Nyx's (A) a cue-magnitude threshold that ignites from the rest
state, Nyx's (B) a rest state parked near the ignition boundary, or something neither prediction names?

WHY IT MATTERS -- It is the cleanest pressure -> architecture mapping on the board: W4 made evolution build a set-once
latch timed by the substrate's reset (Nyx), and W16 removes exactly that timing crutch. If W16 lineages build a true cue
detector, the substrate can grow re-armable memory when pressed; if they route around (plasticity, decaying traces,
numeric artefacts), that is a FR-001/FR-002 data point about which carrier is "accessible" under a new pressure.
