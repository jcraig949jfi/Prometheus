QUESTION -- Where an engine fails, does it fail because the needed state never gets represented (percept, parse, stored
value) or because the machinery that would use that state is absent? Hand-filling the state at a chosen depth and
re-scoring gives an upper bound that splits the two. Which current engine is the cheapest place to apply this next?

WHY IT MATTERS -- With representation and mechanism co-evolving, each negative needs to say which side failed. Without
that, a parser fix can pass for new reasoning. Aporia: fixing an input gap "would be a real capability delta and a false
organism demonstration" (aporia/docs/CYCLE_155S_FOUR_ARE_NOT_FOUR_2026-08-24.md:86@e8aa82595).

UNCERTAINTY -- In evolved substrates the representation is the organism's own. An injection is interpretable only where
the organism's downstream computation is non-trivial given the state; injecting the answer into the readout register
measures nothing. Whether one injection depth suffices (IQ-PORT-1 needed two).

CHEAPEST DISCRIMINATOR -- Ranked by cost with inputs already on disk.
(1) Cheapest overall, fixture-ready: Apollo Task 2 as specified in APOLLO-10/11. Report P(solve | raw / oracle /
corrupted) per task over the Lexis fixture. oracle >> raw and corrupted ~ raw -> the E9 ceiling is representational
(parser); oracle ~ raw -> mechanism ceiling, and the Apollo role question reopens. Cost 2-4 h CPU. BLOCKED on the
operator's authorisation, not on engineering.
(2) Cheapest in the evolution engines: the FR-132 link-injection on the W2_K2 shelf specimens. Inject the second key's
stored value at the STORE depth (tape state via interventions.py, in the organism's own read location if it has one)
and, separately, splice the witness READ block. This is the two-depth IQ-PORT-1 pattern moved to WSE. Lift at store
depth -> the write/representation side is missing; lift only with the read block -> the mechanism side. 3-5 h, CPU.
(3) Ares W16 (FR-118): set the carrier state by hand at the start of the pay window. Cheap, but Nyx's drive already
largely covers it, so it is low value.
