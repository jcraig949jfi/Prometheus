CHEAPEST DISCRIMINATOR -- A repo-only extraction protocol, piloted on the engine era.
Unit of record: one REVERSAL. Claim C was committed as a RESULT (not a prediction) in artifact A1 at t1. A later committed
  artifact A2 at t2 lowers C's disposition: withdrawn; narrowed by >= 2x in magnitude or scope; verdict flipped; or demoted to
  UNRESOLVED/VOID. Excluded, but counted separately: lost preregistered predictions (calibration, not reversal); defects caught
  before any result was stated ("prevented"); term mismatches (FF-2..25).
Fields: rid; seat/engine; C verbatim + A1 path@sha + t1; reversal verbatim + A2 path@sha + t2; latency (t2 - t1); before/after
  magnitude; caught_by {own forensics, other seat, planted control, external review, operator}; LOCUS (below); Goodhart type
  (regressional / extremal / causal / adversarial; PA W4); mechanism note (free text); prior_doc (earliest path@sha, before t1
  and in a DIFFERENT seat, that names the same locus+mechanism, or none); guard_shipped (path@sha or none).
LOCUS, fixed before coding: RULER-comparator | RULER-threshold | RULER-detector/guard | RULER-window/timing | SELECTOR
  (best-of-N, selection on outcome) | GENERATOR/AUTHOR (planted law, tautology) | HARNESS (bug, leak, config) | CONTROL
  (mis-built, inherited) | SAMPLING (seeds, power, small arm) | REFERENT (identity vs heredity) | SUBSTRATE-FACT.
Decision rule: ask what changed between A1 and A2. If the instrument or analysis was repaired, replaced or re-read, code a ruler
  locus. If the instrument was unchanged and a new measurement showed the world differs, code SUBSTRATE-FACT. If both, code both
  and count the reversal as 0.5 to each.
Inter-rater check: two coders who do not see each other's output (two fresh agent sessions, or an agent and a human) code the
  same random 30 records. Report Cohen's kappa for inclusion (is it a reversal?) and for locus. If kappa < 0.6, revise the
  definitions once and recode. If it is still < 0.6, report that the classes are not yet real.
Frame (pilot): the 42 calibration ledgers + Nestor FINDINGS + the ERRATA and defect sections of review packets, 2026-09-14..27,
  engine seats only (Nestor, Bellerophon, Archaeon, Aether, Ananke, Cosmos, Ensorain, Crius, Ares, Aphrodite).
Estimate: 40-80 reversals in the pilot frame; 100-250 program-wide. Basis: >= 261 ledger rows at about 40% reversals, plus the
  Nestor and packet reversals that are not in any ledger.
Belief moves: if the ruler share is >= 0.7 with locus kappa >= 0.6, P-measurement-before-mechanism is supported on the right unit
  and FR-058/059 move to the top. If the substrate share is >= 0.5, the proposition fails. If the rediscovery rate (the share of
  reversals whose class has a prior_doc) is >= 0.5, documentation is not transmitting; build PA T5 step 4 (a pre-launch sheet,
  tested blind on the next 3 launches). If it is < 0.2, the classes are mostly new each time and a catalogue has little value.
Cost: pilot about 1 agent-day, plus a second coder on 30 records (about 2 h). No compute.
