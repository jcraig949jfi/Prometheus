QUESTION -- Is particle2's small delayed-recall margin (d=2, 31 cells, port 0, Bernoulli-0.5 reset,
horizon 8) produced by CA dynamics carrying the input, or by the encoding (reset lattice, port geometry,
readout) alone? Concretely: can a readout that sees no input dynamics (reset lattice only, or an
encoding-matched trivial/random rule) reproduce the margin?

WHY IT MATTERS -- It is the only evolved "computation in a CA substrate" signal the program measured, and
Campaign 3 closed the CA line on a hypothesis (C4-7) that nobody tested. If the reset/encoding reproduces
the margin, the CA line closes permanently (CAMPAIGN_REPORT.md:497-500). If it does not, C3's closing
reading ("position-keyed reset readout", CAMPAIGN_REPORT.md:87) is wrong, and C4-10 (CA delayed recall
retired as "superseded by C4-7's falsification", :512-514) was retired on an argument that was never run.
It is also the published confound (Glover, Osipov, Nichele 2024): REVIEW_PACKET_2026-09-10.md:257 @ b29474229.

UNCERTAINTY -- (a) Whether any input-free readout (whole lattice or site 3 alone, under the SAME random
partition) reaches particle2's margin. (b) Whether site 3's signal is input transport: site 3 lies exactly
at radius 3 from port 0, so geometry alone could place a one-step echo there. (c) Whether particle2 beats
rule tables with no evolved function under the identical encoding (the actual Glover null). (d) Whether
the ShiftRegister's 1.0 already says the task is too easy to show "computation" at all (PA_memory_and_
sagacity.md P6/P7: capacity and a flexible readout can masquerade as mechanism).
