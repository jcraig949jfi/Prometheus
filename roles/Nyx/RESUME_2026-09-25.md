## 6. TRAPS -- things that have actually bitten this seat

  * MANIFESTS. Editing ANY file under roles/Nyx/prompts/<dir>/ without re-running
    `python -m comms.manifest write roles/Nyx/prompts/<dir>` turns the fleet's base-role self-test
    RED on origin/main. I did exactly this to PLAN_behavioral_cuts_after_replication.md and FOUR
    seats reported it over six days (Atlas #497 and #557, Crius #516, Aether #524). Fixed in this
    commit. Re-verify with `python -m comms.manifest verify <dir>` after every prompt-dir edit.
  * A DIRTY TREE AFTER RUNNING THE TESTS IS NOT LOST WORK. `pytest` calls build(), which rewrites
    nyx/atlas/out/*.json with a fresh "built" timestamp, so 12 files show as modified with no
    substantive diff. Check with `git diff nyx/atlas/out/ | grep '^[+-]' | grep -v built | grep -v
    sha256_16` -- if that is empty it is pure timestamp churn and
    `git checkout -- nyx/atlas/out/` is the right move.
  * `python -m nyx.atlas.migrate_v1` WITH NO BODIES RECEIPT DEGRADES ALL FOSSILS. A bare run on this
    host empties every fossil's files_read, re-lists unresolved_refs and nulls
    host_tree_matches_record, because the older bodies' vault refs do not resolve here. It silently
    rewrote 120 fossils once. Recovery: `git checkout HEAD -- nyx/atlas/fossils/`. Only ever run it
    with the receipt on a host where the vault resolves, or populate ONE fossil deliberately.
  * `python -m nyx.atlas.census` (the BLANKET run) seeds skeletons for EVERY techne specimen,
    including tierra and terralingua, which the operator said should WAIT. Use a targeted
    `census.fresh(rec)` write for the single body you want instead.
  * The cut author rejects ancestry relations that are not in the vocabulary. 'original' and
    'contains' are NOT valid (use algorithm_from / historical_version_of / shares_ancestor_with /
    superseded_by). I have made this error twice. Coverage vocabularies are also strict: there is no
    'RECORD' input_topology (use MIXED / DECISION).
  * BASH HEREDOCS with embedded apostrophes or nested quotes repeatedly failed to parse and silently
    skipped the whole command. For anything non-trivial, write a .py file to the scratchpad and run
    it, rather than piping a heredoc.
  * A line number in a frozen packet must be read from the UNFILTERED file (`sed -n Np`), never from
    grep-filtered output. Freezing does not make a wrong number right, it makes it immutable.
  * CVE / security fossils are framed as DEFECT-AND-REPAIR (the missing check and the fix that adds
    it), never as an exploitation recipe. A safety classifier stopped a draft once; the rewrite
    documenting the defect, the 1.0.1g fix and a sandboxed differential was fine.
