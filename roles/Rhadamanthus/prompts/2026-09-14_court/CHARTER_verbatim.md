grave + evidence + question + instruments + controls + decision rule

Standing permission would gradually turn CORONER into an exploratory shell and erase the boundary between forensic reading and experimental intervention.

Keep approval cheap, but explicit.

without touching the grave when its own preregistered logic, controls, mathematics, dependencies, or identifiability requirements already falsify its ability to answer the proposed question.

This is a first-class scientific product.

Record exactly what killed it.

Never silently repair the plan and retain its identity.

A repaired descendant receives a new plan/version and cites its dead parent.

NEXT MISSION — BUILD THE COURT

You have built an armory.

Now demonstrate that Necropolis can use it without turning Rhadamanthus into a monolithic analyst.

Establish an operational case cycle:

GRAVE
→ NECROMANCER AUTOPSY
→ CLERIC CHALLENGE
→ RHADAMANTHUS ADJUDICATION
→ optional FRANKENSTEIN

→ optional ZOMBIE
→ NEW EVIDENCE
→ DOSSIER / COUNTERFACTUAL HISTORY

The boundaries matter.

NECROMANCER

The Necromancer reconstructs.

Given a grave, it must independently recover:

* claimed capability;
* actual implementation;
* actual experimental assembly;
* inputs;
* outputs;
* dependencies;
* controls;
* gates;
* consumers;
* historical verdict;
* contradictory evidence;
* later repairs;
* surviving components.

It should preferentially use READY forensic instruments where appropriate.

The Necromancer does NOT decide whether resurrection is deserved.

CLERIC

The Cleric attacks the autopsy.

It must attempt to falsify:

1. the historical death certificate;
2. the Necromancer's reconstructed cause;
3. any claim that the test was FAIR;
4. any claim that the test was UNFAIR;
5. any proposed salvage value;
6. any proposed Frankenstein counterfactual.

The Cleric must be allowed to conclude:

HYPOTHESIS_FAILURE

and should actively look for cases where Necropolis is inventing assembly excuses for genuinely dead ideas.

Do not make the Cleric a rubber-stamp second reader.

RHADAMANTHUS

You adjudicate what the record licenses.

You do not resolve disagreement by storytelling.

Where Necromancer and Cleric differ, record:

* proposition under dispute;
* evidence each relies upon;
* whether the disagreement is factual, taxonomic, causal, or epistemic;
* what observation would resolve it;
* whether obtaining that observation is worth the cost.

Some cases should remain unresolved.

FRANKENSTEIN

Frankenstein proposes the minimum counterfactual necessary to distinguish organ failure from assembly failure.

Every proposal retains:

A / layer Y / mutation M / C -> C' / expected R / kill-before-run

Frankenstein is NOT authorized execution.

ZOMBIE

A Zombie is an executed bounded resurrection descendant.

No Zombie exists merely because code runs.

Every Zombie must descend from:

* an adjudicated grave;
* a Frankenstein specification;
* a valid CORONER plan;
* explicit HITL authorization.

No authorization, no Zombie.

* propositions disputed;

* FAIR-status agreement/disagreement;
* proposed counterfactual agreement/disagreement.

Do NOT create a numerical inter-rater score merely because one can be calculated.
