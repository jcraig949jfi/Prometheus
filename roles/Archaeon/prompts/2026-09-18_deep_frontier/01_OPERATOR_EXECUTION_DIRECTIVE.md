ARCHAEON -- OPERATOR EXECUTION DIRECTIVE

START DEEP FRONTIER NOW.

This directive supersedes any prior interpretation that requires Archaeon
to wait for fleet-wide administrative closure before executing otherwise
valid experiments.

The purpose of the gates was to protect evidence integrity, not to stop
research while unrelated seats finish paperwork.

Effective immediately:

1. RUN EVERY CURRENTLY RUNNABLE FRONTIER ITEM

Begin execution from the existing exploration, exploitation, and audit
queues.

Do not wait for Proteus, Harmonia, Mnemosyne, Daedalus, Vivarium, or any
other seat unless a specific experiment actually requires an unavailable
capability from that seat.

If the head of a queue is blocked, skip it and execute the next runnable
item.

Maintain a non-empty runnable queue whenever runnable work exists.

2. GLOBAL BLOCKING IS NOW EXTREMELY NARROW

Archaeon may stop the whole loop only if continuing would make the
resulting evidence unreliable or unrecoverable because of an actual
defect in one of:

* deterministic replay;
* checkpoint continuity;
* evidence/schema write correctness;
* provenance;
* observation/interpretation separation;
* crash/interruption recovery.

A suspected problem is not enough.

A global stop must name:

* the concrete failing invariant;
* the reproducing fixture or receipt;
* which evidence would be invalid if execution continued.

If no such failure exists, RUN.

3. EVERYTHING ELSE IS LOCAL

The following must NOT stop Deep Frontier globally:

* PROTEUS-46;
* graph-organism availability;
* graph thresholds;
* weak detector power;
* UNABLE detectors;
* unvalidated rulers;
* failed falsifiers;
* missing positive controls;
* incomplete geometry validation;
* unfinished calibration work;
* pending Harmonia policy;
* pending registry enrichment;
* a blocked lineage;
* a blocked transformation;
* uncertainty about interpretation.

Mark the affected item BLOCKED, UNABLE, FALSIFIER_FAILED, PARTIAL, or
whatever state the evidence warrants, and continue with another item.

4. PROTEUS-46

Consume Proteus's committed verdict using its corrected semantics.

CLIFF_SURVIVES / FALSIFIER_FAILED does NOT imply retirement.

neighbourhood_exhausted = false means the broader lineage is not retired.

formulated.

Reconcile the three-versus-eight graph-transformation bookkeeping
discrepancy without stopping unrelated execution.

This reconciliation is not a launch gate.

5. G6-0

G6-0 is no longer permission to conduct science.

Treat any unfinished G6-0 items as verification work running alongside
the campaign unless they expose one of the concrete evidence-integrity
failures listed in section 2.

Do not wait for a ceremonial fleet-wide receipt if the machinery
Archaeon is about to use already satisfies the relevant integrity
invariants.

If loop.py requires a gate file solely because of the previous
administrative rule, record this operator directive and create the
appropriate operator-authorized execution gate.

Do not manufacture evidence that an unfinished test passed.

Record the distinction clearly:
OPERATOR_EXECUTION_AUTHORIZED
is not
G6_0_ALL_COMPONENTS_VERIFIED.

6. FIRST EXECUTION

Do not conduct another rehearsal.

Do not construct another authorization packet.

Do not add another prerequisite.

Select runnable items from all three pools and execute real campaign
work.

7. ANTI-BUREAUCRACY INVARIANT

From this point forward:

NO LOCAL BLOCKER MAY IDLE THE GLOBAL LOOP.

Every new gate must declare its scope.

If its scope is narrower than the whole evidence system, it cannot stop
the whole evidence system.

If one branch cannot run, run another.

If one substrate cannot run, run another.

If one ruler is UNABLE, preserve telemetry and run.

If an interpretation is unresolved, record the observation and run.

8. REPORTING

Do not return to me merely to announce that another dependency exists.

Return when:

* actual experiments have run and produced findings;
* a genuine global evidence-integrity invariant fails;
* a major discovery or contradiction triggers the Deep Frontier digest;
* or the runnable frontier is genuinely empty.

An empty runnable frontier must be demonstrated from the registry, not
inferred from one blocked dependency.
