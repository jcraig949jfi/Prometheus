PHASE A — REPAIR WHAT “LINEAGE” MEANS

The parent/executor of a reproduction event is not necessarily the genetic source of the offspring.

A host may execute foreign code.

Therefore the system must stop using a single lineage identifier to answer multiple causal questions.

A1. Separate at least four identities

For every reproduction event record:

EXECUTOR

Which organism initiated execution?

EXECUTED MATERIAL

Whose tape/code was actually executed?

This may be:

* self;
* neighbour;
* recombined material;
* other explicitly represented source.

CHILD GENETIC CONTRIBUTORS

Which existing genetic material causally contributed bytes to the resulting child genome?

Track contributor ancestry conservatively.

ECOLOGICAL HOST

Which organism/cell supplied execution opportunity, location, resources, or other non-genetic support?

These identities may coincide.

Do not assume they do.

A2. Genetic lineage

Create a genetic-lineage representation whose ancestry follows the material that actually constitutes the child genome.

At minimum, every birth should permit later determination of:

* executor lineage;
* executed-tape lineage;
* child genetic lineage;
* founder genetic origins;
* host ancestry;
* template contributors;
* reproduction mechanism;
* whether foreign execution occurred;
* whether a genuinely novel child genome appeared.

If byte-level contributor tracking is practical, use it.

If not, use conservative contributor sets and document the approximation.
