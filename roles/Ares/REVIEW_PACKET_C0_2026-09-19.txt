WHAT WAS ASKED
  Determine whether abstract selective PRESSURES (not architectures)
  can steer the emergence of computational machinery. Build toy worlds,
  a generic evolvable organism, controls; run a sweep; report which
  pressures changed the KIND of machinery evolution finds.

WHAT WAS BUILT AND RUN
  Substrate: batched directed-graph organism, 9 arithmetic ops, bias,
  keep coefficient, two input ports, per-edge plasticity rate (0 until
  mutated), strict tick budget. No named modules. 10 mutation operators.
  Worlds: W1 catastrophic tail, W2 rare override, W3 changing rules,
  W4 hidden regime, W5 delayed revelation, W6 scarcity, W7 incompatible
  regimes, W8 transplant, W9 ecological coupling, W10 development,
  W11 irreversible commitment, W12 dying lineage. Each with modes
  present / absent / shuffled.
  Search: mutation-selection GA (P=128, G=120, 4 train eps/gen, elites
  16, tournament 3). 32 balanced held-out episodes. Fitness = world
  reward ONLY; no mechanism ever rewarded or named.
  141 GA runs (3 seeds/cell) + champion dissection + transfer matrix +
  W8 transplant + a combined-memory ablation. Controls: fixed policy,
  random policy, gen-0 population, and per-champion substrate ablations
  (no keep+reset, no plasticity, both). Cheat controls in tests:
  hand-wired conditional-risk and memory organisms detected and
  localised. tests 10/10.

HEADLINE RESULT
  W4 (hidden regime) is MATERIAL in 3/3 seeds: two regimes give
  identical observations after a 3-step early cue and demand opposite
  actions, with NO reward channel. Present champions reach late-life
  accuracy 1.00 for both regimes (shuffled control 0.55 = chance).
  The mechanism is necessary and specific:
      ablation           held-out (W4 present, seed 3)
      intact                 40.0
      no activation memory    2.6   <- collapses to chance
      no plasticity          40.0   <- irrelevant
      no memory at all        2.6
  Node ablation localises it to a GATE+MAX node pair (each removes
  40 -> 2.6). The mechanism ACCRETED over ~13 lineage generations, not
  one mutation. Frozen: ares/fossils/W4_activation_memory_s3/ (replays
  to 40.0000). Nothing named or rewarded memory.

THE MOST RELIABLE OUTPUT: THREE CONTROLS FALSIFIED BY THEIR OWN DATA
  1. The "no_state" ablation left PLASTICITY intact, so it did not
     remove memory; a nostate organism scored 33 on W4 via plastic
     weights. Fixed by a combined no_memory ablation, which is what
     let W4 be attributed to activation memory specifically.
  2. W5 present produced GENUINE cross-delay memory (dec_acc 1.00 in
     2/3; both memory routes needed) -- contradicting the preregistered
     P-W5 "does nothing". The verdict mislabels it because the balanced
     seed set balances only the first hidden binary and W5's payout is
     a second one, inflating the shuffled control.
  3. The W12 fitness threshold was borrowed from the absent mode (~80),
     which the present mode cannot reach because risk is costly; the
     behaviour (state-dependent risk, gap 1.00) is present, the
     threshold was wrong.
  All three recorded in roles/Ares/calibration/LEDGER.md before this
  packet.

WHAT WOULD FALSIFY THE HEADLINE
  If the cycle-1 rerun of W4 with the corrected no_memory control shows
  the collapse is an artifact of the ablation (e.g. resetting state
  also breaks the input path), W4 is not a memory result. The replay
  and the node-level ablation (GATE+MAX, not a global reset) argue
  against this, but it is the test.

WHAT SHOULD WE STOP
  W11 (irreversible commitment) and the W3 within-lifetime-adaptation
  framing produced nothing this substrate can host at this budget; do
  not invest further without a substrate change. W8/W9/W10 gave clean
  nulls and need no rerun unless a positive elsewhere motivates them.

CAN THIS BE "NOT WORTH CONTINUING"?
  Yes, and the stop condition is written (DESIGN_C0 s7 / report s7): if
  cycle 1 shows W4 was the only load-bearing mechanism and every other
  candidate is a reflex, the next question is a SUBSTRATE question, not
  a pressure question, and the pressure catalogue is parked.
