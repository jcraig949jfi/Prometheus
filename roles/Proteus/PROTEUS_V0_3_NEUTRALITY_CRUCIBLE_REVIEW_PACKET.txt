The question this crucible was built to answer:

  Does repeated mutation produce a reproducible directional attractor that
  cannot be explained by finite-state boundaries, representation geometry,
  or an explicitly characterized null process?

It does. One coordinate survives every control and every correction: the
grammar systematically GROWS THE TAPE. Everything else that looked like a
directional prior in V0/V0.1/V0.2 dissolves once a symmetric-by-construction
geometry null is subtracted. Two defects in my own adjudicator are reported
below; both were moving the answer toward MORE declared effects, and both were
found and fixed before this packet. Nothing has been repaired, no campaign has
been launched, no world has been touched.

====================================================================
0. FAILURE MODES, FIRST
====================================================================

F1. A DIRECTIONAL MUTATION PRIOR REMAINS, AND IT IS MINE.
    config_log2_tape_words is the single coordinate that survives Holm
    correction, at both cap-adjacent cohorts, with the sign persisting over
    the second half of the horizon:

      cohort 128:  v0.3 +1.20   NC1B +0.02   delta +1.18  CI [+0.94,+1.43]
      cohort 256:  v0.3 +1.39   NC1B +0.91   delta +0.48  CI [+0.29,+0.67]

    (log2 words, drift over 400 generations, 100 lineages per cohort,
     lineage-cluster bootstrap, 2000 resamples.)

    Mechanism, and it is not a mystery. Grammar v0.2 made a tape halving a
    no-op unless the genome would occupy at most HALF of the new tape.
    Doubling is never blocked until the published maximum. So shrinking is
    conditionally forbidden and growing is not, and the manifest walks
    upward. That rule is the residue of the fix I made in v0.1 and v0.2 to
    stop a length ratchet. The fix removed the length ratchet and left a
    CONFIGURATION ratchet in its place, one level out, where the V0 battery
    was not looking. This is the whole reason the brief replaced length
    neutrality with a multidimensional battery, and the battery found it.

    It is NOT repaired here. The brief forbids repairing a failed result and
    authorizes exactly one grammar change, which was spent on removing
    zeroing. The next decision belongs to review.

F2. TWO DEFECTS IN MY OWN ADJUDICATOR, BOTH FOUND AT ADJUDICATION.
    (a) THE HOLM CORRECTION WAS INERT. It compared a z-equivalent against a
        RATIO of normal quantiles instead of against the quantile, and had no
        step-down stop, which made the "corrected" test WEAKER than simply
        excluding zero. With the bug, TWENTY coordinates appeared to survive
        correction across the five cohorts. That is the number I would have
        published. Fixed to a proper step-down Holm: ONE survives.
    (b) THE PREREGISTERED CONTENT NULL IS CONFOUNDED BY LENGTH. The
        preregistration matched opcode, class and operand coordinates to NC2
        and NC3, both of which FREEZE genome length. In the cohorts whose
        length changes materially (1, 8, 256) that compares against a
        different population -- the wrong-population error this program has
        paid for before. Rather than silently re-matching, the adjudicator
        now computes BOTH the preregistered NC3 comparison and the
        length-matched NC4 comparison, reports both, and declares an effect
        only if it survives against the length-matched null. Under NC3 alone,
        six content coordinates would have been declared at cohort 1; under
        the length-matched null, none is.
    Both corrections moved the answer toward FEWER declared effects. The
    direction of a correction relative to my own hypothesis is stated because
    that is what this program requires be disclosed.

F3. NC4 COULD NOT REPRESENT ITS OWN TARGET ON FIRST IMPLEMENTATION.
    NC4 was written drawing fresh uniform genomes at the V0.3 length
    distribution but with the COHORT TEMPLATE configuration. Organisms whose
    tape had drifted could not be represented and the arm aborted with
    ManifestError: genome longer than tape. Corrected to mirror each
    organism's length AND full configuration. Found from a crash, before any
    V0.3 coordinate was examined. Recorded in PREREG_ADDENDUM_2026-09-03.md.

F4. NC1's CONFIGURATION HALF WAS IMPLEMENTED LATE.
    The preregistration defines NC1 as "the same construction applied to each
    numeric configuration coordinate". The first implementation covered length
    only; the configuration half (NC1B) was implemented AFTER the V0.3 arm ran,
    though BEFORE any configuration coordinate was examined. Since the single
    surviving effect (F1) is adjudicated against NC1B, a reviewer should weigh
    that ordering. The control is symmetric by construction and its code is in
    the same commit as this disclosure.

F5. A DOCUMENTATION ERROR IN THE V0 PACKET, NOW CORRECTED.
    proteus/ARCHITECTURE.md stated that "op = word mod 25" gives opcodes 0..6 a
    slightly elevated frequency. The correct set is 0..20: 2^32 = 25 x
    171798691 + 21, so opcodes 0..20 have probability 171798692/2^32 and 21..24
    have 171798691/2^32. The exact figures are now the analytic reference used
    by NC2 and NC3. The error was in prose, never in code.

F6. THE COHORT-1 CONTENT COORDINATES ARE MEASURED ON ONE-INSTRUCTION GENOMES.
    At checkpoint 0 that cohort's opcode vector is one-hot and its operand
    statistics rest on three words. Drifts there are large and noisy and none
    survives correction. Reported so nobody reads the raw cohort-1 numbers as
    signal.

F7. THE V0 QUARANTINE AUDIT HAD NOT COVERED export.py.
    Re-running the audit for this packet FAILED: proteus/foundry/export.py
    imports base64, which is not on the allowlist. export.py was written in the
    same V0 batch as the contracts, AFTER the audit run whose PASS the V0 packet
    reported, and was never re-audited. So the V0 packet's "string layer PASS"
    was true of the code at the moment it ran and not of the code it shipped.
    The gap is benign in substance -- base64 is a byte-to-ASCII encoder that
    cannot carry natural language into a player, and export.py is on the
    outbound SFE path, never imported by vm.py, probes.py or signatures.py --
    but the allowlist is fail-closed and it failed. Fixed by widening the
    allowlist by exactly that one stdlib name with the justification recorded in
    the audit source. The lesson is procedural: the audit must run in the same
    commit as any change to proteus/foundry, and it now does for V0.3.

F8. THIS OPERATOR'S CALIBRATION RECORD.
    The V0 packet's F6 applies unchanged. The one confident design claim I made

3. THE COMPLETE NEUTRALITY BATTERY
====================================================================

Seventy scalar coordinates per organism plus nine population coordinates, all
reported per component, none collapsed into a score:

  genome_length ; opcode_frequency (25) ; opcode_class_frequency (9) ;
  operand distribution (mean normalized, fraction below 2^16, zero fraction,
  16-bin top-nibble histogram) ; configuration fields (n_regs, log2
  tape_words, code_writable, log2 tick_budget, log2 out_cap, persist shares) ;
  halt/yield/budget proportions ; executed-instruction fraction ;
  transcript-silence fraction ; transcript occupancy, top share and entropy ;
  knockout occupancy, top share and entropy ; status-sequence occupancy ;
  NOP share ; fraction of mutations touching executed code.

Two definitions were fixed in advance because they are contestable:

  TOUCHED SET. The parent instruction indices an operator directly writes,
  deletes, moves or copies from, per its own argument record. Insertion is
  charged its boundary index only. Positional shifting of downstream
  instructions is deliberately NOT counted; under that reading nearly every
  mutation touches executed code and the coordinate carries no information.

  EXECUTED-INSTRUCTION FRACTION. The VM may not be altered and exposes no
  trace, so a SHADOW DECODER mirrors it and additionally records fetched
  indices. It is differentially tested against the authoritative VM on every
  organism measured: outputs, status and final state must match, and a mismatch
  aborts the measurement. Across every run in this packet -- roughly 90,000
  organism-ensemble measurements -- the shadow never diverged once.

4. NULL-CONTROL DEFINITIONS
====================================================================

NC1  SYMMETRIZED REFLECTED LENGTH WALK. The grammar's own length kernel is
     measured on random genomes, then replaced by p_sym(d) = (p(d)+p(-d))/2 and
     walked under the same reflecting no-op bounds, with no content and no VM.
     A symmetric kernel has zero drift in an unbounded space BY CONSTRUCTION,
     so every unit of NC1 drift is boundary and finite-support geometry.

NC1B SYMMETRIC BOUNDED CONFIGURATION WALK. The same construction over the six
     configuration fields: each numeric field steps symmetrically, blocked only
     by the published bounds and by manifest validity. It deliberately OMITS
     the grammar's stricter half-tape rule, because that rule is a property of
     the grammar and must stay visible as a prior rather than be absorbed into
     the geometry control. F1 is measured against this.

NC2  WHOLE-GENOME UNIFORM RESAMPLER. Every mutation redraws the entire genome
     uniformly at fixed length. Stationary content law uniform by construction.

NC3  SINGLE-SITE UNIFORM RESAMPLER. Every mutation overwrites one uniformly
     chosen instruction with four uniform words; length frozen. Same stationary
     law.

     ANALYTIC REFERENCE for NC2 and NC3: 2^32 = 25 x 171798691 + 21, so under
     op = word mod 25 opcodes 0..20 have probability 171798692/2^32 and opcodes
     21..24 have 171798691/2^32.

NC4  GEOMETRY REFERENCE, NO MUTATION. Fresh uniform genomes at the same length
     AND configuration as each V0.3 organism at that checkpoint. Gives the
     phenotype coordinates implied by length, configuration and geometry alone.

Published in commit 4b4823bcb; NC1, NC2 and NC3 were RUN and committed
(071df1e61) before the V0.3 arm executed. NC4 is matched to the V0.3 length
distribution by definition and therefore necessarily runs afterwards.

14. EVERY UNEXPLAINED DIRECTIONAL EFFECT
====================================================================

None. The one surviving effect (F1) has a mechanism I can name in one sentence
and point at in the source: the half-tape rule in op_config_perturbation blocks
shrinking and never blocks growing.

Two effects that are explained but worth a reviewer's attention:

  (a) NC1B itself drifts +0.91 in log2 tape at the cap-adjacent cohort. Part of
      the tape growth in that cohort is geometry, which is why the declared
      delta there (+0.48) is smaller than at cohort 128 (+1.18) even though the
      raw V0.3 drift is larger. Reading the raw number alone would overstate the
      prior at 256 and understate it at 128.
  (b) Mean genome length in the diffusion census rises 17.7 -> 76.2 over 10,000
      events. That is downstream of F1: a bigger tape raises the genome cap.
      Length and tape are not independent coordinates, and F1 is the one with
      the mechanism.

17. CLAIMS AND EXPLICIT CEILINGS
====================================================================

C1  Grammar v0.3 carries a directional prior on tape size: +1.18 log2 words
    beyond the symmetric bounded null at cohort 128 and +0.48 at cohort 256,
    intervals excluding zero, sign persisting over the second half.
    CEILING: 400 generations, 100 lineages per cohort, one tape geometry
    (1024 words initial), one measurement of NC1B implemented after the V0.3
    arm ran. BREAKS IF: a reviewer's own symmetric configuration null shows the
    same drift, which would move the effect from prior to geometry.

C2  Genome length under v0.3 is not distinguishable from a symmetrized
    reflected walk at any of five start sizes, including both bound-adjacent
    ones. CEILING: this is a statement about drift over 400 generations at
    these five starts, not about the stationary distribution. BREAKS IF: a
    10,000-generation horizon separates them.

C3  Removing zeroing removed the V0 content ratchet. NOP-share drift falls from
    +0.133 (v0, 300 generations) to at most +0.0299 raw, surviving no null
    comparison. CEILING: NOP share is one component of one coordinate family;
    24 other opcode components are reported and none survives correction.

C4  Under neutral diffusion to 10,000 events the phenotype set does not
    concentrate beyond its own geometry: top-class share 0.390 vs NC4 0.383,
    entropy 3.80 vs 3.80 bits. Cumulative unique classes keep rising (72 ->
    274). CEILING: 400 lineages, one ensemble, one initialization; per-mutation
    discovery rate does fall steeply, and "does not collapse" is a statement
    relative to NC4, not an absolute claim about reachability.

C5  Phenotype structure is stable across six independent probe ensembles
    (Jaccard 0.9886-0.9993 on the same-class relation). CEILING: all six share
    one measurement design; a structurally different probe design (longer
    horizons, different channel shapes) is untested and could still disagree.

C6  The pipeline replays byte-identically across two CPython minor versions and
    two operating systems. CEILING: one physical machine; a second host is
    untested.

C7  The shadow decoder agreed with the VM on every organism measured (~90,000
    organism-ensemble measurements, zero divergences), so the
    executed-instruction coordinate is trustworthy to that extent. CEILING: it
    is a mirror of the same logic by the same author; agreement is evidence
    against transcription error, not against a shared misconception.

No claim is made about intelligence, reasoning, capability, emergence, progress,
or the fitness of any organism. Nothing here says any organism is good.
