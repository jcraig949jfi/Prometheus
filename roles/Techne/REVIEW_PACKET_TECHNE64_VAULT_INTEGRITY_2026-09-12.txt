1. CLAIM / SUBJECT UNDER REVIEW
--------------------------------------------------------------------------------
Claim A (defect): before this pass, `harvest run` executed recipes INSIDE the
preserved upstream/ tree. Builds wrote products there and configure scripts
rewrote source files, so the bodies Techne hands to Nyx as byte-exact no
longer matched their recorded TREE_SHA256. The run receipts recorded the run's
success, not the body's state (base-role rule 2: a label that lied).
Claim B (repair): with the disposable-copy isolation, a recipe that builds and
edits leaves the preserved body verified, and the receipt carries the measured
property (body_preserved). Falsifier: any run whose receipt says
body_preserved=true while `harvest verify` differs afterwards.
Claim C (restore): every drifted body is back at its pin, from its own
immutable sources only. Falsifier: `harvest verify --all` != 57/57, or a
restore receipt with fabricated content (none: UNRECOVERABLE is a reported
state, not a repair).

--------------------------------------------------------------------------------
2. METHOD / SETUP / SUBSTRATE
--------------------------------------------------------------------------------
Body layout (host-local, gitignored): <vault>/<id>/upstream/ = archive(s) as
fetched + extracted tree (or a pinned git clone). Tracked half:
UPSTREAM_HASHES.txt (sha256 + bytes per file, TREE_SHA256 over those lines),
record.json (hashes.tree_sha256), recipe.json, receipts/.
drift(id): re-hash upstream/ (skipping .git), diff against the hash list ->
rows added / removed / modified, plus recorded vs now tree hash.
run(id): stage <vault>/<id>/work/ = copytree(upstream) + harness/ + empty
build/; execute the recipe there ($BODY = work, so no recipe changed); after
the run re-hash the PRESERVED upstream/ -> tree_sha256_after, body_preserved.
Recipe key "in_place": true opts out; receipt says isolation=in_place.
restore(id): delete added rows; for modified/missing rows, `git checkout` at
the pin (-c core.autocrlf=false) if the tree is a git clone, else re-extract
every archive beside the tree into a temp dir, index by sha256, copy the file
whose CONTENT matches the recorded hash; anything unmatched -> UNRECOVERABLE.
Re-drift; write a tracked restore receipt with every row.

--------------------------------------------------------------------------------
3. GROUND TRUTH / KEY DEFINITIONS
--------------------------------------------------------------------------------
PRESERVED       tree_sha256(now) == record.hashes.tree_sha256 (the pin taken at
                acquisition, tracked in git).
DRIFTED         not PRESERVED; classified by rows: added (in body, not in
                list), removed (in list, not in body), modified (hash differs).
RESTORED        PRESERVED again, with every deleted/recovered path listed.
UNRECOVERABLE   a wanted hash found in neither the git pin nor any archive
                beside the tree; the body stays DRIFTED and nothing is written.

8. KNOWN LIMITATIONS & CAVEATS
--------------------------------------------------------------------------------
- Only 2 of 57 real recipes were re-run under the new isolation. A recipe that
  reads a path OUTSIDE $BODY (none found by grep; 84 $BODY references) or
  relies on state from a previous in-place build would surface only on re-run.
- work/ is a full copy of upstream/ including .git (up to 93 MB for do-mpc/
  avida); acceptable today, a cost at 10x the vault.
- restore trusts UPSTREAM_HASHES.txt as the authority. If that list had been
  regenerated AFTER a dirtying (not observed: all 23 recorded hashes predate
  the drift and matched the archives' content), restore would enshrine drift.
- The archive-content path recovers a file only if some archive beside the
  tree holds identical bytes; files that acquire() fetched loose (ff domains,
  ex/) have no archive source and would be UNRECOVERABLE if modified. None
  were modified in this census.
- Bodies are still host-local only (PRESERVATION.md gap; TECHNE-65, XL,
  operator decision on the mirror location).
- The census before the fix is itself a Techne measurement of Techne's own
  defect; the tests are synthetic; no other seat has verified it.
