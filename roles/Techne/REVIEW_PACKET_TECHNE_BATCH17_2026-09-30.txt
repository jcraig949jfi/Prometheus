3. WHAT WAS DONE, STEP BY STEP

3.1 Ruling (E3 reading, E0 judgement). The 19 records' provenance fields were
dumped and read; the R19 vocabulary lists eight grades with one sentence of
guidance ("a later reconstruction ... does not become original merely because
it works"). Principle applied, from the author's own 2026-09-17 ruling: the
source type says how the bytes were obtained; the grade says what the object
is relative to the claim.
  PSEUDOCODE_PLUS_REFERENCE_IMPL (13)  RECONSTRUCTION of the named mechanism
  FAITHFUL_PORT (3)                    RECONSTRUCTION (+ one RECONSTRUCTS edge)
  LATER_SAME_LINEAGE_RELEASE (3)       ORIGINAL_ARTIFACT of the release read,
                                       dated; never the historical-era body
Three phrases written from memory were removed before posting.

3.2 Scout (E3). 22 candidate repositories: pin by git ls-remote; licence,
size and archive state from the GitHub API and the raw licence file; two
more found by search (MABE2 owner; Aevol's canonical GitLab).
  eligible 20   deferred 6 (one 2.5 GB; three with no licence anywhere;
                one 116 MB duplicate lineage; DeepMind systems with no
                public source)

3.3 Reading (E3, delegated). Ten read-only agents cloned each pin, read the
licence, README, manifests and core files, and wrote a facts file each with
"NOT_FOUND_AT_PIN" where the tree is silent. Every draft's pin was checked
against the author's own ls-remote: 20 of 20 agree. Drafts are committed
verbatim as provenance; the batch script builds records from them plus an
override table (id, section, source type, domain, era, edges, tags).

6. WHAT THIS DID NOT ESTABLISH

- No donor was run, built or tested. Every run classification is
  NOT_ATTEMPTED. Entry points and loop descriptions come from reading.
- No mechanism was extracted. The section II report (TECHNE-122) is not
  started and, under CWO-B, is not to be self-promoted.
- The reader agents' facts were spot-checked (pins, licences, counts), not
  re-derived; a wrong sentence in a draft would be a wrong sentence in a
  record. The drafts are committed so the check can be made later.
- The grade ruling is per source type. It does not issue per-record grade
  blocks, does not re-grade archive mirrors, and does not settle the 39
  rollout fossils (Harmonia to rule on Nyx's proposal).
- Whether ORIGINAL_ARTIFACT of a later release is the right handle for a
  cut about a historical mechanism is a judgement; the ruling requires the
  release to be named in the basis line so a reader can see the gap.
- Six named donors are not here (section 3.2); the raid remains incomplete
  for sections II (DRED, ATEP, AdA, XLand), III (AURORA), IV (FlowLenia,
  DISHTINY, MCC).
- Who wrote the bytecode file into the POET body is inferred from a dated
  line in Nyx's cut script, not observed.
