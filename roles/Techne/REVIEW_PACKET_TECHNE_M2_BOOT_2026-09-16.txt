4. U2 -- DESIGN AS EXECUTED (RQ-4 on run receipts)
-----------------------------------------------------------------------------
Files: techne/fossils/vault.py, techne/fossils/harvest.py,
       techne/tests/test_fossil_environment.py,
       techne/fossils/RECEIPT_CENSUS_2026-09-16.json

Mechanism:
  - vault.getenv(name) is the only way the package reads the environment;
    it records the NAME. One pre-existing read (TECHNE_FOSSIL_VAULT) now
    goes through it. A test greps the package for any other os.environ read.
  - environment_fingerprint() -> {interpreter: {implementation, version,
    executable_basename}, pip_freeze_sha256, pip_freeze_n, env_vars_read,
    env_vars_exported_to_recipe}. The package list comes from
    importlib.metadata (sorted, de-duplicated "name==version"), hashed as
    LF-joined text. No subprocess, no shell.
  - Receipt schema bumped to techne.fossil.run_receipt/2. run() fills the
    block AFTER the recipe executes (so every read during the run is in the
    list) and calls validate_run_receipt(); a defect raises and NO receipt
    is written.
  - `harvest receipt-check [--out F]` censuses every tracked receipt:
    CARRIES_RQ4 / PREDATES_RQ4 (schema/1) / DEFECTIVE / UNREADABLE.

Controls (12 tests, all pass):
  positive   a planted distribution in the list MOVES the hash
  negative   two fingerprints of an unchanged environment are equal
  cheat 1    schema/2 receipt with the block deleted -> "environment block
             missing"
  cheat 2    env_vars_read carrying "TECHNE_FOSSIL_VAULT=D:/somewhere" ->
             refused ("not a bare name")
  cheat 3    pip_freeze_sha256 = "deadbeef" -> refused
  plus       interpreter missing -> refused; unknown schema -> refused;
             schema/1 -> reported as predating, NOT failed; census of the
             263 tracked receipts has 0 defects; end-to-end native run on a
             synthetic specimen writes /2, names TECHNE_FOSSIL_VAULT, and
             the temp vault PATH VALUE does not appear in the written file.

Baseline census (committed): n=263  carries_rq4=0  predates_rq4=263
