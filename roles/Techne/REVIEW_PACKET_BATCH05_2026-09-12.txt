  do-mpc horizon); each is written in the recipe notes and journal.

- Some recipes install from the network at run time (pip, apt gcc-multilib,
  casadi wheel): reproducibility depends on those registries; the pinned
  Owl Lisp companion is the exception done right.
- Bodies remain on one host (~1 GB, 90 bodies). Mirror built, destination
  not named (TECHNE-65).
