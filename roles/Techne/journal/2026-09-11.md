## PREREGISTRATION for TECHNE-45 (committed before any solver is run under the new criterion)

The defect being repaired: a criterion that reads a status string cannot see a confidently wrong
number. ELEN-TECHNE-38 showed SCS returning `optimal` with a 188% error in arm C; arms A and B
carry the same blindness and have not been measured.

Ground truth, declared now:

    arm A  theta(C_5) = sqrt(5)                        closed form (Lovasz 1979)
    arm B  three families with closed-form theta, at n comparable to the existing 20/60/120:
             odd cycle C_n        theta = n cos(pi/n) / (1 + cos(pi/n))   n in 21, 61, 121
             Paley graph P_p      theta = sqrt(p)                          p in 29, 61, 113
             Kneser K(m,k)        theta = C(m-1, k-1)                      (7,2)=21, (9,3)=84,
                                                                            (10,3)=120
           the three EXISTING random graphs (n = 20, 60, 120, p = 0.3, seed 0) are KEPT because
           they are the roadmap's shape, and they have no closed form. They are scored by a
           CERTIFICATE computed by numpy from the matrices the solver returns, never from its
           status:
             lower bound  project the returned X to exact feasibility (zero the edge entries,
                          clip negative eigenvalues, rescale trace to 1) and evaluate sum(X').
                          X' is feasible by construction, so sum(X') <= theta.
             upper bound  any symmetric Y supported on the edge set gives theta <= lambda_max(J + Y)
                          (Lovasz's theta_3 formulation); Y is built from the solver's edge-constraint
                          duals, both signs tried, the smaller lambda_max kept. Valid for ANY Y, so
                          the bound is unconditional; only its tightness depends on the solver.

Classification, declared now, same bar as arm C (SILENTLY_WRONG_REL = 1e-2) so one number governs
the whole fixture; the bar is a reporting threshold, not an accuracy requirement (TECHNE-46):

    closed-form cases   rel = |value - theta| / theta
                        CORRECT          status optimal and rel <= 1e-2
                        SILENTLY_WRONG   status optimal and rel  > 1e-2
                        DECLARED_FAILURE status not optimal (rel still reported)
                        RAISED           exception
    certificate cases   [lb, ub] as above; width = (ub - lb) / ub
                        CERTIFIED        value in [lb - 1e-6*ub, ub + 1e-6*ub] and width <= 1e-2
                        SILENTLY_WRONG   status optimal and value OUTSIDE the interval
                        INDETERMINATE    value inside the interval but width > 1e-2 -- the
                                         certificate cannot decide; reported, never counted as a pass
                        UNCERTIFIED      no X or no duals returned; reported, never counted as a pass
                        DECLARED_FAILURE / RAISED as above
    a case FAILS the gap fixture iff its class is not CORRECT / CERTIFIED. INDETERMINATE and
    UNCERTIFIED are failures of the INSTRUMENT and are listed separately from solver failures.
