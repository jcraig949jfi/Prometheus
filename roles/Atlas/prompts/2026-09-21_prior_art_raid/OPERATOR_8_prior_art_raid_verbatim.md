========================================================================
I. CENTRAL SCIENTIFIC QUESTION

Prometheus is ultimately interested in machinery capable of converting experience
into increasing competence under changing conditions, while allowing unexpected
mechanisms, organisms, ecologies and higher-order structures to emerge.

We especially care about systems in which:

experience
    -> persistent structure
    -> reusable competence
    -> access to previously unreachable experience
    -> further structural change

and where this loop is not entirely specified by us in advance.

The newly recovered prior art suggests several mechanisms that could accelerate,
block, fake or fundamentally alter that loop.

ATLAS must turn those mechanisms into discriminating experiments.

========================================================================
II. DO NOT TEST “DOES THE PAPER WORK?”

Replication is useful but insufficient.

The scientific objective is NOT:

"Can we reproduce Voyager?"

or:

"Can MAP-Elites improve a benchmark?"

Instead ask questions like:

Does persistent executable skill memory produce cumulative capability
beyond equivalent context memory?
Does skill composition open genuinely new reachable state space?
Does a generated curriculum accelerate acquisition while reducing
behavioral diversity?
Does environment generation create capability, or merely teach agents
to exploit generator regularities?
Does learned behavioral niching preserve stepping stones that our
existing observatory would otherwise lose?
Does sharing discoveries between evolutionary branches improve cumulative
innovation, or cause monoculture?
Does allowing the copying machinery itself to mutate create qualitatively
different evolutionary dynamics than fixed-interpreter organisms?
When do collections of organisms become a higher-level unit of selection?
Can an agent's acquired library become an evolutionary substrate itself?
Does self-generated task/reward creation increase competence or merely
move the evaluator?

These are Prometheus experiments.

⸻

F5-0 — PERSISTENCE IS ACTUALLY USEFUL

Question:

Does persistent acquired competence improve future performance beyond simply
giving an agent equivalent historical context?

Treatments:

A. no memory
B. episodic textual memory
C. retrieved demonstrations
D. persistent executable skill library
E. persistent executable skill library with composition

Use the same underlying controller where possible.

Worlds must contain recurring structural regularities without identical tasks.

Measure:

* learning speed;
* transfer;
* retained competence;
* behavioral diversity;
* number of previously unreachable states/tasks reached;
* library utilization;
* library growth;
* competence after context reset.

Critical falsifier:

If executable persistence provides no advantage after controlling for information
content and compute, the Voyager-like mechanism does not justify special treatment.

⸻

F5-1 — SKILL COMPOSITION

Question:

Can independently acquired skills compose into competence never directly trained?

Construct tasks where success requires A+B, while training exposes A and B
independently.

Controls:

* monolithic policy;
* demonstrations;
* retrieved raw episodes;
* noncomposable skill library;
* explicit hand-authored macro.

Measure:

* zero-shot composition;
* number of new reachable goals;
* reuse depth;
* dependency graph;
* failure localization.

Anti-cheat:

Ensure the composite task itself never appeared in training.

⸻

F5-2 — CROSS-WORLD TRANSFER

Question:

Can a substrate-independent skill representation survive changes in world
appearance, geometry, dynamics or embodiment?

Systematically vary:

* visuals;
* topology;
* control mapping;
* object identity;
* physics;
* action primitives;
* embodiment.

Ask which acquired structures transfer.

This experiment should help separate:

WORLD-SPECIFIC SCRIPT

from:

GENERALIZED COMPETENCE.

F5-3 — GENERATED WORLD CURRICULUM

Compare a Genie-like or open substitute world generator against these controls.

* transfer;
* diversity;

⸻

F5-4 — CLOSED COMPETENCE LOOP

Test the loop:

generate world/task
-> attempt
-> acquire skill
-> persist skill
-> select/generate harder novelty
-> reuse / compose skills
-> acquire new competence

A run only counts as cumulative if later progress causally depends on retained
structures from earlier episodes.

Use transplantation / ablation tests.

Remove the accumulated library late in a run.

Replace it with:

* empty library;
* shuffled library;
* equal-size irrelevant library;
* library from another lineage.

Measure the competence collapse.

F5-5 — SELF-GENERATED TASKS AND REWARDS

* generated task + external evaluation;
* generated task + generated reward;
* generated task + adversarial independent evaluator;
* generated task + delayed transfer evaluation.

Critical concern:

Reward/task generator and learner may collude accidentally.

Require independent transfer tests.

XVI. “ALIENNESS” PROTECTION

A major risk of importing mature machinery is importing mature assumptions.

Every prior-art-derived experiment must ask:

WHAT POSSIBILITY DOES THIS MECHANISM MAKE IMPOSSIBLE?

Examples:

* MAP-Elites requires some behavioral partition.
* skill libraries privilege reusable discrete procedures.
* generated rewards privilege measurable objectives.
* world models inherit their training distribution.
* language-conditioned agents inherit linguistic ontology.
* NEAT assumes graph-like neural controllers.
* executable code evolution assumes programmatic representation.
* fixed action spaces constrain possible agency.

For every proposed transplant, create an:

ASSUMPTION_COST

field.

Where practical, design a counterexperiment where the donor’s assumption is removed.

Prometheus must consume the field without becoming trapped inside the field’s ontology.
