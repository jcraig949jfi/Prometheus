5. WHAT WOULD FALSIFY THIS PACKET
   - a consumer on M2 that connects to the fork despite the guard: the pin
     is by schema name; a production schema renamed away from `viv` would
     escape it (known; the schema name is a constant nobody sets)
   - the dead-man relaunching over a live row: it trusts `tasklist` on the
     recorded pid; pid reuse by an unrelated python on this host within the
     staleness window would read BUSY (safe direction) -- the unsafe
     direction (a live consumer read DEAD) needs the pid to be gone
   - a value checker that passes admission and fails execution: the
     identity cheat covers the call, not the arguments; an executor that
     mutates the payload before checking would diverge (none does today)
   - the C2 pulse masking a hung executor: a hung row now looks alive to
     `health`; the stall detector (viv.cli stalls) is the instrument for
     that, unchanged
