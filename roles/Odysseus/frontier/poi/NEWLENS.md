# New-lens candidates -- questions no current engine represents cleanly

Currency: 2026-09-27. Odysseus. From CROSSWALK.md readings 1-6 and the
harvest. A candidate here is a claim that bending an existing engine would
INSTALL the answer or hide the question. Each names the smallest world that
could ask it, and a stdlib toy that would test whether the lens is worth
building. None is built. Pure ASCII.

L1 THE EMERGING INDIVIDUAL (POI-007, POI-008; map I1)
   Gap: ten engines define the organism; Aether defines none and has seen
   none. Smallest world: a lattice with local conserved resource and a
   write cost, no organism, no birth primitive; detector = boundary-free
   segmentation (individuality scan / local causal states) against a
   shuffled-field null. Toy test first: can the detector find planted
   self-maintaining blobs and reject planted inert ones?
   Why not Aether as-is: possibly it IS Aether with a different physics;
   Aether's clean-room doctrine (D-1) would decide. Offer, do not impose.

L2 THE LEARNING RULE NOBODY INSTALLED (POI-061, POI-063; map L1-L4)
   Gap: WTP/SI install the learner; no engine lets a plasticity rule arise
   from physics. Smallest world: relaxational dynamics with slow,
   stress-yielding couplings, repeated perturbation, dissipation (natural
   induction), and a periodic-forcing variant (temporal contrast). Test:
   does the coupling matrix move in a Hebbian direction with no rule, and
   does that improve a later task the system never saw? Frozen-coupling
   and shuffled-perturbation controls.

L3 RESOURCE-CHARGED INFORMATION (POI-070..074; map P4, X6)
   Gap: no engine charges for bits as physics; where costs exist they are a
   designed economy. Smallest world: a byte soup where every overwrite
   draws from a finite local budget replenished by a flux, with block-copy
   removed. Test: does replication survive; does fidelity then trade
   against cost as persistent-copy theory predicts?

L4 COMPOSITION AND THE SECOND TRANSITION (POI-039, POI-012; map O2, P3)
   Gap: no engine observes a major transition; Aether shows almost no joint
   causation. Smallest world: two replicator classes whose products are
   each other's resources (the E6 C8 "reproduction requires computation"
   condition without an installed task), in space. Test: does a
   co-transmitted unit (shared fate) appear, against a well-mixed control
   that should collapse (known dead end)?

L5 MEASURABLE AGENCY (POI-081; map O7)
   Gap: nobody measures goal-directedness. Smallest instrument (not a
   world): counterfactual convergence -- perturb a system off its
   trajectory in ways it never met; score return to the same target set
   vs a matched non-goal-directed dynamical null. Test on toy homeostats
   first; then run on any engine's organisms.

L6 AN ENDOGENOUS OBSERVER FOR OPEN-ENDEDNESS (POI-082; map H6)
   Gap: open-endedness is observer-relative, and every external system
   puts the novelty judge outside the world (often a foundation model).
   Smallest version: a predictor grown inside the same soup; novelty =
   what that predictor fails to predict. Instrument study first.

L7 CHANNEL SEMANTICS (map P6)
   Gap: PTE sums arrivals (no addresses); no engine lets addressing or
   symbols arise. Lower priority: may be a PTE extension rather than a new
   lens; the owner decides.

Pattern: L1, L2 and L4 are what the directive calls "mechanisms outside
familiar modalities". L3 and L5 are cheap and would inform every engine.
