The coordinator rejected the Preisach medium as equivalent to a known mechanism. It and the earlier latches all held the cue as a value that the readout sees. This proposal takes the stored cue value out of the readout entirely: the cue reconfigures how signals are routed, and the readout sees only routed activity. Later symbols, including the query, become carriers that express the cue through where they land.

```python
import numpy as np
from prometheus.cosmos.c3.system import System
from prometheus.cosmos.c3.task import Task, onehot


class Mechanism(System):
    """Contextual routing fabric. A crossbar router W (m x m, row-stochastic) sits between
    an input layer (fixed symbol embeddings) and an output activity layer. The router is
    plastic only while it is 'unconfigured' (plasticity budget p, consumed when the router
    rewires). Symbols move W toward one of a fixed set of routing permutations; the first
    symbol, the cue, spends most of the budget. Each subsequent symbol is pushed through W
    into a leaky output trace, so distractors and the query do not overwrite the cue but are
    transformed by it. The readout sees only the output activity, never W: the cue is visible
    solely as the way it bends the flow of later signals."""

    def __init__(self, task: Task):
        self.task = task
        self.ns = int(task.n_symbols)
        self.m = 16
        r = np.random.default_rng(14142)
        # fixed routing permutations per symbol (cue symbols get distinct ones)
        perms = np.stack([r.permutation(self.m) for _ in range(self.ns)])
        self.Perm = np.zeros((self.ns, self.m, self.m))
        for s in range(self.ns):
            self.Perm[s, np.arange(self.m), perms[s]] = 1.0
        # symbol embeddings on input ports (sparse, nonnegative)
        Emb = np.zeros((self.ns, self.m))
        for s in range(self.ns):
            Emb[s, r.choice(self.m, size=3, replace=False)] = 1.0
        self.Emb = Emb
        self.eta = 0.9            # rewiring rate (times remaining budget)
        self.spend = 0.85         # fraction of budget consumed per rewiring event
        self.leak = 0.5           # output trace leak
        self.sigma_a = 0.1        # output activity noise
        self.sigma_w = 0.02       # router jitter

    def init(self, E):
        W = np.broadcast_to(np.full((self.m, self.m), 1.0 / self.m), (E, self.m, self.m)).copy()
        return {"W": W, "p": np.ones((E, 1)), "a": np.zeros((E, self.m))}

    def noise(self, n, rng):
        return {"a": rng.normal(0.0, self.sigma_a, size=(n, self.m)),
                "w": rng.normal(0.0, self.sigma_w, size=(n, self.m, self.m))}

    def step(self, state, obs_t, noise):
        obs = np.asarray(obs_t, dtype=int)
        W, p, a = state["W"], state["p"], state["a"]
        x = onehot(obs, self.ns)
        e = x @ self.Emb                                           # (E, m)

        # signal flows through the current router into the output trace
        a_new = self.leak * a + np.einsum("eij,ej->ei", W, e) + noise["a"]

        # router plasticity, budget-limited: move toward this symbol's permutation
        target = np.einsum("es,sij->eij", x, self.Perm)
        rate = (self.eta * p)[:, :, None]
        W_new = (1.0 - rate) * W + rate * target + noise["w"]
        W_new = np.clip(W_new, 1e-6, None)
        W_new = W_new / W_new.sum(axis=2, keepdims=True)
        p_new = p * (1.0 - self.spend)
        return {"W": W_new, "p": p_new, "a": a_new}

    def readout_features(self, state):
        return state["a"]

    def full_state(self, state):
        E = state["a"].shape[0]
        return np.concatenate([state["W"].reshape(E, -1), state["p"], state["a"]], axis=1)


def make(task):
    return Mechanism(task)
```

The cue is held in the configuration of a plastic crossbar router. It spends most of a limited rewiring budget, so later symbols can only nudge the router slightly. Every later symbol, the query included, is pushed through the router into a leaky output trace, so the readout sees no stored cue value at all. It sees only how the router reshapes the query and the recent distractors, which turns them from interferers into carriers of the cue.
