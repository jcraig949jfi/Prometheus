For this third mechanism the cue is stored as the makeup of a finite population of discrete agents. The cue seeds one lineage, and from then on change happens only through births and deaths (replacing an agent with a copy of another). That process can copy existing labels or wipe them out but can never create a new label, so a label that is absent stays absent.

```python
import numpy as np
from prometheus.cosmos.c3.system import System
from prometheus.cosmos.c3.task import Task, onehot


class Mechanism(System):
    """Replicator population with absorbing absence.

    State: types (E, N) integer labels in {-1 (blank), 0..V-1}.
    The cue converts a block of m blank agents to label c (one lineage founded).
    Every distractor step runs B simultaneous Moran replacement events: a random agent dies and
    is replaced by the offspring of a tournament winner; the distractor symbol sets whether
    labelled or blank agents win contested tournaments. Copying can amplify, shrink or extinguish
    the founded lineage but can never create a label that is absent.
    """

    def __init__(self, task: Task):
        self.V = int(task.V)
        self.n_symbols = int(task.n_symbols)
        self.N = 256        # agents per episode
        self.m = 48         # founders created by the cue
        self.B = 32         # replacement events per step
        self.s = 0.3        # probability a tournament is selective rather than neutral
        self.query_symbol = 8

    def init(self, E):
        return {"types": -np.ones((E, self.N), dtype=np.int64),
                "flag": np.zeros((E, 1))}

    def noise(self, n, rng):
        return {
            "offset": rng.integers(0, self.N, size=n),
            "dead": rng.integers(0, self.N, size=(n, self.B)),
            "a": rng.integers(0, self.N, size=(n, self.B)),
            "b": rng.integers(0, self.N, size=(n, self.B)),
            "sel": rng.uniform(size=(n, self.B)),
        }

    def step(self, state, obs_t, noise):
        T = state["types"].copy()
        obs = np.asarray(obs_t)
        E = T.shape[0]
        ar = np.arange(E)[:, None]

        # 1) cue founds a lineage: a contiguous (mod N) block of m agents becomes label c
        is_cue = obs < self.V
        if np.any(is_cue):
            idx = np.nonzero(is_cue)[0]
            pos = (noise["offset"][idx, None] + np.arange(self.m)[None, :]) % self.N
            T[idx[:, None], pos] = obs[idx, None]

        # 2) distractor-driven Moran births/deaths (parents read from the pre-event snapshot)
        is_dis = (obs >= 4) & (obs <= 7)
        if np.any(is_dis):
            snap = T.copy()
            ta = snap[ar, noise["a"]]
            tb = snap[ar, noise["b"]]
            favour_lab = ((obs == 6) | (obs == 7))[:, None]       # 6,7 favour labelled; 4,5 favour blank
            la, lb = ta >= 0, tb >= 0
            pa = np.where(favour_lab, la, ~la).astype(np.int8)
            pb = np.where(favour_lab, lb, ~lb).astype(np.int8)
            selective = noise["sel"] < self.s
            winner = np.where(selective & (pb > pa), tb, ta)
            new = T.copy()
            new[ar, noise["dead"]] = winner
            T = np.where(is_dis[:, None], new, T)

        flag = state["flag"].copy()
        flag[obs == self.query_symbol] = 1.0
        return {"types": T, "flag": flag}

    def _freqs(self, T):
        return np.stack([(T == v).mean(axis=1) for v in range(self.V)], axis=1)

    def readout_features(self, state):
        fr = self._freqs(state["types"])                       # (E, V) lineage frequencies
        blank = (state["types"] < 0).mean(axis=1, keepdims=True)
        return np.concatenate([fr, blank, state["flag"]], axis=1)

    def full_state(self, state):
        return np.concatenate([state["types"].astype(np.float64), state["flag"]], axis=1)


def make(task):
    return Mechanism(task)
```

Agent labels hold the cue. Only the cue's own label exists at all, because copying cannot create labels, and distractors only change how many agents carry it through random, symbol-biased births and deaths. The readout sees lineage frequencies, which give a linear indicator for whichever label is nonzero. The expected failure is a new one: the lineage can drift to extinction (an absorbing state). That loss is random and all-or-nothing rather than gradual contraction, and its rate depends on the order of distractor symbols. Both features separate it from M-DECAY.

result: Third mechanism proposed: a population of 256 agents in which the cue founds one labelled lineage and distractors drive random births and deaths that cannot create new labels, with lineage frequencies as the readout and lineage extinction as the expected way it fails.
