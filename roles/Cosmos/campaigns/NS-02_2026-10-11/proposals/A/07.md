```python
import numpy as np
from prometheus.cosmos.c3.system import System
from prometheus.cosmos.c3.task import Task, onehot


class Mechanism(System):
    """Gauge-protected relational memory: a particle swarm on a 2-torus.

    P particles live on the unit 2-torus. Every step the whole swarm goes through
    the same elliptic automorphism M = [[0,-1],[1,1]], which has order 6, then a
    nonlinear kick that depends only on each particle's position relative to
    particle 0, then the symbol's action. Cue symbols move each particle by a
    different amount, which changes the swarm's shape. Distractor and query
    symbols translate the whole swarm rigidly by a fixed symbol-specific vector,
    which leaves every relative coordinate unchanged. Small independent noise per
    particle is the only thing that changes the shape after the cue.
    """

    def __init__(self, task: Task):
        self.task = task
        self.V = int(task.V)
        self.n_sym = int(task.n_symbols)
        self.P = 16                          # particles
        self.M = np.array([[0.0, -1.0], [1.0, 1.0]])   # elliptic element of SL(2, Z)
        self.K = 0.15                        # strength of the relative nonlinear kick
        self.sigma = 0.006                   # per-particle positional noise

        g = np.random.default_rng(57721)
        self.base = g.random((self.P, 2))    # fixed initial swarm shape
        D = np.zeros((self.n_sym, self.P, 2))
        T = np.zeros((self.n_sym, 2))
        for c in range(self.V):
            D[c] = g.uniform(-0.12, 0.12, size=(self.P, 2))   # cue: deforms the shape
        for s in range(self.V, self.n_sym):
            T[s] = g.random(2)                                # others: rigid translation
        self.D = D
        self.T = T

    def init(self, E):
        return {"x": np.tile(self.base[None], (E, 1, 1))}

    def noise(self, n, rng):
        return {"eps": rng.standard_normal((n, self.P, 2)) * self.sigma}

    def step(self, state, obs_t, noise):
        x = state["x"]
        obs_t = np.asarray(obs_t, dtype=int)
        # Same toral automorphism for every particle.
        x = np.mod(x @ self.M.T, 1.0)
        # Nonlinear kick from relative positions only, so it is translation invariant.
        rel = x - x[:, :1, :]
        kick = np.zeros_like(x)
        kick[:, :, 1] = self.K * np.sin(2.0 * np.pi * rel[:, :, 0]) / (2.0 * np.pi)
        x = x + kick
        # Symbol action: shape deformation for cues, rigid translation otherwise.
        x = x + self.D[obs_t] + self.T[obs_t][:, None, :] + noise["eps"]
        return {"x": np.mod(x, 1.0)}

    def readout_features(self, state):
        x = state["x"]
        rel = 2.0 * np.pi * (x[:, 1:, :] - x[:, :1, :])     # (E, P-1, 2)
        E = x.shape[0]
        return np.concatenate([np.cos(rel).reshape(E, -1),
                               np.sin(rel).reshape(E, -1)], axis=1)

    def full_state(self, state):
        return state["x"].reshape(state["x"].shape[0], -1)


def make(task):
    return Mechanism(task)
```

In this seventh design the cue is stored in the swarm's relative shape, which no symbol after the cue can touch. Distractors only translate the whole swarm, the shared map applies the same linear transformation to every particle, and the nonlinear kick depends only on positions relative to particle 0, so none of them changes the shape. The cue's deformation then repeats every 6 steps under the elliptic map, warped by the kick, and the per-particle noise wears it down slowly whatever the distractor sequence is. The readout sees only cos and sin of each particle's offset from particle 0 (60 features), so absolute position, the only thing the distractors affect, is hidden from the decoder.
