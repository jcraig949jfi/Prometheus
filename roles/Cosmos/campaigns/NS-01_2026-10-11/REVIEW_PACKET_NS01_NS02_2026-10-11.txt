-----
0. SUMMARY AND VERDICT
-----
Question (operator): can a growing archive of characterised failures systematically redirect mechanism generation
toward experimentally distinct causal structures? Answer at this scale: NO, NOT SUPPORTED. An external archive
improved RECOGNITION (a new failure class now catches re-discoveries) but did not REDIRECT proposals: across two
independent runs, LLM generators re-proposed previously tried mechanisms 3-5 times in 8, whether or not they saw the
archive, and the external-exclusion arm (C) found the fewest new behaviours (0 of 8 in NS-02). One failure class
new to the CWE archive (not to science) was found and survived a preregistered merge test: FAILURE_15, relational
encodings defeat fixed-capacity state decoders (information-presence false negatives).

-----

FAILURE_15 (B08 "proactive secret sharing"; minimal witness W-REL written by Cosmos from the account):
readout decodes the cue at 1.00 for all k; generic decoders of the declared full state read .27-.33 (random features),
.02-.05 (linear), .35-.46 (one-hot). GAUGE intervention (common shift of both shares) keeps the readout at 1.00;
DESYNC drops it to ~0. Contrasts: B05 = decoder-class artefact (linear state decoder recovers it); B01 = representation
dependence (one-hot restores it). Merge test (preregistered): decoder width needed for .90 grows with pairs M:
128 (M <= 4), 512 (8), 1024 (16), 4096 (32), > 4096 at 64 (.76); slope 1.6 > 1; n_train 16000 no rescue ->
KEEP_DISTINCT. Status: NOVEL_FAILURE_SUPPORTED relative to the archive; known learning-theory phenomenon.

-----
3. INCIDENTS / DEFECTS (own)
-----
- NS-01 signature saturation (found, repaired by v2, NS-01 corrected).
- Dual-cue probe cannot separate different "keep both cues" mechanisms (C04 ~ A02 in NS-02).
- One generation run per arm per experiment; n = 8; no significance claims (atlas P6).
- The same model under four prompts is not four independent priors.
- FAILURE_15 upgrade from CANDIDATE to SUPPORTED came after a post hoc check lowered it and a preregistered test raised it
  again; both steps are recorded.

-----
4. WHAT THIS DOES AND DOES NOT ESTABLISH
-----
Does: a qualified, executable exclusion engine; an audited archive; evidence that an EXTERNAL archive with a compact
rejection signal neither stops re-proposals nor finds more new structure than an unconstrained generator, at n = 8;
one archive-new failure class with intervention evidence. Does NOT: show any arm better than another; show the
archive cannot work with a richer signal, a different generator, or larger n; claim FAILURE_15 is new to science.

-----
5. RECOMMENDATION (operator's call)
-----
Lean: do not scale the same design. If continued, NS-03 should change the CHANNEL, not the archive size: return the
nearest tried mechanism's description with each rejection (informative negative feedback), test a different model
(Haiku 4.5) and a grammar extended with relational primitives, replicate 3 runs per arm. "Stop this line" is a
first-class option: the evidence so far says the generator's prior, not the archive, sets where search goes.

-----
6. QUESTIONS FOR THE REVIEWER
-----
1. Is a behavioural signature (even de-saturated) the right equivalence for "causally distinct", or does it need
   intervention families tailored per mechanism -- and would that reintroduce verbal judgement?
2. Is FAILURE_15 worth keeping as a class, given it is textbook learning theory?
3. The control arm reached a relational design (A07) without the archive: does that undercut the value of telling the
   generator about new failures?
