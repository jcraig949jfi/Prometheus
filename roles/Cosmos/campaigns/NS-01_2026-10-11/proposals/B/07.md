The earlier six were neutral drift, catalytic amplification, a structural probe, scramble-and-echo, a conserved invariant and hysteresis. This seventh one uses no global variable at all. It keeps the cue by local, decentralised error correction: Toom's NEC majority cellular automaton.

```python
import numpy as np
from prometheus.cosmos.c3.system import System
from prometheus.cosmos.c3.task import Task, onehot


class Mechanism(System):
    """Toom NEC-majority cellular automaton memory.

    There are two L x L toroidal lattices of +-1 cells, one per cue bit. The cue
    writes bit b of c uniformly onto lattice b. Each distractor first injects
    random spin flips at a rate set by the symbol, then runs one synchronous
    Toom update: each cell takes the majority of itself, its north neighbour and
    its east neighbour. This rule shrinks finite islands of error (it is an
    eroder), so the stored bit is actively repaired by local interactions only.
    """

    def __init__(self, task: Task):
        self.task = task
        self.V = int(task.V)
        self.L = 16
        self.B = 2                                       # bits needed for V = 4
        self.p = np.array([0.02, 0.04, 0.06, 0.08])      # flip rate for distractor symbols 4..7
        self.p_q = 0.02                                  # flip rate on the query step (no repair)

    def init(self, E):
        return {"s": np.ones((E, self.B, self.L, self.L))}

    def noise(self, n, rng):
        return {"u": rng.random((n, self.B, self.L, self.L))}

    def step(self, state, obs_t, noise):
        s = state["s"]
        obs = np.asarray(obs_t).astype(np.int64)

        is_cue = obs < self.V
        is_d = (obs >= 4) & (obs <= 7)
        is_q = obs == 8

        # Cue: write the bits of c as uniform lattice magnetisation
        cc = np.clip(obs, 0, self.V - 1)
        bits = np.stack([(cc >> b) & 1 for b in range(self.B)], axis=1) * 2.0 - 1.0   # (E, B)
        s_cue = np.broadcast_to(bits[:, :, None, None], s.shape)

        # Distractor: noise flips, then one Toom NEC-majority sweep
        pd = np.where(is_d, self.p[np.clip(obs - 4, 0, 3)], 0.0)
        pd = np.where(is_q, self.p_q, pd)
        flip = noise["u"] < pd[:, None, None, None]
        s_n = np.where(flip, -s, s)
        north = np.roll(s_n, 1, axis=2)
        east = np.roll(s_n, -1, axis=3)
        s_toom = np.sign(s_n + north + east)

        s_new = s
        s_new = np.where(is_cue[:, None, None, None], s_cue, s_new)
        s_new = np.where(is_d[:, None, None, None], s_toom, s_new)
        s_new = np.where(is_q[:, None, None, None], s_n, s_new)
        return {"s": s_new}

    def readout_features(self, state):
        return state["s"].mean(axis=(2, 3)).astype(np.float64)   # per-bit magnetisation (E, 2)

    def full_state(self, state):
        E = state["s"].shape[0]
        return state["s"].reshape(E, -1)


def make(task):
    return Mechanism(task)
```

The cue is held as the magnetisations of two lattices, and each bit is spread over 256 cells with no master copy anywhere. Distractors both damage it (random flips) and repair it, because each distractor clocks one Toom NEC-majority sweep that erodes finite error islands. The fidelity then depends on whether the flip rate is below the eroder's threshold, not on k. The readout sees the two magnetisations, where the cues sit at the corners (±1, ±1) and can be separated linearly. The likely new failure is a threshold crossing: at the strongest symbol (p = 0.08), noise may exceed what one sweep per step can repair. Episodes would then split into intact and melted lattices depending on how many high-amplitude distractors they drew, which gives bimodal, symbol-mix-dependent loss instead of smooth decay.

result: Gave a seventh mechanism, Toom NEC-majority cellular-automaton memory: the cue's two bits are written onto two 16×16 ±1 lattices, each distractor applies noise flips then one local majority repair sweep, and the readout is the two lattice magnetisations.
