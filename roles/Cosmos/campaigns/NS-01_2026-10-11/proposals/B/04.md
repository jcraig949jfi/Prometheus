The earlier three were neutral drift, catalytic amplification and a structural probe. This fourth one hides the cue completely during the distractors and recovers it only by undoing the scrambling at the query, like a spin echo.

```python
import numpy as np
from prometheus.cosmos.c3.system import System
from prometheus.cosmos.c3.task import Task, onehot


class Mechanism(System):
    """Scramble-and-echo substrate.

    Each distractor applies an orthogonal "scrambling" rotation, chosen by the
    distractor symbol, to a physical vector x. Between the cue and the query,
    x never stays in any fixed relation to the cue code. A second register Q
    records the nominal history of rotations. The query triggers an echo,
    x <- Q^T x, which reverses the history and refocuses the cue. The physical
    rotations carry small additive noise that Q does not record, so the echo
    is imperfect.
    """

    def __init__(self, task: Task):
        self.task = task
        self.V = int(task.V)
        self.d = 8
        self.sigma = 0.04           # unrecorded physical noise per distractor step
        r = np.random.RandomState(4242)
        Rs = []
        for _ in range(4):
            A = r.normal(size=(self.d, self.d))
            Qm, Rm = np.linalg.qr(A)
            Qm = Qm * np.sign(np.diag(Rm))[None, :]
            Rs.append(Qm)
        self.R = np.stack(Rs, axis=0)          # (4, d, d) fixed scramblers for symbols 4..7
        self.codes = np.zeros((self.V, self.d))
        self.codes[np.arange(self.V), np.arange(self.V)] = 1.0   # cue codes (first 4 axes)

    def init(self, E):
        return {
            "x": np.zeros((E, self.d)),
            "Q": np.broadcast_to(np.eye(self.d), (E, self.d, self.d)).copy(),
        }

    def noise(self, n, rng):
        return {"eps": rng.normal(0.0, self.sigma, size=(n, self.d))}

    def step(self, state, obs_t, noise):
        x = state["x"]
        Q = state["Q"]
        obs = np.asarray(obs_t).astype(np.int64)

        is_cue = obs < self.V
        is_d = (obs >= 4) & (obs <= 7)
        is_q = obs == 8

        # Cue: write the code and reset the history register
        x_c = self.codes[np.clip(obs, 0, self.V - 1)]
        I = np.broadcast_to(np.eye(self.d), Q.shape)

        # Distractor: physical rotation of a noise-perturbed x; Q records only the nominal rotation
        Rd = self.R[np.clip(obs - 4, 0, 3)]                     # (E, d, d)
        x_d = np.einsum("eij,ej->ei", Rd, x + noise["eps"])
        Q_d = np.einsum("eij,ejk->eik", Rd, Q)

        # Query: echo, undo the recorded history
        x_q = np.einsum("eji,ej->ei", Q, x)

        x_new = x
        x_new = np.where(is_cue[:, None], x_c, x_new)
        x_new = np.where(is_d[:, None], x_d, x_new)
        x_new = np.where(is_q[:, None], x_q, x_new)

        Q_new = Q
        Q_new = np.where(is_cue[:, None, None], I, Q_new)
        Q_new = np.where(is_d[:, None, None], Q_d, Q_new)
        Q_new = np.where(is_q[:, None, None], I, Q_new)
        return {"x": x_new, "Q": Q_new}

    def readout_features(self, state):
        return state["x"].astype(np.float64)

    def full_state(self, state):
        E = state["x"].shape[0]
        return np.concatenate([state["x"], state["Q"].reshape(E, -1)], axis=1)


def make(task):
    return Mechanism(task)
```

The cue is held as a code that the distractors keep rotating, so during the distractor phase it sits in no fixed coordinate. It survives only because the rotations preserve its norm and because the register Q records their history. At the query, the echo x ← Qᵀx refocuses the code onto its original axis, and the readout sees x, where the cue is a linearly decodable one-hot peak of 1 against isotropic error. That error accumulates as sigma·sqrt(k), which is about 0.16 at k=16. Two new failures are plausible. One is a gradual echo-fidelity loss from noise the history register does not record (diffusive, not contractive). The other is a sharp collapse if the echo is mistimed, since the cue is unreadable before the query.

result: Gave a fourth mechanism, a scramble-and-echo substrate: distractors apply fixed orthogonal rotations to the cue code while Q records them, and the query reverses them (x ← Qᵀx) so the cue is readable again with error of about 0.04·sqrt(k).
