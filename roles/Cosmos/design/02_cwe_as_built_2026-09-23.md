## 2. Decisions and departures (with reasons)

D1  NEW clean-room families instead of adapters over WSE / BEE / NPE code. Reason: the
    charter's first requirement is a functional demand that is IDENTICAL across families
    while mechanisms differ; WSE's stream world and BEE's stream substrate already share a
    grammar (01 s5.2: "F1 and F2 share the world grammar"), which is the shared-evaluator
    failure the charter lists. Adapters to donor engines are the natural C1 item.
D2  LAST is MEMORYLESS (answers from the current observation only), not "last value".
    In a cue-then-distractors task a last-value register pays the same maintenance as SEL
    and is strictly worse, so it can never define the high-cost boundary; WSE's TRIVIAL
    plays that role because it holds fewer words. Recorded in the translation manifest.
D3  The certificate is the one shared evaluator (by definition of the phenomenon). The
    physics evaluators are independent; the lineage audit counts code, not ideas.
D4  Coordinates are DECLARED hypotheses (coord maps v1/v2), computed from the spec only.
    Detector leakage guard: the certificate cannot see the spec (test_phenomenon).
D5  Expression identity by rank order on the probe rows (thresholds see only order) --
    Aphrodite's quotient idea applied to the law language; it cut 13,272 expressions to
    ~4,400 classes and makes equivalent forms visibly non-identifiable.
D6  Recovery of planted laws is judged FUNCTIONALLY (agreement on a dense grid), because
    C - G exp(-N) <= t and G log C + N <= t trade places on finite data.
D7  No GPU, no AGE in C0. The AGE oracle is pure Python with no player concept (the
    certificate would be UNABLE on it); the RTX 5060 Ti adds speed, not a new substrate,
    for any family written here. Compute acceleration is not substrate diversity.
D8  Atlas is an export target (atlas_export.py), not a dependency (writes need Postgres).
D9  Operational state under COSMOS_HOME (default the user profile on C:), never on the
    M2 D: SMR disk; compact summaries are committed under roles/Cosmos/campaigns/.
D10 The permutation null reruns the ENTIRE search per permutation in a process pool;
    pickling the miner per task broke the Windows pipe (WinError 1450), so each worker
    rebuilds it once through an initializer.

## 3. Revisions made during the campaign (appended 2026-09-23 ~15:35Z; each driven by a recorded result)

D11 Coordinate map v3 (+ capacity Q = min(1, slots/(K+1)), + post-repair N): C0's adversary found the
    logger's capacity and native repair missing from v1 (campaigns/c0/RESULT_run2.md).
D12 The adversary evaluates in the LAW's coordinate map and keeps only transforms that preserve it
    (defect I1); every round attacks worlds never observed before (C0s S1 defect).
D13 Matched pairs share common random numbers (seed_key); zero eligible edges is INDETERMINATE.
D14 Intervention prescriptions report every flip of the law along the intervention axis (the band law
    broke the one-flip engine: G6 FAIL 0/12); intervention gates carry a naive-constant chance floor.
D15 Boundary LOCATION is a first-class attack (locate.py) and a kill criterion (C1+): the confident-
    contradiction rule cannot see a boundary shifted inside its own band, and pooled residual tests
    hid per-family offsets of opposite sign.
D16 Coordinate map v4 = v3 with the EXPECTED maintenance cost (ring: destroyed packets stop costing;
    clone: extinct clones stop costing, growing ones cost more).
D17 Location-aware SELECTION among near-tied candidates (select.py): LOLO accuracy is flat across
    laws whose boundaries differ by 30% in cost. Weakness: selection and gate share a criterion.
D18 Worker pools are memory-bounded and fall back to serial on any worker failure (two crashes).
D19 Three sealed universes (D, E, F) instead of one: D was spent in C0b, E tests a law frozen before E
    existed, F was sealed before the revision work it adjudicates.
