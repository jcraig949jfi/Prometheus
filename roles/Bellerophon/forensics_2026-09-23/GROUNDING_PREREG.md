## 0. What this round is and is not

It is a CONFIRMATION round: do the phenomena the forensics left standing reproduce under repaired instruments,
fresh seeds, fixed allocation and frozen adjudication rules? It is not a discovery campaign: no promotion, no adaptive
allocation, no new detectors mid-round, no threshold changes after seeing data. Every lane, cell, arm, seed and
config override is generated by `grounding.plan(inputs)`; its sha256 is frozen here (s9).

## 1. Common settings

ticks 500, cells 256, budget 256 (the campaign's sizes). Physics v2 unless a cell says v1 (G7P1 contrast).
Base vector: GRID / Z80_64 / SHARED / ENDOGENOUS_COPY / IMPLICIT / LOCAL / INC / ATOMIC / ABR / FIXED / BYTE / MED /
NONE / RANDOM; each cell overrides only what it names. Seeds: 9e12 + lane*1e9 + k (campaign seeds lie in
[1.6e11, 2.2e12]; disjoint). Matched arms of one pair share the seed and therefore the identical initial population
(the population draw precedes any arm-dependent RNG use; GRAPH adjacency is drawn first and is shared too).

## 2. Frozen detector definitions (read ONLY repaired fields; prometheus/z80atlas/adjudication.py)

- SELF_REPLICATION birth (world._is_self_copy): the child matches the writer's tape at >= 0.9 BEFORE and AFTER the
  writer's execution; >= 90% of the L window bytes were last written by LDI/LDIR/COPYALL whose SOURCE address lies in
  the writer's own tape [0,L); >= 90% of those writes were executed with the PC inside the writer's own tape; the
  material is the writer's (not a capture). COPY_EVENT = any registered birth.
- spontaneous(run): init RANDOM, no init_tapes, and a first SELF_REPLICATION whose writer is not of seed/transplant
  lineage. SUSTAINED(run, d): a SELF_REPLICATION chain of depth >= d (primary d = 3; secondary d = 10) AND
  sr_alive_end >= 1 (a self-replication-born organism alive at tick 500). EVOLUTIONARILY_ACTIVE(run):
  sr_variants_transmitted >= 1 (an SR-born variant, tape != its writer's, itself self-replicated).
- task_reached(run): not extinct AND >= 1 living organism whose tape, alone, answers every input of the configured
  task's fixed 16-input panel exactly under the run's read gate (tasks.verify_tape).
- paired beneficial density (geometry.scan_paired): base and every mutant (each position x 16 fixed deltas) scored
  on ONE seeded 8-input panel of the configured task; identity self-check must read 0.
- reproductive-architecture descriptor (adjudication.repro_descriptor, on the run's dominant SR tape): self_copy,
  copy_op, copy_pc, exec_own_bytes, exec_before_copy, uses_io, task_accuracy (panel accuracy on the arm's task).
- G6 origin classes (on first_self_replication.genealogy; the writer is genealogy[0]):
  CLIFF_AT_INIT      writer mechanism 'init' and its tape AT BIRTH is already self_copy (repro_descriptor)
  MUTATED_INIT       writer mechanism 'init', birth tape not self_copy, pre-execution tape at first SR is
  BUILT_BY_COPY      writer born by a non-SR COPY_EVENT (constructed by another organism's writes)
  RAMP (flag, any class): some ancestor genealogy[i>0] whose birth tape copies >= 25% of the window from its own
                     bytes by its own code in isolation, i.e. a partial copier existed in the line before the first
                     self-replicator. Otherwise CLIFF.
  Essential steps: bytes where the writer's pre-execution tape differs from its nearest non-SR ancestor's birth tape;
  each reverted singly; the count whose reversion abolishes self_copy in isolation.

## 3. Hypotheses, units, predictions, tests

Forensic priors quoted below are EXPLORATORY readings of the long campaign (POST_CAMPAIGN_FORENSICS.md); the
predictions are written so they can fail in the direction that would embarrass the forensic reading.

G1 Replication accessibility (lane G1, G1T; unit = run = one independent random initial population).
  Estimate per cell: P(spontaneous) with Wilson 95% CI; time to first SR; also per-organism-tick exposure.
  Prediction G1a: ENDOGENOUS_COPY / Z80_64 (n = 400): P(spontaneous) > 0, Wilson lower bound > 0.
  Prediction G1b: CONSTRUCTIVE shows the lowest rate of the five physics (historically 0/1,869 fixed-lane runs).
  G1T estimates across the six task families (n = 150 each); no directional prediction (exploratory estimation).

G2 Sustained reproduction (derived from G1/G1T/G7 RANDOM runs; unit = spontaneous run).
  Estimate: P(SUSTAINED d=3 | spontaneous), P(SUSTAINED d=10 | spontaneous), P(EVOLUTIONARILY_ACTIVE | spontaneous).
  Prediction G2a: P(SUSTAINED d=3 | spontaneous) >= 0.5 (forensic traced replay: deep chains in most spontaneous runs).

G3 Endogenous causal advantage (lane G3; unit = seed PAIR; arms ENDOGENOUS_COPY vs EXTERNAL; identical initial
  population; ext_mut_mult 0 so offspring of both arms are exact copies plus the same background mutation).
  Outcome: task_reached. Test per cell: exact two-sided sign test (McNemar) on discordant pairs; pooled over the 8
  primary cells: stratified sign test (sum of discordant counts). Prediction G3a (forensic: exposure-matched
  first runs favoured EXTERNAL 1,554 vs 443): pooled discordant pairs favour EXTERNAL; the ENDOGENOUS-favoured
  historical flag does NOT reproduce. Secondary cell extmut4 (historical 4x external mutation): same test,
  reported beside the primary to show what mutation supply contributes. Also reported: births per arm (offspring
  quantity is NOT matched and is shown, not hidden).

G4 Beneficial-neighbourhood mechanism (specimen-level, no worlds; unit = specimen = one independent origin).
  Specimens: (i) the 10 historical flagged runs with the largest paired gain (receipts/GEOM_AUDIT_flagged.json):
  their top tape; (ii) the first 30 G1 ENDOGENOUS_COPY/Z80_64 runs (by run id) whose dominant SR tape is
  self_copy in isolation. Interventions per specimen X (paired BD, configured task INC unless the run's task
  differs): X intact; X with copy ops NOPed; the copy routine (bytes [0, copy_pc]) grafted onto 10 foreign
  genomes (the INC witness padded with random bytes, and random tapes, seeded) vs a same-length random graft.
  Effect = BD(X) - BD(X_nopped); transplant effect = mean BD(foreign + routine) - mean BD(foreign + random graft).
  Prediction G4a (forensic: paired gain mean 0.0006): median |effect| < 0.02 and the transplant effect's 95%
  bootstrap CI (over specimens) includes 0. A median effect > 0.05 with a CI excluding 0 would REVIVE the claim.

G5 Architecture response (lane G5; unit = seed TRIPLE; identical seeded-replicator populations; arms ON = INC
  INCREMENTAL EXPLICIT, OFF = NEUTRAL EXPLICIT, ALT = ECHO INCREMENTAL EXPLICIT; equal ticks/cells/budget).
  Primary outcome: TASK_LINKED_ARCH = dominant SR tape self_copy AND task_accuracy >= 0.5 on the arm's task

  junk event). A null here is reported with its detectable-effect size, not as "no effect".

G6 Incremental construction (derived from every spontaneous G1/G1T/G7 run; unit = spontaneous run = one origin).

## 4. Statistics (directive Phase 9)

Every comparison states its unit, numerator/denominator, exposure-normalised rate where relevant, 95% interval
(Wilson for proportions; exact binomial for sign tests; bootstrap over the unit for means), and effect size.
Confirmatory tests (preregistered): G3 pooled sign test, G5 ON-vs-OFF sign test, G7a v1-vs-v2 POLLINATION
extinction sign test. Holm correction across these three. Everything else is ESTIMATION or EXPLORATORY and is
labelled so. Descendants are never counted as origins: the origin unit is the run (one first SR per run).
A null result is reported with the smallest effect the design could detect at 80% power, never as "no effect".
Multiple runs of one cell are independent replicates (distinct seeds, fresh populations); pairs/triples are the
unit wherever arms share a seed.

## 5. Stopping rule

The round stops when every planned run has a result line, OR 12.0 hours after the FIRST start (STATUS.json
first_start_ts), whichever comes first. Submission order: lane priority G8, G7P1, G1, G3, G5, P8, HIST, G1T, G7,
then plan order. Runs not completed at the cap are reported NOT_RUN by cell. No run is added, removed or re-seeded
after the start; a restart re-executes only runs with no result line.

## 6. What would change the verdict

Readiness for a multi-day campaign (Phase 10) requires: G8 all expectations hold; G1a holds; replay sample 100%;
G7a holds (the P1 channel is confirmed and removed) or the topology claims are withdrawn. G3/G4/G5/G6 outcomes shape
WHAT the next campaign optimises for, not whether the harness is ready.
