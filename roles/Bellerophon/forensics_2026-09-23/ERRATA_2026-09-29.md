## E1 -- G6a "160/160 BUILT_BY_COPY" is wrong; the correct figure is 103/160 (DEF-BEL-001)

- **Exposed by:** Artemis R-26 (comms #877, 2026-09-28), relayed as a suspension in Archaeon's
  ops/campaigns/C-001/ATTRIBUTION_ARC_2026-09-28/FIXEDPOINT_RESULT.md s3.
- **Defect:** tools/grounding_analysis.py g6_class tests genealogy[0]["mechanism"] == "init". World._spawn(..., "init")
  never records birth_class for initial organisms, so World._genealogy reports their mechanism as None. The "init"
  branch was therefore unreachable, and every origin fell through to BUILT_BY_COPY.
- **Recount** (tools/g6_recount.py; receipt receipts/G6_RECOUNT_2026-09-29.json; input
  C:/Users/James/z80atlas_grounding_2026-09-23/results.jsonl on M2, sha256 bc71eeb0...1108). Same 160 spontaneous origins:
  * the writer of the first self-replication was an INITIAL organism in 57/160, and in 26 of those it replicated with
    its unmodified initial random tape;
  * copy-born writers 103/160 = 64%: ENDOGENOUS_COPY 72, ENDOGENOUS_PARTIAL 15, PAIR_EXECUTION 11, CONSTRUCTIVE 4,
    OVERWRITE 1.
- **Consequences:**
  * GROUNDING_REPORT G6a still passes its frozen gate (>= 50%), but at 64%, not unanimously.
  * The sentence "160/160 first self-replicators are BUILT_BY_COPY" and the matching row "160/160 ... REPRODUCED_ASSOCIATION"
    are withdrawn. Cite 103/160, with 57 initial writers of which 26 were unmodified.
  * G6b (RAMP 83/160) and the essential-step counts were computed over the same rows. The RAMP test reads ancestors after
    genealogy[0], so it is unaffected by this defect, but it was not re-audited here.
- The original report is left unedited; this file is the correction of record.

## E2 -- the spontaneous-origin set is pseudo-replicated: 160 origins, 83 distinct seeds, 45 exact duplicates

- **Exposed by:** Artemis S3 (comms #1005; Fabric tsk-2b96eda5e96c), which estimated about 20 copies. This recount finds
  more.
- **Defect:** prometheus/z80atlas/grounding.py plan() sets seed = SEED_BASE + lane*1e9 + k, with no cell term. Every
  task / reproduction / representation cell of a lane reuses the same seeds, and grounding_analysis.py pools lanes G1,
  G1T and G7-RANDOM as if each origin were independent.
- **Recount** (tools/dedup_recount.py; receipt receipts/DEDUP_RECOUNT_2026-09-29.json; same input as E1):
  * 160 origins, 83 distinct seeds;
  * 45 EXACT duplicates (identical seed, first-SR tape and first-SR tick: the same event counted more than once).

  | set | n | G2 sustained (depth >= 3, alive) | G6 copy-born |
  |---|---|---|---|
  | as published (all origins) | 160 | 63 (39.4%) | 103 (64.4%, after E1) |
  | unique events | 115 | 33 (28.7%) | 82 (71.3%) |
  | one origin per seed | 83 | 21 (25.3%) | 57 (68.7%) |

- **Consequences:**
  * No frozen gate changes: G2a (>= 50%) fails in every version, and G6a (>= 50%) passes in every version.
  * The published G2 rate 63/160 and its Wilson CI treat duplicates as independent and are withdrawn. Cite the
    unique-event or one-per-seed figures, with the unit named.
  * POST_CAMPAIGN_FORENSICS.md s116-120, "replication shows no task dependence", is NOT_ADJUDICABLE: the task cells ran
    the same seeds, and the comparison pools every pressure.
  * The E1 figure 103/160 is superseded by this table for any independence-based statement.
