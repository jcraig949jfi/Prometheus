3. WHAT SURVIVES SCRUTINY, WHAT DOES NOT
-----------------------------------------------------------------------
SURVIVES (weakly, n=10):
  - Fable 5.1 clears the position-majority decoy on 7 of 10 packets and
    reaches 0.5215 (XP-009 Thermodynamics+Genetic Algorithms+Model
    Checking) and 0.5161 (XP-001 Quantum Mechanics+Neural Plasticity+
    Model Checking). NO original 1.0 tool exceeded 0.473; NO cheap 2026
    model (groq/gemini) exceeded 0.414. Two Fable tools >= 0.50 is a
    thing neither the 2026-03 pipeline nor 2026-09 cheap models did.
  - The lift is TIER-3 (R3 median 0.667 for Fable vs the ruler's NCD
    floor 0.639 and originals' weaker R3). R4 stays low (0.18) for
    everyone -- the wall is unmoved there.

DOES NOT survive / must not be claimed:
  - "Newest model invents a novel reasoning mechanism." FALSE by the
    shape fingerprint (shape.py). Fable tools are the SAME costume as
    1.0: regex structural parsing + NCD tiebreak + meta_confidence. What
    changed is DEGREE, not kind -- Fable writes ~30 regex calls / 49
    regex literals per tool vs the originals' 3 / 7. The 2026-03 models
    leaned on NCD and mostly IGNORED the prompt's "structural >= 50%,
    NCD <= 15%" instruction; Fable FOLLOWS it. The gain is instruction-
    following on the architecture constraint, not a new mechanism.
  - "Fable beats the original tools." NOT SHOWN cleanly. Only ONE
    Fable-scored packet (XP-034 Spectral Analysis+Falsificationism+
    Criticality) had committed original code to pair against, and there
    the ORIGINAL WON: original 0.473 vs Fable C_orig 0.425 / C_new 0.301.
    The 9 stronger Fable packets (XP-001..007, 009) are honest-era (Apr/
    May) whose original code was forged on M3 and NEVER COMMITTED, so the
    comparison is distribution-vs-distribution, not paired. The single
    clean paired test favors 1.0.
  - The idea is not the lever. C_new (0.433) ~= C_orig (0.422): giving
    Fable the 2026-03 analysis instead of its own barely moves the code
    score. The 2026-09 improvement lives in the code step, not the
    cross-pollination analysis step.
  - Cheap 2026 models are NOT the story. groq sits at the original/
    random level (median 0.355) and its picks agree with the NCD
    baseline 0.84 of the time (it echoes the baseline). Fable's picks
    agree with NCD only 0.76 -- it diverges from the trivial decoy more,
    which is consistent with it doing more real parsing.

5. DEVIATIONS FROM THE 1.0 PROTOCOL (all recorded per call)
-----------------------------------------------------------------------
  - Fable runs via claude -p (subscription), not raw API (Anthropic key
    unfunded). It is an agent harness with a fixed system prompt;
    temperature not settable. This is a real confound vs the 1.0 raw
    API calls and is why the arm is labeled fable51, not "claude".
  - PYTHONUTF8=1 (1.0 scrapped 85 tools on a cp1252 UnicodeEncodeError
    that was an environment bug its own sanitizer targeted).
  - Hosted arms given 4x the 1.0 token budget (2026 models spend it on
    thinking; gemini truncated code at the 1.0 budget).
  - Coeus enrichment section omitted from the code prompt.

6. WHAT WOULD FALSIFY THE ONE POSITIVE
-----------------------------------------------------------------------
The only positive is "Fable reaches 0.50-0.52, above the whole 1.0 and
cheap-2026 field." It dies if: (a) a 3-draw replicate on XP-009/XP-001
regresses to the mean (< 0.45 median); or (b) the same two triples,
scored on Charon's blind held-out battery rather than this development
ruler, fall to the field. Neither has run. Until (a) and (b), treat
0.52 as a development-ruler single draw.
