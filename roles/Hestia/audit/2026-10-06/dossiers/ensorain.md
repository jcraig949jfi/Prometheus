## 1. Mechanism (code, cited)

### 1.1 The world

- A World Genome is a JSON dict of 12 "laws" (genome.py:149-150) drawn by random_genome
  (genome.py:63-107): substrate, geometry, observation, transition, irreversibility, resource,
  memory, learning, credit, search, boundary, time.
- The world's physics is ONE real-valued scalar field x over a small tensor index (64..4096 cells,
  genome.py:32-51) built from a generator class (tt, cp, lowrank, pairwise, sparse, spectral, random,
  sum; world.py:30-74) followed by a chain of 0-3 "field atoms" from a registry of 22 numpy ops
  (registry.py:57-227, FIELD_OPS at registry.py:283), then standardised (world.py:77-93).
- A graph (12 geometry kinds, genome.py:14-15) maps nodes to cells. Dynamics are exogenous and
  pre-drawn: drift blends in a fresh field every drift_period steps (world3.py:293-298), basis
  permutations, rewiring, catastrophes that zero a slice (world3.py:299-315), doors that delete edges
  (world3.py:388-389).
- Payoff: harvesting max(0, rew[cell] - theta) at the occupied node with regrowth (world3.py:337-339)
  and, since WTP-03, a graded PREDICTION MARKET that pays query_reward x (1 - err^2/V0) for predicting
  the field at a random cell (world3.py:340-347; genome3.py:10-17 forces a market into every world).
- Consequence: the world is a static-or-slowly-drifting lookup surface. Nothing in the world reacts to
  the organism except door closure and the harvest regrowth clock. There is no object, no other
  strategic agent, no hidden state that an action can change, and no task whose answer is a
  composition of steps.

### 1.2 The organism

- The organism is NOT generated by the foundry; it is chosen from a menu. memory.substrate is one of
  10 hand-written classes (genome.py:17; organism.py:455-456): none/marks (a running mean,
  organism.py:14-37), table (LRU key-value, 98-150), sketch (hashed slots, 153-176), additive
  (per-mode marginals, 215-235), lowrank (matrix factorisation of one unfolding, 238-288), tt
  (tensor train, 291-353), cp (CP decomposition, 356-384), dct (low-frequency cosine coefficients,
  387-426), mixture (table + additive, 429-452).
- Every memory implements the same interface: predict(cell index) -> scalar, learn(cells, y) by
  SGD/NLMS/Hebbian/(1+1)-evolution (organism.py:185-212). The learning TARGET is the observed field
  value itself (world3.py:225-279). It is self-supervised regression of x over the index set.
- The policy is one of 7 hard-coded rules (genome.py:19; world3.py:349-385): random; greedy = argmax
  predicted value over neighbours; eps-greedy; softmax; novelty = greedy + 10 x unvisited bonus;
  probe_greedy = pay to sense neighbours then greedy; rollout = depth-limited max over at most 4
  successors using the memory as the value model (world3.py:363-369).
- "Credit" law (world3.py:228-243): delay, label noise, sign flips and neighbour smearing applied to the
  REGRESSION SAMPLES. There is no return, no value bootstrapping, no eligibility trace. Delay only
  postpones when a supervised (cell, value) pair is applied.
- "Representation fluidity" (world3.py:404-417): at checkpoints, distil the memory into a random other
  class and keep it if it fits the recent buffer better (organism.py:467-475).
- Multi-organism "boundary" law: n_org in {1,2,4} and marks in {none, private, shared}
  (genome.py:99-100); shared marks are a common bounded cache of (cell -> last observed value)
  (world3.py:180-194, 328-335). That is the only inter-agent channel: a shared lookup table.
- Organism design space: 10 memories x 7 rules x 7 policies = 490 discrete organism types
  (x 6 forget modes = 2,940), each with a few real hyperparameters. No organism can be built that is
  not one of these. collider.py:241 states it directly: NOT_IMPLEMENTED = {"symbolic": "no
  symbolic-rule substrate exists in this engine"}.

### 1.3 The instrument (WTP-03 collider, inherited by WTP-04)

- experience(): run one life of a fixed behaviour carrier and TAP the exact (step, cell, value) samples
  (collider.py:85-96). Every substrate and every null is trained on that SAME stream at matched float
  budget (collider.py:1-15, 257+).
- Test sets on never-touched cells: interp, novel, and recomb (collider.py:99-151). recomb deletes every
  sample with >= 2 coordinates in held-out value subsets H_m, so each primitive value is seen alone but
  no pair is: a genuine compositional-generalisation probe at the level of tensor indices.
- Null ladder (collider.py:164-210): N0 zero, N1 constant and recent constant, N2 marginal (one-hot
  ridge), N3 linear in coordinates, N4 bounded nearest-Hamming lookup; N5 = online simple substrates
  (collider.py:238); N6 = post-data tuned batch ALS / CP-ALS (wtp3/n6_check.py:15-54).
- Surrogates: marginal_surrogate preserves mean, every per-mode marginal and variance exactly and
  destroys interaction structure (collider.py:36-48; validation V5 mean diff 2.8e-17, var ratio
  1.0000000, runs/wtp03/summary.json).
- WTP-04 unit (wtp4/habit.py:47-66): immortal twins (metabolism 0, energy 1e9) for random-policy,
  frozen-memory, oracle, 3 cheap carriers, 4 structured carriers; labels TRAPPED / INFO_VALUELESS /
  DEAD / CHEAP_PAYS / STRUCT_PAYS by margins on earning rate (habit.py:69-98). 11 one-gene axes over
  12 families (wtp4/axes.py:71-83; families.py:131-150).

## 3. Matrix

### 3a. Combinatorial explosion and reachability

Numbers (computed from the registry and genome grammar; scratchpad ens_space.py):
- Field-op chains: sum_{k=0..3} 22^k = 11,155 (before continuous params).
- Categorical world+organism skeletons: ~6.1e18 (10^18.8), before any real-valued gene.
- Organism types: 490 (memory x rule x policy), 2,940 with forget mode.
- Field state: one real per cell, 64..4096 cells. A deterministic reflex policy over a 4096-node
  6-neighbour graph is already 6^4096 = 10^3187 policies; the menu covers 7 of them (parametrised).
- Explored: WTP-01 3,000 + WTP-02 24,000 + WTP-03 38,000 = 65,000 candidate worlds, i.e. a fraction
  ~1e-14 of the categorical skeleton space alone. That is fine for a quality-diversity search, but the
  hit rate shows the space is a desert:
  - random draws: 0 / 2,000 admissible (WTP-03 dev); first founder at ~6,000;
  - admitted: 0.48%, 174/181 found by mutating near-misses (effective N = 13 lineages);
  - structure-dependent lineages per founder candidate: 7 / ~26,600 = 0.026%;
  - specimens beyond known batch completion: 0 / 9 (N6), so the rate of "new physics" is 0 / 65,000.
- Where the desert comes from (code, not luck): the field-op chain (registry.py:57-227) is mostly
  information-destroying (noise, phase scramble, masks, reduce_max, fft_abs, topk). The seat's own
  finding: "transform chains, credit corruption and graph-cell maps almost always make the stream
  uninformative" (WTP-03 s4; 3 of 181 admitted worlds are "wild"). Weirdness and learnability are
  anti-correlated BY CONSTRUCTION, because learnability means "a low-complexity regressor of x exists"
  and random numpy chains raise the field's description length.
- Where it explodes: nowhere that matters. The organism side is 490 types, so there is no
  combinatorial pressure on mechanism at all; the explosion is entirely on the world side, and it is
  exploded with mostly-noise.

### 3b. Cosplay vs foundation

- The work called "competence" / "learning" is done by: online SGD/NLMS fitting of a fixed low-rank /
  CP / TT / DCT parameterisation to (cell, value) samples (organism.py:185-212, 291-320). This is
  known matrix/tensor completion; the seat itself labels its best specimens "KNOWN PHYSICS -- bounded
  online MATRIX / TENSOR COMPLETION" and shows a batch ALS beats every one (WTP-03 verdict).
- The work called "search" / "planning" is done by: argmax over neighbour predictions or a fixed
  depth-<=4, branch-<=4 recursion (world3.py:349-385). In dev WTP-04 F08 the rollout policy turned
  information valueless; in F09 it was DEAD. Lookahead never paid.
- The work called "credit assignment": a FIFO delay on supervised samples (world3.py:243-245). On a
  static field this is a no-op, and the dev map confirms it (delay 0..64 flat). Selection removed
  credit delay from 179 of 181 admitted worlds.
- The work called "representation fluidity": greedy model swap by recent-buffer MSE
  (world3.py:404-417). WTP-03 Wave G: 0 of 21 conversions beat direct training.
- The work called "communication": a shared LRU cache of observed values (world3.py:180-194).
- Classification: a selection loop over a tiny operator set (10 regressors x 7 heuristics) wrapped in
  a world generator. It is NOT compositional on the organism side: an organism cannot combine two
  memories (except the hard-coded mixture and hybrid_al), cannot build a new policy, and has no
  internal state other than regression weights.
- Reasoning would not be selected for even if a reasoning-capable organism were inserted: the payoff
  is (a) harvest at the current cell and (b) squared error at a random query cell. Both are maximised
  by the best static regressor of x plus greedy ascent. No world in the grammar requires remembering
  WHERE one has been in order to act, inferring a hidden variable that actions change, chaining two
  sub-goals, or modelling another agent. The dev axes confirm the ceiling: lifetime, delay and
  forgetting are flat; only memory band, noise, drift period, info cost, compute cost and topology
  move the label, i.e. the variables of a regression estimator's bias-variance budget.
- Ceiling, concretely: the best attainable "organism" in this engine is the best batch low-rank/CP fit
  of the field on the samples seen (N6); measured specimens sit 0.2-2.3 AC BELOW it. The engine's
  maximum discovery is "which of 10 known function classes matches a field drawn from one of 8 known
  generators". The diagonal of that 10 x 8 table is predictable a priori, and WTP-03 found exactly the
  diagonal.

### 3c. Substrate bottlenecks

- Representation: scalar field over a fixed integer index; every organism is f: index -> R. No
  symbols, no variables, no relations between cells beyond tensor-index adjacency. Ceiling is the
  function class.
- State: organism state = regression parameters + optional mark cache. No working memory, no
  recurrent/control state, no program counter. The ARC3 line showed (answer-keyed) that window
  statistics cannot reach Bayes on a finite-causal-state process (Even process; RESULTS_S1_PILOT.md
  s3) -- yet no WTP world has such hidden state, so the WTP organisms never face that wall.
- Memory: capped floats (band x cells) is a good, honest budget (world3.py:77-78), but it budgets
  parameters, not computation steps or description length of the procedure.
- Addressing: content is addressed by the true global cell index (organism.py:112-113,
  ravel_multi_index), handed to the organism for free. Locating oneself is never a problem to solve,
  which removes one of the few routes to spatial reasoning.
- Credit assignment: supervised per-sample; no temporal credit (see 3b).
- Compositionality: only at the instrument level (recomb test set); none in the organism.
- I/O bandwidth: up to 64 observations per step (MAXOBS, world3.py:32) of exact cell values with
  indices: an organism sees labelled training pairs, not perceptual streams.
- Scale: pure-python per-sample loops (organism.py:200-211; TT eval per cell organism.py:305-306);
  WTP-03 Wave A 38,000 candidates took 611 min on 20 workers. WTP-04 is limited to <= 3 workers on
  ubu006 (journal 2026-10-06). The substrate is not GPU-bound or tensorised despite the name.

## 4. Deliverable sections

### Discovery Approach

Generate worlds by composing tensor generators, numpy field atoms, graph geometries and economic
prices; drop in an organism picked from a menu of tensor regressors and greedy policies; keep worlds in
which a learned organism out-earns a memoryless or frozen twin; replay the organism's experience to
every substrate in a collider with a ladder of cheap and batch nulls; map, along one-gene axes, where
learning pays and whether a structured or cheap substrate wins (WTP-04).

### The Brick Walls

1. Prescribed organisms. 490 organism types, all f: index -> R regressors with hand-coded policies;
   "no symbolic-rule substrate exists" (collider.py:241). Discovery is capped at selecting among
   pre-written function classes. Number: 0 of 9 promoted specimens beat the tuned batch estimator N6.
2. Worlds without necessity. Payoff = static-field harvest + squared prediction error; credit delay is
   a no-op (dev: flat across 0..64; 179/181 admitted worlds have delay 0), lookahead never paid
   (rollout INFO_VALUELESS/DEAD in both dev families), lifetime x0.25 still pays. Nothing to reason
   ABOUT. Number: 0 world families in the grammar whose optimal policy needs hidden state.
3. Reachability desert from noise-dominated grammar. 0/2,000 random candidates admissible; 0.48%
   after mutation-climbing; 0.026% structure-dependent per founder; effective sample 13 lineages.
   Number: 0 "beyond known physics" specimens in ~65,000 candidate worlds over three campaigns.
4. (secondary) Off-lattice topologies trap the organism: 10/10 dev cells TRAPPED for F08/F09 on ring,
   small-world, erdos, tree, scale-free (dev_axes_score.json), so the "graph physics" half of the
   grammar is largely uninhabitable for these policies.
5. (secondary) Throughput: python per-sample loops; 38,000 worlds = 10 h on 20 workers; now <= 3
   workers. Any open-ended organism search at 1e5-1e6 evaluations is out of reach as written.

### Seed Viability

- As a cognitive architecture: no seed. The organisms are textbook online estimators and the policies
  are textbook heuristics. The seat's own record (E2: in-life structure discovery fails; WTP-03: known
  completion physics; WTP-02: one float) reaches the same conclusion. DEAD_END for the organism line
  as built.
- As an instrument: a real seed. The WTP-03 collider is one of the better-constructed falsification
  rigs in the fleet. It would detect a real circuit IF one arose, because:
  - every competitor sees the same tapped stream at matched budget (no data-advantage counterfeits);
  - the best-constant rung, N4 lookup and N6 batch rung kill the three counterfeits that actually
    occurred (variance artefact, running mean, online completion);
  - the marginal-preserving surrogate isolates interaction structure exactly;
  - the pair-block recomb holdout is a clean compositional-generalisation test.
  Its known weaknesses are documented by the seat (W1 tautological same-field transfer, W2 admission
  pre-selects completion, W3 founder concentration, W4 missing N6; ENSORAIN_WTP03_REPORT.md s3).
- The ARC3 answer-keyed sufficiency ladder (exact Bayes oracles for Even / golden-mean / order-k /
  key-value worlds, CSSR causal-state learner, crypticity D_k) is the second salvageable component: it
  is the right ruler for "did a system discover a hidden state variable", which is the closest thing
  in this engine to a primitive reasoning measurement.
- Verdict: SALVAGE_COMPONENT (collider + null ladder + recomb holdout + ARC3 exact-oracle ladder).

### Evolutionary Roadmap

Only worth doing if the organism side is replaced; otherwise WTP-04 will map a bias-variance diagram of
known estimators.

1. Put necessity into the world (refactor world3.run_life payoff, not the field grammar):
   - hidden-state worlds: the field or the reward depends on a latent finite-state process driven by
     the organism's own actions (e.g. an Even-process or counter gate on doors; a key-then-door
     dependency), so a stateless f: index -> R is provably suboptimal. Use the ARC3 exact Bayes
     oracle to compute the attainable gap in closed form.
   - delayed, action-contingent reward (a true return), so credit_delay stops being a no-op.
   - remove free addressing: observe local content, not the global index.
2. Replace the organism menu with a compositional substrate searched by the foundry:
   - a typed program / register-machine or finite-state-transducer genome (typed lambda calculus or a
     small DSL with LOAD/STORE/branch/compare over a bounded register file), with mutation and
     crossover at the AST level; or a state-splitting learner (CSSR-style causal-state
     reconstruction, which the seat already has in arc3/suff/cssr.py) as the organism memory;
   - score with MDL: total description length of program + residual, so that compression is
     rewarded and lookup is penalised in the same currency the collider already budgets (floats).
3. Keep the collider, extend the null ladder: N7 = windowed statistic STAT(k) (the ARC3 window floor),
   N8 = CSSR causal-state learner; a specimen must beat N6 AND the window floor on held-out lives, and
   transfer across FIELD instances of the same generator family (fix W1).
4. Multi-agent only after (1)-(3): shared marks are a cache, not communication. If pursued, make the
   channel bandwidth-limited and make the payoff require information one agent has and another lacks
   (a referential game over hidden state), and measure mutual information between message and latent.
5. Open-endedness metric for the foundry search: count of distinct program-class winners per
