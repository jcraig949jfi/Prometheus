0. WHAT THIS PACKET IS
  A review of (a) the creation of a new seat, Hestia, and (b) a tool built in
  the same session to create future seats fast. CONFLICT OF INTEREST: the author
  built both and ran every check below; the one independent review that was
  started was stopped before it reported (section 6). Grades: E3 = executed
  this session and quoted from output; E1 = regenerable by the commands in
  section 10; E0 = the author's prose or estimate.

1. CONTEXT
  Prometheus is a fleet of ~80 named "seats" (roles/<Name>/), each inheriting
  roles/base-role (a constitution: worktree per seat, never `git pull`, journal,
  comms, a HOLD state until the operator gives a charter). A new seat needs
  about twelve files, two rows in a register, a hash MANIFEST of the operator's
  verbatim words, a comms boot, and a fast-forward push to a shared main that
  other seats push to every few minutes. Hestia's was done by hand.

2. THE QUESTIONS
  Q1 (operator): create Hestia, inherit base-role, mostly self-contained, a
     moonshot, details to follow.
  Q2 (operator): make seat creation possible in under 60 seconds.

6. WHAT THIS DID NOT ESTABLISH
  - "Under 60 seconds" is MEASURED only to 24.0 s WITHOUT comms boot and push.
    Comms boot and a real push were not timed in the tool (the push logic was
    tested against a scratch bare repo, never a real fake-seat push, because
    that would publish a fake seat). Total with both is an estimate (E0).
  - The tool was run once end to end, on Windows/Git Bash only. Not run on a
    Linux host, nor with a real --push, nor by a second person.
  - The seat creation was NOT independently reviewed: a three-lens read-only
    review was launched and stopped at the operator's word before reporting.
  - Sparse-baseline comparison can hide a seat-caused failure inside one of
    the six tests that already fail sparse; the validator covers the seat-
    specific properties but is the author's own check.
  - The moonshot, what "self contained" excludes, and Hestia's dependency
    surface are unknown; nothing has been started toward them.
  - Whether the new seat should heartbeat Aporia is undecided (deferred).
