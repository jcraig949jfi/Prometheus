0. WHAT THIS PACKET IS

A new instance of the Harmonia seat ("Harmonia F") was started on machine

1. CONTEXT

Prometheus is a multi-seat program in which named roles (seats) run as
separate AI sessions on several machines and talk through a shared queue.
The Mechanism Archaeology Pipeline recovers old computational artifacts
("fossils"), decomposes them into candidate mechanisms with falsifiable
predictions (Nyx), and has Harmonia execute those predictions against an
oracle before anything moves downstream. A prediction packet fixes, before
any run, the code boundary, the interventions, their expected magnitude
bands, and three controls (cheat, positive, negative). By rule, a failed
mandatory control makes every row of the packet INDETERMINATE.
M3 (hostname GANDALF, Windows 10 Home) cannot run Docker, WSL2 or a C
compiler (virtualization is off in firmware), so only pure-Python fossils
can be executed there. The specimen is "particles" v0.4, a Python
sequential-Monte-Carlo library; the mechanism under test is its resampling
trigger: resample when the effective sample size (ESS) drops below a
fraction ESSrmin of the particle count N.

Reading. The positive control asked the instrument to see the 1/N scaling
of the estimator's variance. It saw a 5463-fold change, larger than the
band's ceiling of 1000. At N = 10 every seed's estimate sits more than 20
nats below the exact value: the variance there is weight degeneracy, not
sampling noise, and the 1/N picture the band assumed begins only near
N = 200 on this world. Two coordinates are kept apart: (i) by the packet's
own rule the reading is INDETERMINATE; (ii) by the seat's charter the band
is a constant computed from a model that does not hold, so it is the
control specification that is defective. Both were returned.

Typed returns: RETURN 1 PREDICTION_INDETERMINATE (failing item named).
RETURN 2 PREDICTION_PACKET_CHALLENGE on the positive control's band;
required response is a superseding packet 002 with interventions I1-I3
and the mechanism claim unchanged.

Two design observations from the SEEN scout rows, offered for 002's world
choice only: the trigger is saturated on this world (R median 98-99 of 99

seed for seed and the baseline's R band [10, 90] cannot be met; and the
