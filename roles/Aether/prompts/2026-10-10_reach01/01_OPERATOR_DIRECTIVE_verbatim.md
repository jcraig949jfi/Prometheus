2. EXPERIMENT R2 — EXPRESS01

MINIMUM PHYSICS FOR COMPOSITION

Hestia’s strongest diagnosis is that existing Aether writes replace information instead of combining information.

Test that diagnosis directly.

Objective

Determine which minimal local-law extensions permit genuine composition.

Historical aeth01.v1 remains immutable.

Every candidate physics receives its own semantics identifier.

Candidate physics families

Start with a small operation table that allows incoming information to interact with existing local state.

Candidate operations:

* REPLACE — historical control.
* XOR — combination.
* ADD modulo 256 — accumulation.
* AND — conditional combination.

These are calibration primitives, not the required final architecture.

Investigate an additional unfamiliar local operation if there is a plausible reason it might provide richer composition.

Do not implement neural networks, explicit message buses, conventional instruction processors, or hand-built multi-stage execution frameworks.

The computational architecture should be able to emerge from local interactions.

Protect the experiment from trivial shortcuts

A primitive XOR operation that directly outputs XOR is not itself a discovered two-part circuit.

Distinguish:

PRIMITIVE CAPABILITY

A local operation combines two values.

MULTISTEP COMPUTATION

Several interactions are required to produce the output.

COMPOSITION

Two or more causally necessary substructures interact to produce a capability unavailable from either alone.

AUTONOMOUS DISCOVERY

A mechanism emerges without the experimenter directly constructing its internal arrangement.

These are different scientific rungs.

Planted controls

Before random exploration, construct small exact arrangements proving whether the substrate can implement:

C0 — Value transmission.

C1 — State-dependent input combination.

C2 — Delayed state retention.

C3 — Conditional response to two distinguishable inputs.

C4 — Two-part composition in which removing either part destroys the capability.

C5 — Multiple-step causal dependence.

Each must include appropriate negative controls.

The positive controls are deliberately designed.

They establish expressibility only.

Do not report them as spontaneous discoveries.

Test the mechanism, not the picture

Use causal twins and counterfactual intervention.

Test:

* remove component A;
* remove component B;
* remove both;
* preserve both;
* replace a component with a shuffled alternative;
* change initial placement;
* perturb unrelated surrounding state.

Do not infer function from loops, graph topology, entropy, or activity.

A mechanism must actually do something its components cannot individually do.

Decision

If no proposed primitive supports even a planted conditional computation:

EXPRESSIBILITY_STILL_BLOCKED

Identify the exact missing capability.

If planted computation succeeds:

EXPRESSIBILITY_SUPPORTED

Record which operations and arrangements are sufficient.

If two causally necessary substructures compose:

PLANTED_COMPOSITION_SUPPORTED

This is the minimum qualification for R3’s compositional discovery search.

Do not conflate it with autonomous discovery.

3. EXPERIMENT R3 — FRONTIER01

CROSSING REACHABILITY DESERTS

Gemini’s strongest contribution was the reachability objection.

Even if the physics permits compositional computation, search may be unable to assemble the necessary structure.

Aether must now test whether preserving meaningful intermediate states helps cross that barrier.

Critical prerequisite

Use only a physics family that passed EXPRESS01’s planted control.

If none passed, R3 becomes an expressibility diagnosis and the search experiment must not claim a composition result.

Three discovery strategies

Compare three approaches under equivalent compute and evaluation budgets.

A — Ordinary exploration

Fresh independent initial configurations.

Existing native search operators.

No frontier restoration.

B — Random-checkpoint restoration

Archive and restore randomly chosen intermediate states.

This controls for the generic advantage of obtaining more restarts.

C — Certificate-guided frontier restoration

Archive states using causally meaningful descriptors.

Examples:

* number of distinct input dependencies;
* certified causal depth;
* retained input information;
* independently necessary substructures;
* successful partial input combination;
* acquisition of a new conditional behavior.

Do not use simple entropy, turnover, byte novelty, or spatial complexity as the primary archive descriptor.

Those can reward precisely the trivial dynamics identified by Hestia.

Reachability archive

Implement a lightweight checkpoint/archive system.

Each entry should preserve:

* reconstructible physical state;
* physics and code identity;
* RNG/scheduler state;
* causal descriptor;
* trajectory to the frontier;
* acquisition cost;
* subsequent outcomes.

Use Git-compatible manifests and durable artifact storage.

Avoid building a large new database abstraction.

The archive is an exploration aid, not an organism’s memory.

Frontier selection

The archive should occasionally return exploration to a previously reached promising state and branch from it.

But do not assume this guarantees further discovery.

Measure whether restoration actually increases useful reachability.

Preserve a random-frontier control using equivalent restart frequency and compute.

Most important separation

Report:

ARCHIVE-ASSISTED DISCOVERY

Search found a mechanism with frontier assistance.

Separately report:

AUTONOMOUS COMPETENCE

The resulting mechanism functions in an independent evaluation without checkpoint restoration, archive consultation, or hidden search assistance.

Do not treat the second as proven by the first.

Experimental scale

Start with 8 screening seeds per arm.

Only expand a promising comparison to approximately 32 seeds when measured compute economics support it.

Use common random numbers where practical.

Do not run a giant factorial merely because the 72-hour ceiling permits it.

Primary measurements

* certified mechanisms discovered;
* highest composition rung;
* distinct certified frontier states;
* acquisition cost per mechanism;
* revisit/recovery success;
* fraction of archive entries that produce useful descendants;
* independent autonomous success;
* search-efficiency improvement over both controls.

Do not use generic novelty as the primary outcome.

Decision

FRONTIER_NO_GAIN

No meaningful improvement over ordinary and random-checkpoint search.

REACHABILITY_EXPANDED

New certified frontiers are reached, but no new functional mechanism is discovered.

ARCHIVE_ASSISTED_COMPOSITION

Frontier exploration discovers a causally certified composition absent or materially rarer in both controls.

AUTONOMOUS_COMPOSITION

A discovered composition works independently of the archive and passes fresh-condition causal tests.

The distinction between these outcomes is essential.

4. EXPERIMENT R4 — ACCUM01

CAN A DISCOVERY BECOME A BUILDING BLOCK?

This is the next step toward Sagacity.

The objective is not to accumulate more interesting patterns.

It is to test:

Does preserving one certified computational mechanism make another computational mechanism easier to discover?

Use the strongest mechanism from R2/R3.

If only a planted mechanism exists, run an explicitly labelled assisted-control experiment.

Do not claim evolved cumulative development.

Mechanism extraction

Attempt to identify a minimal causally sufficient substructure.

Preserve:

* its state;
* execution preconditions;
* inputs and outputs;
* functional certificate;
* destructive ablation results;
* tested environmental limits.

Avoid reducing the mechanism to a hand-written answer to the experimental task.

Promotion

Try one minimal promotion mechanism.

A certified substructure becomes an addressable component that later search can:

* duplicate;
* relocate;
* modify;
* combine with another component.

The mechanism’s discovery is historical evidence.

Its subsequent use is a separate experiment.

Comparative arms

Evaluate:

1. No reusable component.
2. Random or shuffled component.
3. Correct component available but not structurally promoted.
4. Correct component promoted into a reusable unit.

Keep available compute and search budgets comparable.

The critical measurement

Do not merely ask whether the original mechanism still works.

Ask:

Can a later search discover a genuinely new capability more efficiently because the earlier mechanism is available?

Measure:

* acquisition cost;
* successful reuse;
* highest compositional rung;
* causal necessity of the reused component;
* stability in a changed environment;
* subsequent discovery rate.

Compare with a fresh search under the same budget.

Failure modes

Look specifically for:

* component interfaces that only work at the original location;
* promotion that encodes the desired answer;
* libraries that grow but provide no reuse advantage;
* archived state replay mistaken for learning;
* improvements that vanish under a shuffled-library control;
* inherited mechanisms that impair later exploration.

That last case is important given Aphrodite’s earlier negative inheritance results.

Decision

REUSE_NOT_SUPPORTED

TRANSPLANT_SUPPORTED

COMPOSITION_REUSE_SUPPORTED

CUMULATIVE_ACQUISITION_ADVANTAGE

Do not promote a result to cumulative acquisition unless a prior discovery measurably helps acquire a genuinely new capability.
