## 6. E3: R8, frozen now, executed ONLY if REPLICATION_GATE = PASS
**Question:** does a library produced by the improved improver (g11) make the NEXT generation's improvement process
better than a library produced by I_0?

1. **Donor libraries:**
   - For each usable E-block seed d: **L_g11** = the selected_entries of E1's g11_O10 donor; **L_I0** = the
     selected_entries of E1's g0_O4 donor.
   - Reference: **L_P** = the pristine entries (no inheritance).
2. **Freeze and hash:**
   - Only the entry lists are written to beta02/runs/R8/R8_LIBRARIES.json, with sha256 per library.
   - The hashes are re-verified at run time.
3. **Destroy donor state:**
   - Nothing else crosses: no donor history, caches, task identities, scoring traces or selection tables.
   - Next-generation donors run in fresh worker processes that receive only (machinery, supply roles, library
     entries).
4. **Next generation:**
   - Supply: the UNSEEN LIN seed n = d + 24 (lineage-independent, never used), with roles and extras from the same
     rules.
   - Each library is transplanted as the START library (gtc.donor_g start_override).
   - Identical machinery, budgets, task sequence (common cell seeds) and evaluator access.
5. **Machinery:**
   - **primary = I_0 @ O4** (the original improver: only the library differs);
   - secondary = g11 @ O10.
6. **Endpoint: next-generation IMPROVEMENT.** For seed n, library L, machinery m: improvement = the number of n's 32
   held-out TRANSFER families where the generation-2 selected library reaches a qualified program and **its own
   inherited start library L is censored** in that cell.
   - This measures what the next generation ACQUIRED, not what the inherited library already solves.
7. **R8_PASS (primary):** an exact one-sided sign-flip test over pairs on
   improvement(L_g11) - improvement(L_I0) under I_0 machinery gives p < 0.05 AND sum > 0.
   - Also reported:
     - the same test under g11 machinery;
     - each library vs L_P;
     - the inherited libraries' own capability on the unseen supply (vs PRISTINE). This is reported separately and
       is NOT the R8 endpoint.
8. **If R8 passes, stop.** No further recursion.

**Interpretation (frozen):**

| R8 result | Reading |
|---|---|
| PASS | the heritable product of the improved improver makes a fresh improver improve better on unseen opportunities: a second-order effect at tier 2 (the R8 rung, first instance) |
| NOT PASS, with L_g11 capability > L_I0 | inheritance transfers capability but not improvement (first-order inheritance only) |
| NOT PASS, with neither capability nor improvement | the g11 library does not travel across lineages |
