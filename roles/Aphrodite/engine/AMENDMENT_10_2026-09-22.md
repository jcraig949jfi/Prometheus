1. SEMANTIC IDENTITY REPLACES SOURCE-STRING EQUALITY
--------------------------------------------------------------------------

Source-string equality is NO LONGER ADMISSIBLE as mechanism identity
anywhere in this program.

The semantic-identity layer is deterministic and combines:
  - AST normalisation over the bounded DSL;
  - canonical ordering of operands for the commutative primitives
    (add, mul, gcd);
  - constant and algebraic simplification (identity and absorbing elements,
    idempotence of gcd, x//x, x%x, pow with exponent 0 or 1);
  - canonical primitive names (math.gcd(abs(a), abs(b)) -> gcd(a, b));
  - a DENOTATIONAL SIGNATURE: the expression's value vector over a frozen,
    exhaustive probe battery covering the declared bounded input domain for
    (acc, v, first, last). The signature is the PRIMARY identity; the
    normalised AST selects the canonical representative within a class.

Original source strings are PRESERVED for provenance and never used for
identity. Scientific classification, duplicate detection, success libraries
and sham construction all operate on SEMANTIC CLASSES.

REGRESSION FIXTURES, committed with the layer, including at minimum the
Tier-3A equivalences:
    acc + v                                   == v + acc
    acc * math.gcd(abs(v), abs(v))            == acc * v
    math.gcd(abs(v), abs(math.gcd(abs(acc), abs(acc))))  == gcd(acc, v)
    math.gcd(abs(acc), abs(v + acc))          == gcd(acc, v)
    acc + math.gcd(abs(v), abs(v))            == acc + v
The rules are GENERAL. The fixtures verify the general layer; they do not
define it, and no rule may be written that collapses only an observed
example. The fourth fixture above is a number-theoretic identity no AST rule
would catch, which is why the denotational signature is primary.

2. DEVELOPMENT-SET DISCRIMINATION IS QUALIFIED BEFORE ANY META-SEARCH
--------------------------------------------------------------------------

Tier 3A showed stronger search reaching false programs faster. That is an
APPARATUS property and is measured directly, in advance.

For each load-bearing development family, before meta-search:
  1. enumerate, under a FROZEN exhaustive rule, the semantically distinct
     candidate programs reachable in the declared grammar within the
     declared budget (the PRISTINE library entry space, deduplicated by
     semantic class);
  2. determine which INCORRECT semantic classes are indistinguishable from
     the target on the proposed development instances;
  3. report the development battery's FALSE-POSITIVE BASIN (the count of
     such classes);
  4. if the basin is non-empty, add development instances by a FROZEN
     mechanical counterexample-selection rule: from a frozen candidate pool,
     greedily add the instance that eliminates the most surviving incorrect
     classes, ties broken by the lowest instance index;
  5. repeat to a declared cap of 16 development instances; then either the
     PREREGISTERED DISCRIMINATION CRITERION -- false-positive basin = 0 --
     is met, or the family is declared UNSUITABLE and excluded.

The development set is NEVER sized by watching Tier-3 search performance.
The hostile tribunal remains separate and hidden; development discrimination
does not replace tribunal generalisation testing.

3. A SHAM DISTRIBUTION, NOT ONE HAND-LABELLED SHAM
--------------------------------------------------------------------------

SHAM is never again constructed as "source strings the donor did not
observe". Before meta-development, EIGHT matched sham proposal libraries are
generated mechanically and their hashes frozen.

Each sham: uses the same interface; carries a declared, donor-independent
EIGHT bodies (fixed in advance, not matched to the donor's eventual
artifact); preserves base-grammar fallback; preserves expressive
equivalence; and passes through the same semantic canonicaliser.

Generation rule (frozen): for sham k, draw 8 distinct SEMANTIC CLASSES
uniformly at random, with seed derived from k, from the canonicalised body
space, and take each class's canonical representative. No hand labelling and
no filtering on usefulness.

The Tier-3 artifact is compared against the WHOLE DISTRIBUTION. An
individual sham that unexpectedly helps is an OBSERVATION, reported as such,
not an automatic invalidation.
