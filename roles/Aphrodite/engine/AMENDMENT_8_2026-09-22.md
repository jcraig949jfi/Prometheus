--------------------------------------------------------------------------
1. THE CORE CAUSAL CONSTRAINT
--------------------------------------------------------------------------

ORGAN and SCRATCH must have EQUAL ULTIMATE EXPRESSIVE POWER. The organ may
supply a reusable representation / search coordinate. It may NOT supply a
mechanism class SCRATCH cannot reach.

HOW EQUALITY IS ACHIEVED, and certified before any search:
  - both arms carry the SAME common grammar G4 (below), which contains the
    structural constructors needed to build a fold FROM FIRST PRINCIPLES:
    an initialisation statement, a bounded loop over the parsed sequence,
    and a final expression;
  - the ORGAN arm additionally carries the frozen fold organ
    5488abb9f6354f02... as a NAMED MACRO with its three typed holes;
  - the macro is DEFINABLE in G4: every macro instantiation expands to a
    G4 program. So ORGAN's expressible set is a subset of G4's;
  - ORGAN also retains all of G4 as fallback, so G4's expressible set is a
    subset of ORGAN's.
  Therefore the two sets are EQUAL. The certificate verifies this
  mechanically by expanding every macro instantiation into G4 and checking
  identical outputs on a shared input battery, not by assertion.
  If equivalence cannot be established, the slice STOPS.

The ONLY difference between the arms is the ORDER AND SHAPE OF THE SEARCH:
ORGAN enumerates macro instantiations first (a coordinate system), then
falls back to G4. SCRATCH enumerates G4 directly.

--------------------------------------------------------------------------
2. THE GRAMMAR G4 (versioned, and not to be enlarged after seeing yield)
--------------------------------------------------------------------------

    GRAMMAR_VERSION_4 = "g4-imperative-v1"

    PROGRAM  := SHAPE_EXPR | SHAPE_FOLD
    SHAPE_EXPR := return FINAL
    SHAPE_FOLD := acc = INIT ; for v in vals: acc = BODY ; return FINAL

    variables: acc, v, first (= nums[0]), last (= nums[-1])
    constants: 0, 1
    primitives: the declared seven (add, sub, mul, fdiv, mod, gcd, powr)

    INIT  : depth <= 1 over {0, 1, first, last}
    BODY  : depth <= 2 over {acc, v, first, last, 0, 1}
    FINAL : depth <= 1 over {acc, first, last, 0, 1}

The organ's macro holes are NARROWER than G4's fold shape, which is the
whole point: the macro is a better coordinate, not a bigger space.
    H1 (INIT) : {0, 1}
    H2 (BODY) : depth <= 2 over {acc, v} only
    H3 (FINAL): acc, or a single primitive over {acc, last}
The ORGAN arm composes the macro's result with a G4 FINAL expression.

Before execution the certificate reports, for each selected family: total
reachable candidate counts for both arms, the target witness, its rank
under DETERMINISTIC enumeration, the expected budget, and an explicit
demonstration that the witness is not trivially among the first candidates.
Enumeration ordering is the natural declared order; witnesses are NOT
deliberately buried. The purpose is measurement, not difficulty theatre.

6. THE SEARCH-LEVERAGE CRITERION
--------------------------------------------------------------------------

STRUCTURAL_SEARCH_LEVERAGE = YES only if, across the selected unseen
families, the ORGAN arm shows a REPRODUCIBLE reduction in search cost or
an increase in fixed-budget discovery probability relative to the
expressively equivalent SCRATCH arm.

  - capability available only to ORGAN does NOT count, and cannot occur
    here by construction, because the certificate establishes equal
    expressive power;
  - SHAM must not reproduce the advantage; if it does, the effect is
    carrying a macro, not carrying THIS macro;
  - a result on ONE family is a fossil, not a general reuse claim;
  - HETEROGENEITY ACROSS FAMILIES IS REPORTED, never collapsed into one
    favourable aggregate. Per-family M1 and M2 appear in the report even
    where they disagree.
