## 1. Question
Beta-02's R8 = NO stays frozen and is not relabelled. E1 asks WHY the inherited library reduced new acquisition:
- **H1, saturation:** it already solves what the recipient would otherwise learn.
- **H2, interference:** it suppresses acquisition even where real opportunities exist.
- **H3, representation ceiling:** there is too little second-level structure for it to enable anything.

These hypotheses are not mutually exclusive.

## 4. Endpoints
- **A. Inherited capability:** families each START library reaches that PRISTINE (= the L_P start) cannot.
- **B. Common residual opportunity set:**
  - For recipient seed n: the families of n's 32 TRANSFER families that **no START library (L_g11, L_I0, L_P)
    reaches in either cell** at cap 1M.
  - It is computed mechanically from the start walks only, written and hashed (E1_COMMON_RESIDUAL.json) BEFORE any
    recipient runs. The runner refuses recipients without it.
- **C. New acquisition (PRIMARY measure):** the number of common-residual families the recipient's selected library
  reaches in >= 1 cell.
- **D. End state:** families reached by the recipient's selection OR its start.
- **E. Interference:** the paired contrast C(L_g11) - C(L_P).
- **Secondary:**
  - Beta-02's own-start-censored improvement;
  - failed opportunities;
  - newly derived semantic classes (n_derived and classes medians);
  - the candidate-ordering charge ratio (L_g11 vs L_P recipients on families both reach);
  - compositional extensions of the inherited schema (the selected schema = inherited[H := x], x containing {H}).

## 5. Frozen decision rules (statistical unit = pair; exact sign-flip tests)
- **Positive control (PC):** L_g11 recipients acquire >= 5 common-residual families in total, across >= 3 pairs.
  - This is the directive's "mechanisms learnable after inheritance".
  - If it fails, the disposition is INCONCLUSIVE_NO_POSITIVE_CONTROL (the assay cannot adjudicate).
- **INTERFERENCE_SUPPORTED:** PC passes AND a two-sided p < 0.05 on d = C(L_g11) - C(L_P) with sum d < 0.
- **SATURATION_SUPPORTED:** both of the following hold.
  - The own-start deficit (L_g11 - L_P, Beta-02 measure) is significant (one-sided p < 0.05, sum < 0).
  - headroom share = 1 - (sum common-residual d / sum own-start d) >= 0.5. This is the fraction of the own-start
    deficit that disappears when both arms are scored on the SAME opportunity set.
- **REPRESENTATION_CEILING_SUPPORTED:** all of the following hold.
  - PC passes.
  - Enabling is not shown (C(L_g11) > C(L_P) is not significant one-sided at 0.05).
  - The best arm acquires < 25% of the common-residual slots.
  - No L_g11 recipient that compositionally extends its inherited schema acquires any common-residual family.
- The labels may co-occur. If none holds, the label is **INCONCLUSIVE**.
- **Multiplicity:** Holm at 0.05 over {interference p, saturation p} is reported alongside.
- **Disposition:**
  - MEASURED iff the known answers pass, PC passes and supply is OK;
  - otherwise INCONCLUSIVE_NO_POSITIVE_CONTROL / MEASUREMENT_FAILED / SUPPLY_LIMITED.
