RULING ON C1:

The proposed hidden-scale s∈{1,2,3} world is NOT YET sufficient for Campaign 1. Your own D3 says the expensive learned object must be a PROCEDURE rather than a datum. A three-valued latent recovered by a two-probe protocol remains a datum and may select only for conditional policy/state.

Revise DESIGN_C1.md before implementation.

1. FITNESS

Replace the gain/budget ratio with competence-first selection.

Unsolved tasks pay their full budget.

Selection must be lexicographic:

primary: competent behavior / tasks solved under the qualification regime
secondary: lifetime resource cost among competent organisms

If the search implementation requires a scalar, choose constants such that one additional solved task dominates the maximum possible efficiency advantage from solving fewer tasks.

Do not reward abstention.

2. WORLD REQUIREMENT

Build a world in which repeated experience exposes a reusable PROCEDURE, partial computation, transformation, transducer, strategy fragment, or equivalent computational object.

The reusable object must not collapse to a tiny latent scalar, fixed answer table, or static action sequence.

Fresh tasks must require application/adaptation of that acquired procedure.

The world should remain generic enough that no prescribed workspace mechanism is necessary: evolution may cache, compile, index, checkpoint, recombine, memoize, create continuations, or discover something we have not named.

3. ARTIFACT CAUSALITY GATE

Before evolutionary search begins, demonstrate with frozen controls that this world contains an independently useful artifact channel.

Required witness:

ARTIFACT_TRANSPLANT > CODE_ONLY

on unseen procedural tasks, with executable code held fixed.

Artifact ablation must remove or substantially reduce that transferred advantage.

FULL_TRANSPLANT may perform better still, but artifact-only transfer must carry measurable acquired competence or measurable reusable computational savings.

If no such positive control exists, redesign the world. Do not begin search.

4. SEARCH-PARTITION IMMUNITY

Do not expose evolution indefinitely to one frozen finite task table.

Use a frozen procedural generator.

Within comparisons, use common random task streams where needed for variance control. Rotate generated streams during search. Maintain a sealed qualification stream never used for selection.

Randomize task order and apply semantics-preserving identifier/action permutations where appropriate.

Hard-coded ACTION scripts and lucky enumeration orders should fail because the environment varies, not because a post-hoc detector recognizes their syntax.

5. SANDBOX INTEGRITY

Fix BLK_NEW/resource-exhaustion semantics before C1.

Allocation failure or any workspace status must use a tagged/status channel that cannot alias RESET or any organism action.

Add the C0 EMPTY-block clock as a permanent regression test.

6. VARIATION

Check Apollo before implementing another crossover system.

Generic recombination, splice, duplication and structural mutation are admissible if they improve accessibility of coordinated mechanisms.

Do NOT introduce a workspace-specific macro or mutation that directly encodes store→lookup→replay or any other desired solution.

The substrate supplies generic affordances; evolution supplies the mechanism.

7. PRE-SEARCH GATE

Do not launch C1 search until the preregistered packet demonstrates all of:

A. abstention cannot dominate competence;
B. unsolved work pays full budget;
C. integrity/status channels cannot alias organism actions;
D. procedural held-out generation defeats static memorization;
E. an accumulated positive control gains from prior experience;
F. ARTIFACT_TRANSPLANT beats CODE_ONLY on fresh tasks;
G. artifact ablation removes that advantage;
H. the transferable learned object is procedural, not merely a scalar or answer table.

If A-H pass, freeze world, generator, metric, qualification protocol, variation operators, fingerprints and predictions, then run random / seeded / recombination arms.

The scientific target for Campaign 1 is not “does evolution use the provided block store?”

It is:

Does selection discover any persistent computational machinery whose
accumulated products reduce the cost of solving future novel tasks
without sacrificing competence?

Instrument richly enough that an unexpected mechanism can be recovered after the fact.

Proceed with CRIUS-12/13 under this ruling.
