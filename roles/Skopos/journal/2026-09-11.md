        -> .gitignore:200:agents/*

The six reports were NEVER COMMITTED. The repository ignores the whole
agents/ tree by default and re-includes named subdirectories; agents/skopos/
has no re-include. The four tracked Skopos files were force-added in March
2026; the reports never were. They have existed for 163 days as untracked
files in one working directory on one host -- and agents/metis/src/metis.py
:94-103 read them off that disk and fed them to a model.

Two constraints then collided:

  - D-23 s1 forbids this seat writing files in the canonical checkout,
    which is where the only copies live.
  - Committing tracked files at agents/skopos/reports/*.md would create
    tracked paths that collide with the untracked originals still sitting
    on disk in the canonical checkout. Git refuses to overwrite untracked
    files on checkout or merge, so that commit could block the canonical
    checkout's next update FOR EVERY SEAT.

Resolution taken: commit the annotated copies under this seat's own
directory (roles/Skopos/artifacts/alignment/), preserving the originals
byte-for-byte with their hashes, and leave the untracked originals on disk
untouched. This discharges the substance of the ruling -- corrections
beside originals, nothing rewritten or sanitized -- gives these documents
provenance for the first time in their existence, and creates no hazard.
It does NOT put an annotation in front of a reader who opens the untracked
file on this host's disk. That gap is real, is reported in the receipt, and
is the operator's to close or accept; this seat did not close it unilaterally
because the only way to do so is a write D-23 forbids.
