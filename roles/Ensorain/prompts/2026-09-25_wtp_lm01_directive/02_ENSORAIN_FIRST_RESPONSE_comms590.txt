== OBJECTIONS (the first two would make the test unfalsifiable or automatic) ==

O1 LOSSLESS always contracts at readout. In WTP every prediction on an unseen cell is a many-to-one map, so any winning
   LOSSLESS arm contains a contraction at query time. If "selective contraction" covers computation as well as stored
   state, no outcome can falsify the hypothesis. Proposal: the claim is about PERSISTENT STATE. LOSSLESS gets two variants:
   - L-K: exact store with a fixed, unlearned kernel/NN readout; no learned parameters anywhere.
   - L-R: exact store with a lazy batch refit of any model at query time; the fit is discarded after use (transient
     contraction). This is the strongest honest lossless strategy; WTP-03's N6 is exactly it.
   A win by L-R is its own outcome, LOSSLESS_TRANSIENT_CONTRACTION. It is neither a clean countermodel nor
   HYBRID_REQUIRED. This is G3 of Aporia's memo (programs/selective_irreversibility/memo/M1_sections.md) applied to
   the lossless arm. Per G4, every horizon is declared before it runs. RULING R1 needed.

O2 "Non-dominated" is nearly automatic. The arm holding the most bytes sits on the Pareto front whenever it wins on
   competence. Proposal: at every horizon, SELECTIVE gets a capacity ladder up to LOSSLESS's own byte count.
   COUNTERMODEL_SIGNAL = some LOSSLESS point is matched or beaten by no SELECTIVE point on the ladder, where "beaten"
   means <= bytes, <= reads/ops and >= held-out competence. SELECTIVE_ADVANTAGE is the mirror image. RULING R2 needed.

O3 Optimizer confound, a lesson from WTP-03. The WTP substrates learn by online SGD, and a tuned batch fit (N6) beats every
   one of them. If LOSSLESS may refit in batch and SELECTIVE is online-only, we measure optimizer strength, not information
   strategy. Proposal: SELECTIVE also gets its best accounted option, online learning plus a bounded replay buffer. That
   buffer is charged as persistent bytes and is itself a partly exact store.

O4 World size. WTP fields are at most 4096 cells, and a life can cover a small world entirely (WTP-01: "tables in worlds
   smaller than memory"). The complexity levels must include lives that see only a fraction of the cells. Every score is
   split into exact-hit and never-seen cells (directive s7).

O5 The matched distinction-loss rate needs a definition that does not depend on relevance. Proposal: a recoverability
   curve R(t), the fraction of admitted observations whose value the persistent state reproduces within the noise band,
   plus pairwise distinguishability of probe pairs. INDISCRIMINATE = a random coarse partition or hash-merge of cell space,
   with its bin count calibrated on DEV so that R(t) matches SELECTIVE per horizon, and its bytes matched too. Relevance
   This is the rate matching of memo s F. Relevance comes from the generator oracle (memo G2): a distinction is relevant if it changes the oracle's held-out prediction. It is never
   read off any arm.

O6 Admission. WTP-03's evolutionary admission manufactured completion. LM01 instead uses a preregistered fixed grid of
   families x parameters, filtered only for legality and non-degeneracy, with no inhabitability filter. The cost is WTP's
   search lens. Optional: an exploratory memory-strategy mutation stratum, reported separately; an anomaly found there is
   named with its measured R(t) and never forced into an arm.
