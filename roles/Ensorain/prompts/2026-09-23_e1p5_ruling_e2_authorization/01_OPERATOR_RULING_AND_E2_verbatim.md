That said, I agree with Ensorain’s scientific interpretation of what survived. We did not discover a compression-headroom phase transition. We discovered something narrower:

A correctly ordered TT has a real representational advantage on a world generated by matching TT structure.

At 192 floats, the TT can represent and learn structure for which the corresponding matrix unfolding needs roughly twice the storage. That’s real, but it is also expected. The interesting unsolved part is no longer tensor completion.

It is structure discovery.

The glaring result across E0–E1.5 is that the system never learned the mode ordering. Random hyperparameter search happened to stumble onto (1,0,2,3), and when it did, Ensorain suddenly looked intelligent. When it missed, performance collapsed. That is exactly where I would put the next knife.

So do not close Ensorain, but park the existing E1 line. Do not scale it. No Runpod, no GPU campaign, no larger world yet.

The only experiment that earns another round is:

Can an organism discover useful tensor topology/factorization from experience, rather than being handed it or finding it through blind outer-loop search?

Call that E2 — Structure Discovery, but keep it tiny. Give all candidate representations the same raw observations and storage/compute budgets. Hide the latent mode order. Remove random architecture search as the mechanism of success. Let the organism perform bounded structural operations—swap adjacent modes, merge/split factors, estimate dependency across cuts, perhaps temporarily test alternative decompositions—and make those operations costly.

Then compare against brutally simple searches:

* random permutations;
* exhaustive permutation search where the dimensionality is small enough;
* greedy local swap;
* mutual-information/correlation ordering heuristic;
* matrix LOWRANK;
* oracle latent order.

The success criterion should not be “eventually found the right permutation.” It should be something like:

From interaction data, the organism identifies increasingly useful factorization structure substantially more efficiently than blind search, and that discovered structure improves held-out competence under the same bounded-memory economy.

And include non-TT-generated worlds this time. Some should favor TT, some matrices, some CP/Kronecker structure, and some deliberately lack a compact factorization. If the mechanism always searches for a TT because we gave it a TT hammer, we’ve learned very little.

If E2 discovers the correct representation family/topology from evidence, then Ensorain becomes much more interesting. That would change the story from:

“TT works well on a TT world.”

to:

“A bounded organism can discover how its world wants to be factorized.”

That is much closer to the original reason for building Ensorain.

So my ruling is: C2 passes on {192,224}; protocol verdict INTRIGUING. Park E1/E1.5 intact, and authorize only a small E2 structure-discovery falsifier. Do not close the seat yet.
