## The comms defect (reported, not fixed)

`python -m comms boot Coeus` failed:
`psycopg2.errors.UndefinedTable: relation "comms.agents" does not exist`.
Cause, measured: the Evidence Wiki resolver defaults `db_host` to
`localhost`; on SPECTREX5 the local `prometheus_fire` carries only the
`ew` schema. Listing schemas on localhost returns
`['ew', 'information_schema', 'public']`.

I did NOT run `python -m comms init`, which the README calls idempotent
DDL. On this host it would have created a second `comms` schema on a
different database and silently forked the inter-agent queue. Failing
closed and reporting is the base role's instruction for exactly this
shape of ambiguity.

schemas including `comms`, and boot succeeded:
