Candidate Architecture Portfolio R0-R9
"Race Cars" for the Recursive Sagacity Observatory
Important provenance note
The labels R0-R9 are synthesis labels, not legacy Prometheus engine names.
Some candidates come directly from the independent Phase 3 architects.
Some are descendants of v1/v2 physical machinery stripped of its old claims.
Some are strong controls.
Some are greenfield architecture hypotheses.
They should not be treated as ten engines already approved for implementation.
The current purpose is to preserve the architecture hypothesis space while the wind tunnel is built.

R0 -- Conventional recurrent / meta-learning reference
Physics
A fixed or mostly fixed recurrent numerical architecture with familiar learning mechanisms.
Variants should include ordinary recurrent learner, plastic recurrent learner, meta-learned recurrent learner, fixed topology vs structural plasticity, and conventional gradient or black-box optimization where computationally appropriate.
Why it belongs
Prometheus must permit familiar ML to win.
"Alien" is not the target.
If a conventional system satisfies the same causal developmental tests more efficiently, that is an important result.
Main role
Reference for task learning, learning-to-learn, nuisance robustness, acquisition efficiency, resource frontier, and recursive-sagacity impostor tests.
Primary danger
Treating R0 as philosophically uninteresting and therefore under-optimizing it.
The reference needs to be strong enough to kill weak novelty claims.
R1 -- Addressable Workspace Machine
Provenance
Directly inspired by Fable's proposed Workspace Machine.
Prometheus fossils:
- Crius persistent workspace/block store;
- Proteus graph/call machinery;
- callable persistent procedures;
- historical lessons about semantically rich opcodes smuggling target faculties.
Physics
Potential minimal ingredients:
- transient state;
- persistent blocks/records;
- local rewrite;
- create/delete/copy;
- readdressable references;
- bounded call/invocation;
- resource cost for storage and internal computation.
Avoid building in semantic faculties such as planner, analogy, hypothesis, abstraction, or a privileged "working-memory" module.
Main hypothesis
Addressable persistent structures make BUILD/COMPOSE relatively easy because constructed structures can become callable objects.
Expected strength
Causal dissection and explicit composition.
Mechanism boundaries may be unusually legible.
Expected weakness
Reachability Desert.
Program-like spaces may have tiny viable islands.
Required wind-tunnel test
Scaffold Free-Fall and full search-geometry curves before any open-ended interpretation.
R2 -- Developmental Graph Machine
Provenance
Directly from Opus 5.5's DGM proposal.
Related fossils:
- Proteus graph organisms;
- Crius workspace;
- developmental graph/program ideas from external literature.
Physics
Small computational nodes plus lifetime developmental operations such as spawn, link, unlink, rewrite, set-decay, and prune.
Crucially, developmental rules can themselves become state changed during the lifetime.
Main hypothesis
Cognition can emerge through graph-level structural development rather than only parameter learning.
Scientific advantage
Provides explicit causal provenance for higher-order writes.
Good candidate for testing Opus's developmental-order criterion.
Main danger
The developmental instruction set may already constitute a privileged programming language for self-construction.
A successful R2 result must therefore be compared with a much more local substrate.
R3 -- Plastic Structural Network
Provenance
Fable Plastic Network + Astra Track C.
Physics
- recurrent numerical units;
- persistent activations or state;
- writable weights/couplings;
- local plasticity;
- optional growth/pruning;
- modulatory signals;
- potentially modifiable plasticity rules.
Main hypothesis
Distributed continuous systems may achieve developmental construction with smoother search geometry than program spaces.
Expected strength
Potentially much better reachability.
Small parameter changes need not catastrophically destroy function.
Expected weakness
Composition/reification may be difficult to localize.
Higher-order causal slicing may be ambiguous.
Critical contrast
R1/R2 may be good at explicit composition but difficult to search.
R3 may be searchable but poor at explicit reusable-object construction.
That contrast could reveal useful hybrid physics.
R4 -- Spatial Developmental Chemistry
Provenance
Astra Track B.
Fable explicitly reserved lattice/cellular local dynamics as an open arm.
Prometheus fossils that inform it but do not validate it include Aether lattice propagation, Ananke local/message dynamics, Nestor/BEE resource/copying worlds, and other CA-family substrates.
Physics
No privileged global pointer.
Possible primitives:
- bounded spatial sites;
- local state/token multisets;
- transport;
- binding/unbinding;
- local reactions;
- rule-bearing material;
- conserved or priced resources;
- diffusion/propagation;
- local structural persistence.
Long-range effect requires time/resources.
Why it matters
This is the principal early anti-gravity architecture.
It forces the observatory to handle cognition that does not look like a software object graph.
Initial role
By Day 45, a minimal R4 should exist as an observatory shadow comparator even if it is not yet a serious scientific competitor.
Its first job is to reveal Track-A assumptions in event schemas, snapshots, provenance, intervention APIs, and ruler expectations.
Main danger
Local chemistries can generate visually interesting complexity with almost no useful cognition.
Demand certificates and cheap controls remain mandatory.
R5 -- Message / Packet Ecology
Provenance
Fable's first open-arm recommendation explicitly referenced message passing.
Ananke provides a real fossil: delayed packet/state dynamics.
Physics
Persistent organization resides partly in messages, queues, circulating tokens, routing, interaction protocols, and dynamically changing communication topology.
Cognitive state may not live in any single node.
Main hypothesis
Useful cognitive machinery can exist as stable circulation/protocol rather than static memory objects.
Why interesting
Potentially bridges organism cognition, collective cognition, asynchronous systems, stigmergic processes, and social dynamics.
Main challenge
Causal ownership and provenance.
A naive lineage model will misattribute circulating information.
R6 -- Expression / Reaction Chemistry
Provenance
Fable's proposed "function chemistry," expanded as a greenfield candidate.
Physics
Structures are simultaneously material, executable, and transformation rules.
Expressions react with or transform other expressions under explicit resource laws.
Possible dynamics include catalysis, inhibition, templating, decomposition, binding, execution, and replication with variation.
Main hypothesis
Compositional cognitive machinery can arise without an explicit distinction between code and data or an externally imposed call stack.
Scientific attraction
Could produce mechanisms difficult for LLM designers to anticipate.
Main danger
Huge search space and extremely weak initial demand alignment.
Likely a later Track-B-family experiment, not an MVP.
R7 -- Tensor / Factor Organism
Provenance
Fable proposed tensor-network organisms as an open substrate.
Ensorain provides relevant lessons but not a ready implementation.
Physics
Candidate organization:
- tensor/factor nodes;
- chain/tree/graph structure;
- explicit local dimensional capacity;
- mutable topology;
- mutable local factors;
- cost tied to bond/rank/capacity.
Why interesting
Capacity has unusually explicit quantitative dials.
This makes questions like "how much representational capacity is actually required?" potentially cleaner than in general programs.
Lessons from Ensorain
Do not mistake low-dimensional state, running means, completion, or compact predictors for abstraction or cognition.
Cheap tuned predictors and constant/lookup baselines come first.
Main danger
Importing human mathematical factorization directly into the substrate may strongly bias the search.
R8 -- Library-Building Program Learner
Provenance
Aphrodite's history plus external library-learning/program-synthesis systems.
Physics
A relatively fixed learning/search procedure accumulates reusable procedures/macros/templates and invokes them later.
Potential variants:
- fixed update rule + growing library;
- composition of stored procedures;
- search guided by prior library;
- library pruning/consolidation.
Role
This is less a hoped-for architecture than an extremely important recursive-sagacity counterfeit.
It can show reduced future acquisition cost, reusable compression, deeper compositions, and accelerating task acquisition without necessarily modifying the machinery that constructs learning machinery.
Mandatory use
Any RSE ruler should be qualified against sophisticated R8 variants.
If it calls ordinary library accumulation recursive sagacity, the ruler is insufficient.
R9 -- Cellular Developmental Automaton
Provenance
Synthesis of Opus's developmental-program framing, cellular/developmental encoding prior art, Fable/Astra local substrate families, and Prometheus's extensive CA/lattice fossils.
Physics
Inherited material encodes local growth/development rules.
During a lifetime the organism constructs a larger computational morphology.
Possible primitives include cell division, differentiation/state change, local signaling, local connection growth, apoptosis/pruning, resource flow, and developmental timing.
Main hypothesis
Evolution/search may more easily discover compact developmental programs than mature architectures.
This directly tests:
\[
G + E_{0:T} \rightarrow A_T
\]
rather than encoding \(A_T\) directly.
Main danger
Development may merely unfold a precompiled blueprint.
World/history interventions must distinguish fixed morphogenesis, experience-dependent development, and genuinely adaptive developmental construction.
R10 and beyond -- Architecture Foundry output
Do not stop at R0-R9.
The most important anti-gravity "architecture" may be an architecture generator.
Define low-level physical primitives such as persistence, movement, reaction, decay, binding, copying, local rewrite, topology change, cost, delayed activation, and rule modification.
Generate combinations without semantic names.
Then allow the RSO to determine whether any generated physics supports useful developmental transitions.
The foundry should reserve search mass for architectures not proposed by an LLM.
Unclassifiable + reproducible + causal + transferable should increase investigation priority.
Unclassifiable alone means nothing.
Portfolio strategy
Do not build all R0-R9 now.
MVP candidates
- R0 strong conventional reference;
- R1 or R2 primary Track-A implementation;
- tiny R4 shadow implementation by Day 45.
Next full competitor
Choose between R3 if the main unresolved question is reachability/continuous plasticity, or R4 if the main unresolved question is Track-A ontology dependence.
Controls to build early
R8 should exist early in a lightweight form because it protects the recursive-sagacity criterion.
Later high-risk/high-novelty candidates
R5, R6, R7, R9.
These should enter when the wind tunnel can test them without custom scientific semantics.
What "learning from failure" means
The v1/v2 lesson is not:
old engine failed, discard every component.

It is:
\[
\text{failed engine}
\rightarrow
\begin{cases}
\text{physical affordance}\\
\text{known confound}\\
\text{cheap competitor}\\
\text{measurement fixture}\\
\text{search pathology}\\
\text{causal-control requirement}
\end{cases}
\]
Examples:
- Crius: persistent workspace is interesting; semantically rich opcodes can smuggle in the target faculty.
- Proteus: graph/call substrate remains interesting; greedy search failures prove reach must be measured separately.
- Ananke: packet physics remain interesting; planted XOR demonstrates capacity is not discovery.
- Aether: propagation is real; propagation is not content transport, learning, or reasoning.
- Ensorain: factorized representations are interesting; running means/constants demonstrate why cheap baselines must precede interpretation.
- Aphrodite: growing libraries can look recursive; therefore library accumulation becomes a mandatory counterfeit.
- Nestor/BEE: copying/construction physics remain useful; seeded/transplant lineage confusion becomes a permanent provenance attack fixture.
That is the intended fossil-to-foundry loop.
