# Recursive Sagacity Observatory -- Hardening Design v0.2

## 1. Architecture decision

Keep the observatory model, but **do not build a universal organism runtime**.

Phase 3 becomes a **thin federation of native experimental runtimes** joined by shared scientific contracts:

- registered cells and claims;
- world/custody/exposure records;
- resource accounting;
- qualification receipts;
- known-answer challenges;
- comparison semantics that have themselves been qualified.

Each physics keeps native dynamics, state representation, interventions, search operators, and replay/equivalence semantics.

The tunnel standardizes accountability, not ontology.

## 2. Immediate target

The program may retain the name Recursive Sagacity, but the **strong recursive-sagacity ruler is not yet qualified**.

Fable's counterfeit work showed that a fixed library builder can satisfy one reasonable operationalization, and an inherited search-order selector another. Astra independently showed how task-distribution cargo can be wrapped in fresh updater objects and create a misleading V->U->S ancestry trace.

Therefore the first hardening target is:

> developmental retention, transfer, economic advantage, and nested improvement at a stated world order, with explicit information and resource channels.

Until a genuine positive exists that defeats the counterfeit battery:

`RECURSIVE_SAGACITY_RULER = DETECTION_UNQUALIFIED`.

This is a hardening success, not a defect.

## 3. Cross-physics axes

The v0.1 HOLD/ADAPT/BUILD/COMPRESS/COMPOSE/RECURSE vocabulary remains useful shorthand, but should not be the primary cross-physics coordinate system because several terms depend on how an organism's internal state is partitioned.

### ORDER

Defined by the world's nesting:

- Order 1: savings within a task;
- Order 2: across tasks of a family;
- Order 3: across distinct families;
- Order 4+: across meta-families/groups of families.

### RETENTION

Information about prior experience that survives a declared boundary or perturbation and is causally useful later.

Where the world draws a random key, behavior can lower-bound retained bits against the exact class that carries nothing across the boundary.

### ORIGIN

Whether a capability was selected from inherited alternatives, built by a fixed builder, or built by a changed builder remains an **open measurement problem**. Do not infer this from write ancestry or memory size alone.

## 4. Registered developmental cell

Every claim is conditional on:

`C = (physics, search, world, development, boundary, resources, measurement, exposure)`.

Search is part of the architecture. A substrate has no context-free reachability result.

## 5. Qualification facets

Keep the core five questions:

- CAPACITY
- DEMAND
- REACH
- DETECTION
- DEVELOPABILITY

Add:

### NEUTRALITY

Does a purportedly shared ruler return the registered answer across unlike physical realizations and their impostors?

A ruler may be `PHYSICS_SPECIFIC`. That is valid, but it cannot support cross-physics claims.

## 6. Two-door physics entry rule

A physics can be explored freely. Before a physics-specific null, ruler, or serious search campaign receives scientific authority, enter through one of two doors:

### Door A -- designed known answer

A native known-positive organism plus matched negative/impostor.

### Door B -- blind-found known answer

A behaviorally certified positive found without the designer supplying the mechanism, admitted through world-side/class-exclusion evidence.

Door B prevents the tunnel from admitting only physics that humans/LLMs can already hand-program.

## 7. Isomer panel

The first tunnel-neutrality panel implements the same bounded retention capability in unlike forms:

1. stored word / thin Track-A machine;
2. recurrent attractor / plastic network;
3. packet in flight / message ring;
4. stable spatial pattern / lattice.

Each needs a positive and matched impostor. Add second-author and blind-found positives as the program matures.

No ruler is called shared until it returns registered answers on the relevant panel.

## 8. Federated runtime contract

A native runtime declares only:

1. observation/action adapters (preferably at least two encodings);
2. inheritance channel and capacity/dial;
3. perturbations: WAIT, DISTRACT; optional QUENCH and NOISE;
4. state-capture/restart equivalence contract;
5. native resource unit plus host-cost accounting;
6. optional interventions plus matched-sham generator;
7. optional tracer if provenance is claimed;
8. native search regimes.

It need not expose pointers, modules, fast/persistent state, V/U/S anatomy, lineage graphs, or transplantation.

Claims are limited to what the physics can measure validly.

## 9. Reality / observation hardening

Retain a thin Reality Plane and Observation Plane, but qualify observer non-interference per physics.

Required checks include:

- observer off/minimal/full/overloaded;
- RNG invariance where meaningful;
- timing/scheduling equivalence;
- numerical precision/integrator checks;
- complete in-flight queue capture for message systems;
- ruler output never feeds search unless registered as scaffold.

Out-of-band analysis does not make event emission automatically non-invasive.

## 10. Search hardening

Scaffold Free-Fall is retyped as **repair reach**, not cold discovery.

Measure separately:

`R_repair(distance, budget)`

and

`R_cold(budget)`.

For serious substrate/search pairs include:

- multiple unlike known targets;
- cold founders;
- at least two bounded search operators;
- finite ascent/plateau/valley fixtures where possible;
- hit-rate intervals;
- censored time/resource-to-hit;
- mutation-neighborhood uncertainty;
- search tuning cost;
- functional equivalence, not exact target bytes.

## 11. World program

### W0 -- exact calibration

Known truth for reset/leak/ruler/intervention qualification.

### W1 -- economic crossover

A parameterized world family asking **where development pays, including nowhere**.

Recommended first family: renewal hidden-law tasks sweeping law turnover and reuse horizon, with exact or tightly bounded class values.

Frozen competitors include fixed policy, sufficient statistic, lookup, library learner, ordinary adaptive learner, meta-learner, and ideal observer where computable.

### W2 -- defer during hardening

Do not build an unbounded adversarial universe in the first round. Specify its discovery/confirmation custody split on paper.

## 12. Cognitive boundary

Keep externalized cognition, but begin with a 2x2:

- internal retention on/off;
- external retention on/off.

Use priced persistent worksite marks, erasure, scrambling, read blocking, donor swaps, and physical-damage shams.

If benefit follows the niche, claim joint/niche cognition, not organism-only development.

## 13. Claim facets first, display level second

A claim stores independent facets:

- demand;
- detection;
- reach;
- developability;
- causality;
- origin;
- transfer;
- independence;
- resources;
- custody/exposure.

Then derive a display strength:

- L0 OBSERVED
- L1 QUALIFIED
- L2 ROBUST
- L3 REPRODUCED
- L4 PREDICTED

Claim kind is separate: EFFECT / TRANSFER / MECHANISM / LAW.

Without an exact restricted-class bound, structure claims default to an L1 ceiling during hardening.

## 14. Nested-improvement hardening

Keep V->U->S only as a registered experimental mapping, not a universal anatomy.

The counterfeit suite must include:

- inherited procedure selector;
- fixed builder + growing library;
- inherited search-order selector;
- maturation/unlock;
- memorizer;
- external/world parking;
- nested compiler carrying task/meta-task cargo;
- hierarchical selector;
- flattened information-equivalent competitor.

Freeze all ambiguous protocol choices before a run:

- cost definition;
- how B/C/D/E differ from A and each other;
- content-reset semantics;
- sham construction;
- family-A curriculum;
- wrong-history definition;
- effect threshold;
- power;
- amortization horizon.

Every clause needs a fixture capable of making it false.

Report:

> nested improvement, order k, setting S, acquired-information estimate I, lifecycle cost C.

Reserve "recursive" until the ruler has a genuine positive and defeats the counterfeit kit.

## 15. Strong R0 doctrine

R0 gets an owner whose job is to make conventional methods win, with a tuning/search budget competitive with candidate architectures.

Order:

1. ideal observer;
2. in-context learner;
3. online-gradient learner;
4. later external-memory learner;
5. later self-referential/meta learner.

## 16. Observatory acceptance

Before calling the system a cross-physics observatory:

- exact W0 bounds pass;
- positives/impostors exist in at least three unlike physics;
- shared rulers return all registered answers;
- physics-specific rulers are flagged;
- observer equivalence passes;
- historical failure fixtures fire;
- verdict attainability/power is checked pre-run;
- one world and one ruler receive second implementations;
- repair and cold reach are separately measured;
- claim promotion refuses missing facets;
- BLOCKED/UNQUALIFIED is distinct from FAIL.

The reference harness in this package implements a minimal executable form of these rules.
