# Phase 3 Hardening Test Harness Specification

## Purpose

The harness prevents rules from living only in prose. It has two jobs:

1. software conformance -- contracts, receipts, resources, reset/custody and fail-closed refusal;
2. scientific qualification -- known answers, counterfeits, attainable verdicts, cross-physics neutrality and claim demotion.

It does not prove cognition.

## Harness layers

### H0 -- schema / receipt integrity

Require complete registered cell, resources, exposure, physics/runtime identity, search regime, ruler version. Missing inputs fail closed.

### H1 -- W0 known-answer qualification

Require exact truth, positive, negative/impostor, and ideal observer/class bound where appropriate.

### H2 -- isomer neutrality

The same bounded capability is represented in >=3 unlike physics. Every purportedly shared ruler carries a presumption sheet and registered answer for every positive/impostor.

### H3 -- observer/reset torture

Run observer off/minimal/full/overloaded. Inject:

- RNG advance;
- timing/outcome perturbation;
- uncleared clock/counter;
- external mark carryover;
- omitted in-flight queue;
- stale state after restart.

### H4 -- search geometry

Separate repair/free-fall from cold discovery. Include ascent/plateau/valley finite fixtures and at least two search policies.

Reject:

- repair success reported as cold discovery;
- plateau failure reported as substrate impossibility;
- zero hits reported as latent impossibility;
- adaptive/dependent trials analyzed as IID without qualification.

### H5 -- baseline / demand closure

Fixtures:

- constant predictor omitted;
- lookup omitted;
- clock solves world;
- answer key leaks;
- holdout champion selection;
- post-data comparator treated as confirmatory.

### H6 -- intervention qualification

Mechanism claims require target perturbation, matched physical sham, random/equal-size structure control, rescue, and off-target accounting. Failure returns INTERVENTION_INVALID, not mechanism absence.

### H7 -- nested-improvement counterfeit gauntlet

Register:

- PROCEDURE_SELECTOR
- LIBRARY_FIXED_BUILDER
- SEARCH_ORDER_SELECTOR
- MATURATION_UNLOCK
- MEMORIZER
- WORLD_PARKING
- NESTED_COMPILER_CARGO
- HIERARCHICAL_SELECTOR
- FLATTENED_INFORMATION_EQUIVALENT

The strong recursive-sagacity ruler remains unqualified until a genuine positive exists and every clause has a reachable fail fixture.

### H8 -- custody / adaptive-world separation

Adaptive world generation is discovery. Confirmation uses frozen panels or separately held generator families. Catch holdout access, custody-hash mismatch, seed-only pseudo-independence and adaptive-generator reuse.

### H9 -- claim facets / demotion

Promotion is a function of evidence facets. Inject defects into detection, custody, baseline, intervention and reach; dependent claims must demote automatically.

## Historical failure fixture pack

The production harness should eventually encode at least:

1. seeded/transplanted phenomenon called endogenous;
2. answer/label leakage;
3. missing constant baseline;
4. impossible/non-failing control;
5. ruler unable to emit required verdict;
6. clock/counter leak;
7. coordinate/location bias;
8. holdout champion selection;
9. search operator unable to cross neutral step;
10. propagation called learning/content transport;
11. library growth called recursive improvement;
12. source-read organ called mechanism;
13. same-code repeat called independent replication;
14. post-data analysis promoted retroactively;
15. incomplete reset / external carryover;
16. write ancestry/task cargo called recursive order;
17. persuasive false auditor accusation;
18. observer instrumentation changes dynamics.

## Gate semantics

Every gate returns one of:

- PASS
- FAIL
- BLOCKED
- UNQUALIFIED

A missing positive for a ruler means UNQUALIFIED, not FAIL and not evidence of absence.
