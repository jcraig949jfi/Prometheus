## Allocation target

- 35% tunnel core + qualification automation
- 30% candidate runtimes + standards
- 20% discriminating experiments
- 10% independent challenge/reimplementation
- 5% blind/found-physics census

## Days 1-15 -- harness first

Build:

- thin runner/refusal gates/receipts;
- W0 RETAIN-1 with exact nothing-carried bound;
- R0 ideal observer;
- thin R1/R2 positive + impostor;
- tiny R4 local-spatial positive + impostor;

Run first isomer neutrality and first repair-vs-cold fixture.

## Days 16-30 -- qualify the tunnel

Add R3 designed retention latch/impostor, second-author isomer where feasible, second observation adapters, exact ascent/plateau/valley search fixtures, power/attainability preflight, and first W1 renewal hidden-law family.

Goal: at least three unlike physics with registered answers.

## Days 31-45 -- search and economics

Run repair reach and cold founders, >=2 search operators where meaningful, initial hardwire-vs-develop W1 map, lifecycle accounting, and first internal/external 2x2 custody world.

Gate 45: if shared rulers still fail the isomer panel after one repair round, suspend cross-physics comparison.

## Days 46-60 -- freeze one fresh confirmation

Freeze effect size, baselines, sample unit, stop rule, custody and one W1 contrast. Independently implement one world and one ruler/checker. Expand R8 with nested-compiler cargo and flattening attacks.

Select the second deep candidate by evidence: R3 if reach is limiting, R4 if ontology/locality is limiting, R5 if distributed state capture is limiting.

## Days 61-75 -- registered confirmation

Execute one fresh preregistered confirmation. Pilot causal/nuisance or internal/external work only if their controls are qualified. Pilot winners do not become confirmations.

## Days 76-90 -- hardening closure

Run independent challenge, facet-demotion tests, found-organism isomer where feasible, and a bounded blind-physics census only if earlier gates were on schedule.

Attempt strong-recursion qualification only if a genuine positive has been constructed.
