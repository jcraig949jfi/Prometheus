**DIAGNOSTIC.** The rule is broken in a specific, general way: a permutation null computed on
the same rows as the effect **inflates with the effect**, because permuting labels across
strongly separated classes manufactures large spurious gaps. On a bounded [0,1] statistic that
drives the bar to the ceiling. "2x the 95th percentile of a permutation null" is a sound rule
for an unbounded statistic and an unsound one for a bounded proportion.

## 1. What was built

`world3.py` — TINYPROG. Objects are 4-tuples over Z6; a task is a hidden program over 10
anonymous typed primitives; the solver sees only extensional behaviour on 6 fixed probes.

The construction inverts the order that killed worlds v1 and v2. Every program is a function of
the single input and every primitive combines such functions POINTWISE, so a program is
representable by its extensional SIGNATURE, signature space is closed under the primitives, and
bottom-up enumeration with deduplication gives **exactly** the minimal program size of every
reachable function, the complete inventory of shallow routes, and a flat solver whose costs are
directly instrumented. The graph worlds could only ever SAMPLE their shortcut inventory, so
their "no shortcut" claim was always a claim about a sample. This one is a claim about a closure.

Closure at depth 6: 69,738 candidates expanded, 18,224 distinct signatures, budget not
exhausted. Layer widths 1 / 5 / 25 / 119 / 570 / 2782 for type V.

## 4. W5, and why its FAIL does not count

The measured separation is as clean as this kind of thing gets:

    rec_late    REUSE 1.0000   NO_REUSE 0.0347   DECOY 0.0625   LATE 1.0000   CONTROL 1.0000
    rec_early   REUSE 1.0000   NO_REUSE 0.1667   DECOY 1.0000   LATE 0.2847   CONTROL 1.0000

DECOY is high early and at chance late. LATE is low early and 1.0 late. That is exactly the
preregistered pattern, on the axis the classes were built to differ on.

The rule nevertheless returned FAIL, on **two independent pre-existing grounds** that make the
FAIL inadmissible rather than merely wrong:

**(1) The gate was unreachable.** `rec_late` is a fraction, so the largest possible class gap is
1.0. The preregistered bar is 2x the 95th percentile of the label-permutation null, and that
percentile came in at 0.5 — putting the bar at **exactly 1.0, the ceiling**. No input to this
experiment could have fired the gate. This is the GATE MUST BE SHOWN REACHABLE failure, in my
own preregistration, one day after restating the doctrine, and it was not caught by writing the
prereg carefully.

**(2) W5 never passed a known-POSITIVE.** The A2 calibration ran a known-negative for W5
(`KNOWN_BAD_no_separation`, REUSE secretly generated with reuse probability zero, which
correctly failed) but **no fixture ever asserted W5 == True**. Under the program-wide instrument
rule adopted 2026-08-27, a probe that has never passed a known-positive cannot issue a
scientific FAIL. The calibration was incomplete in a way provable from its own fixture table.

The preregistered verdict string `WORLD_REJECTED_CLASSES_NOT_SEPARATED` is kept verbatim in the
artifact with `verdict_admissible: false` beside it. Editing it to what I believe it should say
would be retune-to-pass.

## 5. The instrument defect the calibration caught before the world reading

A2-CAL's first run returned INSTRUMENT_UNVALIDATED, and it was right to.

The W4 statistic originally divided the class-mean spread by the sd of ALL episodes — which
includes the between-class variance the statistic exists to detect. That makes the reading
**self-limiting**: for five classes it cannot exceed sqrt(8) = 2.8284 however enormous the class
effect is, and the bar sat at 2.49, inside 12% of a hard ceiling. A world with class means at
five different program sizes read 2.191 and was declared MATCHED. Dividing by the **within-class**
sd instead — the standard one-way effect size, unbounded above — moved the same fixture to 5.778.

**The same defect, twice in one pass, in two different statistics.** Both are the bounded-
statistic-against-an-inflating-bar shape. The difference is that the calibration caught the W4
instance before it could contaminate a reading, and the W5 instance is caught only by the
admissibility rules afterwards. That is the argument for the instrument rule stated as a
measurement rather than as a preference.

A second, smaller correction: the first interventional sweep moved a MIXTURE fraction (what
share of one class's episodes were drawn a size larger), which moves the class mean and the
within-class variance together and produced a flat, non-monotone reading. Sweeping a
homogeneous size shift instead gives 0.597 / 2.333 / 3.100 / 4.489 / 6.170 with the verdict
flipping between sigma 1 and 2. That was an intervention-design error, not a probe defect, and
it is recorded rather than quietly replaced.

**Weakness of the metamorphic arm, stated:** renaming can only catch code that keys on a name
string. It is not an algebra automorphism, so it does not test the statistics against a genuine
symmetry of the world. I did not find a non-trivial automorphism of this primitive set that
commutes with the increment operator.

## 8. What A2 does NOT establish

- It says nothing about the language-of-thought hypothesis. It is an instrument-and-world
  result. Quoting any A2 number as progress on the hypothesis is the category error amendment 1
  diagnosed.
- W1 solve rate 1.0 is **true by a construction argument, not an empirical finding**: a program
  of tree size 6 is necessarily reachable in a closure enumerated to depth 6, so W1 tests only
  that the enumeration budget did not bite. Its attainable range is not really [0,1] for this
  generator. Recorded as a vacuity flag.
- No promotion mechanism has been run against these classes. Whether a system can tell REUSE
  from NO_REUSE is A3's question; A2 establishes only that the two differ on the reuse axis and
  are matched on everything else measured.
- The nuisance set is the four statistics named in the preregistration. A class-identifying
  feature outside that set would not have been caught.
