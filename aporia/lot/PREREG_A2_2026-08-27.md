# PREREG — A2, THE SEMANTIC-FIRST WORLD. Filed before any world-v3 code exists.

Pass P176. Governed by `AMENDMENT_1_LEVELS_AND_INSTRUMENT_RULE_2026-08-27.md`, which governs
over the charter where they conflict.

**This rung tests NO hypothesis about the language of thought.** It builds a world and measures
whether that world is admissible as a testbed. A2 can only ever return a world verdict. Quoting
any A2 number as evidence for the charter hypothesis is the category error the amendment names.

---

## 1. WHAT IS BEING BUILT, AND IN WHICH ORDER

Amendment section 6 prescribes the construction order and section 7 prescribes the content:

    latent semantics -> prove the properties EXACTLY -> compile to a surface

    NOT: surface first, sample, hope

So the world is a **value algebra plus an enumerable function space**, not a graph. Graphs were
rejected as a hostile surface after three failures, and the failure mode is now understood:
degree, density, components, path length, symmetry and motifs are a factory for unintended
classifiers.

**World v3 (TINYPROG).** Objects are 4-tuples over Z6. A task is a hidden program over 10
anonymous typed primitives; the solver sees only input/output pairs and must find any program
that agrees extensionally on a fixed probe set. Nothing in the surface is nameable except the
primitives, and their names carry no semantics (tested below by relabelling).

**Why this shape satisfies "boring enough to enumerate every shallow route":** every program is
a function of the single input, and every primitive combines such functions pointwise, so a
program can be represented by its EXTENSIONAL SIGNATURE over a fixed probe set. Signature space
is closed under the primitives, therefore bottom-up enumeration with deduplication by signature
gives, exactly and not statistically:

- the minimal program size for every reachable function, up to the enumeration budget
- the complete set of shallow routes to any target, by construction
- a flat solver whose cost is directly instrumented

This is what the graph worlds could not provide: their shortcut inventory was sampled, so
"no shortcut" was always a claim about the sample.

## 2. COST MODEL — FIXED NOW, BECAUSE A3 DEPENDS ON IT

Amendment section 5 names unit-cost macro privilege as the unnamed confound.

    C_search     number of distinct candidate signatures expanded by the enumerator
    C_execution  number of primitive applications executed, counted over the probe set

**These are recorded separately at every reading and are never summed.** A macro, when A3
introduces one, is charged the execution cost of its expansion and may cost one search decision.
The whole phenomenon under test lives in that difference, so a merged budget would define the
result into existence.

## 3. THE FIVE WORLD CLASSES (amendment section 7, verbatim in intent)

    REUSE        a hidden subexpression recurs in downstream tasks
    NO_REUSE     no subexpression recurs above the chance rate
    DECOY_REUSE  a subexpression recurs during the discovery half but NOT downstream
    LATE_REUSE   a subexpression is weakly evidenced early and common late
    CONTROL      the useful subexpression is available as a primitive from the beginning

A2 does not run any promotion mechanism against these. A2 asks only whether the five classes
are constructible such that they differ on the reuse axis and on NOTHING ELSE that is measurable.

## 4. READINGS AND THRESHOLDS — fixed before any world data is generated

Thresholds that depend on an unknown variance are preregistered as MULTIPLES OF A MEASURED NULL
BAND rather than as absolute numbers, per the LOOP doctrine on thresholds failing in both
directions. The null is a class-label permutation null computed on the same rows.

    W1  SOLVABILITY        flat solve rate within budget B, over all tasks
                           PASS band [0.60, 1.00]
                           attainable [0, 1]
                           FAILING INPUT: a generator emitting programs outside the enumerable
                           closure, so the ground truth cannot be found at any cost

    W2  NON-TRIVIALITY     fraction of tasks whose MINIMAL size is >= 3
                           PASS >= 0.90
                           attainable [0, 1]
                           FAILING INPUT: a primitive set with hidden identities (six rotations
                           of a 4-vector composing back to the identity), which would collapse
                           nominally deep programs to size 0-2

    W3  COST HEADROOM      median C_search over solved tasks, expressed as a multiple of the
                           size-1 layer width
                           PASS >= 10x
                           attainable [1, B]
                           FAILING INPUT: targets that sit in the first enumeration layer, where
                           there is no search for a macro to compress

    W4  NUISANCE MATCH     across the five classes, on each of (minimal size, C_search,
                           C_execution, output entropy): max pairwise class gap, standardised
                           PASS <= 2x the 95th percentile of the class-label permutation null
                           attainable [0, large]
                           FAILING INPUT: the deliberately size-skewed generator built as the
                           calibration known-negative

    W5  CLASS SEPARATION   on the intended axis only, the downstream subexpression recurrence
                           PASS requires ALL THREE:
                             (a) REUSE - NO_REUSE > 2x the 95th percentile of the same null
                             (b) DECOY early-half recurrence high, late-half within the null

                             (c) LATE_REUSE the reverse of (b)
                           attainable [0, 1] for each recurrence
                           FAILING INPUT: REUSE generated with reuse probability 0, which is
                           NO_REUSE under another name; this is the calibration known-negative
                           for W5

## 5. BRANCH TABLE — evaluated in order, so every reading maps to exactly one terminal

    1. any of W1, W2, W3 fails                    -> WORLD_REJECTED_UNUSABLE_BAND
    2. W1-W3 pass, W4 fails                       -> WORLD_REJECTED_NUISANCE_CONFOUND
    3. W1-W4 pass, W5 fails                       -> WORLD_REJECTED_CLASSES_NOT_SEPARATED
    4. W1-W5 all pass                             -> WORLD_ADMISSIBLE

The terminal set is asserted to be exactly these four in code, and the ordered evaluation makes
the mapping total and single-valued. Nothing else may be written into the verdict field.

**Null output of the verdict rule, stated before running:** a world generated by sampling
programs uniformly with no class structure at all would pass W1-W4 and fail W5(a), landing on
WORLD_REJECTED_CLASSES_NOT_SEPARATED. A world whose classes were built by changing program size
would fail W4 and land on WORLD_REJECTED_NUISANCE_CONFOUND. Neither null lands on ADMISSIBLE,
which is the property that makes the rule discriminating.

## 6. THE PROBE FOR W4 AND W5 IS NEW, SO IT IS CALIBRATED FIRST

Program-wide instrument rule, adopted 2026-08-27:

    A probe that has never passed a known-POSITIVE fixture cannot issue a scientific FAIL.
    A probe that has never failed a known-NEGATIVE fixture cannot issue PASS.

The A1 calibration validated the REACHABILITY_CENSUS, which is a probe for boolean-label
worlds. It says nothing about the nuisance-match probe introduced here. A2 therefore runs its
own calibration, in a separate artifact, and **the world reading is inadmissible unless the
calibration returns INSTRUMENT_VALIDATED.**

    KNOWN_GOOD_matched          two class samples from the SAME generator
                                -> W4 must PASS (verdict MATCHED)
    KNOWN_BAD_size_skew         classes drawn at deliberately different program sizes
                                -> W4 must FAIL
    KNOWN_BAD_no_separation     REUSE built with reuse probability 0
                                -> W5 must FAIL
    INTERVENTIONAL SWEEP        skew parameter 0 -> 1 in five steps; the W4 statistic must be
                                monotone non-decreasing and the verdict must flip
    METAMORPHIC                 apply a permutation to primitive NAMES consistently in the
                                generator and the solver; every reading and every verdict must
                                be invariant, because a name carries no semantics

The metamorphic arm is the one that would catch a solver or a statistic that had accidentally
been written against a specific primitive rather than against the algebra.

## 7. WHAT A2 MAY NOT DO

- may not mint, promote or reify anything
- may not report any transfer, advantage or LoT claim
- may not adjust any threshold in section 4 after seeing a world reading; a mismatch is
  reported beside the verdict instead
- may not merge C_search and C_execution
- may not use the calibration fixtures as world data

## 8. PREDICTED READINGS, RECORDED BEFORE MEASUREMENT

Cost-to-falsify is prospective, per the standing correction. Predictions:

- W1 will pass. The enumerator and the generator share the same primitive set, so the ground
  truth is reachable by construction unless the budget bites.
- W2 is the one I expect to fight. A 4-tuple rotation has order 4 and Z6 addition has order 6,
  so short compositions collapsing to the identity are likely, and my prediction is that the
  first generator draw produces some tasks with minimal size below 3. If so the fix is
  rejection on the MEASURED minimal size, not a change to the threshold.
- W3 will pass comfortably if W2 does.
- W4 is genuinely uncertain. Reuse is imposed by construction, and imposing it constrains
  program structure, which could easily move minimal size or search cost with it. This is the
  most likely honest failure and it would be a real result about the class construction.
- W5(a) will pass by construction. W5(b) and W5(c) are the informative ones.

**Cost-to-falsify prediction:** one enumeration run settles W1-W3; one generator run plus one
permutation null settles W4-W5. Two probes, no model calls.

## 9. WHAT WOULD MAKE ME ABANDON THE WORLD RATHER THAN REPAIR IT

If W4 fails and the mismatch traces to the reuse imposition itself rather than to a generator
detail, then reuse cannot be varied at fixed nuisance in this construction, and the world is
wrong in the same way the graph worlds were wrong. That is kill criterion 1 in the amendment,
and it is the second of the two attempts the amendment allows before parking the arc.
