## 1. WHAT IS WRONG, STATED AS A GENERAL DEFECT

The preregistered W5 rule was

    PASS if observed class gap > 2 x P95( max pairwise gap under class-label permutation )

A permutation null is computed on the same rows as the effect. When the true effect is large,
permuting labels **mixes strongly separated classes**, which manufactures large spurious gaps
and drives the percentile up **with** the effect. On an unbounded statistic that merely makes
the rule conservative. On a **bounded** statistic — `rec_late` is a fraction, ceiling 1.0 — the
bar climbed to exactly 1.0 and **no input could fire the gate**.

    General form: a bar defined as a MULTIPLE of a null computed on the same rows is unsafe
    whenever the statistic is bounded, because the bar and the ceiling can meet.

This is the third distinct member of the bounded-statistic family in two days: the W4 statistic
capped at sqrt(8) by its own denominator, this one, and the 2026-08-23 preregistered cut of 0.14
against a maximum attainable 0.1364.

## 2. THE REPAIRED RULE

Use the permutation distribution as a **reference distribution**, not as a scale factor:

    g_obs = mean(rec_late | REUSE) - mean(rec_late | NO_REUSE)
    for b in 1..B:  permute class labels; g_b = max over ordered class pairs of (mean_a - mean_b)
    p = (1 + #{ b : g_b >= g_obs }) / (B + 1)
    PASS if p <= 0.05

with B = 1999, so the smallest attainable p is 1/2000 = 0.0005.

Two properties, both data-independent:

- **REACHABLE.** The attainable range of p is [1/(B+1), 1]. The bar 0.05 lies strictly inside
  it. Contrast this with the killed rule, whose bar could equal the statistic's ceiling.
- **MAX-T MULTIPLICITY.** The reference is the maximum over all ordered class pairs, so the
  named contrast is tested against the most extreme gap any pair could show by chance. The rule
  is conservative in the correct direction rather than in the direction that cannot fire.

Same rule, same B, same bar for the two supporting contrasts:

    W5b  DECOY:  p(early lift vs NO_REUSE) <= 0.05  AND  p(late gap vs NO_REUSE) > 0.05
    W5c  LATE:   p(late lift  vs NO_REUSE) <= 0.05  AND  p(early gap vs NO_REUSE) > 0.05

The "must NOT separate" halves are one-sided in the same direction, and a non-significant
p-value is being used as evidence of absence there. **That is a weak inference and is labelled
as such in the artifact** — it is a statement that the world was not caught differing, not a
statement that it does not differ. It is admissible here only because the accompanying half of
the same class is required to be significant, so the pattern as a whole cannot be produced by
low power alone: low power would fail the significant half first.

## 3. FIXTURES — the reachability proof is a fixture, not an argument

**Rule-level, independent of the world generator.** Episode-level `rec_late` values are
synthesised directly and handed to the rule. This tests the rule in isolation, so a shared
defect in the world generator cannot flatter it.

    RULE_KNOWN_POSITIVE     one class at 1.0, one at 0.0, three at chance -> W5a must PASS
    RULE_KNOWN_NEGATIVE     all five classes drawn from one distribution  -> W5a must FAIL
    RULE_CEILING_CHECK      the killed rule is re-run on RULE_KNOWN_POSITIVE and must FAIL,
                            demonstrating on a synthetic input that the old gate could not fire

**Generator-level.**

    GEN_KNOWN_POSITIVE      REUSE generated with reuse probability 1.0   -> W5a must PASS
    GEN_KNOWN_NEGATIVE      REUSE generated with reuse probability 0.0   -> W5a must FAIL
    GEN_ALL_IDENTICAL       all five classes from one recipe             -> W5a must FAIL

**Interventional sweep.** Reuse probability rho in {0, 0.25, 0.5, 0.75, 1.0}, applied as a
deterministic evenly-spread quota so that the shared-motif task set at a lower rho is a subset
of the set at a higher rho. The observed contrast must be monotone non-decreasing in rho and the
verdict must flip.

**Metamorphic.** Relabel all ten primitives; every reading must be bit-identical.

    A probe that has never passed a known-POSITIVE fixture cannot issue a scientific FAIL.
    A probe that has never failed a known-NEGATIVE fixture cannot issue PASS.

A2b's own reading is inadmissible unless every fixture above lands as specified.

    2. W4 fails                  -> WORLD_REJECTED_NUISANCE_CONFOUND
    3. W5 fails                  -> WORLD_REJECTED_CLASSES_NOT_SEPARATED

**A2b verdict of record:**

    WORLD_ADMISSIBLE                 iff ALL FIVE fresh seeds return WORLD_ADMISSIBLE
    WORLD_UNSTABLE                   iff the five seeds disagree with each other
    the common terminal              iff all five agree on a rejection

Unanimity is required rather than a majority, because five seeds cannot resolve a rate: a 4-of-5
result is 0.8 with a 95% interval running from roughly 0.28 to 0.99, which is not a measurement
of anything. Disagreement is reported as WORLD_UNSTABLE, which is a finding about the world and
not a failure of the rung.
