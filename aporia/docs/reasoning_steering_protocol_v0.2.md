## 0. The unification, sharpened (why this is one problem, and what would kill it)

Three objects we treated separately are one:

- **The failure landscape** has wells = states where reasoning *succeeds* (low
  damage), surrounded by a field of failure-pointers.
- **The reasoning ladder** (R1–R5+), read in v0.1 as scalar difficulty. The
  hypothesis: it is a **basis**, not a scalar — and the rigorous form of "basis"
  is that the failure-pointer field is **non-conservative**. A scalar difficulty
  function can only ever induce a *conservative* (curl-free) field; so if the
  field has circulation that survives nulls, no scalar difficulty reproduces it,
  and the ladder is structurally not a height map.
- **The ejection / convergence pathology:** pretraining installs a suppressor that
  ejects correct-but-uncertain reasoning for **statistically plausible answers
  that sound good** — a *global attractor* (bypass) that *hardens with scale*.

**The guardrail (load-bearing).** Non-conservativity is the **first structural
falsifier** of the scalar-ladder hypothesis — the *necessary condition* for the
basis thesis to be nontrivial. It is **not** "the whole game." Some real reasoning
subdomains may be locally gradient-dominated (genuinely scalar "easy rungs") while
embedded in a larger non-conservative landscape. The protocol must die only if the
**whole supposed basis structure collapses to scalar difficulty**, never because a
few easy rungs are gradient-like.

**Central Law (carried from v0.1).** *A gradient-enriched failure landscape is a
reasoning substrate iff directional interventions derived from its wells bend a
model toward correct reasoning — generalizing BEYOND the generators that built the
landscape — more than (a) random-direction nulls and (b) raw-answer training.*

**Doctrine sentence (this version).**
> A reasoning rung is not a difficulty level unless its failure flow is
> gradient-dominated. A non-gradient rung has **intrinsic rank**: the number of
> independent cyclic/harmonic directions required to traverse its local well.

## 1. Representation — the atomic datum and the flow it induces

Extends the failure-signal record (`failure_signal_protocol_v0.1` §1):

```
{
  "state":            "<problem/proof state>",     // a node in the state-graph
  "move":             "<operator/verb>",            // an edge: state_i -> state_j
  "gradient":         <float>,                       // damage-change of the move
                                                      //  (<0 = toward a well)
  "target_well":      "<basis-direction id>",
  "outcome":          "CORRECT | SOUNDS_GOOD_WRONG | NEUTRAL",
  "emitter":          "<operator-family id>",        // for the operator-null
  "null_p":           <float>,
  "provenance":       {...}, "emitter_version": "<hash>"
}
```

These records define a **directed weighted graph**: states are nodes, moves are
edges, and the edge flow `f(i→j)` is the damage-change (gradient). The whole
protocol is the analysis of this flow. `SOUNDS_GOOD_WRONG` remains the
load-bearing label — a fluent, high-likelihood, *wrong* continuation, generated by
a strong plausible-but-wrong generator, never random corruption (a weak null
poisons H-R3).

## 2. The Hodge spine (the math the hypotheses measure)

Combinatorial Hodge / HodgeRank decomposition of the edge flow `f`:

```
f  =  ∇φ        +        δψ        +        h
       │                  │                  │
   gradient            curl /              harmonic /
 (scalar diff.)    local cyclic        global hole (H¹)
```

- **∇φ** — the part explained by a global scalar potential `φ`. This *is* the
  scalar-difficulty reading. A pure-`∇φ` flow means a single difficulty number
  reproduces every failure pointer.
- **δψ** — local circulation (A→B→C→A with net descent): path-dependence, traversal
  that must switch direction partway.
- **h** — harmonic component, a basis for H¹ of the state-graph: global circulation
  tied to the *holes*. This is `feedback_failure_signal_vector_field`'s "voids ARE
  the mathematics," made into a measured subspace.

**Decisive scalar:**
```
non_gradient_mass = (‖δψ‖² + ‖h‖²) / ‖f‖²
```
The decisive question is **not** "is it nonzero?" (heterogeneous operators induce
cycles trivially) but **"does it exceed what survives the null battery of §4?"**

**Per-well rank:** localize the non-gradient subspace (δψ ⊕ h) to a neighborhood of
each target well; its dimension is the **rung rank** — James's "one or more
gradient fields required to traverse." Rank-1 ⇒ single steepest-descent reaches the
well. Rank-k ⇒ k independent directions / an ordered composition (e.g.
COMPOSE-then-DUALIZE) are required.

## 3. Hypotheses (nested: structure → rank → steering → training)

### H-R1 — Scalar-collapse falsifier (Stage 0, pure data)
*Claim:* the failure-pointer flow contains non-gradient structure that survives the
null battery.
*Metric:* `non_gradient_mass` (§2).
*Null:* operator-permutation, degree-preserving rewire, emitter-family holdout (§4).
*Kill condition:* `non_gradient_mass` not above null ⇒ the basis claim is **not
supported on this dataset**; the ladder may be scalar here. (Per §0: this kills the
basis thesis only if it holds *globally*, not for an easy sub-region.)

### H-R1b — Predictive lift (consequence, not the primary test)
*Claim:* the multi-D / non-gradient decomposition predicts next-correct-move and
solution success better than a 1-D difficulty scalar.
*Null:* the scalar matches. *Falsifier:* no lift. Demoted from v0.1's H-R1 to a
*consequence* of H-R1 — useful corroboration, but a regression contest, not the
structural test. H-R1 can pass while H-R1b is weak (structure exists but is hard to
exploit predictively) and vice versa; report both.

### H-R2 — Rung-rank measurement (Stage 0, pure data)
*Claim:* different wells have different local non-gradient rank.
*Metric:* local rank of (δψ ⊕ h) near each well — **but curl-rank and harmonic-rank
are estimated and reported separately, then summed**, never collapsed early:
```
local_non_gradient_rank_r = local_curl_rank_r + local_harmonic_rank_r
```
because they mean different things — curl = local path-dependence / operator
composition (appears in small balls); harmonic = global obstruction / a hole in
reasoning state-space (often needs enough topology to exist, so it may only appear
at larger radii or whole connected components). Collapsing them hides which one
fired.

**H-R2 LOCALIZATION FREEZE (preregistered, no post-hoc radius selection).** Local
rung-rank is computed on **fixed graph-distance balls** `B_r(w)`, `r ∈ {1,2,3}`,
around each known well `w` — the worst researcher degree of freedom is the
neighborhood, so it is frozen, not chosen. Spectral localization is deliberately
**rejected** as the primary rule for v0.2 (it adds eigenvalue-cutoff / bandwidth /
diffusion-time / normalization knobs — exactly where artifacts hide). For each `w`:
restrict the flow to the induced subgraph `f|B_r(w)`, run local Hodge decomposition,
estimate `gradient_mass_r`, `curl_mass_r`, `harmonic_mass_r`, `non_gradient_mass_r`,
`curl_rank_r`, `harmonic_rank_r`. **All three radii are reported.** A local-rank
claim is valid only if:
- `rank_r > null_rank_95th_percentile_r` (matched null), **and**
- it holds at **two adjacent radii** of {B_1, B_2, B_3}, **and**
- `non_gradient_mass_r` exceeds the matched null at both, **and**
- it survives operator-permutation controls.

*Null:* all wells rank-1, or ranks do not exceed the operator-null expectation.
*Kill condition:* rank collapses to 1 everywhere ⇒ "one or more fields" reduces to
"one"; the basis is trivial. A rank appearing at **only one radius** (or vanishing
under radius perturbation) is labeled **`UNSTABLE_LOCALIZATION`** and **cannot
support H-R2** — it is not evidence. The "two of three radii" criterion is what stops
a single lucky shell from becoming a rung claim.

### H-R3 — Cross-protocol steering prediction (Stage 1, the keystone & bridge)
*Claim:* rung rank **predicts where single-vector steering fails.** A steering
vector `v_w = mean(CORRECT) − mean(SOUNDS_GOOD_WRONG)` at v_proj is *one* direction;
rank-1 wells should be steerable by it, rank-k wells should require k independent
vectors, an ordered steering sequence, or operator-conditioned steering.
*Precondition (was v0.1 H-R2):* at v_proj on a ≤3–4B local model
(`feedback_vram_ceiling`), `CORRECT` vs `SOUNDS_GOOD_WRONG` are linearly separable
once content/length confounds are matched; chance-level probe ⇒ no well direction to
steer toward.
*Measurement:* on held-out OOD problems the base model gets wrong by sounding-good,
single-vector steering should succeed on rank-1 wells and fail on rank-k>1 wells, in
a pattern that tracks the *independently computed* Stage-0 rank.
*Nulls:* (a) random-direction steering of equal norm; (b) non-lever site;
(c) shuffled well-labels; (d) **rank does not predict single-vector failure better
than baseline features** (length, lexical rarity, base-model loss).
*Falsifier:* rank carries no predictive signal over baselines ⇒ the rank is elegant
graph analysis with no causal purchase on the model. This is the part that makes the
whole frame hard to dismiss as decoration: the *data-side geometry* (Stage 0)
forecasts a *model-side failure* (Stage 1).

### H-R4 — Gradient-enriched training transfers (Stage 2, HARD-3-GATED)
*Claim:* a tiny model trained on §1 records generalizes to held-out problems better
than the same model trained on raw answers.
*Null:* raw-answer training matches. *Falsifier:* no lift; OR lift is oracle-feature
leakage (`feedback_causal_vs_oracle_features` — step_index, steps_to_end,
is_last_step are ORACLE and banned).

## 4. The null battery (brutal by design — the field is too good at finding structure)

Any sufficiently heterogeneous operator menu induces cycles. The claim only matters
if circulation survives **all** of:

1. **Operator-label shuffle** — same graph, permuted operator/emitter labels.
2. **Endpoint permutation** — same operator counts, permuted edge endpoints.
3. **Degree-preserving rewire** — `feedback_permutation_null` on the graph.
4. **Emitter-family holdout** — recompute with one operator family removed; does the
   non-gradient mass survive its absence? (generalizes beyond the generators —
   Central Law clause; the H5-OEIS artifact guard, `project_charon_*` discipline).
5. **Synthetic no-cycle / no-void graph** — a planted-conservative control: should
   read `non_gradient_mass ≈ 0` (noise only). Failure ⇒ the decomposer hallucinates
   structure. Calibrates the false-positive floor.
6. **Synthetic planted-cycle graph** — known local circulation: should recover
   `curl_mass` at the planted cycles. Failure ⇒ the decomposer is blind to curl.
7. **Synthetic planted-hole graph** — known H¹: should recover a harmonic basis
   matching the planted hole(s). Failure ⇒ H¹ detection is broken or the graph
   construction is wrong. (Distinct from #6 — curl ≠ harmonic; both must be
   independently verified.)
8. **Operator-menu artifact graph** — same operator labels and counts as the real
   data, but randomized state topology. Whatever curl this produces **is** the
   operator-induced false-positive floor; the real claim must clear it.

**The distinction that is everything — operator-induced vs state-induced curl:**
- If measured curl **disappears** under operator-label shuffle (null 1), we learned:
  *the operator menu manufactures the apparent basis* — circularity, the H5
  artifact, and the claim dies honestly.
- If curl **survives** the shuffle, we learned: *the state landscape itself carries
  non-conservative structure* — and that is the finding.

## 5. Staging (smallest-first; HARD-3 compliance explicit)

- **Stage 0 — structure (HARD-3-OK, pure data). No model.** Run in a fixed order
  that proves the instrument before it is asked theological questions:
  - **0a — instrument controls FIRST, real data untouched.** Run the decomposer
    against §4 controls #5→#8 in order (no-cycle/no-void → planted-cycle →
    planted-hole → operator-menu artifact). The decomposer must **see nothing in
    no-structure data and recover planted structure where it exists**, and must
    surface the operator-induced false-positive floor. Milestone artifact:
    **`stage0_hodge_controls_report.json`**. Real data does not run until this passes.
  - **0b — H-R1 global, runnable today.** On the real §1 graph: does
    `non_gradient_mass` beat the §4 null battery? If H-R1 falsifies globally, stop —
    the ladder is scalar, no wells to steer.
  - **0c — H-R2 local rank, only after the localization freeze is in force** and 0a
    passes. Emit per-well curl-rank / harmonic-rank across {B_1,B_2,B_3} with the
    two-of-three-radii criterion; UNSTABLE_LOCALIZATION wells excluded. Milestone
    artifact: **`stage0_real_failure_results.json`** (never produced before 0a's
    controls report).
- **Stage 1 — probe + steer (HARD-3-OK, measurement not training):** H-R3 on an
  existing ≤3–4B local model via activation probing and inference-time steering at
  v_proj. Representation engineering / measurement, NOT training a navigator on an
  incomplete tensor — but **flag for human ratification before running** (it touches
  the model; HARD-3 caution applies).
- **Stage 2 — train (HARD-3-GATED):** H-R4. Do NOT run until the closed-loop tensor
  condition is met OR a human waiver is recorded. Never silent.

## 6. Controls & discipline (every stage)

- **Strong sounds-good baseline:** `SOUNDS_GOOD_WRONG` continuations fluent,
  high-likelihood, wrong — a real competitor, not random noise.
- **Generalization, not memorization:** held-out problems from a family/structure
  absent from training, sealed against operator-closure leakage (failure protocol
  §6.1).
- **Causal not oracle features** (`feedback_causal_vs_oracle_features`).
- **Replicate across ≥5 seeds** (`feedback_replicate_seeds`).
- **Surface vs substance:** steering must move *correctness on OOD problems*, not
  style/fluency. Report task accuracy, not perplexity.

## 7. Honest risks (this is the kind of frame that hypnotizes)

1. **Too good at finding structure.** The risk is not that Hodge is wrong — it is
   that *any* heterogeneous operator menu induces cycles. §4's null battery, and the
   operator-vs-state-curl distinction, are the entire defense. Without them this
   discovers our own menu (the H5-OEIS artifact: "voids" that were transform-density).
2. **The attractor is scale-hardened** (`project_convergence_theory`). A steering
   vector may bend 3B and fail at 70B. Report whether the bend *holds OOD*.
3. **VRAM ceiling** (`feedback_vram_ceiling`): ≤3–4B locally; a null at 3B does not
   falsify the idea at scale — state that explicitly.
4. **Steering ≠ reasoning.** OOD-generalization is the guard; perplexity/style is not.
5. **Necessary ≠ sufficient.** Non-conservativity passing does NOT establish that the
   wells are reasoning attractors — only that the ladder isn't a height map. The
   reasoning claim still rests on H-R3 + the Central Law's beyond-generators clause.

## 9. The Arachne bridge (one pipeline, not two ideas)

Arachne and reasoning-steering are the same object read at three stations:

```
Arachne crawls (failure crawler over the kill ledger)  →  emits the edge-flow f
Hodge decomposes f                                      →  non_gradient_mass, per-well rank
Reasoning-steering tests                                →  does rank predict steering failure?
```

The failure crawler (ChatGPT's crawler #4, `feedback_failure_signal_vector_field`'s
first instance `agents/_shared/mutation_registry.py`) produces exactly the typed,
provenanced, null-tested edge-flow this protocol decomposes. Arachne is the
instrument that *builds* the gradient fields; this protocol is what you *do* with
the wells once they are mapped. Provenance on every edge (§1 `emitter`) is what makes
null 4 (emitter-family holdout) possible — the two protocols share one discipline.
