# Report 93 — Brumer-Stark at LMFDB Scale

**Target agent:** Charon
**Domain:** Number fields / L-values / class groups
**Date:** 2026-04-23
**Status:** Instrument-mode design; not an oracle claim

## 1. Precise Problem

Let `K/k` be a finite abelian extension of number fields with `k` totally real and `K` a CM field (or with a distinguished complex conjugation). Let `S` be a finite set of places of `k` containing archimedean places and those ramifying in `K`. The **Stickelberger element** is

```
θ_{K/k,S}(0) = Σ_{σ ∈ Gal(K/k)} L_{K/k,S}(0, σ^{-1}) · σ  ∈  ℚ[Gal(K/k)]
```

By Deligne-Ribet / Cassou-Noguès, `θ_{K/k,S}(0) ∈ ℤ[Gal(K/k)]` under standard conditions. Let `w_K = |μ(K)|`.

**Brumer (weak):** `w_K · θ_{K/k,S}(0)` annihilates `Cl(K)`.

**Brumer-Stark (strong):** For every fractional ideal `𝔞` of `K`, the ideal `𝔞^{w_K · θ}` is principal, generated by an **anti-unit** `ε` (so `ε · ε^c = 1`) whose extension `K(ε^{1/w_K})/k` is abelian.

## 2. Literature Spine

- Brumer, A. (~1970, unpublished) — weak annihilation.
- Stark, H. (1971, 1975, 1976, 1980) — "L-functions at s=0" series, *Adv. Math.*; strong form with anti-unit and abelianness clause.
- Tate, J. (1984) — *Les conjectures de Stark sur les fonctions L d'Artin en s=0*, Birkhäuser. Canonical reference.
- Greither, C. (2007) — Fitting-ideal refinement; relates θ to `Fitt_{ℤ[G]}(Cl(K)^∨)`.
- Burns, Kurihara, Sano (2017+) — zeta elements; derivation from eTNC.
- **Dasgupta, S. and Kakde, M. (2023)** — proof of Brumer-Stark away from `p=2`, *Ann. of Math.*, via Ritter-Weiss modules and equivariant Iwasawa main conjecture.
- Dasgupta-Kakde-Silliman (2023-24) — `p=2` case; essentially complete for odd characters.

Charon must treat Brumer-Stark as **theorem** at odd primes, **conjecture/frontier** for the 2-part and Fitting-ideal refinements.

## 3. LMFDB Data Surface

~22M number fields available. Relevant slices:

- `nf_fields` filter: `galois_group` abelian and `signature[1] = 0` → totally real `k`.
- CM extensions `K/k`: LMFDB CM flag (~800K fields).
- `class_group` stored as abelian invariants.
- Ramified primes from discriminant factorization.
- **L-values at s=0:** not directly stored; compute via PARI/Magma `ArtinLfunction` or, when `k=ℚ`, exactly via generalized Bernoulli numbers `B_{1,χ}`.

First-pass target: `k = ℚ`, `K` imaginary abelian. θ reduces to the classical Stickelberger element `Σ (a/f − 1/2) σ_a^{-1}` (Iwasawa, Sinnott).

## 4. Test Design (Charon-Runnable)

**T1 — Annihilation audit:** For 50K imaginary abelian `K` with conductor `f ≤ 200`:
1. Build `θ = Σ (a/f − 1/2) σ_a^{-1}` in `ℤ[G]` after multiplying by `w_K`.
2. Load `Cl(K)` from LMFDB.
3. For each generator `c_i`, verify `c_i^{w_K θ} = 0` in `Cl(K)`.
4. Expected: 100% pass (theorem). Pipeline sanity gate.

**T2 — Fitting-ideal refinement:** Compute `Fitt_{ℤ[G]}(Cl(K)^∨)` and test whether `θ · Ann(μ_K) ⊆ Fitt` with equality away from 2. Probes Greither-Kurihara / Dasgupta-Kakde.

**T3 — Anti-unit reconstruction:** For 200 small-conductor cases, actually solve `𝔞^{wθ} = (ε)` in PARI; verify `ε ε^c = 1` and that `K(ε^{1/w})/k` is abelian.

**T4 — 2-part stress test:** Restrict to `K` with non-trivial 2-part of `Cl(K)`. Confirms Dasgupta-Kakde-Silliman.

## 5. Falsification Criteria

- T1 failure ⇒ pipeline bug (Stickelberger sign/normalization) — never the conjecture.
- T2 failure at odd `p` ⇒ almost certainly a convention mismatch; hand-check a cyclotomic example.
- T2 failure at `p=2` ⇒ scientifically interesting but must survive null battery and permutation test.
- T3 failure of abelianness of `K(ε^{1/w})` ⇒ root-of-unity branch issue; not a real counterexample.

Discipline: given theorem status, any apparent anomaly is an instrument bug until it survives full battery plus hand-verified small case.

## 6. Budget

- T1: 50K cases × ~0.2 CPU-s ≈ 3 CPU-hr (trivially parallel).
- T2: 50K × ~5 CPU-s ≈ 70 CPU-hr (one node overnight).
- T3: 200 × ~30 CPU-s ≈ 2 CPU-hr.
- T4: 5K × ~10 CPU-s ≈ 14 CPU-hr.

Total: under one CPU-day. No GPU required.

## 7. Expected Outcome

Calibration, not discovery. T1 and T4 should pass at 100%; they green-light Charon's Stickelberger/L-value pipeline for downstream work (Iwasawa main conjecture tests, Gross-Stark units, p-adic L-functions). T2 is the only channel where genuine signal could appear, most plausibly as a 2-part Fitting-ideal discrepancy on a narrow character-conductor strip. Prior probability of real novelty: low. Value if it appears: high. Value even if it doesn't: a certified Stickelberger engine Charon can reuse across reports 89–92 and the Iwasawa program.
