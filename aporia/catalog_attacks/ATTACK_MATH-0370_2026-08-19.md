## Question and test spec (from triage)
Zero-density: N(sigma,T) = #{zeros with real part beta > sigma, |gamma| < T} should satisfy
N(sigma,T) << T^{2(1-sigma)+eps}. Falsification: any excess for sigma in (1/2, 1).

## Result: VACUOUS-BY-SCHEMA (a new vacuous sub-class, distinct from 0260)
Signature-existence check: the mirror's positive_zeros entries are SCALAR REAL ORDINATES
(verified: float lists) — the storage format records only the imaginary parts of zeros ON
the critical line, because LMFDB verifies RH numerically in-range and stores accordingly.
The schema CANNOT REPRESENT an off-line zero. Therefore N(sigma,T) = 0 for all sigma > 1/2
identically, BY FORMAT — a "confirmation" that would be pure circularity.

Distinction from ATTACK_MATH-0260 (subset-absent): there the data class was missing and
ingestion cures it. Here NO ingestion cures it — upstream stores the same format, and any
archive built by RH-verifying pipelines presupposes the hypothesis its zeros would test.
CIRCULARITY-BY-FORMAT: a dataset that presupposes a hypothesis cannot test that hypothesis,
and the presupposition can live in the SCHEMA rather than the values.

## Disposition
DONE-VACUOUS (not parked — there is nothing to wait for). The density hypothesis is testable
only by instruments that compute L-values off the critical line directly (argument-principle
counts in boxes), i.e. a computation harness, and even then only as consistency checking far
inside proven Ingham/Huxley territory. Correctly a non-thread for this data era.
