## What happened

`pivot/reasoning_ladder_v01_2026-05-24.md` — a table that carries an explicit **SUPERSEDED**
banner. The canonical semantics live in `aporia/doctrine/reasoning_ladder.md` §3 (Canon v2.0,
semantics unchanged from 05-27) and differ from R2 upward.

alter a rung's kill test except by ratified amendment.* My rung notes cite Canon v2.0 while
using v0.1 numbers — a citation that does not match its content. That is precisely the fossil
pattern this loop has been writing doctrine about, committed by the loop itself, in the same
week. Recording it in full rather than quietly relabelling.
