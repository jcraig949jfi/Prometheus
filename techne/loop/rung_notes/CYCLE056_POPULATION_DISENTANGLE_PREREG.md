# Cycle 056 — PRE-REGISTRATION: is it the intervention or the population?

**Committed before selecting or opening any function.**

## The confound, found this cycle

Cycle 055 headlined:

```
P(found | INCIDENTAL reading) = 0/11        P(found | TARGETED review) = 7/8
```

`LADDER_CLAIMS_LEDGER.md:1204` records the provenance of the eleven: *"Cycles 029-041 found
eleven instances **in code written for the loop**."* **The 0/11 was measured on my own
techne code. The 7/8 was measured on ergon's production code.**

**Two variables changed at once** — intervention (incidental → targeted) *and* population (mine
→ ergon's). The cycle-055 comparison therefore cannot support *"targeted reading beats
incidental reading"*. It supports only *"targeted reading found 7 of 8 in ergon"*, which is a
standalone measurement, not a contrast.

Cycle 041's design caused this honestly: it required *"modules outside the eleven already
audited, so no item has a known answer"* — avoiding a known-answer bias and introducing a
population change in the same move.

## What this cycle measures instead

**Flag rate by role**, on one fresh mechanically-selected population spanning **every** role
including my own. If ergon is an outlier, cycle 055's 7/8 reflects **house style**, not reading
power. If roles score alike, the class is general and the population confound is benign.

## Selection rule, fixed and NOT truncated

Measure-like non-test functions (`rate|ratio|fraction|frequenc|share|density|mean|coverage`)
across `ergon, charon, harmonia, aporia, theseus, techne`. **Full enumeration — no `head`,
no cap.** Cycle 055's population was 87.5% ergon precisely because a `head -40` truncated the
traversal at the first role it reached; that error is not repeatable if nothing is truncated.

Sample **up to 4 per role** by a fixed rule (first 4 by path sort **within each role**), so
every role is represented and no role can dominate.

## Predictions, with confidence, difficulty, and the opposite reading

1. **Ergon's flag rate is NOT an extreme outlier** — it lands within the spread of other roles
   rather than above all of them. Confidence **low-to-moderate**; **OPEN**.
   *Opposite:* if ergon is highest by a clear margin, **cycle 055's 7/8 is a house-style
   measurement** and I must retract the reading-power reading of it.
2. **At least one role scores 0 flags.** Confidence **moderate**; **OPEN**.
   *Opposite:* a nonzero floor everywhere means the class is endemic to the repo, which is a
   larger finding than anything about reading.
3. **My own `techne` code flags at a rate comparable to others** (not conspicuously lower).
   Confidence **moderate**; **OPEN**. *Opposite:* if mine is lowest, the 0/11 may reflect that
   my loop code genuinely has fewer instances — which would mean incidental reading was never
   given a fair chance to find any, and the baseline is not a detection rate at all.
4. **A valid negative control exists** — at least one function whose empty-domain result is
   semantically unambiguous (raises, or returns a structurally distinct empty value like `{}`).
   Confidence **moderate-to-high**; **OPEN**. *Opposite:* if none exists across all roles, the
   ambiguity is **intrinsic to the shape** and no false-positive rate can ever be established
   this way.
5. **The overall flag rate is below cycle 055's 7/8 = 0.875.** Confidence **moderate**;
   **OPEN**. *Opposite:* matching or exceeding it would strengthen the reading result and
   weaken the house-style worry.

## Kill test

**If prediction 1's opposite fires — ergon clearly highest — I retract cycle 055's headline**
and restate it as a measurement about ergon's conventions. That retraction ships in this
cycle's report, not deferred.
