# Missing Compositions

Only strongly justified candidates. Each states whether the historical parts exist, whether the
composition was tested, and the smallest experiment that would settle it.

## C1  developmental memory + same-probe counterfactual        [HIGHEST VALUE]

    parts exist?      YES -- the S1 formalism defines both B and the mutation operator
    tested?           NO  -- no recovered source holds P* fixed and varies B by history
    information gain  HIGH. This is the difference between "history moved the population"
                      and "history modified the machine". Everything else in this programme
                      is downstream of it.
    smallest test     Evolve two lineages under different historical target sets. Select
                      genotypes whose ADULT PHENOTYPE is matched between lineages. Apply the
                      IDENTICAL mutation operator. Measure the offspring phenotype
                      distribution. Pre-register: same mean, different shape.
    kills             If the distributions are indistinguishable, K2 fires and developmental
                      memory changes only current phenotype.

## C2  developmental memory + open-ended environmental novelty  [FINDS THE CEILING]

    parts exist?      YES -- S3 supplies unseen-environment evaluation
    tested?           PARTIALLY. S3 tests unseen environments drawn from the SAME structural
                      regularity. A NEW regularity is not tested.
    information gain  HIGH, and it is the test most likely to produce a negative.
    smallest test     Train on regularity R1, evaluate on R2 orthogonal to R1, against a
                      naive-B control. Pre-register the possibility that memory is WORSE
                      than no memory.
    kills             If memory underperforms a naive map on R2, the lock-in reading is
                      established and "more evolvable" must be scoped to within-family.

## C3  developmental memory + self-modifying update rule

    parts exist?      NO. Recursion depth in the lineage is ONE; no source selects over the
                      rule that updates B.
    tested?           NO
    information gain  HIGH but the part must be BUILT, not recovered. That makes it
                      construction, not archaeology, and it should not be smuggled in as a
                      historical finding.
    smallest test     Parameterise the learning rate r as an evolvable trait; measure whether
                      it is selected upward in switching environments.

## C4  developmental memory + local offspring-cloud detector

    parts exist?      Detector is HC-T01 territory (UNVERIFIED here)
    tested?           NO
    information gain  MEDIUM -- largely a measurement instrument for C1 rather than a
                      separate question.
    note              Do not run before C1. It is the same measurement with more machinery.

## Deliberately NOT proposed

Compositions involving Kashtan/Alon or Toussaint parts are omitted, because those sources were
not recovered and a composition built on a RECALLED part would inherit the recall.
