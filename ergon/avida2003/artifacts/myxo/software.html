Avida Software and Configuration Files

Our experiments used version 1.6 of the Avida software platform, which can be downloaded free of charge here.

Here are the default configuration files we used for both the "reward-all" and "EQU-only" regimes. All that was varied from these defaults were the random number seeds; in both cases we used the values from 100 to 149. Warning: These setups will produce a lot of data, much of which is used for detailed visualization purposes. Reduce the frequency of the "detail_pop" event in the event_list configuration file to limit this extra data.
