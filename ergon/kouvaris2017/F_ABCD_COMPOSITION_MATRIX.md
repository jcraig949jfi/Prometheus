## 2. Directive §7 — does Kouvaris satisfy Herakles's statement?

Herakles's claimed missing composition, verbatim:

> a ONE-VARIATION-STEP offspring distribution inside an ON/OFF ABLATION of a variation/representation
> mechanism, related to adaptive acquisition WITHIN RUNS.

**Kouvaris 2017 satisfies no clause of it.**

- *one-variation-step offspring distribution* → it is a uniform draw over the entire genotype space,
  explicitly substituted for drift. **Absent.**
- *on/off ablation of a variation/representation mechanism* → all four arms are selection-side; the
  representation `B` changes as an evolved *response*, never as a manipulated variable. **Absent.**
- *within runs* → arm-level, on frozen endpoint architectures. **Absent.**

No hedging is required and none is offered. On the directive's §7 test the answer is a clean
negative, and the corresponding falsification questions **F2, F3 and F4 are all TRUE** (see

## 3. Why the A/A-local distinction is not implementation trivia (directive §9)

In this model the one-step neighbourhood of `G` is `{G ± δ e_i : δ ≤ 0.1}` — a perturbation of one
of sixteen coordinates. Relative to the `[−1,1]^16` cube the detector samples, that set has
vanishing measure. The two distributions are not approximations of one another in either direction:

- A map `B` can concentrate the *uniform-sample* distribution on the structural class while the
  *local* neighbourhood of the current `G` reaches nothing new, if `G` sits deep inside one basin.
- Conversely a map can have a locally rich neighbourhood while the global sample is dominated by a
  few large attractors.

Kouvaris's own results make the first case concrete rather than hypothetical: under L1 the induced
distribution converges to exactly four bits of entropy, i.e. four independent binary modules, which
means large flat basins. Deep inside such a basin, single-coordinate perturbations of 0.1 will
usually develop back to the same attractor. **The paper's detector says the map can express eight
phenotypes; it says nothing about how many of them are one mutation away from where the lineage
currently is.** That is the distinction HC-T01 exists to measure, and it is real.

## 4. Where the specimen is *stronger* than HC-T01

Recorded because the directive forbids protecting HC-T01, and because these are the axes on which a
reviewer should press.

1. **Non-tautological intervention.** No Kouvaris knob touches the variation operator, so the entire
   movement of the detector is an evolved response. HC-T01's `β` is the rate of second-type
   mutations and therefore parameterises the operator that *induces* the exploration distribution;
   Herakles's own preregistration declares this TRAP 1 LIVE and mandates a generation-zero
   mechanical-effect null. Kouvaris needs no such null because the mechanical effect is zero by
   construction.
2. **A real train/test split over environments**, defined by construction rather than by assertion:
   3 training targets inside an 8-member class generated by 4 independent binary modules. HC-T01 has
   no held-out environment set at all.
3. **Acquisition includes unreachability, not only speed.** Fig 5's censored outliers are targets the
   evolved map cannot express at any budget, and the L1 arm reaches a phenotype otherwise
   inaccessible. That distinguishes `REACHES_PREVIOUSLY_UNREACHABLE` from `ACQUIRES_FASTER`, which
   HC-T01's scalar time-to-target does not.
4. **Same-probe counterfactual by construction.** One fixed 5000-point Sobol set, used at every time
   point and in every arm, so between-arm and between-time differences cannot be probe noise. This is
   a design property HC-T01's preregistration does not currently specify.

## 5. Where the specimen — and its lineage — is *weaker*, and one finding that cuts against HC-T01

**Weaker:** no replication and no uncertainty on any longitudinal figure; the number of evolutionary
runs is never stated; three primary sources give three different values for the `B`-mutation
probability; the generality claim in S1 rests on replacing evolution with Hebb's rule.

**The finding that cuts against HC-T01.** The same author implemented a genuine `A-local` detector
and never reported it. `computeM.m` and `evalMutCorr.m`, in the recovered
*Phenotypic-Plasticity-Logical-Inference* repository, apply `mNum = 300` **single** mutations to
**each individual in a population**, develop each mutant, and compute the mutational-effect vectors
`mPhens − uPhens`, from which they derive mutational variance and pairwise mutational correlations —
the M-matrix, estimated from real one-step mutants. The mutation draws are generated once, saved to
`rand_nums.mat`, and **re-used across replicates**, which is a same-probe design applied to a *local*
detector. It loops over `replicate_N_Pop.mat` files, so it is replicated.

It is **endpoint-only** — there is no loop over generations — and it appears in **no publication**
and **zero times in 159 pages of the thesis**.

Two consequences, both against HC-T01:

- The one-step offspring detector is **not** an instrument this field lacked the capability to build.
  It was built, in this exact lineage, and left unreported. HC-T01's novelty is therefore a
  **composition and reporting** novelty, not an instrument novelty, and should stop being described
  as the latter.
- It is the second time this programme has found unreported detector code sitting beside a published
  experiment that omits it — the first being Toussaint's own `avgfit`. Two instances is a pattern
  worth naming: **in this literature the detector is usually built and usually not reported.** That
  materially weakens any argument of the form "nobody measured X", because absence from the
  literature is now known to be weak evidence about absence from the work.

So after this pass HC-T01's residual novelty is not "nobody has composed these". It is narrower and
should be stated as such: **nobody has run a quantified, replicated, one-step offspring detector

preregistered mechanical-effect null separating the definitional part of the arm difference from the
