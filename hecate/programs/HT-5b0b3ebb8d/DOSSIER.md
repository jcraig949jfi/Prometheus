## RAW INTERPRETATIONS
- [spec] I1: Counterexample as surprise: the model checker's counterexample (or a world trace that contradicts the verified model) is the surprising fact that triggers abduction; the abduced object is a minimal model repair; a repair becomes knowledge only when it survives re-verification plus fresh traces. Experiment: repair loops on hidden automata, measuring trace-efficiency and brittleness of repairs.
- [spec] I2: Knowledge as a model-checkable modal property: the agent's epistemic state is a finite set of candidate models (epistemic alternatives); 'the agent knows phi' is literally 'phi holds in every remaining candidate', decided by model checking; abduction is the operator that removes and adds candidates. Experiment: track the frontier of known formulas as evidence accumulates and test for discontinuous jumps and false-knowledge events.
- [spec] I3: Explanatory virtue as verification cost: the virtue that abduction should maximize is not description length but the cost of exhaustively checking the explanation; cheap-to-verify explanations are preferred because only they can be justified by the agent's bounded checker. Experiment: pit a verification-cost prior against an MDL prior where the two disagree (short programs with huge reachable state spaces).
- [spec] I4: Three justification topologies as three state-space regimes: foundationalism = acyclic support graph with axioms, coherentism = greatest consistent fixed point of mutually constraining models, reliabilism = temporal property over the history of a belief-forming process. Experiment: insert abductive hypotheses into each topology and measure retraction avalanches and consistency maintenance cost.
- [spec] I5: Safety/liveness epistemic asymmetry: from finite evidence, safety claims are refutable but never finitely verified by traces alone, liveness claims are neither finitely refutable nor verifiable; abduction of a model is what lets an agent come to 'know' liveness, so liveness knowledge is structurally more abduction-dependent and more fragile. Experiment: compare false-knowledge rates for safety vs liveness formulas under matched base rates.
- [spec] I6: Spec-relevant abstraction as justified granularity: an agent that abduces an abstraction only as fine as a specification requires (CEGAR-style) holds beliefs at the coarsest granularity that justifies its decisions; distinctions the spec does not need are never believed. Experiment: compare spec-triggered splitting with prediction-error splitting and measure whether the learned partition aligns with the spec-relevant quotient.
- [spec] I7: Gettier cases as unrealized witnesses: a belief can be true and model-checked (justified) while its witness path does not exist in the real system; this is a checkable, mechanical definition of epistemic luck. Experiment: flag beliefs whose certificate path was never observed and test whether they fail more under mechanism shifts.

## CANDIDATE PHYSICS
- [spec] M1 (error-correction mechanism): Counterexample-guided abductive repair: an agent holds a finite automaton model plus a fixed spec; whenever a world trace contradicts the model, it abduces the minimal edit (add state / redirect transition / flip label) that explains the trace AND keeps the spec satisfied; edits are provisional until they survive k fresh traces.
- [spec] M2 (learning pressure): Verification-cost prior: explanations are ranked by the number of reachable states the agent must explore to check them against its spec battery, not by description length; the agent prefers explanations it can afford to justify.
- [spec] M3 (representation): Epistemic frontier by exhaustive checking: the belief state is a finite set of candidate models; knowledge of phi is computed by model checking phi in every candidate; abduction adds candidates on surprise, evidence removes them; the agent acts only on known formulas.
- [spec] M4 (memory structure): Certificate-chained justification: each accepted belief stores the model-checking certificate (witness or invariant) that justified it and the abductions that model depended on; retracting an abduction recursively invalidates all beliefs whose certificates depended on it.
- [spec] M5 (dynamical law): Coherence fixed point under abductive insertion: beliefs are mutually constraining small models; after each abductive insertion the checker recomputes the greatest mutually consistent subset; the system exhibits retraction avalanches whose size distribution depends on how tightly models constrain each other.
- [spec] M6 (selection mechanism): Reliabilist process selection: a population of abductive procedures (minimal-edit, merge-states, most-recent-reuse, random-consistent) each proposes models; a procedure's weight is the fraction of its past proposals that later passed model checks on held-out traces; beliefs are held with the weight of the process that produced them, not the evidence for the belief.
- [spec] M7 (causal constraint): Spec abduction with asymmetric credence: the agent abduces temporal-logic properties of the world from finite traces; safety-type hypotheses are refutable by a finite trace, liveness-type are not; the agent assigns structurally lower ceiling credence to abduced liveness properties unless they are entailed by an abduced model.
- [spec] M8 (information bottleneck): Horizon-tagged belief: the checker runs with depth bound k; every belief carries its horizon tag and the agent must represent 'unknown beyond k' separately from 'true'; abduction is only allowed to fill in beyond-horizon structure when a spec forces it.
- [spec] M9 (learning pressure): Spec-disagreement exploration: the agent chooses actions that maximize disagreement among candidate models about whether the SPEC holds (not about next-state predictions), so exploration concentrates where verification verdicts are uncertain.
- [spec] M10 (developmental process): Spec-driven abstraction growth: the agent starts with a one-state abstraction of the world and splits abstract states only when a counterexample to the spec turns out spurious on real traces; the belief partition therefore grows only as fine as the spec requires.
- [spec] M11 (error-correction mechanism): Witness grounding (mechanical Gettier detection): a belief phi is flagged as lucky if it is true in the world and verified in the agent's model but its certificate (witness path) has never been realized in observed traces; lucky beliefs are held at reduced strength and prioritized for testing.
- [spec] M12 (representation): Bisimulation-quotient epistemics: hypotheses that are bisimilar with respect to observable labels are identified; abduction operates on quotient classes; the agent never distinguishes observationally equivalent explanations and cannot represent a preference between them.
- [spec] M13 (interaction law): Skeptic-believer game: a skeptic searches (by model checking over candidate structures) for a counter-model consistent with all evidence in which the believer's claim fails; the believer answers by abducing a discriminating experiment; a claim becomes knowledge when the skeptic's bounded search is exhausted.
- [spec] M14 (mutation operator): Abductive directed mutation under a verifier guard: an evolving population of candidate automata mutates by abducing a minimal edit that fixes one misclassified example, and offspring that violate a known spec are killed before selection.
- [spec] M15 (memory structure): Obligation memory: memory stores open temporal obligations (pending 'until' and 'eventually' formulas implied by current beliefs) instead of facts; a belief is demoted when an obligation it created expires unmet and promoted when obligations are discharged.
- [spec] M16 (learning pressure): Loveliness as checkable scope: an explanation's loveliness is the number of spec formulas it makes decidable within the checker's budget; the agent prefers lovely explanations over merely likely ones and the question is whether loveliness predicts future survival beyond likelihood.
- [spec] M17 (world rule): Surprise tax: in a world where every unexplained observation costs the agent, and every model-checking step also costs, the agent must trade abductive repair against verification; the rule predicts an interior optimum of checking effort per repair that shifts with world stochasticity.
