## RAW INTERPRETATIONS
- [spec] I1: Adaptation is constraint repair rather than gradient descent: every closed-loop observation becomes a clause over a discretised model/controller space, the adapting agent maintains a satisfiable clause set, and when the plant changes the set turns UNSAT; the MUS localises which past observations conflict with the new regime, so forgetting is targeted to the conflict instead of uniform in time. Experiment: switching plant, core-guided forgetting vs time-based forgetting.
- [spec] I2: Adaptation should be functorial: if controllers for subsystems compose into a controller for the whole, the adaptation operator should commute with composition (adapt(g o f) = adapt(g) o adapt(f)); SAT enforces the interface constraints. Experiment: adapt modules separately, recompose, and test whether the composite works without retuning vs non-functorial adaptation.
- [spec] I3: The SAT solver is itself the plant: its noise/restart parameters are control inputs, its unsat-clause trajectory is the output, and the random-SAT phase transition is a plant nonlinearity; an adaptive controller should be equivariant under instance isomorphisms (renaming), a categorical requirement. Experiment: MRAC on local-search noise near alpha ~ 4.2.
- [spec] I4: Persistent excitation is a Yoneda question: an unknown plant among a finite category of candidates is determined by its responses to probes, and the agent should choose probes forming a separating family, found by SAT as a hitting-set problem. Experiment: probes needed to identify the plant with SAT-chosen separating probes vs random excitation.
- [spec] I5: The adaptation target is a universal object rather than a point estimate: act only with controls valid in the limit (intersection) of all models still consistent with data; when that intersection is empty (UNSAT) the MUS names the models in conflict and drives targeted probing (dual control). Experiment: forbidden-state entries of limit-seeking vs certainty-equivalence control.
- [spec] I6: There is a phase transition of adaptability: as specifications per adjustable parameter rise, the closed-loop spec set passes from almost-always-repairable to almost-never-repairable, with adaptation time and MUS size peaking at the threshold. Experiment: sweep spec density, measure adaptation time and core size.
- [spec] I7: Regime changes are natural transformations: a regime maps a task category to behaviours; a regime shift is a family of components, one per task, tied by naturality squares; encoding squares as clauses lets an agent that re-adapted on a few tasks propagate the adaptation to unseen tasks. Experiment: accuracy of propagated components on unseen objects vs independent per-task adaptation.
