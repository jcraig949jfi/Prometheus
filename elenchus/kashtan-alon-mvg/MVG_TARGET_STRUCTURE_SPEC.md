# MVG TARGET STRUCTURE SPEC -- what "modularly varying" actually means

The phrase carries more hidden structure than any other term in this lineage. Resolved
below against the retrieved primary text, question by question as issued.

================================================================================
THE NINE QUESTIONS
================================================================================

1. WHAT MAKES TWO GOALS MODULARLY RELATED?
   They are instances of a fixed composition scheme with the same slots, differing in
   which operator occupies a slot. Verbatim (2008): goals within MVG language "are of the
   form u(x,y,w,z) = f(g(x,y), h(w,z))". Two goals are modularly related when both parse
   under this template. 2007 states the same idea generally: "each new goal shares some
   of the subgoals with the previous goal".

2. WHICH SUBPROBLEMS ARE SHARED?
   In the canonical circuit pair, the two XOR subfunctions g and h are shared and held
   fixed; only the combining function f changes between AND and OR.
     G1 = (x XOR y) OR  (w XOR z)
     G2 = (x XOR y) AND (w XOR z)
   In 2007 model 1 the sharing is at a higher arity: G = F(M1,M2,M3) with M_i in
   {XOR, EQ}, and "the varying goal changed ... by applying changes to F". The MODULES
   ARE HELD CONSTANT AND THE WIRING IS VARIED. That is the invariant of the whole
   programme.
   In the RNA model the shared objects are structural: hairpin loops and open loops, and
   MVG is applied "by modifications of single hairpin at a time".

3. WHAT IS CHANGED BETWEEN ENVIRONMENTS?
   One slot filler, usually the top-level combining function. In the 2005 six-input
   family, one of three subgoal couplings at a time (OR moves through the three slots,
   ending at the all-AND goal G4).

4. WHAT IS INVARIANT?
   The decomposition itself: arity, the number of modules, the input partition
   ({x,y} vs {w,z}), and the identity of the sub-functions. The experimenter fixes the
   input partition, which is the single most load-bearing act of authorship in the
   design. Nothing in the environment ever asks the system to discover a DIFFERENT
   partition of the inputs.

5. IS THE FUTURE TARGET CONSTRUCTED FROM THE SAME SUBPROBLEMS?
   In the historical tests, mostly yes, with one partial exception the paper is careful
   about. Two novel classes were defined (2008), verbatim:
     "(a) New-comb is a goal that presents previously seen subgoals but in a new
      combination"
     "(b) Novel-module refers to goals where one of the subgoals is a previously unseen
      one, while the other subgoals are kept unchanged"
   Novel-module goals DO introduce content never seen -- "a novel goal is generated by
   replacing a XOR module by a previously unseen 2-input Boolean function, such as AND or
   NOR". So the module CONTENT can be new. The SLOT STRUCTURE never is.

6. DOES THE EXPERIMENTER KNOW THE LATENT DECOMPOSITION?
   Completely. The experimenter writes it. The decomposition is not merely known, it is
   the generative device from which every goal in every condition is drawn, and it is
   also the object against which the modularity metric is later scored -- the module
   assignment used for the intra-module vs inter-module analysis corresponds to the same
   partition. This is the tightest form of the authored-curriculum concern: the analysis
   basis and the environment generator share an author.

7. DOES THE EVOLVING SYSTEM RECEIVE ANY EXPLICIT MODULARITY REWARD?
   No, and this is a genuine strength that must not be diluted. Fitness is defined purely
   as agreement with the goal truth table (circuits) or structural distance (RNA). The
   only structural term anywhere is a GATE-COUNT penalty, which pushes toward parsimony,
   not toward modularity. Q_m is never in the objective. Modularity is emergent under
   selection for function alone.

8. IS MODULARITY ENTIRELY EMERGENT?
   Emergent in the genotype; authored in the environment. The organism is never told to
   be modular. It is told, repeatedly, to solve problems that were built modularly by
   someone else. The correct description is: the environment carries the modularity and
   the genome comes to mirror it. Whether mirroring counts as discovery is the question
   AUTHORED_CURRICULUM_ANALYSIS.md exists to adjudicate.

9. HOW MUCH OF THE FUTURE TARGET IS ALREADY IMPLICIT IN THE HISTORICAL GOAL FAMILY?
   Quantifiably almost all of it, and the paper measured the boundary itself. Within the
   language, MVG wins. Outside it, verbatim:
     "We find that MVG's outperformance occurred only toward goals within the modularity
      language. MVG adaptation toward non-modular goals was not significantly different
      from FG's (Figure 6E)."
   The size of the authored family, for the canonical circuit case: g and h each drawn
   from {XOR, EQ} and f from {AND, OR}, so the language contains 2 x 2 x 2 = 8 goals
   (the paper reports "all six Boolean goals studied", so the studied subset is 6). The
   test space of "novel" targets is a handful of substitutions inside a template with
   three slots. The comparison space -- randomly generated 4-input 1-output truth tables
   -- has 2^16 = 65,536 members. The authored family is on the order of 1e-4 of the
   phenotype space, and it is the only region where the effect exists.

================================================================================
THE DECOMPOSITION LADDER (what is authored at which level)
================================================================================

  level                         authored by experimenter?   varied across environments?
  ---------------------------   -------------------------   --------------------------
  arity / input partition       YES, fixed for all runs      never
  number of modules             YES                          never
  slot topology f(g(.),h(.))    YES                          never
  identity of sub-functions     YES, drawn from {XOR,EQ}     rarely (novel-module only)
  combining function f          YES, drawn from {AND,OR}     YES -- this is "the varying"
  circuit wiring realising it   NO -- evolved                n/a
  which gates form a module     NO -- emergent               n/a

Read down the "authored" column. Everything structural is authored; what evolution
supplies is the IMPLEMENTATION of a fixed scheme and, critically, an implementation whose
mutational neighbourhood happens to be organised along the authored seams.

================================================================================
THE HONEST STATEMENT OF WHAT WAS DISCOVERED
================================================================================

Do not say the system discovered modularity. Say this instead, which is stronger because
it survives the objection:

  Under selection for FUNCTION ALONE, with no structural term in the objective, a
  population exposed to a sequence of goals sharing a fixed decomposition came to encode
  that decomposition in its genotype-phenotype map, such that single mutations act within
  the authored module boundaries and rarely across them, and such that the phenotypes one
  mutation away are disproportionately the other goals of the authored family.

That sentence is fully supported by the retrieved evidence. Every word of it that sounds
like discovery is doing real work, and the phrase "the authored family" is the boundary
condition that the rest of this deep-dive is about.
