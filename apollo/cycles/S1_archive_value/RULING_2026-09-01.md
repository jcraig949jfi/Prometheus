## The Source Viability Gate (built: `apollo/serendipity/source_viability_gate.py`)
Absolute calibration BEFORE relative comparison — because a random-derived tau cannot
detect the pathology where random itself is a meaningless floor (S1's exact failure). Four
gates, all must PASS, machine-enforced (s1_campaign refuses the scored phase without a PASS
artifact for the engine+release):
  G1 FRONTIER DEPTH   >= 3 distinct NONTRIVIAL operation types reach an absolute functional
                      threshold (several distinct OPERATIONS, not reparameterizations of one
                      trivial op).
  G2 POPULATION MASS  a passing task has >= 3 distinct organisms at/above threshold (not one
                      lucky champion).
  G3 HEADROOM         ladder best-fitness spans a range and is neither all-floor nor
                      all-ceiling (enrichment statistic not saturated).
  G4 NEGATIVE DISCRIM the dead/random control stays BELOW threshold on depth and mass.

## Q2 — the LAST admissible move if the new release is still thin
A partial-credit / behavioural endpoint is admissible ONLY if the partial coordinate z has
INDEPENDENTLY demonstrated downstream meaning BEFORE MAP-Elites is tested against it:
  - increasing z predicts improved held-out task performance;
  - intervention/ablation on the structure responsible for z changes that performance;
  - the relationship survives across seeds/worlds;
  - dead/random worlds do NOT produce the same apparent signal.
This is **one substrate-semantic validation, not one Apollo endpoint rescue.** Without that
precursor, do not weaken "useful" — that resurrects decorative ecology (the dead world
already proved diversity can exist while task value is absent).

## Q4 — mechanical retirement flip
Flip toward ONE actual S1 run only if the new Foundry demonstrates ALL THREE:
  1. Nontrivial reachability — several DISTINCT operations reliably attainable at feasible
     budget (not parameterizations of one trivial op);
  2. Population-level material — enough useful organisms that transfer rate is
     statistically meaningful (one champion per world is insufficient);
  3. Nondegenerate held-out discrimination — cross-world evaluation separates useful
     structure from junk before MAP-Elites/random labels are revealed.
If all hold: keep the frozen prereg, freeze, run S1 exactly ONCE (enrichment < 2x =>
RETIRE; >= 2x => continuation earned). If not: **retire scheduled mining; preserve the
infrastructure as on-demand measurement capability.** That is the intended architectural
outcome when selection pressure cannot demonstrate economic value — not "Apollo failed."
